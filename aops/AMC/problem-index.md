> Note: the **2021 Fall AMC 12B** answer key is present (`EBCECCDDBECBEBEBAAEAACACC`) but its problems were never added in community format, so 2021 Fall is **not** part of the 250. Add its community PDF later if you want an 11th set.

> ⚠️ **Answer keys are not infallible.** The downloaded AoPS-Wiki key PDFs had several transcription errors, all verified by hand and corrected in the Ans columns below:
> - 2023 #16 and #23 — both verified to be **11**.
> - 2020 #17 — key said C; verified **A (0)**: roots are closed under ×ω (primitive cube root of unity), so non-zero roots come in orbits of 3; with const term 2020≠0 the degree must be divisible by 3, but it is 5 → no valid polynomial.
> - 2021 Spring #21 — key said D; verified **E**: $x=\sqrt2$ is an exact root and the second root $\approx 8.94$, so $S\approx 10.35\ge 6$.
>
> When a solver's worked answer disagrees with the key, re-derive by hand before trusting the key.
