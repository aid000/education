Chapter 1 — Exponents and Logarithms

Exponents are shorthand for repeated multiplication, just as multiplication is shorthand for repeated addition. Master a handful of rules — all of which we'll derive — and everything from radicals to logarithms follows.

1.1 Integer Exponents

In $a^n$, the number $a$ is the base and $n$ is the exponent (or power). The core rules come straight from counting how many copies of the base you have:

Laws of Exponents $$a^m \cdot a^n = a^{m+n} \qquad \frac{a^m}{a^n} = a^{m-n} \qquad (a^m)^n = a^{mn}$$ $$a^{-n} = \frac{1}{a^n} \qquad a^0 = 1 \;\; (a \neq 0)$$

Why? $2^5 \cdot 2^6$ is just the product of five 2's times six 2's — eleven 2's in all, so $2^{11}$. Division cancels: $a^0 = a^{n-n} = a^n/a^n = 1$.

$0^0$ is undefined (you'd need $0$ in a denominator to derive it), and $0$ to any negative power is undefined too. The exponent laws only apply when the bases match.
📝 Example — the two faces of a "stacked" exponent

$2^{3^4}$ and $(2^3)^4$ are not the same. In $2^{3^4}$ the exponent itself is raised: $3^4 = 81$, so $2^{3^4} = 2^{81}$. But $(2^3)^4 = 2^{3\cdot 4} = 2^{12}$.

📝 Example — distribute carefully

The 5 divides every term of a sum, but only one factor of a product:

$$\frac{5^5 + 5^2}{5} = 5^4 + 5 \qquad\text{but}\qquad \frac{5^5 \cdot 5^2}{5} = 5^6$$

Same trap as $\dfrac{3+x}{3}$ (not reducible) versus $\dfrac{3x}{3} = x$.

1.2 Fractional Exponents

If the rules hold for fractions too, then $25^{1/2}$ must satisfy $(25^{1/2})^2 = 25^1 = 25$ — so $25^{1/2} = \sqrt{25} = 5$. The exponent $1/n$ is the $n$-th root:

Roots as exponents $$a^{1/n} = \sqrt[n]{a} \qquad a^{m/n} = \left(\sqrt[n]{a}\right)^m = \sqrt[n]{a^m}$$

Take the root first, then the power: $8^{2/3} = (8^{1/3})^2 = 2^2 = 4$. Likewise $8^{5/3} = (8^{1/3})^5 = 2^5 = 32$.

$\sqrt{25} = 5$ only (the radical sign means the positive root), but $x^2 = 25$ has two solutions $x = \pm 5$. Rule of thumb: if the radical/fractional power was already in the problem, give only the positive root; if you introduced it, keep all roots.
📝 Example — $(-1)^{1/2}$ vs $-1^{1/2}$

$(-1)^{1/2} = \sqrt{-1}$ has no real value, while $-1^{1/2} = -\sqrt{1} = -1$. The parentheses change everything.

1.3 Simplifying Radical Expressions

Pull every perfect-power factor out of the radical. The reliable method: write the prime factorization, apply the root to each factor, and extract integer exponents.

Worked: $\sqrt{1440}$ $$\sqrt{1440} = \sqrt{2^5 \cdot 3^2 \cdot 5} = 2^{5/2}\,3^{2/2}\,5^{1/2} = (2^2\sqrt 2)(3)(\sqrt 5) = 12\sqrt{10}$$

By inspection it's faster: $1440 = 144 \cdot 10$, and $144$ is a perfect square, so $\sqrt{1440} = 12\sqrt{10}$. Similarly $\sqrt 8 = 2\sqrt 2$ and $\sqrt{96} = \sqrt{16 \cdot 6} = 4\sqrt 6$.

Reduce fractional exponents before extracting, or you'll miss simplifications. $\sqrt[4]{9} = (3^2)^{1/4} = 3^{1/2} = \sqrt 3$ — if you don't reduce $2/4$, you might wrongly call it irreducible.

1.4 Rationalizing Denominators

Multiplying top and bottom by the same value doesn't change a fraction (it's multiplying by 1) — use it to clear roots from the denominator.

Single root $$\frac{1}{\sqrt 2} = \frac{1}{\sqrt 2}\cdot\frac{\sqrt 2}{\sqrt 2} = \frac{\sqrt 2}{2}$$

For a two-term denominator, multiply by its conjugate radical (flip the middle sign). The cross terms cancel:

Conjugate radical $$\left(a\sqrt b + c\sqrt d\right)\left(a\sqrt b - c\sqrt d\right) = a^2 b - c^2 d \quad\text{(rational!)}$$ $$\frac{1}{1+\sqrt 2} = \frac{1-\sqrt 2}{(1+\sqrt 2)(1-\sqrt 2)} = \frac{1-\sqrt 2}{-1} = \sqrt 2 - 1$$
📝 Example — a three-term denominator

Group $5 - \sqrt 2 - \sqrt 3 = (5-\sqrt 2) - \sqrt 3$ and multiply by $(5-\sqrt 2)+\sqrt 3$ to knock out one radical at a time. Two passes, but each is just the conjugate trick.

1.5 Logarithms

$\log_b x$ is simply the power you raise $b$ to in order to get $x$. Since $2^3 = 8$, we have $\log_2 8 = 3$. A logarithm is just an exponential equation written the other way around.

Definition $$\log_b x = y \quad\Longleftrightarrow\quad b^y = x$$

The fastest way to evaluate is to set it equal to $x$ and convert: "What is $\log_7 343$?" → $7^x = 343 = 7^3$ → $x = 3$.

The base and argument must be positive for a real result — $\log_3(-3)$ is impossible since no power of a positive number is negative. The result can be negative: $\log_2 0.5 = -1$. A bare $\log$ usually means base 10.
📝 Example — $\log_3\frac{1}{243}$ and $\log_8 2$

$3^x = \tfrac{1}{243} = 3^{-5} \Rightarrow x = -5$.   For $\log_8 2$: $8^x = 2 \Rightarrow 2^{3x} = 2^1 \Rightarrow x = \tfrac{1}{3}$.

✏️ Exercise 1-9 — find each value

$\log_5 625$,   $\log_{1/2} 2$,   $\log_9 \sqrt 3$,   $\log_{\sqrt 5}\sqrt 5$.

💡 Big Picture — why logarithms were invented John Napier (early 1600s) built logarithms as a multiplication trick: since $\log MN = \log M + \log N$, you could multiply huge numbers by adding their logs from a table. That's exactly how slide rules work. Logs also turn powers into multiplication ($\log x^2 = 2\log x$) — the basis of log-scale graph paper.
Logarithms compress quantities spanning many orders of magnitude. Decibels ($\mathrm{dB} = 10\log_{10}$ of a power ratio), the Richter scale, pH, and stellar magnitude are all logarithmic. In statistical mechanics, entropy $S = k_B \ln \Omega$ is the log of the number of microstates — turning an astronomically large count into a manageable additive quantity.

2024 AMC 12BProblem 8 logarithms

What value of $x$ satisfies $\dfrac{\log_2 x \,\cdot\, \log_3 x}{\log_2 x + \log_3 x} = 2$?

$\textbf{(A)}\ 25 \quad \textbf{(B)}\ 32 \quad \textbf{(C)}\ 36 \quad \textbf{(D)}\ 42 \quad \textbf{(E)}\ 48$

Worked solution

Divide numerator and denominator by $\log_2 x \cdot \log_3 x$:

$$\frac{\log_2 x \cdot \log_3 x}{\log_2 x + \log_3 x} = \frac{1}{\dfrac{1}{\log_3 x} + \dfrac{1}{\log_2 x}} = \frac{1}{\log_x 3 + \log_x 2}.$$

Since $\log_x 3 + \log_x 2 = \log_x 6 = \dfrac{1}{\log_6 x}$, the whole expression equals $\log_6 x$. So $\log_6 x = 2 \Rightarrow x = 6^2 = 36$.

Answer: (C) 36

2022 AMC 12BProblem 16 logs · exponents

Suppose $x$ and $y$ are positive real numbers such that $x^{y} = 2^{64}$ and $(\log_2 x)^{\log_2 y} = 2^{7}$. What is the greatest possible value of $\log_2 y$?

$\textbf{(A)}\ 3 \quad \textbf{(B)}\ 4 \quad \textbf{(C)}\ 3+\sqrt 2 \quad \textbf{(D)}\ 4+\sqrt 3 \quad \textbf{(E)}\ 7$

Worked solution

Let $a = \log_2 x$ and $b = \log_2 y$, so $y = 2^{b}$. Taking $\log_2$ of $x^{y} = 2^{64}$:

$$y \log_2 x = 64 \;\Rightarrow\; 2^{b}\, a = 2^{6} \;\Rightarrow\; a = 2^{\,6-b}.$$

Taking $\log_2$ of $(\log_2 x)^{\log_2 y} = 2^7$ gives $b \log_2 a = 7$. Substitute $\log_2 a = 6-b$:

$$b(6-b) = 7 \;\Rightarrow\; b^2 - 6b + 7 = 0 \;\Rightarrow\; b = 3 \pm \sqrt 2.$$

The greatest value is $3+\sqrt 2$.

Chapter 2 — Complex Numbers

The whole subject begins by daring to ask a "forbidden" question: what is $\sqrt{-1}$? Accepting one new number, $i$, lets us solve every polynomial equation — and the arithmetic that follows is just the algebra you already know, with one extra rule.

2.1 The Square Root of $-1$

The equation $x^2 + 1 = 0$ has no real solution, because the square of any real number is non-negative. To solve it anyway, we invent a number whose square is $-1$ and call it $i$:

Definition of $i$ $$i = \sqrt{-1} \qquad\Longleftrightarrow\qquad i^2 = -1$$

A real multiple of $i$ — like $2i$ or $\sqrt 2\,i$ — is a pure imaginary number. Don't let the name "imaginary" fool you: $i$ is no less legitimate than a negative number, just newer to you.

Now watch what happens as we keep multiplying by $i$. Each power is built from the one before, and we collapse $i^2$ to $-1$ every time it appears:

Powers of $i$ cycle with period 4 $$i^1 = i,\quad i^2 = -1,\quad i^3 = i\cdot i^2 = -i,\quad i^4 = (i^2)^2 = 1$$ $$i^5 = i,\quad i^6 = -1,\quad i^7 = -i,\quad i^8 = 1,\ \dots$$

Because $i^4 = 1$, the values repeat every four steps: $i,\,-1,\,-i,\,1,\,i,\,-1,\dots$ To evaluate any power, just reduce the exponent modulo 4. For example $i^{17} = i^{16}\cdot i = (i^4)^4\cdot i = 1\cdot i = i$.

You cannot merge the radicals: $\sqrt{-1}\cdot\sqrt{-1} = i\cdot i = -1$, but writing $\sqrt{(-1)(-1)} = \sqrt{1} = 1$ gives the wrong answer. The rule $\sqrt a\sqrt b = \sqrt{ab}$ only holds for non-negative $a,b$.
📝 Example — high powers of $i$

$i^{69}$: divide $69$ by $4$ to get remainder $1$, so $i^{69} = i^1 = i$.   $i^{1972}$: since $1972 = 4\cdot 493$, the remainder is $0$, so $i^{1972} = i^0 = 1$.

2.2 Complex Numbers and Addition

A complex number is the sum of a real and a pure imaginary part, written $z = a + bi$ with $a,b$ real. Every real number is complex (its imaginary part is $0$), and numbers with $b \neq 0$ are called imaginary. Complex variables are usually named $z$ or $w$, since $x$ and $y$ are reserved for reals.

To add (or subtract) two complex numbers, combine the real parts and the imaginary parts separately — exactly like collecting like terms:

Addition $$(a + bi) + (c + di) = (a + c) + (b + d)i$$

This works because $i$ behaves like any algebraic symbol: $bi + di = (b+d)i$ by the distributive law.

📝 Example — adding two complex numbers

Add $3 + 4i$ to $-3 + 8i$: the real parts give $3 + (-3) = 0$ and the imaginary parts give $4i + 8i = 12i$, so the sum is $0 + 12i = 12i$.

2.3 Multiplication

Multiply two complex numbers by the distributive law (FOIL), then replace $i^2$ with $-1$:

Multiplication $$(a + bi)(c + di) = ac + adi + bci + bd\,i^2 = (ac - bd) + (ad + bc)i$$

The term $bd\,i^2$ becomes $-bd$ — that single sign flip is the only thing separating complex multiplication from ordinary polynomial multiplication.

📝 Example — multiply $3 + 4i$ by $-3 + 8i$
$$(3 + 4i)(-3 + 8i) = (3)(-3) + (3)(8i) + (4i)(-3) + (4i)(8i)$$ $$= -9 + 24i - 12i + 32i^2 = -9 - 32 + 12i = -41 + 12i.$$

The $-32$ comes from $32i^2 = 32(-1)$ — the classic place the sign sneaks in.

Don't forget $i^2 = -1$ when you reach the last term. Treating $i^2$ as $+1$ (or leaving it as $i^2$) is the single most common complex-arithmetic mistake.

2.4 Conjugates and Division

The conjugate of $z = a + bi$ is $\bar z = a - bi$ — same number with the imaginary part negated. We call $a$ the real part $\operatorname{Re}(z)$, and $b$ the imaginary part $\operatorname{Im}(z)$.

$\operatorname{Im}(z)$ is the real coefficient $b$, not $bi$. So $\operatorname{Im}(a + bi) = b$, never $bi$.

Conjugates matter because the product of $z$ and $\bar z$ is always a real number — the imaginary cross-terms cancel:

$z\bar z$ is real $$(a + bi)(a - bi) = a^2 - (bi)^2 = a^2 + b^2$$

This is exactly the conjugate-radical trick from Chapter 1: multiplying by the conjugate clears the "root" — here, the $i$ — from a denominator. To divide, multiply top and bottom by the conjugate of the denominator:

Division $$\frac{a + bi}{c + di} = \frac{a + bi}{c + di}\cdot\frac{c - di}{c - di} = \frac{(ac + bd) + (bc - ad)i}{c^2 + d^2}$$
📝 Example — divide $3 + 4i$ by $-3 + 8i$

Multiply numerator and denominator by the conjugate $-3 - 8i$. The denominator becomes $(-3)^2 + 8^2 = 9 + 64 = 73$, and the numerator is

$$(3 + 4i)(-3 - 8i) = -9 - 24i - 12i - 32i^2 = (-9 + 32) + (-24 - 12)i = 23 - 36i.$$ $$\frac{3 + 4i}{-3 + 8i} = \frac{23 - 36i}{73} = \frac{23}{73} - \frac{36}{73}i.$$

2.5 Magnitude (Modulus)

Plot $z = a + bi$ as the point $(a, b)$ in the plane. Its distance from the origin is the magnitude (or modulus) $|z|$ — by the Pythagorean theorem,

Magnitude $$|z| = \sqrt{a^2 + b^2} = \sqrt{z\bar z}$$

The link $|z|^2 = z\bar z$ is precisely why $z\bar z = a^2 + b^2$ came out real and non-negative in §2.4. For example $|3 + 4i| = \sqrt{9 + 16} = \sqrt{25} = 5$.

📝 Example — magnitude of a conjugate

Since $\bar z = a - bi$, we have $|\bar z| = \sqrt{a^2 + (-b)^2} = \sqrt{a^2 + b^2} = |z|$. A number and its conjugate are mirror images across the real axis, so they sit the same distance from the origin.

💡 Big Picture — why we needed complex numbers Complex numbers were forced on mathematicians not by $x^2 = -1$ (which one could just call unsolvable), but by the cubic formula of the 1500s: it produced real answers only by passing through square roots of negatives along the way. Accepting $i$ then paid off enormously — the Fundamental Theorem of Algebra says every degree-$n$ polynomial has exactly $n$ complex roots. By adding one number, every equation becomes solvable.
Complex numbers run modern physics and engineering. In AC circuit analysis a voltage or current is written as a phasor $z = |z|e^{i\theta}$, turning differential equations into algebra: the magnitude $|z|$ is the amplitude and the angle is the phase. In quantum mechanics the wavefunction $\psi$ is complex, and the probability of finding a particle is $|\psi|^2 = \psi\bar\psi$ — the same $z\bar z$ that gave us a real, non-negative magnitude here. In wave mechanics, writing waves as $e^{i(kx - \omega t)}$ packages amplitude and phase into a single rotating point in the complex plane.

2008 AMC 12BProblem 19 complex function, minimize |α|+|γ|

A function $f$ is defined by $f(z) = (4+i)z^2 + \alpha z + \gamma$ for all complex numbers $z$, where $\alpha$ and $\gamma$ are complex numbers and $i^2 = -1$. Suppose that $f(1)$ and $f(i)$ are both real. What is the smallest possible value of $|\alpha| + |\gamma|$?

$\textbf{(A)}\ 1 \quad \textbf{(B)}\ \sqrt{2} \quad \textbf{(C)}\ 2 \quad \textbf{(D)}\ 2\sqrt{2} \quad \textbf{(E)}\ 4$

Worked solution

Write $\alpha = a + bi$ and $\gamma = c + di$ with $a,b,c,d$ real.

$f(1)$ real: $f(1) = (4+i) + (a+bi) + (c+di) = (4+a+c) + (1+b+d)i$. For this to be real, the imaginary part vanishes:

$$1 + b + d = 0.$$

$f(i)$ real: $f(i) = (4+i)(i^2) + \alpha i + \gamma = -(4+i) + (a+bi)i + (c+di) = (-4 - b + c) + (-1 + a + d)i$. For this to be real:

$$-1 + a + d = 0.$$

So $a = 1 - d$ and $b = -1 - d$, while $c$ is free. To minimize $|\alpha| + |\gamma|$, set $c = 0$, giving $|\gamma| = |d|$ and

$$|\alpha| = \sqrt{(1-d)^2 + (1+d)^2} = \sqrt{2 + 2d^2}.$$

Then $|\alpha| + |\gamma| = \sqrt{2 + 2d^2} + |d|$, which is minimized at $d = 0$, giving

$$|\alpha| + |\gamma| = \sqrt{2}.$$

Answer: (B) $\sqrt{2}$

2017 AMC 12BProblem 12 sum of roots of z^12=64 with Re>0

What is the sum of the roots of $z^{12} = 64$ that have a positive real part?

$\textbf{(A)}\ 2 \quad \textbf{(B)}\ 4 \quad \textbf{(C)}\ \sqrt{2}+2\sqrt{3} \quad \textbf{(D)}\ 2\sqrt{2}+\sqrt{6} \quad \textbf{(E)}\ (1+\sqrt{3})+(1+\sqrt{3})i$

Worked solution

Since $64 = 2^6$, every root has modulus $|z| = 64^{1/12} = 2^{1/2} = \sqrt2$, and the roots are $\sqrt2\,e^{i\pi k/6}$ for $k = 0,1,\dots,11$ (angles $30k^\circ$).

A root has positive real part when its angle lies strictly in $(-90^\circ, 90^\circ)$. The angle $90^\circ$ ($k=3$) gives real part $0$ and is excluded. The qualifying roots have angles $0^\circ, \pm30^\circ, \pm60^\circ$.

The imaginary parts cancel in conjugate pairs, so the sum is real:

$\sqrt2\left(\cos 0^\circ + 2\cos 30^\circ + 2\cos 60^\circ\right) = \sqrt2\left(1 + 2\cdot\tfrac{\sqrt3}{2} + 2\cdot\tfrac12\right) = \sqrt2\,(2+\sqrt3).$

Expanding: $2\sqrt2 + \sqrt6$.

Answer: (D) $2\sqrt{2}+\sqrt{6}$

2019 AMC 12BProblem 17 complex equilateral triangle

How many nonzero complex numbers $z$ have the property that $0$, $z$, and $z^3$, when represented by points in the complex plane, are the three distinct vertices of an equilateral triangle?

$\textbf{(A)}\ 0 \quad \textbf{(B)}\ 1 \quad \textbf{(C)}\ 2 \quad \textbf{(D)}\ 4 \quad \textbf{(E)}\ \text{infinitely many}$

Worked solution

For an equilateral triangle with one vertex at the origin, the other two vertices $z$ and $z^3$ are related by a rotation of $\pm 60^\circ$ about $0$. Rotating $z$ about the origin gives

$$z^3 = z\cdot e^{\pm i\pi/3}.$$

Since $z \neq 0$, divide by $z$:

$$z^2 = e^{\pm i\pi/3}.$$

Each of the two right-hand sides is a nonzero complex number, and each has exactly $2$ distinct square roots. That gives $2\times 2 = 4$ candidate values of $z$.

Each candidate has $|z| = 1$, so $z$, $z^3$, and $0$ are genuinely distinct (the rotation by $\pm 60^\circ$ keeps $z \neq z^3$, and neither equals $0$). All $4$ work.

Answer: (D) 4

2021 Spring AMC 12BProblem 18 complex modulus

Let $z$ be a complex number satisfying $12|z|^2 = 2|z+2|^2 + |z^2+1|^2 + 31$. What is the value of $z + \dfrac{6}{z}$?

$\textbf{(A)}\ -2 \quad \textbf{(B)}\ -1 \quad \textbf{(C)}\ \tfrac{1}{2} \quad \textbf{(D)}\ 1 \quad \textbf{(E)}\ 4$

Worked solution

Write $|w|^2 = w\bar{w}$ throughout. Using $|z+2|^2 = (z+2)(\bar z + 2) = |z|^2 + 2(z + \bar z) + 4$ and $|z^2+1|^2 = (z^2+1)(\bar z^2 + 1) = |z|^4 + (z^2 + \bar z^2) + 1$, the equation becomes

$12|z|^2 = 2|z|^2 + 4(z+\bar z) + 8 + |z|^4 + (z^2 + \bar z^2) + 1 + 31.$

Since $z^2 + \bar z^2 = (z+\bar z)^2 - 2|z|^2$, let $s = z + \bar z$ and $p = |z|^2$. This simplifies to

$12p = 2p + 4s + 8 + p^2 + (s^2 - 2p) + 32 = p^2 + s^2 - 0\cdot p + 4s + 40,$

i.e. $p^2 - 12p + s^2 + 4s + 40 = 0$, which is $(p-6)^2 + (s+2)^2 = 0.$

Therefore $p = |z|^2 = 6$ and $s = z + \bar z = -2$. Now $\dfrac{6}{z} = \dfrac{|z|^2}{z} = \dfrac{z\bar z}{z} = \bar z$, so $z + \dfrac{6}{z} = z + \bar z = -2.$

Answer: (A) -2

2024 AMC 12BProblem 12 complex numbers

Suppose $z$ is a complex number with positive imaginary part, with real part greater than $1$, and with $|z| = 2$. In the complex plane, the four points $0$, $z$, $z^2$, and $z^3$ are the vertices of a quadrilateral with area $15$. What is the imaginary part of $z$?

$\textbf{(A)}\ \dfrac{3}{4} \quad \textbf{(B)}\ 1 \quad \textbf{(C)}\ \dfrac{4}{3} \quad \textbf{(D)}\ \dfrac{3}{2} \quad \textbf{(E)}\ \dfrac{5}{3}$

Worked solution

Write $z = 2e^{i\theta}$ with $|z| = 2$. The constraint $\operatorname{Re}(z) = 2\cos\theta > 1$ means $\cos\theta > \tfrac12$, so $0 < \theta < 60^\circ$. The vertices are

$0,\quad z = 2e^{i\theta},\quad z^2 = 4e^{2i\theta},\quad z^3 = 8e^{3i\theta}.$

Use the shoelace formula in complex form: area $= \tfrac12\left|\sum \operatorname{Im}\!\big(\overline{v_k}\,v_{k+1}\big)\right|$ over consecutive vertices $0 \to z \to z^2 \to z^3 \to 0$. The two nonzero terms are

$\operatorname{Im}(\overline{z}\,z^2) = \operatorname{Im}\!\big(z|z|^2\big) = 4\cdot\operatorname{Im}(z),$

$\operatorname{Im}(\overline{z^2}\,z^3) = \operatorname{Im}\!\big(z|z|^4\big) = 16\cdot\operatorname{Im}(z).$

With $\operatorname{Im}(z) = 2\sin\theta$, the area is

$\tfrac12\,(4 + 16)\cdot 2\sin\theta = 20\sin\theta.$

Setting $20\sin\theta = 15$ gives $\sin\theta = \tfrac34$, so $\operatorname{Im}(z) = 2\sin\theta = \tfrac32$. (Check: $\cos\theta = \tfrac{\sqrt7}{4} > \tfrac12$, consistent.)

Answer: (D) $\dfrac{3}{2}$

2023 AMC 12BProblem 12 complex numbers

For complex numbers $u = a + bi$ and $v = c + di$, define the binary operation $\otimes$ by

$u \otimes v = ac + bd\,i.$

Suppose $z$ is a complex number such that $z \otimes z = z^2 + 40$. What is $|z|$?

$\textbf{(A)}\ \sqrt{10} \quad \textbf{(B)}\ 3\sqrt{2} \quad \textbf{(C)}\ 2\sqrt{6} \quad \textbf{(D)}\ 6 \quad \textbf{(E)}\ 5\sqrt{2}$

Worked solution

Write $z = a + bi$. Then by the definition, $z \otimes z = a^2 + b^2 i$, while $z^2 = (a^2 - b^2) + 2ab\,i$.

Setting $z \otimes z = z^2 + 40$ and matching real and imaginary parts:

Real: $a^2 = (a^2 - b^2) + 40 \ \Rightarrow\ b^2 = 40.$

Imaginary: $b^2 = 2ab \ \Rightarrow\ b = 2a$ (since $b \ne 0$).

From $b = 2a$ we get $b^2 = 4a^2 = 40$, so $a^2 = 10$.

Therefore $|z|^2 = a^2 + b^2 = 10 + 40 = 50$, giving $|z| = \sqrt{50} = 5\sqrt{2}$.

Answer: (E) $5\sqrt{2}$

Chapter 3 — Linear Equations

An equation is any statement with an equal sign. An unknown quantity is a variable; a fixed quantity is a constant; and a constant multiplying a variable term is its coefficient. The simplest — and most ubiquitous — equations are linear, and almost every word problem you meet first becomes a linear equation in disguise.

3.1 What Is a Linear Equation?

The degree of a term is the sum of the powers of its variables: $x$ has degree $1$, while $xy^2$ has degree $3$. The degree of an equation is the highest degree among its terms. A linear equation is one of degree exactly one — and with no variables under roots or fractional powers.

Linear form $$a_1 x_1 + a_2 x_2 + \cdots + a_n x_n = c \qquad (\text{all } a_i, c \text{ constant})$$

So $x + y + z + w = 0$ is linear, but $x^2 + y = 4$ and $xy = 4$ both have degree two and are not. The key test: every variable appears alone, to the first power, never multiplied by another variable.

An equation can fail to be linear in subtler ways. $3^x + y = 0$ has a variable in the exponent, so no degree can even be assigned — it is not linear. The same goes for variables inside trigonometric functions or logarithms, and for $x + \tfrac{y}{x} = 3$, which hides an $xy$ term once you clear the denominator.
📝 Example — which of these are linear?

$x^2 + y = 4$: degree $2$ — not linear.   $xy = 4$: degree $2$ — not linear.   $x + y + z + w = 0$: degree $1$ — linear.   $3^x + y = 0$: variable exponent, no degree — not linear.

3.2 One Equation, One Variable

A single linear equation in one variable always yields to a two-step recipe: collect the variable terms on one side and the constants on the other, then divide by the variable's coefficient.

Solving $ax + b = c$ $$ax + b = c \;\Longrightarrow\; ax = c - b \;\Longrightarrow\; x = \frac{c - b}{a} \quad (a \neq 0)$$

The letters $a,b,c$ are just constants even when written as letters; the procedure is identical to working with numbers.

📝 Example — solve $3x + 5 = 11 + x$

Subtract $5$ from both sides: $3x = 6 + x$. Subtract $x$: $2x = 6$. Divide by $2$: $x = 3$.

Check (always!): $3(3) + 5 = 14$ and $11 + 3 = 14$. ✓

📝 Example — make it linear first

To solve $\dfrac{1}{y} + 1 = 3$, multiply through by $y$: $1 + y = 3y$, so $2y = 1$ and $y = \tfrac{1}{2}$. A non-linear-looking equation can often be cleared into a linear one.

✏️ Exercise 3-1 — solve for $y$

$3y + 2 = y - 3 + 4y$.

3.3 Two Equations, Two Variables

A single equation like $x + y = 3$ has infinitely many solutions $(x,y)$ — $(3,0)$, $(0,3)$, $(1,2)$, all the points on a line. Pin things down with a second equation: the solution to the system is where the two lines meet. There are two standard techniques.

Substitution. Solve one equation for one variable, then substitute into the other. From $x + y = 3$ we get $x = 3 - y$; putting this into $x - y = 1$ gives $(3 - y) - y = 1$, so $y = 1$ and $x = 2$.

Elimination. Add multiples of the equations to cancel a variable. Here, simply adding $x + y = 3$ and $x - y = 1$ gives $2x = 4$, so $x = 2$, then $y = 1$.

Elimination, in general $$\begin{aligned} a_1 x + a_2 y &= a_3 \\ b_1 x + b_2 y &= b_3 \end{aligned} \quad\xrightarrow{\;\times(-b_1),\;\times a_1\;}\quad (a_1 b_2 - a_2 b_1)\,y = a_1 b_3 - a_3 b_1$$

To eliminate $x$, multiply the first equation by $-b_1$ and the second by $a_1$, then add — the $x$ terms cancel because $-b_1 a_1 + a_1 b_1 = 0$. (You may eliminate either variable, and substitute for either variable; pick whichever is least messy.)

📝 Example — solve $2x + 3y = -1$, $\;3x - 4y = 7$

Elimination: multiply the first by $-3$ and the second by $2$:

$$\begin{aligned} -6x - 9y &= 3 \\ 6x - 8y &= 14 \end{aligned}$$

Adding: $-17y = 17$, so $y = -1$, and back-substituting gives $x = 1$. Thus $(x,y) = (1,-1)$.

Check: $2(1) + 3(-1) = -1$ ✓ and $3(1) - 4(-1) = 7$ ✓. Substitution works too: from the first equation $x = -\tfrac{1}{2} - \tfrac{3}{2}y$, plugged into the second.

📝 Example — rearrange, then eliminate

Find $(x,y)$ with $2x = 2y - 4$ and $2y = 2 + x$. First group variables on one side:

$$\begin{aligned} 2x - 2y &= -4 \\ -x + 2y &= 2 \end{aligned}$$

Adding eliminates $y$: $x = -2$, hence $y = 0$. So $(x,y) = (-2, 0)$.

📝 Example — linear in disguise

Solve $2\sqrt{x} + 4\sqrt{y} = 10$ and $2\sqrt{x} - 3\sqrt{y} = 3$. These are not linear in $x,y$, but they are linear in $\sqrt{x}$ and $\sqrt{y}$. Subtracting: $7\sqrt{y} = 7$, so $\sqrt{y} = 1$. Then $2\sqrt{x} + 4 = 10$ gives $\sqrt{x} = 3$. Squaring: $(x,y) = (9, 1)$.

Always substitute your final $(x,y)$ back into both original equations to confirm it satisfies each one — a sign slip during elimination is easy to make and easy to catch this way.
✏️ Exercise 3-3 — solve for $(x,y)$

$3x = 5 + 2y$  and  $2x - 2y = 7$. Then try $0.1x + y = 3$,   $0.5x - 3y = 7$.

3.4 One, None, or Infinitely Many Solutions

Two lines in a plane do one of three things: cross once, run parallel, or coincide. Algebraically these are exactly the three outcomes of a $2\times 2$ system.

Three outcomes $$\text{cross} \to \text{one solution} \qquad \text{parallel} \to \text{no solution} \qquad \text{same line} \to \infty \text{ solutions}$$

If one equation's coefficients are a constant multiple of the other's, the lines are parallel — so either they never meet (no solution) or they are identical (infinitely many).

📝 Example — no solution

For $2x - 4y = 7$ and $x - 2y = 2$, multiply the second by $2$ to get $2x - 4y = 4$. Subtracting from the first yields $0 = 3$ — impossible. The lines are parallel and never intersect, so there is no solution.

📝 Example — infinitely many

For $2x - 2y = 6$ and $x - y = 3$, the first is exactly twice the second. Elimination gives $0 = 0$ — always true. The two equations describe the same line, so there are infinitely many solutions.

💡 Big Picture — equations vs. unknowns A loose rule of thumb: to pin down $n$ unknowns you generally need $n$ independent linear equations. Too few, and a whole family of solutions survives (the line $x+y=3$); just enough and independent, and you get a unique point; but if equations secretly repeat (dependent) or contradict (inconsistent), you fall back to infinitely many or none. Larger systems — three equations in three unknowns and beyond — are solved by the same substitution/elimination, just done more systematically (this is the heart of linear algebra).

3.5 Word Problems

A word problem is a system of equations written in English. Translate it with a three-step procedure: (1) define every variable, (2) write the equations the words describe, (3) solve.

📝 Example — Johnny & Gina's ages

Johnny is twice as old as Gina and five years older. Let $J$, $G$ be their ages. Then $J = 2G$ and $J = G + 5$. Setting equal: $2G = G + 5$, so $G = 5$ and $J = 10$. Johnny is $\boxed{10}$.

📝 Example — a digit puzzle

A two-digit number has units digit three times its tens digit; reversing adds $54$. Let $t,u$ be the digits, so the number is $10t + u$. Then $u = 3t$, and $(10u + t) - (10t + u) = 9(u - t) = 54$, giving $u - t = 6$. With $u = 3t$ this is $2t = 6$, so $t = 3$, $u = 9$, and the number is $\boxed{39}$.

Many recurring problem types share one master formula. For motion, $\textbf{rate} \times \textbf{time} = \textbf{distance}$; for work, the same idea reads rate of work $\times$ time $=$ fraction of job done.

Two master formulas $$r \cdot t = d \qquad\qquad (\text{work rate}) \cdot (\text{time}) = (\text{fraction completed})$$
📝 Example — average speed is not the average

Jim drives $40$ mi at $40$ mph (1 hour), then back at $20$ mph (2 hours). Average speed is total distance over total time: $\dfrac{80}{3} = 26\tfrac{2}{3}$ mph — not $30$. Average speed always uses the whole trip, never the average of the two rates.

📝 Example — frog in a current

A frog swims $8$ mi downstream in $2$ h and back upstream in $14$ h. Let $x$ = still-water rate, $y$ = current. The current adds going down and subtracts coming up:

$$(x + y)(2) = 8 \qquad (x - y)(14) = 8$$

So $x + y = 4$ and $x - y = \tfrac{4}{7}$. Adding: $2x = \tfrac{32}{7}$, giving $x = \tfrac{16}{7}$ mph in still water (and $y = \tfrac{12}{7}$).

📝 Example — two pipes filling a pool

Pipe A fills a pool in $5$ h (so $\tfrac{1}{5}$ per hour), pipe B in $4$ h ($\tfrac{1}{4}$ per hour). Together in $x$ hours they fill $x\!\left(\tfrac{1}{4} + \tfrac{1}{5}\right)$; set this to $1$:

$$x\left(\tfrac{1}{4} + \tfrac{1}{5}\right) = 1 \;\Longrightarrow\; x\cdot\tfrac{9}{20} = 1 \;\Longrightarrow\; x = \tfrac{20}{9} = 2\tfrac{2}{9}\text{ hours.}$$
✏️ Exercise 3-4 — football tickets

Adult tickets cost $\$3.25$ and student tickets $\$1.75$. If $1350$ fans paid a total of $\$2700$, how many adults attended? Let $a$ + $s$ = $1350$ and $3.25a + 1.75s = 2700$; eliminate $s$.

✏️ Exercise 3-7 — two knights

One knight can storm a castle in $15$ days; with his partner it takes $10$ days. How long does the partner take alone? Use $\tfrac{1}{15} + \tfrac{1}{p} = \tfrac{1}{10}$.

Linear systems are the workhorse of physics. A body in static equilibrium obeys $\sum F_x = 0$ and $\sum F_y = 0$ — a linear system whose unknowns are tensions and normal forces; statics problems for trusses and bridges are nothing but large such systems. In circuits, Kirchhoff's laws (currents into a node sum to zero, voltages around a loop sum to zero) produce one linear equation per node and per loop, solved by the very elimination you just learned. As the unknowns multiply, these systems are written as a matrix equation $A\mathbf{x} = \mathbf{b}$ and solved by Gaussian elimination — the systematic, large-scale version of this chapter, and the foundation of linear algebra throughout mechanics, quantum theory, and computation.

Bricklayer Brenda would take $9$ hours to build a chimney alone, and bricklayer Brandon would take $10$ hours to build it alone. When they work together they talk a lot, and their combined output is decreased by $10$ bricks per hour. Working together, they build the chimney in $5$ hours. How many bricks are in the chimney?

$\textbf{(A)}\ 500 \quad \textbf{(B)}\ 900 \quad \textbf{(C)}\ 950 \quad \textbf{(D)}\ 1000 \quad \textbf{(E)}\ 1900$

2008 AMC 12BProblem 20 walker vs garbage truck meetings

Michael walks at the rate of $5$ feet per second on a long straight path. Trash pails are located every $200$ feet along the path. A garbage truck travels at $10$ feet per second in the same direction as Michael and stops for $30$ seconds at each pail. As Michael passes a pail, he notices the truck ahead of him just leaving the next pail. How many times will Michael and the truck meet?

$\textbf{(A)}\ 4 \quad \textbf{(B)}\ 5 \quad \textbf{(C)}\ 6 \quad \textbf{(D)}\ 7 \quad \textbf{(E)}\ 8$

Worked solution

Set $t=0$ when Michael passes a pail at position $0$; the truck is then $200$ ft ahead, just leaving its pail. Michael's position is $x_M = 5t$.

The truck's cycle: it travels $200$ ft at $10$ ft/s ($20$ s), then waits $30$ s — a $50$-second cycle covering $200$ ft, for an average speed of $4$ ft/s. Since Michael's $5$ ft/s exceeds this, he gradually closes the initial $200$-ft gap.

Track the gap $g(t) = x_{\text{truck}}(t) - x_M(t)$. Each time the truck stops, Michael gains on it; each time the truck drives, it pulls ahead at $10-5=5$ ft/s. The gap oscillates while trending downward, and Michael and the truck meet whenever $g(t)=0$.

Working through the cycles (truck stopped over $[20,50]$, $[70,100]$, $[120,150]$, $\dots$ and Michael at $5t$), the crossings occur at approximately

$$t \approx 200,\ 240,\ 260,\ 280,\ 320 \text{ seconds}.$$

That is $\mathbf{5}$ meetings before Michael permanently outpaces the slower-on-average truck.

Answer: (B) 5

Chapter 4 — Proportions

A proportion relates one quantity to another. When five apples cost 39 cents we tie apples to money: $\frac{\text{apples}}{\text{cost}} = \frac{5}{39}$. The whole subject reduces to writing the right equation between two quantities — then everything else is algebra you already know.

4.1 Direct and Inverse Proportion

Two quantities are directly proportional when their quotient is constant: as one grows, so does the other. They are inversely proportional when their product is constant: as one grows, the other shrinks. That fixed quotient or product is the constant of proportionality.

Direct vs. inverse $$\text{direct:}\quad \frac{x}{y} = k \qquad\qquad \text{inverse:}\quad xy = k$$

The reliable move is always to write the relationship as an equation, substitute what you're given, and solve. Ratios may also be written with colons — $a:c = 5:39$ — and this is the only convenient way to relate three or more quantities at once. A ratio of trucks to cars of $4:3$ means $4$ of every $7$ vehicles are trucks; convert to fractions ($\tfrac47$, $\tfrac37$) before computing.

📝 Example — shadows scale directly

A ten-foot pole casts an eight-foot shadow. How long is a pole casting a twelve-foot shadow? Height is directly proportional to shadow length, so the quotient is constant:

$$\frac{\text{pole}}{\text{shadow}} = \frac{10}{8} \;\Rightarrow\; \frac{\text{pole}}{12} = \frac{10}{8} \;\Rightarrow\; \text{pole} = 12\cdot\tfrac{10}{8} = 15\text{ ft}.$$
📝 Example — splitting by a ratio

The ratio of boys to girls is $3:2$ in a class of $35$. Out of every $5$ students, $2$ are girls, so girls make up $\tfrac25$ of the class: $35\cdot\tfrac25 = 14$ girls.

📝 Example — inverse proportion

$x$ and $y$ are inversely proportional, and $x=10$ when $y=6$. Then $xy = 60$ always. When $y=4$: $4x = 60 \Rightarrow x = 15$.

📝 Example — joint proportion (combining variables)

$x$ is directly proportional to $y$ and $z$ and inversely proportional to $w$. Then a single combination is constant — multiply the variables that go with $x$ into the denominator and the inverse one into the numerator:

$$\frac{xw}{yz} = k.$$

Given $x=4$ at $(w,y,z)=(6,8,5)$: $k = \frac{4\cdot 6}{8\cdot 5} = \frac{24}{40} = \frac35$. At $(w,y,z)=(4,10,9)$:

$$x = \frac{k\,yz}{w} = \frac{\tfrac35\cdot 10\cdot 9}{4} = \frac{54}{4} = \frac{27}{2}.$$
📝 Example — work: houses, people, and days

It takes $3$ days for $4$ people to paint $5$ houses. How long for $2$ people to paint $6$? More houses needs more days and more people, so houses is directly proportional to both — putting both in the denominator:

$$\frac{\text{houses}}{(\text{people})(\text{days})} = \frac{5}{4\cdot 3} = \frac{5}{12}.$$ $$\text{days} = \frac{12\cdot\text{houses}}{5\cdot\text{people}} = \frac{12\cdot 6}{5\cdot 2} = \frac{36}{5}\text{ days}.$$
When the four o'clock minute and hour hands coincide, the answer is not $20$ minutes — the hour hand moves while you wait. Set $x = 20 + 5\cdot\tfrac{x}{60}$ and solve: $x = \tfrac{240}{11}$ min. Don't memorize a "clock formula"; reconstruct the proportion each time.

4.2 Manipulating Proportions

Given $\frac{a}{b} = \frac{c}{d}$, a whole family of equal ratios follows. These are the workhorses of ratio-heavy geometry problems.

Equal-ratio identities $$\frac{a}{b} = \frac{c}{d} = \frac{a+c}{b+d} = \frac{a-c}{b-d} = \frac{a+kc}{b+kd}$$

Proving the general one proves them all (set $k=1$ and $k=-1$ for the first two). Let $\frac{a}{b}=\frac{c}{d}=r$, so $a = rb$ and $c = rd$. Then

Why it works $$\frac{a+kc}{b+kd} = \frac{rb + k(rd)}{b+kd} = \frac{r(b+kd)}{b+kd} = r = \frac{a}{b}.$$

A second standard tactic is multiplying proportions to cancel a common variable. Given $\frac{x}{y}=\frac45$ and $\frac{z}{y}=\frac43$, flip the second and multiply so the $y$'s cancel:

Chaining ratios $$\frac{x}{z} = \frac{x}{y}\cdot\frac{y}{z} = \frac45\cdot\frac34 = \frac{3}{5}.$$
📝 Example — fancy isn't always needed

Find $\frac{x}{y}$ if $\dfrac{x+2y}{x-y} = \dfrac34$. Despite the section's theme, plain algebra wins. Clear the fraction:

$$4(x+2y) = 3(x-y) \;\Rightarrow\; 4x+8y = 3x-3y \;\Rightarrow\; x + 11y = 0,$$

so $x = -11y$ and $\dfrac{x}{y} = -11$.

4.3 Conversion Factors

To change units, multiply by fractions equal to $1$. Because each conversion factor equals $1$, the value never changes — only the units do, cancelling like ordinary algebraic symbols. Orient each factor so the unwanted unit cancels.

Length conversion $$180\text{ cm} \times \frac{1\text{ in}}{2.54\text{ cm}} \times \frac{1\text{ ft}}{12\text{ in}} \approx 5.9\text{ ft}.$$

Had we written $\frac{2.54\text{ cm}}{1\text{ in}}$ instead, the centimeters would not cancel — so always pick the orientation that kills the unit you're leaving. For squared or cubed units, apply the factor the matching number of times: converting area uses the factor twice, since $\text{ft}^2 = \text{ft}\cdot\text{ft}$.

Area conversion ($1\text{ ft} \approx 0.3048\text{ m}$) $$5\text{ ft}^2 \times \left(\frac{0.3048\text{ m}}{1\text{ ft}}\right)^2 \approx 0.4645\text{ m}^2.$$
Match the exponent on the unit with the power on the conversion factor. To convert a density in $\mathrm{kg/m^3}$ to $\mathrm{kg/ft^3}$ you multiply by $\left(\tfrac{0.3048\text{ m}}{1\text{ ft}}\right)^3$ so that all three meters cancel — using the factor only once leaves stray $\mathrm{m^2}$ behind.
📝 Example — converting through a middle unit

If $4$ gleeps $= 3$ glops and $2$ glops $= 5$ glips, how many glips equal $10$ gleeps? No direct gleep–glip rate exists, so chain through glops:

$$10\text{ gleeps} \times \frac{3\text{ glops}}{4\text{ gleeps}} = 7.5\text{ glops},\qquad 7.5\text{ glops} \times \frac{5\text{ glips}}{2\text{ glops}} = 18.75\text{ glips}.$$

4.4 Percent

Percent means "per hundred," so $30\% = \frac{30}{100} = 0.30$. Percent is just a proportion. The key translation: "of" means multiply, and "is" / "are" mean equals. So "$5\%$ of all people are left-handed" becomes $0.05\cdot(\text{people}) = (\text{left-handed})$.

Increase and decrease $$\text{up }p\%:\; (1+\tfrac{p}{100})\,x \qquad\qquad \text{down }p\%:\; (1-\tfrac{p}{100})\,x$$

A $25\%$ discount on a \$22 book gives $0.75\cdot 22 = \$16.50$; a $25\%$ increase gives $1.25\cdot 22 = \$27.50$. Interest is just repeated percent increase: a loan of \$2000 at $8\%$ becomes $1.08\cdot 2000$ after a year, and the distributive law lets you carry the factor instead of multiplying out early.

📝 Example — reverse percent

$75$ is $20\%$ of what number? Let $x$ be the number: $0.20x = 75 \Rightarrow x = 375$.

📝 Example — successive percents don't cancel

A \$10000 car is decreased $25\%$, then increased $25\%$. The result is not \$10000:

$$0.75\cdot 10000 = 7500,\qquad 7500\cdot 1.25 = \$9375.$$

Each percent acts on a different base, so the two changes don't undo each other.

📝 Example — compound interest

Borrow \$4000 at $5\%$ annual interest; how much is owed after $4$ years? Each year multiplies the previous balance by $1.05$:

$$4000(1.05)^4 = 4000(1.21550625) \approx \$4862.03.$$
📝 Example — mixing solutions

Mix $2$ L of $20\%$ acid with $8$ L of $50\%$ acid. Concentration is total acid over total volume:

$$\frac{2(0.20) + 8(0.50)}{2+8} = \frac{0.4 + 4}{10} = \frac{4.4}{10} = 44\%.$$
A $p\%$ increase followed by a $p\%$ decrease (or vice versa) does not return you to the start: the net factor is $(1+\tfrac{p}{100})(1-\tfrac{p}{100}) = 1 - (\tfrac{p}{100})^2 < 1$. To undo a $25\%$ rise you must decrease by $20\%$, not $25\%$, because the base changed.

💡 Big Picture — proportions are everywhere As the simplest relation between two variables, proportions show up across science. Around 1800 Dalton noticed that in any pure substance the weight ratio of constituent elements is always constant — evidence that matter is built from atoms combining in fixed whole-number ratios. In economics, price and demand are often modeled as inversely proportional ($PD = \text{const}$): raise the price, demand falls. The pattern is so basic it's the first model anyone reaches for.
Physics is saturated with proportionality. Scaling laws: area scales as length$^2$ and volume as length$^3$, so doubling an animal's size multiplies its weight (and bone-crushing load) by $8$ while cross-sectional bone strength rises only $4\times$ — why elephants have proportionally thicker legs than mice. Inverse-square laws: gravity and the Coulomb force fall as $1/r^2$, and light intensity dims the same way because a fixed amount of flux spreads over a sphere of area $4\pi r^2$. Dimensional analysis — the conversion-factor trick of cancelling units — lets you guess formulas: a pendulum's period can only be $T \propto \sqrt{L/g}$ because that's the one combination with units of time. Density ($\rho = m/V$, mass directly proportional to volume) and the Ideal Gas Law ($PV/T = \text{const}$, so squeezing a balloon at constant temperature raises its pressure) are proportions at heart.

Chapter 6 — Quadratic Equations

A quadratic is an equation of degree 2 — the unknown appears squared. They show up the instant the world stops being linear: a rock falling under gravity, an area, an energy. We'll learn to factor them, complete the square, and derive the quadratic formula from scratch — then bend a surprising range of other problems into quadratic shape.

6.1 What's a Quadratic?

Throw a rock off a 100-foot tower. If it moved at a constant rate it would be a linear equation — but gravity accelerates it, so its height is $h(t) = 100 - 5t - 16t^2$. Asking "when does it hit the ground?" means solving $100 - 5t - 16t^2 = 0$, an equation of degree 2. The general form is

Standard form $$ax^2 + bx + c = 0, \qquad a \neq 0$$

Here $a$, $b$, $c$ are the coefficients. The values of $x$ that satisfy the equation are its roots (also called zeroes or solutions). A quadratic has exactly two roots (possibly equal, possibly complex).

6.2 Factoring Quadratics

Quadratics arise as products of linear factors: $(x+2)(x+3) = x^2 + 5x + 6$. Running this backwards is the key idea — if we can write a quadratic as a product, the zero-product property hands us the roots:

Factored form & zero-product $$ax^2 + bx + c = a(x-r)(x-s) = 0 \;\Longrightarrow\; x = r \;\text{ or }\; x = s$$

A product is zero only when one of its factors is zero. So $(x+2)(x+3)=0$ forces $x = -2$ or $x = -3$. Expanding $(x-r)(x-s) = x^2 - (r+s)x + rs$ reveals the link between roots and coefficients — a preview of Vieta (§6.3): the coefficient of $x$ is minus the sum of the roots, and the constant is their product.

To factor $x^2 + bx + c$ (leading coefficient 1), write it as $(x+u)(x+v) = x^2 + (u+v)x + uv$ and find two numbers with product $c$ and sum $b$. The signs are a free hint: if $c > 0$ the numbers share a sign (which one is fixed by the sign of $b$); if $c < 0$ they have opposite signs.

📝 Example — solve $x^2 + 9x + 18 = 0$ and $x^2 - x - 30 = 0$

First: product $18 > 0$ and sum $9 > 0$, so both numbers are positive. From $18 = 3\cdot 6$ with $3+6=9$, we get $(x+3)(x+6)=0$, so $x = -3, -6$.

Second: product $-30 < 0$, so the numbers differ in sign; sum $-1$ means they differ by 1 in magnitude. Since $5\cdot 6 = 30$, take $-6$ and $5$: $(x-6)(x+5)=0$, so $x = 6, -5$.

📝 Example — leading coefficient $\neq 1$: solve $x^2 + \tfrac{3}{2}x = 1$

Always clear fractions and move everything to one side first. Multiply by 2: $2x^2 + 3x - 2 = 0$. Seek $(sx+u)(tx+v)$ with $st = 2$, $uv = -2$, $sv + ut = 3$. Trying $s=1,t=2,u=2,v=-1$ gives $(x+2)(2x-1)=0$, so $x = -2$ or $x = \tfrac12$. Check: $2(\tfrac14) + \tfrac32 - 2 = 0$. ✓

Three special factorizations are worth memorizing:

Special factorizations $$ax^2 + bx = x(ax+b) \qquad x^2 - a^2 = (x-a)(x+a) \qquad x^2 \pm 2ax + a^2 = (x\pm a)^2$$

Watch for disguised versions: $4x^2 - 9 = (2x+3)(2x-3)$ (a difference of squares with $2x$), and $4x^2 + 12x + 9 = (2x+3)^2$ (a perfect square with $2x$ and $3$).

Don't divide by a negative or fractional leading coefficient — it spawns ugly fractions. Instead factor out $-1$ so the $x^2$ coefficient is positive: $-4x^2 - 8x - 3 = -(4x^2 + 8x + 3) = -(2x+1)(2x+3)$. The sign hints only work when the coefficient of $x^2$ is positive.

6.3 Completing the Square & the Quadratic Formula

Not every quadratic factors nicely — try $x^2 + x - 1 = 0$ and you'll give up guessing. We need a method that always works. The trick: massage the quadratic into a perfect square $x^2 + 2mx + m^2 = (x+m)^2$, because we know how to take its square root. This is completing the square. Let's derive the quadratic formula with it.

Start from $ax^2 + bx + c = 0$ and divide by $a$:

Derivation — step 1: normalize & isolate $$x^2 + \frac{b}{a}x + \frac{c}{a} = 0 \;\Longrightarrow\; x^2 + \frac{b}{a}x = -\frac{c}{a}$$

The coefficient of $x$ is $\tfrac{b}{a} = 2m$, so $m = \tfrac{b}{2a}$. To complete the square we add $m^2 = \left(\tfrac{b}{2a}\right)^2$ to both sides:

Derivation — step 2: complete the square $$x^2 + \frac{b}{a}x + \frac{b^2}{4a^2} = -\frac{c}{a} + \frac{b^2}{4a^2} \;\Longrightarrow\; \left(x + \frac{b}{2a}\right)^2 = \frac{b^2 - 4ac}{4a^2}$$

The left side is now a perfect square. Take the square root of both sides — keeping both signs — and the equation collapses to linear:

Derivation — step 3: solve the linear equation $$x + \frac{b}{2a} = \pm\frac{\sqrt{b^2 - 4ac}}{2a} \;\Longrightarrow\; \boxed{\,x = \frac{-b \pm \sqrt{b^2 - 4ac}}{2a}\,}$$

That box is the quadratic formula. The $\pm$ packs both roots into one expression. More valuable than memorizing it is owning the derivation — completing the square is a general tool (it reappears for circles, conics, and integrals). Applied to our stubborn example, $x^2 + x - 1 = 0$ gives $x = \dfrac{-1 \pm \sqrt{5}}{2}$ — irrational roots you'd never have guessed.

📝 Example — complex roots: $3x^2 + x + 4 = 0$

Plug in $a=3,b=1,c=4$:

$$x = \frac{-1 \pm \sqrt{1 - 4(3)(4)}}{2(3)} = \frac{-1 \pm \sqrt{-47}}{6} = \frac{-1 \pm i\sqrt{47}}{6}.$$

The roots are a complex conjugate pair — no factoring or trial-and-error would ever reach them.

6.4 The Discriminant

Where could complex numbers possibly enter the quadratic formula? Only through the square root. So the quantity under the radical decides everything. It is called the discriminant:

Discriminant $\;D = b^2 - 4ac$ $$D > 0:\ \text{two distinct real roots} \qquad D = 0:\ \text{one repeated real root}\ \left(x=-\tfrac{b}{2a}\right) \qquad D < 0:\ \text{complex conjugate roots}$$

The discriminant lets you classify roots without solving. For $3x^2 + x + 4$ above, $D = 1 - 48 = -47 < 0$, immediately telling us the roots are complex. When $D = 0$ the $\pm$ contributes nothing and both roots coincide at $-\tfrac{b}{2a}$ — the quadratic is a perfect square.

Conjugate root theorem $$\text{real coefficients:}\;\; x+yi \text{ a root} \Rightarrow x-yi \text{ a root} \qquad \text{rational coefficients:}\;\; x+y\sqrt z \text{ a root} \Rightarrow x-y\sqrt z \text{ a root}$$

This follows directly from the $\pm$ in the formula. It's extremely handy: if you know one irrational or complex root, you instantly know the other.

📝 Example — reconstruct the quadratic from one root

If $3+\sqrt2$ is a root of $x^2 + bx + c = 0$ (rational coefficients), then $3-\sqrt2$ is the other. So

$$\big(x-(3+\sqrt2)\big)\big(x-(3-\sqrt2)\big) = x^2 - 6x + (9-2) = x^2 - 6x + 7,$$

giving $b = -6$, $c = 7$. (The sum of roots is $6$ and product is $7$ — see Vieta below.)

📝 Example — perfect-square condition

For what $c$ is $9n^2 - 30n + c$ a perfect square for all $n$? A perfect square has $D = 0$: $(-30)^2 - 4(9)(c) = 900 - 36c = 0$, so $c = 25$. Check: $9n^2 - 30n + 25 = (3n-5)^2$. ✓

💡 Big Picture — Vieta's formulas Expanding $a(x-r)(x-s) = ax^2 - a(r+s)x + ars$ and matching to $ax^2 + bx + c$ gives Vieta's formulas: $$r + s = -\frac{b}{a}, \qquad rs = \frac{c}{a}.$$ You can read the sum and product of the roots straight off the coefficients — no need to solve. This is the engine behind countless "find the sum of the solutions" shortcuts, and it generalizes to polynomials of any degree (sums and products of roots in terms of coefficients).

6.5 Rearrangements & Substitutions

Most "quadratic" problems don't arrive in standard form. Two moves convert them. Rearrangement: clear denominators or square away radicals until a quadratic appears. Substitution: spot an expression and its square, then rename the expression as a single new variable.

📝 Example — variable in a denominator

To solve an equation with $x$ in a denominator, multiply through by every denominator that appears, then collect terms. After clearing fractions you typically land on something like $5y^2 - 20y = 0$, i.e. $5y(y-4)=0$, giving $y = 0$ or $y = 4$.

After multiplying by an expression containing the variable, you must check every candidate against the original equation. A value that makes any original denominator zero is an extraneous root and must be discarded.
📝 Example — radical equation: $\sqrt{x+3} + 4 = \sqrt{8x+1}$

Square both sides: $(x+3) + 8\sqrt{x+3} + 16 = 8x + 1$, so $8\sqrt{x+3} = 7x - 18$. Square again: $64(x+3) = 49x^2 - 252x + 324$, which rearranges to $49x^2 - 316x + 132 = 0 = (x-6)(49x-22)$. So $x = 6$ or $x = \tfrac{22}{49}$.

Check both: $x=6$ gives $\sqrt9 + 4 = 7 = \sqrt{49}$. ✓ But $x = \tfrac{22}{49}$ fails — squaring introduced the negative root of $\sqrt{x+3}$, which the original (positive) radical forbids. So $x = 6$ only.

Squaring an equation can create solutions that don't satisfy the original — a written radical $\sqrt{\,\cdot\,}$ always means the non-negative root. Every solution of a squared or denominator-cleared equation must be verified.
📝 Example — substitution: $1 + 2^n + 2^{2n} = 73$

Notice $2^{2n} = (2^n)^2$. Let $x = 2^n$, so the equation is $x^2 + x + 1 = 73$, i.e. $x^2 + x - 72 = (x+9)(x-8) = 0$. Then $x = 8$ or $x = -9$. Since $2^n > 0$, reject $-9$; $2^n = 8$ gives $n = 3$.

📝 Example — substitution: $x^4 + 3x^2 - 4 = 0$

Let $z = x^2$ (so $z^2 = x^4$): $z^2 + 3z - 4 = (z+4)(z-1) = 0$, giving $z = 1$ or $z = -4$. Back-substitute: $x^2 = 1 \Rightarrow x = \pm 1$, and $x^2 = -4 \Rightarrow x = \pm 2i$. All four are valid.

Caution: the trick needs only the expression and its square. Adding a stray $x$ term ($x^4 + 3x^2 + x - 4$) breaks it — no single substitution makes it quadratic.

6.6 Square Roots of Irrationals & Imaginaries

Since $(x+y)^2 = x^2 + 2xy + y^2$, expressions like $\sqrt{a + b\sqrt c}$ or $\sqrt{a + bi}$ often have clean closed forms. Run the squaring in reverse: assume a form, square it, and match parts. For $\sqrt{a + b\sqrt c}$ with $c$ prime, guess $x + y\sqrt c$:

Denesting system $$(x + y\sqrt c)^2 = (x^2 + cy^2) + 2xy\sqrt c = a + b\sqrt c \;\Longrightarrow\; \begin{cases} 2xy = b \\ x^2 + cy^2 = a \end{cases}$$

Solve the system for $x,y$ — by trial and error if $b$ has few factors, or directly otherwise.

📝 Example — $\sqrt{34 - 24\sqrt2}$

Form $x + y\sqrt2$, so $(x+y\sqrt2)^2 = x^2 + 2y^2 + 2xy\sqrt2 = 34 - 24\sqrt2$. The system is $xy = -12$ and $x^2 + 2y^2 = 34$. Testing factor pairs of $-12$, $(x,y) = (4,-3)$ works: $16 + 18 = 34$. ✓

So $(4 - 3\sqrt2)^2 = 34 - 24\sqrt2$. But $-(4-3\sqrt2) = -4 + 3\sqrt2$ is also a square root. Since $\sqrt{\,\cdot\,}$ means the positive value and $3\sqrt2 = \sqrt{18} > 4 = \sqrt{16}$, we have $-4 + 3\sqrt2 > 0$. Therefore $\sqrt{34 - 24\sqrt2} = 3\sqrt2 - 4$.

When denesting an irrational, always pick the positive root. Here $4 - 3\sqrt2 < 0$, so the answer is its negative, $3\sqrt2 - 4$.

Direct method: from $y = -12/x$, the second equation becomes $x^4 - 34x^2 + 288 = (x^2-16)(x^2-18) = 0$, recovering $x = \pm4$.

If $c$ is not prime, the form $x + y\sqrt c$ may fail; try $x\sqrt w + y\sqrt z$ where $c = zw$. For $\sqrt{5 + 2\sqrt6}$, set $x\sqrt2 + y\sqrt3$: $(x\sqrt2 + y\sqrt3)^2 = 2x^2 + 3y^2 + 2xy\sqrt6$. Matching gives $2xy = 2$, $2x^2 + 3y^2 = 5$, solved by $(1,1)$, so $\sqrt{5 + 2\sqrt6} = \sqrt2 + \sqrt3$.

For imaginaries, $\sqrt{a + bi} = x + yi$ leads to the same kind of system from $(x+yi)^2 = (x^2 - y^2) + 2xyi$:

Complex square-root system $$\begin{cases} 2xy = b \\ x^2 - y^2 = a \end{cases}$$
📝 Example — $\sqrt{5 - 12i}$

Let $\sqrt{5-12i} = a + bi$. Then $a^2 - b^2 = 5$ and $2ab = -12$. From $b = -6/a$: $a^4 - 5a^2 - 36 = (a^2-9)(a^2+4) = 0$, so $a = \pm3$ (real). This gives $\pm(3 - 2i)$. Check: $(3-2i)^2 = 9 - 12i + 4i^2 = 5 - 12i$. ✓ For complex numbers there's no "positive" — both $3-2i$ and $-3+2i$ are equally valid square roots.

6.7 Beyond Quadratics

Linear equations use the first power; quadratics use the first and second. The natural next step is a polynomial — a sum of constant multiples of non-negative integer powers of $x$, like $x^{17} + 38x^{11} + 12x^{10} - 76x^4 + 123$.

Roots & factored form $$\text{roots } r_1,\dots,r_n:\qquad a(x - r_1)(x - r_2)\cdots(x - r_n) = 0$$

Like a quadratic, a degree-$n$ polynomial factors into $n$ linear pieces, one per root (counted with multiplicity). Degree 3 is a cubic, degree 4 a quartic. Many higher-degree problems are secretly quadratic in disguise — the substitution trick of §6.5 reduces them.

💡 Big Picture — formulas only go so far There is a "quadratic formula" for cubics (Cardano/Tartaglia, mid-1500s): substitute $y = x + a/3$ to kill the $x^2$ term, reducing $x^3 + ax^2 + bx + c = 0$ to $y^3 + dy + e = 0$, then solve a hidden quadratic in $u,v$. Quartics reduce to cubics. But for degree 5 and above, no general formula in radicals exists — Galois proved this in the 1800s, founding abstract algebra in the process. Quadratics sit at the boundary of what's "easy."
Quadratics are the language of accelerated motion. Constant acceleration gives position $x(t) = x_0 + v_0 t + \tfrac12 a t^2$ — a quadratic in time — so "when does the projectile land?" or "when does it reach height $h$?" is a quadratic equation, and the discriminant tells you whether it ever reaches a target at all (real vs. complex roots). The two roots of a projectile's $h(t)=0$ are its launch and landing times; their average, $-b/2a$ via Vieta, is exactly the time of peak height. The range equation and the maximum of a parabolic trajectory both come from completing the square (the vertex form $a(x-h)^2 + k$). The same algebra governs energy minima — near equilibrium a potential $U(x)$ looks like $U \approx \tfrac12 k(x-x_0)^2$, the quadratic whose curvature $k$ sets the frequency of simple harmonic motion, $\omega = \sqrt{k/m}$. And complex conjugate roots are not a curiosity: a damped oscillator's characteristic equation $m\lambda^2 + b\lambda + k = 0$ has discriminant $b^2 - 4mk$, whose sign distinguishes overdamped (real roots), critically damped ($D=0$), and underdamped (complex roots — actual oscillation).

Worked solution

If the roots are integers $r$ and $s$, then by Vieta's formulas $rs = 36$ and $r + s = -k$. Each unordered pair of integers with product $36$ produces one value of $k$.

The positive factor pairs of $36$ are $\{1,36\},\{2,18\},\{3,12\},\{4,9\},\{6,6\}$. Negating both factors gives the corresponding negative pairs.

Since the roots must be distinct, discard $\{6,6\}$ and $\{-6,-6\}$. That leaves $4$ distinct unordered pairs of each sign, for $4 \times 2 = 8$ pairs.

Each pair gives a different sum $r+s$, hence a different $k$, so there are $8$ values of $k$.

  • $\{-1, -2, -3\}$: $a = -6,\ b = 11$
  • $\{1, -1, 6\}$: $a = -6,\ b = -1$

Each ordered pair $(a, b)$ is distinct, giving $5$ valid pairs. (Sets like $\{1,1,-6\}$ are excluded because the roots must be distinct.)

2002 AMC 12BProblem 6 Vieta: roots are the coefficients

Suppose that $a$ and $b$ are nonzero real numbers, and that the equation $x^2+ax+b=0$ has solutions $a$ and $b$. Then the pair $(a, b)$ is

$\textbf{(A)}\ (-2,1) \quad \textbf{(B)}\ (-1,2) \quad \textbf{(C)}\ (1,-2) \quad \textbf{(D)}\ (2,-1) \quad \textbf{(E)}\ (4,4)$

Worked solution

By Vieta's formulas, if $a$ and $b$ are the roots of $x^2+ax+b=0$, then

$$a+b = -a \qquad \text{and} \qquad ab = b.$$

From $ab=b$ and $b\neq 0$, divide by $b$ to get $a=1$.

Substituting into $a+b=-a$: $\;1+b=-1$, so $b=-2$.

Both are nonzero, so $(a,b)=(1,-2)$.

Answer: (C) $(1,-2)$

2019 AMC 12BProblem 21 roots equal coefficients

How many quadratic polynomials with real coefficients are there such that the set of roots equals the set of coefficients? (For clarification: If the polynomial is $ax^2 + bx + c$, $a \neq 0$, and the roots are $r$ and $s$, then the requirement is that $\{a, b, c\} = \{r, s\}$.)

$\textbf{(A)}\ 3 \quad \textbf{(B)}\ 4 \quad \textbf{(C)}\ 5 \quad \textbf{(D)}\ 6 \quad \textbf{(E)}\ \text{infinitely many}$

Worked solution

By Vieta's formulas, $r + s = -\dfrac{b}{a}$ and $rs = \dfrac{c}{a}$. The set $\{a,b,c\}$ has the same two values as $\{r,s\}$, so among the three coefficients two must be equal. Split into cases by which coefficient repeats.

Case $b = c$: then $\{a,b\} = \{r,s\}$, so $\{r,s\} = \{a,b\}$. From $rs = c/a = b/a$ and $r+s = -b/a$, one finds $a = 1$, giving $\{r,s\}=\{1,b\}$. Solving yields $x^2 + x - 2$ (roots $1,-2$) and $x^2 - \tfrac{1}{2}x - \tfrac{1}{2}$ (roots $1,-\tfrac12$).

Case $a = b$: then $r+s = -b/a = -1$ and the values are $\{a,c\}$. This gives $-x^2 - x$ (i.e. $a=b=-1,\,c=0$), with roots $0,-1 = \{a,c\}$. ✓

Case $a = c$: then $rs = c/a = 1$ and $\{r,s\}=\{a,b\}$. Setting $b = 1/a$ and substituting into $r+s = a+b = -b/a$ gives $a^3 + a + 1 = 0$, which has exactly one real root $a \approx -0.682$, producing one more valid polynomial.

Collecting the distinct polynomials:

$$x^2 + x - 2,\quad x^2 - \tfrac12 x - \tfrac12,\quad -x^2 - x,\quad \text{and the } a^3+a+1=0 \text{ polynomial}.$$

That is $4$ in total. (Direct numerical solution of the full system also returns exactly these $4$.)

Answer: (B) 4

2022 AMC 12BProblem 20 polynomial remainders

Let $P(x)$ be a polynomial with rational coefficients such that when $P(x)$ is divided by the polynomial $x^2+x+1$, the remainder is $x+2$, and when $P(x)$ is divided by the polynomial $x^2+1$, the remainder is $2x+1$. There is a unique polynomial of least degree with these two properties. What is the sum of the squares of the coefficients of that polynomial?

$\textbf{(A)}\ 10 \quad \textbf{(B)}\ 13 \quad \textbf{(C)}\ 19 \quad \textbf{(D)}\ 20 \quad \textbf{(E)}\ 23$

Worked solution

The moduli $x^2+x+1$ and $x^2+1$ are coprime, so by the polynomial Chinese Remainder Theorem there is a unique remainder modulo their product $(x^2+x+1)(x^2+1)$ of degree at most $3$. That remainder is the least-degree polynomial $R(x) = ax^3+bx^2+cx+d$.

Modulo $x^2+x+1$ we use $x^2 \equiv -x-1$, hence $x^3 \equiv 1$. Then $R \equiv a + b(-x-1) + cx + d = (a-b+d) + (c-b)x$. Matching $x+2$: $\;c-b=1$ and $a-b+d=2$.

Modulo $x^2+1$ we use $x^2 \equiv -1$, hence $x^3 \equiv -x$. Then $R \equiv -ax - b + cx + d = (d-b) + (c-a)x$. Matching $2x+1$: $\;c-a=2$ and $d-b=1$.

From these: $a = b-1$, $c = b+1$, $d = b+1$, and substituting into $a-b+d=2$ gives $b=2$. So $(a,b,c,d) = (1,2,3,3)$ and $R(x) = x^3 + 2x^2 + 3x + 3$.

The sum of the squares of the coefficients is $1^2 + 2^2 + 3^2 + 3^2 = 1+4+9+9 = 23$.

Answer: (E) 23

2017 AMC 12BProblem 23 cubic, lines re-intersect, find f(0)

The graph of $y = f(x)$, where $f(x)$ is a polynomial of degree $3$, contains points $A(2,4)$, $B(3,9)$, and $C(4,16)$. Lines $AB$, $AC$, and $BC$ intersect the graph again at points $D$, $E$, and $F$, respectively, and the sum of the $x$-coordinates of $D$, $E$, and $F$ is $24$. What is $f(0)$?

$\textbf{(A)}\ -2 \quad \textbf{(B)}\ 0 \quad \textbf{(C)}\ 2 \quad \textbf{(D)}\ \dfrac{24}{5} \quad \textbf{(E)}\ 8$

Worked solution

The points lie on $y = x^2$ (since $4=2^2$, $9=3^2$, $16=4^2$). So $f(x) - x^2$ vanishes at $x = 2,3,4$, giving

$f(x) = a(x-2)(x-3)(x-4) + x^2$ for some constant $a$.

Chapter 7 — Special Factorizations & Clever Manipulations

A short list of algebraic identities turns brutal arithmetic into one-line answers. The trick is recognizing when a problem is secretly a difference of squares or a sum of cubes — and knowing how to manufacture the pattern when it isn't handed to you. We'll derive each factorization, then build a toolkit of manipulations for problems where finding the variables directly is hopeless.

7.1 The Special Factorizations

Why bother factoring numbers? Evaluate $10002^2 - 9998^2$. Squaring and subtracting is painful, but the difference of squares makes it trivial:

Difference-of-squares shortcut $$10002^2 - 9998^2 = (10002-9998)(10002+9998) = 4 \cdot 20000 = 80000.$$

Here are the four identities every problem-solver should know cold:

The Big Four $$a^2 - b^2 = (a-b)(a+b) \qquad a^2 + b^2 = (a+b)^2 - 2ab$$ $$a^3 - b^3 = (a-b)(a^2 + ab + b^2) \qquad a^3 + b^3 = (a+b)(a^2 - ab + b^2)$$

The "sum of squares" line isn't a true factorization — it's a rewrite, but an indispensable one. You'd write $x^2 + 2xy + y^2 = (x+y)^2$ when factoring, but only invoke $a^2+b^2 = (a+b)^2 - 2ab$ when it unlocks a further step. For the cubes, a memory aid: the sign in the binomial factor $(a \pm b)$ matches the sign in the original, and the quadratic factor's middle sign is the opposite.

Do not confuse the two cube factorizations. In $a^3 - b^3 = (a-b)(a^2 + ab + b^2)$ the middle term is $+ab$; in $a^3 + b^3 = (a+b)(a^2 - ab + b^2)$ it is $-ab$. Also note there is no real factorization of $a^2 + b^2$ into two real linear factors — that's why it gets the "rewrite" treatment instead.
📝 Example — verifying the difference of cubes

Expand the right side of $a^3 - b^3 = (a-b)(a^2 + ab + b^2)$:

$$(a-b)(a^2+ab+b^2) = a^3 + a^2b + ab^2 - a^2b - ab^2 - b^3 = a^3 - b^3.\;\checkmark$$

The four interior terms cancel in pairs, leaving exactly the difference of cubes.

📝 Example — where do the cube factorizations come from?

Every root of an expression gives a factor. Set $a^3 - b^3 = 0$; the obvious root is $a = b$, so $(a-b)$ must be a factor: $a^3 - b^3 = (a-b)\,f(a,b)$. Matching leading and trailing terms, $f$ needs an $a^2$ (since $a \cdot a^2 = a^3$) and a $b^2$. Trying $f = a^2 + b^2$:

$$(a-b)(a^2+b^2) = a^3 + ab^2 - a^2b - b^3,$$

which has two leftover terms. Adding $ab$ to $f$ supplies the missing $-ab^2$ (from $-b \cdot ab$) and $+a^2 b$ (from $a \cdot ab$) that cancel them. So $f = a^2 + ab + b^2$. The sum of cubes drops out the same way from the root $a = -b$.

📝 Example — chaining two identities

Factor $x^4 + x^2y^2 + y^4$. It's not yet a difference of squares, so manufacture one by completing the square:

$$x^4 + x^2y^2 + y^4 = (x^2+y^2)^2 - x^2y^2 = (x^2+y^2)^2 - (xy)^2.$$

Now apply difference of squares:

$$= (x^2 + y^2 - xy)(x^2 + y^2 + xy).$$
📝 Example — factorizations run backwards (rationalizing)

The hidden form of these identities is the conjugate. Since $(\sqrt9 + \sqrt8)(\sqrt9 - \sqrt8) = 9 - 8 = 1$, the reciprocal of $\sqrt9 + \sqrt8$ is simply $\sqrt9 - \sqrt8$. So a telescoping sum like

$$\frac{1}{\sqrt9+\sqrt8} + \frac{1}{\sqrt8+\sqrt7} + \cdots + \frac{1}{\sqrt4+\sqrt3}$$

becomes $(\sqrt9-\sqrt8)+(\sqrt8-\sqrt7)+\cdots+(\sqrt4-\sqrt3)$. Everything cancels but the ends: $\sqrt9 - \sqrt3 = 3 - \sqrt3$.

📝 Example — a disguised quadratic factor

If $\dfrac{1}{a+c} = \dfrac{1}{a} + \dfrac{1}{c}$, find $(a/c)^3$. Clear denominators by multiplying through by $ac(a+c)$:

$$ac = c(a+c) + a(a+c) \;\Longrightarrow\; a^2 + ac + c^2 = 0.$$

That left side is exactly the quadratic factor of $a^3 - c^3$. Multiply both sides by $(a-c)$:

$$(a-c)(a^2+ac+c^2) = a^3 - c^3 = 0,$$

so $a^3 = c^3$ and $(a/c)^3 = 1$.

7.2 Factoring $a^n - b^n$ and Higher Powers

The difference of squares and cubes are special cases of a general pattern. Since $a = b$ is always a root of $a^n - b^n = 0$, the factor $(a-b)$ always divides it:

General difference of $n$-th powers $$a^n - b^n = (a-b)\left(a^{n-1} + a^{n-2}b + a^{n-3}b^2 + \cdots + b^{n-1}\right)$$

The long factor is a sum of $n$ terms whose exponents on $a$ count down while those on $b$ count up — a geometric pattern. For odd $n$, $a = -b$ is also a root, so $(a+b)$ divides $a^n + b^n$ too. For even $n$, $a^n - b^n$ is doubly a difference of squares and factors repeatedly.

💡 Big Picture — factor in layers, then look for primes To factor a number like $2^{16} - 1$, peel off difference-of-squares layers: $2^{16}-1 = (2^8-1)(2^8+1) = (2^4-1)(2^4+1)(2^8+1) = (2^2-1)(2^2+1)(2^4+1)(2^8+1) = 3 \cdot 5 \cdot 17 \cdot 257$. Repeated factoring turns an intimidating number into its prime building blocks almost for free.
📝 Example — fully factoring $x^8 - y^8$

Apply difference of squares three times:

$$x^8 - y^8 = (x^4-y^4)(x^4+y^4) = (x^2-y^2)(x^2+y^2)(x^4+y^4)$$ $$= (x-y)(x+y)(x^2+y^2)(x^4+y^4).$$

Over the integers that's as far as it goes. But $x^4 + y^4$ can be split with real coefficients using the trick from 7.1: $x^4+y^4 = (x^2+y^2)^2 - 2x^2y^2 = (x^2 + y^2 - \sqrt2\,xy)(x^2 + y^2 + \sqrt2\,xy)$, giving five real factors.

📝 Example — a difference of cubes inside a difference of squares

Factor $x^9 - x$. Pull out $x$, then it's a difference of even powers:

$$x^9 - x = x(x^8 - 1) = x(x^4-1)(x^4+1) = x(x^2-1)(x^2+1)(x^4+1)$$ $$= x(x-1)(x+1)(x^2+1)(x^4+1).$$

Five polynomial factors plus the monomial $x$.

7.3 Manipulations: Raising Equations to Powers

Sometimes you're asked for $x^3 + \frac{1}{x^3}$ given only $x + \frac1x = 1$. Solving for $x$ gives the ugly $x = (1 \pm i\sqrt3)/2$ — cubing that is misery. The clever route never finds $x$ at all. Cube the given equation instead, using $(u+v)^3 = u^3 + 3u^2v + 3uv^2 + v^3$ with $u = x,\, v = \frac1x$:

Cube of a sum, applied to $x + 1/x$ $$\left(x + \tfrac1x\right)^3 = x^3 + 3x + \tfrac3x + \tfrac{1}{x^3} = x^3 + \tfrac{1}{x^3} + 3\left(x + \tfrac1x\right)$$

With $x + \frac1x = 1$: $\;1^3 = x^3 + \frac{1}{x^3} + 3(1)$, so $x^3 + \frac{1}{x^3} = 1 - 3 = -2$. No imaginary numbers required.

The same idea solves the broad family of problems where you're given two of $\{xy,\; x+y,\; x^2+y^2,\; x^3+y^3\}$ and asked for a third. The two workhorse identities:

The two workhorses $$(x+y)^2 = (x^2+y^2) + 2xy \qquad (x+y)^3 = (x^3+y^3) + 3xy(x+y)$$

Each links the sum, the product, and a sum-of-powers. Given any two, solve for the third — almost always finding $xy$ first.

To climb to the sixth power, go in steps: square then cube (or cube then square), not a single sixth power. Each step reuses the squaring/cubing tools, and at every stage you must include the cross terms — e.g. squaring $x + \frac1x$ produces a $+2$ you must not drop: $\left(x+\frac1x\right)^2 = x^2 + \frac{1}{x^2} + 2$.
📝 Example — $a^4 + b^4$ from $a+b$ and $a^2+b^2$

Given $a+b = 1$ and $a^2+b^2 = 2$, find $a^4 + b^4$. First square the sum to extract $ab$:

$$(a+b)^2 = a^2+b^2+2ab \;\Longrightarrow\; 1 = 2 + 2ab \;\Longrightarrow\; ab = -\tfrac12.$$

Now square $a^2+b^2$ to reach fourth powers:

$$(a^2+b^2)^2 = a^4 + b^4 + 2(ab)^2 \;\Longrightarrow\; 2^2 = a^4 + b^4 + 2\left(-\tfrac12\right)^2,$$

so $4 = a^4 + b^4 + \frac12$, giving $a^4 + b^4 = \frac72$.

📝 Example — sixth power in two steps

Find $x^6 + \dfrac{1}{x^6}$ given $x + \dfrac1x = 3$. Square first:

$$\left(x+\tfrac1x\right)^2 = x^2 + \tfrac{1}{x^2} + 2 = 9 \;\Longrightarrow\; x^2 + \tfrac{1}{x^2} = 7.$$

Cubing a square gives a sixth power, so cube the last equation:

$$\left(x^2 + \tfrac{1}{x^2}\right)^3 = x^6 + \tfrac{1}{x^6} + 3\left(x^2 + \tfrac{1}{x^2}\right) = 7^3 = 343.$$

Thus $x^6 + \frac{1}{x^6} = 343 - 3(7) = 343 - 21 = 322$.

📝 Example — the reciprocal-sum shortcut

Find $\dfrac1A + \dfrac1B$ given $A+B = 6$ and $AB = 3$. Combine over a common denominator:

$$\frac1A + \frac1B = \frac{A+B}{AB} = \frac63 = 2.$$

Memorize this one — $\frac1A + \frac1B = \frac{A+B}{AB}$ appears constantly.

💡 Big Picture — Euler's four-square identity The crown jewel of clever manipulation: the product of two sums of four squares is itself a sum of four squares. Writing $m = x_1^2 + x_2^2 + x_3^2 + x_4^2$ and $n = y_1^2 + y_2^2 + y_3^2 + y_4^2$, Euler found that $mn$ equals $(x_1y_1 + x_2y_2 + x_3y_3 + x_4y_4)^2 + (x_1y_2 - x_2y_1 + x_3y_4 - x_4y_3)^2 + \cdots$ (four squared terms in all). This single identity — said to have eluded Euler for twelve years — is the engine behind Lagrange's theorem that every positive integer is a sum of four squares: prove it for primes, then multiply your way up.
Factorization and series rewrites are everywhere in physics. The small-angle and binomial approximations $(1+x)^n \approx 1 + nx$ come from truncating the same algebraic expansions used here — they turn the relativistic energy $E = mc^2(1 - v^2/c^2)^{-1/2}$ into $mc^2 + \frac12 mv^2 + \cdots$, recovering classical kinetic energy as the leading correction. Perturbation theory in quantum mechanics expands energies in powers of a small coupling, exactly the "raise the equation to powers and keep the cross terms" move. And difference-of-squares factoring of an energy difference, $E_f^2 - E_i^2 = (E_f - E_i)(E_f + E_i)$, repeatedly simplifies scattering and relativistic-momentum algebra where $E^2 = (pc)^2 + (mc^2)^2$.

Chapter 21 — Functions

A function is a machine: feed it one input, it returns exactly one output. That single idea — one input, one output — underlies everything in this chapter, from graphing and domains to composing, inverting, and transforming functions. Master the machine metaphor and the rest is bookkeeping.

21.1 Welcome to the Machine

Take the line $-3x + 4y = 12$. Solving for $y$ gives $y = \tfrac{3}{4}x + 3$, so each $x$ we feed in produces one and only one $y$. That is the defining property of a function. To emphasize that the rule has a life of its own we name it, say $f$, and write $f(x)$ ("$f$ of $x$"):

Function notation $$f(x) = \tfrac{3}{4}x + 3$$

A function returns one output per input. So $\sqrt{x}$ as written is not a function unless we specify the positive root — $\sqrt{1}$ would otherwise be ambiguous between $1$ and $-1$. To evaluate, you just substitute and "turn the crank."

$f(x)$ means "$f$ evaluated at $x$," not "$f$ times $x$." And the input variable is a placeholder: $f(t)$, $h(y)$, $g(\text{box})$ all describe the same rule — whatever goes in the parentheses gets fed through the machine.
📝 Example — turn the crank

If $r(x) = \dfrac{x}{x^2 + 1}$, then we substitute each input directly:

$$r(-1) = \frac{-1}{(-1)^2+1} = -\tfrac{1}{2}, \quad r(0) = \frac{0}{1} = 0, \quad r(2) = \frac{2}{2^2+1} = \tfrac{2}{5}.$$
📝 Example — the input can be an expression

Given $f(x+1) = x^3 + 6x^2 + x + 3$, find $f(4)$. We need the input $x+1$ to equal $4$, so set $x = 3$:

$$f(4) = 3^3 + 6\cdot 3^2 + 3 + 3 = 27 + 54 + 3 + 3 = 87.$$

21.2 Graphing Functions

Graph a function exactly as you would an equation: the horizontal axis carries the independent variable $x$, the vertical axis carries the output (labeled $f(x)$ instead of $y$). Plot enough points $\big(x, f(x)\big)$ to see the shape, then fill it in.

Vertical line test $$\text{A curve is a function} \iff \text{no vertical line meets it more than once.}$$

This is just the "one output per input" rule drawn out: a vertical line is a single $x$, and the curve may cross it only once. Note the asymmetry — two different $x$'s may share one $f(x)$ (a horizontal line can hit the curve many times), but one $x$ can never map to two outputs.

📝 Example — graphing $f(x) = x^2$

Plug in values and plot. $f(0) = 0$; $f(\pm 1) = 1$; $f(\pm 2) = 4$; $f(\pm 3) = 9$. The points trace the familiar upward parabola, symmetric about the $y$-axis. Notice $x = 2$ and $x = -2$ both give $4$ — allowed — but no single $x$ gives two outputs.

21.3 Domain and Range

Consider $f(x) = \dfrac{1}{1 - x^2}$. At $x = \pm 1$ the denominator is $0$, so those inputs are forbidden. The set of allowable inputs is the domain; the set of all resulting outputs is the range.

Definitions $$\textbf{domain} = \{\text{allowed inputs }x\} \qquad \textbf{range} = \{\text{all outputs }f(x)\}$$

Unless told otherwise, assume inputs and outputs are real. So you exclude inputs that (a) divide by zero, or (b) take an even root of a negative number, or (c) take a log of a non-positive number. The range is usually found by common sense about what outputs are achievable.

A negative number is not in the domain of $\sqrt{x}$ (no real output), and a non-positive number is not in the domain of $\log x$. Always scan a formula for division, even roots, and logs before declaring "all reals."
📝 Example — domain of $\log x$, range of $2^x$

$\log x$ asks for the $y$ with $10^y = x$. A positive power result is achievable only for $x > 0$, so the domain of $\log x$ is the positive reals. For $2^x$, a positive base to any real power is positive and can be made as small or large as we like, so the range of $2^x$ is the positive reals (output never reaches $0$).

21.4 Composing Functions

Feed the output of one function into another. Running $f$ twice gives $f(f(x))$; using a second function $g$ on $f$'s output gives $g(f(x))$, also written $g \circ f$. At every stage the intermediate value must lie in the next function's domain.

Composition $$(g \circ f)(x) = g\big(f(x)\big) \qquad f^{n}(x) = \underbrace{f(f(\cdots f(x)\cdots))}_{n\ \text{copies of }f}$$

Work from the inside out. If $f(x) = 6x^2$ and $g(x) = \dfrac{x}{\sqrt{x}+1}$, then $(g \circ f)(x) = g(6x^2) = \dfrac{6x^2}{\sqrt{6x^2}+1} = \dfrac{6x^2}{\sqrt{6}\,x + 1}$ (for $x>0$).

$f^{n}(x)$ (iterated composition) is not $[f(x)]^n$ (the $n$th power). With $f(x)=x^2$: $f^3(x) = ((x^2)^2)^2 = x^8$, but $[f(x)]^3 = (x^2)^3 = x^6$. The notation $\sin^2 x = (\sin x)^2$ is a stubborn exception adopted only because $\sin(\sin x)$ is so rare. Also, composition is not commutative: $f\circ g \neq g \circ f$ in general.
📝 Example — iterating an "add 2" machine

If $f(x) = x + 2$, each pass adds $2$. So $f^6(x) = ((((((x+2)+2)+2)+2)+2)+2) = x + 12$, and in general $f^n(x) = x + 2n$.

21.5 Even and Odd Functions

Some functions carry symmetry that simplifies everything. The parabola $f(x)=x^2$ is mirror-symmetric across the $y$-axis; $f(x)=x^3$ looks the same after a $180^\circ$ rotation about the origin. These are the two classic symmetries:

Even and odd $$\textbf{even:}\ \ f(-x) = f(x) \qquad\qquad \textbf{odd:}\ \ f(-x) = -f(x)$$

Even = symmetric about the $y$-axis (the $f(-x)=f(x)$ identity). Odd = symmetric under $180^\circ$ rotation about the origin ($f(-x)=-f(x)$). For a polynomial, it is even when every term has even degree, odd when every term has odd degree, and neither when degrees are mixed. Most functions are neither.

📝 Example — odd functions pass through the origin

If $f$ is odd, set $x = 0$ in $f(-x) = -f(x)$: $f(0) = -f(0)$, so $2f(0) = 0$ and $f(0) = 0$. An odd function (if defined at $0$) must pass through the origin. An even function gets only $f(0) = f(0)$, no restriction.

21.6 Some Special Functions

A few important functions don't fit a tidy formula family and must be handled case by case.

Absolute value. $|x|$ returns the distance from $x$ to $0$ — that is, $x$ itself if $x \ge 0$ and $-x$ if $x < 0$. So $|{-3}| = 3$ and $|0| = 0$. Distance between numbers: $|x - y| < 2$ means $x$ and $y$ are within $2$ of each other.

Splitting an absolute value $$|M| = N \iff M = N \ \text{ or }\ M = -N$$

Floor and ceiling. The floor $\lfloor x \rfloor$ is the greatest integer $\le x$; the ceiling $\lceil x \rceil$ is the least integer $\ge x$. Thus $\lfloor 4.3 \rfloor = 4$, $\lfloor -3.6 \rfloor = -4$, $\lceil 4.3 \rceil = 5$. The fractional part is $\{x\} = x - \lfloor x \rfloor$, always in $[0,1)$. These functions are discontinuous — their graphs jump at each integer (you must lift your pen).

Piecewise functions. When a function behaves differently on different regions, define it case by case. Absolute value itself is secretly piecewise:

Piecewise form of $|x|$ $$|x| = \begin{cases} x, & x \ge 0 \\ -x, & x < 0 \end{cases}$$

Make sure the cases together cover the whole intended domain, with no gaps or overlaps.

$\sqrt{x^2} = |x|$, not $x$. The radical always returns the non-negative root, so for $x = -5$ we get $\sqrt{25} = 5 = |-5|$. Forgetting the absolute value here is a classic sign error.
📝 Example — solving $|x^2 - 3x| = 4$

Split into two equations. Case $x^2 - 3x = 4 \Rightarrow x^2 - 3x - 4 = 0 \Rightarrow (x-4)(x+1)=0 \Rightarrow x = 4, -1$. Case $x^2 - 3x = -4 \Rightarrow x^2 - 3x + 4 = 0$, whose discriminant $9 - 16 < 0$ gives no real roots. So the real solutions are $x = 4$ and $x = -1$.

21.7 Inverse Functions

An inverse undoes a function: if $f$ sends $a$ to $b$, then $f^{-1}$ sends $b$ back to $a$. It exists only when $f$ is one-to-one (each output comes from a single input — the horizontal line test), and its domain and range are those of $f$ swapped.

Inverse function $$f^{-1}\big(f(x)\big) = x \quad\text{and}\quad f\big(f^{-1}(x)\big) = x$$

To find $f^{-1}$: write $y = f(x)$, swap $x$ and $y$, and solve for $y$. Graphically, $f^{-1}$ is the reflection of $f$ across the line $y = x$.

The inverse notation $f^{-1}$ does not mean the reciprocal $\dfrac{1}{f}$, nor the iterate from §21.4. Yet another overloaded "$-1$" — read it from context. And an inverse exists only if $f$ is one-to-one; $f(x)=x^2$ has no inverse over all reals (both $\pm a$ give $a^2$) unless you restrict the domain.
📝 Example — inverting a linear function

Let $f(x) = \tfrac{3}{4}x + 3$. Set $y = \tfrac{3}{4}x + 3$, swap to $x = \tfrac{3}{4}y + 3$, and solve: $x - 3 = \tfrac{3}{4}y$, so $y = \tfrac{4}{3}(x - 3)$. Thus $f^{-1}(x) = \tfrac{4}{3}x - 4$. Check: $f^{-1}(f(0)) = f^{-1}(3) = \tfrac{4}{3}\cdot 3 - 4 = 0$. ✓

21.8 Transforming a Function

From one function you can build many by four basic moves. Test them all on $f(x) = |x|$ with $a = 2$ and watch the graph.

The four transformations $$f(x+a):\ \text{shift left by } a \qquad f(x)+a:\ \text{shift up by } a$$ $$a\,f(x):\ \text{vertical stretch by } a \qquad f(ax):\ \text{horizontal shrink by } a$$

The two horizontal moves feel "backwards." For $f(x+2)$: the new output at $x$ equals the old output at $x+2$, a point $2$ to the right, so the graph slides $2$ to the left. Likewise $f(2x)$ compresses horizontally by $2$ because $g(1)=f(2)$, $g(2)=f(4)$, etc. Vertical moves act as written: $f(x)+2$ lifts the curve up $2$, and $2f(x)$ doubles every height.

A vertical stretch and a horizontal shrink are not generally the same, even though $2|x|$ and $|2x|$ happen to coincide. Counterexample with the square root: $g(x) = 2\sqrt{x}$ gives $g(8) = 4\sqrt{2}\approx 5.66$, but $h(x) = \sqrt{2x}$ gives $h(8) = \sqrt{16} = 4$. Different functions.
📝 Example — reading off a transformation

Start with $f(x) = |x|$. Then $g(x) = -|x+1| + 4$ is, in order: shift left $1$ ($|x+1|$), reflect over the $x$-axis ($-|x+1|$, since the multiplier $a=-1$ flips heights), then shift up $4$. The result is an upside-down "V" with its peak at $(-1, 4)$.

💡 Big Picture — functions are the language of relationships Almost every quantitative law in science is a function: position as a function of time, pressure as a function of volume, cost as a function of quantity. The transformations above let you take one known shape and adapt it to new data without starting over — shifting an axis, rescaling units, or flipping orientation. Recognizing that two graphs are the "same" curve under a shift or stretch is exactly how physicists reuse a single solved problem across endless variations.
Functions are the natural objects of physics. A wavefunction $\psi(x)$ encodes a quantum particle's state, and its parity — whether $\psi(-x) = \psi(x)$ (even) or $\psi(-x) = -\psi(x)$ (odd) — is a conserved symmetry that dictates which transitions are allowed. Potential energy functions $U(x)$ govern motion, with stable equilibria at minima and force given by $F = -dU/dx$; an even, symmetric well like $U(x) = \tfrac{1}{2}kx^2$ produces the harmonic oscillator. The four transformations are coordinate changes in disguise: shifting $f(x) \to f(x - a)$ is choosing a new origin, scaling $f(ax)$ is changing units, and reflections $f(-x)$ implement parity. Function composition is how transformations chain — applying one Lorentz boost then another, or mapping a field through successive coordinate systems — and inverse functions turn a forward law (input $\to$ measurement) into the reconstruction (measurement $\to$ input) at the heart of every inference from data.

Chapter 22 — Inequalities

Once we stop demanding that two sides be equal and allow them to be ordered, we enter a new realm of mathematics. Inequalities behave like equations in many ways — but a few crucial rules differ, and one tiny statement, $x^2 \ge 0$, turns out to be a surprisingly powerful tool.

22.1 What They Do

There are two flavors of inequality sign. A strict inequality ($<$ or $>$) says the larger (open) side is definitely bigger — e.g. $3 < 4$, $-1000 < -100$. A nonstrict inequality ($\le$ or $\ge$) has a bar underneath and allows equality too: $1 \ge 0$ is true even though $1 \ne 0$. Writing $x, y, z > -17$ means each variable independently beats $-17$ — it says nothing about how $x$, $y$, $z$ compare to one another.

In some ways inequalities act just like equations. You may add or subtract the same thing on both sides, and you may chain them:

Safe operations $$x < y \;\Longrightarrow\; x \pm c < y \pm c \qquad\qquad a<c,\; b<d \;\Longrightarrow\; a+b < c+d$$

Multiplication is where things change. Multiplying $a<c$ and $b<d$ to get $ab<cd$ is valid only when all the quantities are positive. With positives, $x > y > 0$ also gives $x^2 > y^2$, $x^3 > y^3$, and $\sqrt{x} > \sqrt{y}$.

The sign-flip trap. Obviously $2 > 1$, but multiplying both sides by $-1$ gives $-2 > -1$, which is false. When you multiply or divide both sides by a negative number, you must reverse the inequality sign: $x < y \implies -x > -y$. Multiplying by $0$ is illegal (it collapses both sides to $0$); dividing by $0$ is forbidden as always.
📝 Example — taking reciprocals reverses the sign

If one side is negative and the other positive, signs are preserved: $-2 < 3$ gives $-\tfrac12 < \tfrac13$. But if both sides have the same sign, the reciprocal flips the inequality. From $2 < 3$, divide by $2$: $1 < \tfrac32$; divide by $3$: $\tfrac13 < \tfrac12$. Hence $2 < 3 \implies \tfrac12 > \tfrac13$.

Rule: taking reciprocals reverses the sign whenever both sides are positive, or both negative.

22.2 Linear Inequalities

A linear inequality contains only first powers of the variables, e.g. $x > 4y + 3$ (linear) versus $x^2 > 1/y$ (not). In one variable they are easy — $x < -3$ is just a ray on the number line, drawn with an open circle at $-3$ (a filled circle if the inequality were $\le$).

In two variables, the trick is to start from the boundary equality. Rewrite $x > 4y+3$ as $x - 4y - 3 > 0$ and graph the line $x - 4y - 3 = 0$. Every parallel line $x - 4y - 3 = k$ sits on one side of the boundary according to the sign of $k$, so the solution is an entire half-plane.

Half-plane method $$\text{Boundary: } x - 4y - 3 = 0 \quad\text{(dashed if strict, solid if }\ge\text{)}$$ $$\text{Shade the side where } x - 4y - 3 > 0.$$

Which side? Just test a point. For $x > 4y+3$ try $(0,0)$: is $0 > 4(0)+3$? No. So $(0,0)$ is not a solution — shade the opposite side. Because the inequality is strict, the boundary line itself is excluded and drawn dashed.

📝 Example — a system of two inequalities

To solve $x+y > 0$ and $x-y < 0$ simultaneously, graph each half-plane and take the overlap (intersection). Both boundaries pass through the origin; the common region is the wedge where both conditions hold. If a strict $<$ became $\le$, that boundary ray would turn solid and join the solution.

22.3 Quadratic Inequalities

For a one-variable quadratic inequality like $x^2 - x - 6 > 0$, start exactly as with a quadratic equation: find the zeros by factoring.

Sign analysis $$x^2 - x - 6 > 0 \;\Longleftrightarrow\; (x-3)(x+2) > 0$$

A product is positive when its two factors have the same sign (both $+$ or both $-$) and negative when they have opposite signs. The factors change sign at the roots $x = -2$ and $x = 3$, which split the line into three regions. Test one point per region:

Sign chart for $(x-3)(x+2)$ $$\begin{array}{c|ccc} & x<-2 & -2<x<3 & x>3 \\\hline x+2 & - & + & + \\ x-3 & - & - & + \\\hline \text{product} & + & - & + \end{array}$$

So $(x-3)(x+2) > 0$ holds when $x < -2$ or $x > 3$. Had the sign been $< 0$ we would instead pick the single middle region where the factors disagree. The same sign-analysis machinery solves any factored polynomial inequality.

Answers can be written three ways. As a compound inequality: $x < -2$ or $x > 3$. Or in interval notation, where $[\,]$ includes an endpoint and $(\,)$ excludes it:

Interval notation $$x^2 - x - 6 > 0 \;\Longrightarrow\; (-\infty,\,-2)\,\cup\,(3,\,\infty)$$

The $\cup$ ("union") replaces "or," and we always pair $\infty$ with a parenthesis since infinity is not a real number to be included. (If the inequality were $\ge$, the endpoints $-2$ and $3$ would join the solution and we'd use square brackets there.)

Never cross-multiply an inequality with a variable in the denominator. In $\dfrac{2}{x+1} \ge \dfrac{3}{x-3}$ you can't multiply through by $x-3$ — you don't know its sign. Instead move everything to one side and combine: $$\frac{2}{x+1} - \frac{3}{x-3} \ge 0 \;\Longrightarrow\; \frac{-x-9}{(x+1)(x-3)} \ge 0.$$ Now do sign analysis on all three linear factors (numerator and denominator alike). The solution is $(-\infty,-9] \cup (-1,3)$: $x=-9$ is included (numerator zero makes the fraction $0$, allowed by $\ge$), while $x=-1$ and $x=3$ are excluded (they make the denominator zero).
📝 Example — disguised quadratic in $x^4$

To solve $x^4 - 5x^2 + 6 > 0$, substitute $y = x^2$: $y^2 - 5y + 6 = (y-2)(y-3) > 0$, so $y < 2$ or $y > 3$. Back-substitute: $x^2 < 2$ gives $-\sqrt2 < x < \sqrt2$, and $x^2 > 3$ gives $x < -\sqrt3$ or $x > \sqrt3$. Combined: $(-\infty,-\sqrt3)\cup(-\sqrt2,\sqrt2)\cup(\sqrt3,\infty)$.

22.4 Absolute-Value Inequalities

These reduce to the quadratic case once you isolate the absolute value and then strip the bars. Take $4|x+3| + 3 \ge 9$. Subtract $3$ and divide by $4$:

Isolate first $$4|x+3| + 3 \ge 9 \;\Longrightarrow\; |x+3| \ge \tfrac32$$

Now the key split. The two cases hinge on which side of the inequality the absolute value sits:

Removing the bars $$|u| \ge c \;\Longleftrightarrow\; u \ge c \;\text{ or }\; u \le -c \qquad\text{(outside)}$$ $$|u| \le c \;\Longleftrightarrow\; -c \le u \le c \qquad\qquad\text{(between)}$$

For our problem, $|x+3| \ge \tfrac32$ becomes $x+3 \ge \tfrac32$ or $x+3 \le -\tfrac32$, i.e. $x \ge -\tfrac32$ or $x \le -\tfrac92$ — in interval notation $\left(-\infty,-\tfrac92\right] \cup \left[-\tfrac32,\infty\right)$.

Watch the flipped sign in the second case. $|u|\ge c$ means $u$ is far from $0$, which includes the large negative branch $u \le -c$ — note the $\le -c$, not $\ge -c$. Reversing this is the most common absolute-value error.
📝 Example — the "between" case

$|x+3| \le \tfrac32$ unpacks to the single chain $-\tfrac32 \le x+3 \le \tfrac32$. Subtract $3$ from all three parts: $-\tfrac92 \le x \le -\tfrac32$, the interval $\left[-\tfrac92,-\tfrac32\right]$. When the absolute value is on the small side, you get one bounded interval; on the large side, you get two outward rays.

22.5 A Trivial Inequality

The deepest classical inequalities — Arithmetic-Geometric Mean (AM-GM) and Cauchy-Schwarz — wait until Volume 2. But one almost embarrassingly simple statement does enormous work right now: for every real number $x$,

The Trivial Inequality $$x^2 \ge 0, \qquad\text{with equality iff } x = 0.$$

Its power is that you can apply it to a cleverly chosen square. For instance, it proves the two-variable AM-GM relation. We work backwards from the goal to a known truth:

Proving $\frac{x^2+y^2}{2} \ge xy$ $$\frac{x^2+y^2}{2} \ge xy \;\Longleftrightarrow\; x^2+y^2 \ge 2xy \;\Longleftrightarrow\; x^2 - 2xy + y^2 \ge 0 \;\Longleftrightarrow\; (x-y)^2 \ge 0.$$

The final line is the Trivial Inequality, hence true; since every step is reversible (we only multiplied by the positive constant $2$ and rearranged), the original statement holds, with equality exactly when $x = y$.

A second, very practical use: finding the minimum of a quadratic by completing the square. For $x^2 + 5x + 1$,

Minimum via complete-the-square $$x^2 + 5x + 1 = \left(x + \tfrac52\right)^2 - \tfrac{21}{4} \;\ge\; -\tfrac{21}{4},$$

because the squared term is $\ge 0$ by the Trivial Inequality. The minimum value $-\tfrac{21}{4}$ is attained exactly when $x + \tfrac52 = 0$, i.e. $x = -\tfrac52$. This is how you extremize a parabola without any calculus.

Backwards proofs must be reversible. Arriving at a true statement is only a valid proof if every step can be run in reverse. A step that isn't reversible — like squaring both sides, which can introduce false solutions — breaks the chain. Always check that each "$\Longleftrightarrow$" really goes both ways.
📝 Example — maximizing a downward parabola

A ball's height is $-t^2 + 60t + 700$. Complete the square: $-(t^2 - 60t) + 700 = -\left[(t-30)^2 - 900\right] + 700 = -(t-30)^2 + 1600$. Since $-(t-30)^2 \le 0$, the height is at most $\boxed{1600}$, reached at $t = 30$.

💡 Big Picture — inequalities are how mathematicians bound the unknown Equations pin a quantity to one exact value; inequalities fence it in. Most of analysis — limits, convergence, error estimates — is built not on equalities but on inequalities like $|a_n - L| < \varepsilon$. The trick of replacing a hard quantity by a square you know is nonnegative, then reading off a bound, is the seed of the entire theory of optimization: AM-GM, Cauchy-Schwarz, and the calculus of variations all generalize this one move.
Inequalities govern physics as tightly as equations do. Stability of an equilibrium means the potential energy is at a minimum — a Trivial-Inequality statement, $U(x) \ge U(x_0)$ near $x_0$ — which is why completing the square diagnoses stable versus unstable points. The Heisenberg Uncertainty Principle, $\Delta x\,\Delta p \ge \tfrac{\hbar}{2}$, is literally an inequality placing a hard floor on simultaneous knowledge of position and momentum. Variational bounds let physicists estimate ground-state energies from above without solving the problem exactly, and AM-GM underlies countless optimization arguments — e.g. that a fixed-perimeter rectangle has maximum area when it is a square, since $\sqrt{xy} \le \tfrac{x+y}{2}$. Even Bell's inequality, a bound on correlations any "common-sense" local theory must obey, was the experimentally tested line that quantum mechanics provably crosses.

Chapter 23 — Operations and Relations

So far every "$+$" and "$\times$" has felt automatic. This chapter steps back and asks what an operation actually is — a rule that turns inputs into an output — and which structural properties (commutativity, associativity, identities, inverses) those rules may or may not have. The same lens applies to relations like $=$, $\parallel$, and $\cong$. This is your first taste of abstract algebra.

23.1 What Is an Operation?

An operation is any action performed on a set of quantities. Addition, subtraction, multiplication, and division are all operations. The most important kind takes two inputs and is called a binary operation. Most have symbols ($+$, $-$, $\times$, $\div$, $\ast$, $\circ$), but some don't — exponentiation is written as a superscript, as in $2^4$.

You can define an operation any way you like. The key skill is mechanical: once a formula is given, just drop the numbers into their slots.

A custom operation $$\text{Define } a\,\#\,b = a + b - ab. \qquad\text{Then}\qquad 4\,\#\,3 = 4 + 3 - 4(3) = -5.$$

When several operations are stacked, the usual conventions apply: work innermost parentheses first, then all exponentiations, then multiplications/divisions left-to-right, then additions/subtractions left-to-right.

A defined operation's symbol carries no meaning of its own — everything comes from the formula. Don't assume $\#$ behaves like $+$ or $\times$ (it may not be commutative, associative, or anything else). Always re-read the definition before each step.
📝 Example 23-1 — nested custom operation

If $a\,\#\,b = a + b - \dfrac{3a}{b}$, find $(1\,\#\,2)\,\#\,3$. Evaluate the inner parentheses first:

$$1\,\#\,2 = 1 + 2 - \frac{3(1)}{2} = 3 - \frac{3}{2} = \frac{3}{2}.$$

Now apply $\#$ again with the result and $3$:

$$\frac{3}{2}\,\#\,3 = \frac{3}{2} + 3 - \frac{3\left(\tfrac{3}{2}\right)}{3} = \frac{3}{2} + 3 - \frac{3}{2} = 3.$$
✏️ Exercise 23-A — evaluate a defined operation

With $a\,\ast\,b = 2a - b$, find $3\,\ast\,2$. Then with $x\,@\,y = \dfrac{x+y}{x-y}$, find $5\,@\,3$.

23.2 Properties of Operations

Properties let us classify and manipulate operations. To prove a property fails, a single counterexample is enough; to claim it holds, you need it to be true for all inputs.

The core properties of an operation $\#$ $$\textbf{Commutative:}\quad a\,\#\,b = b\,\#\,a$$ $$\textbf{Associative:}\quad a\,\#\,(b\,\#\,c) = (a\,\#\,b)\,\#\,c$$ $$\textbf{Distributive over } @:\quad a\,\#\,(b\,@\,c) = (a\,\#\,b)\,@\,(a\,\#\,c)$$

Addition and multiplication are both commutative and associative; subtraction and division are neither. Associativity is what lets us drop parentheses and just write $a\,\#\,b\,\#\,c$. The most useful distributive law is multiplication over addition, e.g. $2(3+1) = 2(3) + 2(1) = 8$; running it backwards to compress an expression is called factoring.

A counterexample disproves a property forever. Subtraction is not commutative because $1 - 2 = -1$ but $2 - 1 = 1$. Division is not associative: $(8 \div 4)\div 2 = 1$ while $8 \div (4 \div 2) = 4$.
📝 Example 23-2 — distributive law in reverse

Evaluate $45(33333) + 45(66667)$. Factor out the common $45$ instead of multiplying twice:

$$45(33333) + 45(66667) = 45(33333 + 66667) = 45(100000) = 4{,}500{,}000.$$
📝 Example 23-3 — distributing a product of binomials

Use distributivity twice to expand $(x-1)(x-2)$:

$$(x-1)(x-2) = x(x-2) - 1(x-2) = x^2 - 2x - x + 2 = x^2 - 3x + 2.$$

23.3 Identities and Inverses

An operation $\#$ has an identity $e$ if $b\,\#\,e = e\,\#\,b = b$ for all $b$ — applying it changes nothing. The identity of addition is $0$ ($x+0=x$); the identity of multiplication is $1$. Once an identity exists, the inverse of $a$ is the element $b$ with $a\,\#\,b = b\,\#\,a = e$. Inversion is symmetric: if $b$ inverts $a$, then $a$ inverts $b$.

Identity and inverse $$b\,\#\,e = e\,\#\,b = b \;\;(\text{for all } b) \qquad\qquad a\,\#\,b = b\,\#\,a = e$$

Two clean theorems hold: an operation has at most one identity, and under an associative operation each element has at most one inverse.

📝 Example 23-4 — finding an identity element

Does $a\,\#\,b = 2ab + a + b$ have an identity? Look for $e$ with $e\,\#\,b = b$ for all $b$. Setting $a = e$: we need $2eb + e + b = b$, i.e. $2eb + e = 0$ for every $b$. That forces $e = 0$. Check: $0\,\#\,b = 0 + 0 + b = b$ and $b\,\#\,0 = b$. So the identity is $\boxed{0}$.

📝 Example 23-5 — the inverse is unique (uses associativity)

Suppose $a$ had two inverses $b$ and $c$, so $a\,\#\,b = e$ and $c\,\#\,a = e$. Apply $c$ to the first:

$$c\,\#\,(a\,\#\,b) = c\,\#\,e = c.$$

By associativity the left side is $(c\,\#\,a)\,\#\,b = e\,\#\,b = b$. Hence $b = c$ — there is only one inverse.

💡 Big Picture — these four ingredients make a group When a set with an operation is associative, has an identity, and gives every element an inverse, mathematicians call it a group. Groups are the central object of abstract algebra — the generalization of ordinary algebra where you study operations on arbitrary sets rather than on numbers. Group theory underlies modern particle physics and even proves that fifth-degree polynomial equations have no general solution by radicals.

23.4 Relations

A relation specifies how two objects are connected. Equality ($=$) is the most basic, but objects need not be numbers: parallelism ($\parallel$), perpendicularity ($\perp$), congruence ($\cong$), $>$, and $<$ are all relations, and so are everyday ones like friendship. Three properties matter most.

The three key properties of a relation $\sim$ $$\textbf{Reflexive:}\quad a \sim a \;\;(\text{for all } a)$$ $$\textbf{Symmetric:}\quad a \sim b \;\Rightarrow\; b \sim a$$ $$\textbf{Transitive:}\quad a \sim b \text{ and } b \sim c \;\Rightarrow\; a \sim c$$

Equality has all three. Greater-than ($>$) is transitive but not reflexive (no number exceeds itself) and not symmetric ($x>y$ does not give $y>x$). Perpendicularity is symmetric but neither reflexive nor transitive. A relation with all three properties is called an equivalence relation; it behaves in most ways like $=$.

Don't confuse the three properties. Symmetry is about swapping the two objects; transitivity is about chaining through a middle object. A relation can have one without the other — perpendicularity is symmetric ($\ell \perp m \Rightarrow m \perp \ell$) yet not transitive ($\ell \perp m$ and $m \perp n$ make $\ell \parallel n$, not $\ell \perp n$).
📝 Example 23-6 — is congruence an equivalence relation?

Triangle congruence $\cong$ is reflexive ($\triangle ABC \cong \triangle ABC$), symmetric ($\triangle ABC \cong \triangle DEF \Rightarrow \triangle DEF \cong \triangle ABC$), and transitive (two triangles each congruent to a third are congruent to each other). All three hold, so congruence is an equivalence relation.

✏️ Exercise 23-D — classify the relations

Which of these are equivalence relations: equality, congruence, perpendicularity, greater-than-or-equal-to ($\ge$), similarity, less-than?

Equality, congruence, and similarity qualify. $\perp$ fails reflexivity/transitivity; $\ge$ and $<$ fail symmetry.

Operations and their symmetries are the language of modern physics. The symmetry transformations of a system (rotations, translations, gauge transformations) form a group under composition, and Noether's theorem ties each continuous symmetry to a conserved quantity — rotational symmetry $\to$ angular momentum, time-translation symmetry $\to$ energy. The non-abelian (non-commutative) groups $\mathrm{SU(2)}$ and $\mathrm{SU(3)}$ organize the Standard Model. Even familiar vector operations break the "nice" properties: the cross product is neither commutative ($\vec a \times \vec b = -\,\vec b \times \vec a$) nor associative ($\vec a \times (\vec b \times \vec c) \neq (\vec a \times \vec b)\times \vec c$), which is exactly why torque and angular momentum require such careful bookkeeping.

Chapter 24 — Sequences and Series

A sequence is just a list of numbers; a series is what you get when you add a sequence's terms together. The magic of this chapter is that two famous families — arithmetic (constant difference) and geometric (constant ratio) — have closed-form sums you can derive with one clever trick each, and that some infinite series add up to a finite number.

24.1 Arithmetic Sequences & Series

In an arithmetic sequence each term differs from the previous one by a fixed common difference $d$. Starting from a first term $a$, the sequence is $a,\ a+d,\ a+2d,\ a+3d,\dots$ The $n$-th term sits $(n-1)$ steps from the first:

$n$-th term of an arithmetic sequence $$a_n = a + (n-1)d$$

To sum the first $n$ terms, use the reverse-and-add trick. Write the sum $S$ forwards, then again backwards, and add the vertically aligned pairs:

Deriving the sum: reverse and add $$S = a + (a+d) + \cdots + \big(a+(n-1)d\big)$$ $$S = \big(a+(n-1)d\big) + \cdots + (a+d) + a$$ $$2S = \underbrace{\big(2a+(n-1)d\big) + \cdots + \big(2a+(n-1)d\big)}_{n \text{ identical terms}} = n\big(2a+(n-1)d\big)$$ $$\boxed{\,S = \frac{n}{2}\big(2a+(n-1)d\big)\,}$$

Every pair sums to the same thing because as one term climbs by $d$, its partner drops by $d$. Since $2a+(n-1)d$ is just (first term) + (last term), the formula also reads $S = \dfrac{n}{2}(\text{first} + \text{last})$ — number of terms times the average of the ends.

📝 Example — the daily-allowance problem

A child gets 10 cents, then 3 more cents each following day: $10, 13, 16,\dots$ After 20 days, how much total? Here $a=10$, $d=3$, $n=20$:

$$S = \frac{20}{2}\big(2(10)+19(3)\big) = 10(20+57) = 10(77) = 770\text{ cents.}$$
📝 Example — first $n$ positive integers

For $1+2+3+\cdots+k$ we have $a=1$, $d=1$, $n=k$, so $S=\dfrac{k}{2}(1+k)=\dfrac{k(k+1)}{2}$. Thus $1+2+\cdots+100 = \dfrac{100\cdot 101}{2} = 5050$ — Gauss's famous schoolboy sum, which is the reverse-and-add trick in disguise.

24.2 Geometric Sequences & Series

In a geometric sequence each term is a fixed common ratio $r$ times the previous one: $a,\ ar,\ ar^2,\ ar^3,\dots$ Compare the $n$-th term to the arithmetic case — multiplication replaces addition:

$n$-th term of a geometric sequence $$a_n = a\,r^{\,n-1}$$

To sum the first $n$ terms, use the multiply-by-$r$ and subtract trick. Multiplying $S$ by $r$ shifts every term up one slot, so almost everything cancels:

Deriving the sum: subtract $rS$ $$S = a + ar + ar^2 + \cdots + ar^{\,n-1}$$ $$rS = \phantom{a +{}} ar + ar^2 + \cdots + ar^{\,n-1} + ar^{\,n}$$ $$S - rS = a - ar^{\,n} \quad\Longrightarrow\quad S(1-r) = a\big(1-r^{\,n}\big)$$ $$\boxed{\,S = \frac{a\big(1-r^{\,n}\big)}{1-r}\,}\qquad (r \neq 1)$$

Subtracting the two rows annihilates every middle term, leaving only the first term of $S$ and the last term of $rS$. The condition $r\neq 1$ matters: if $r=1$ every term equals $a$ and the sum is simply $na$.

📝 Example — a five-term geometric sum

Sum $\dfrac{2}{3}+\dfrac{4}{9}+\dfrac{8}{27}+\dfrac{16}{81}+\dfrac{32}{243}$. Here $a=\tfrac{2}{3}$, $r=\tfrac{2}{3}$, $n=5$:

$$S = \frac{\tfrac{2}{3}\left(1-\left(\tfrac{2}{3}\right)^5\right)}{1-\tfrac{2}{3}} = \frac{\tfrac{2}{3}\left(1-\tfrac{32}{243}\right)}{\tfrac{1}{3}} = 2\cdot\frac{211}{243} = \frac{422}{243}.$$

Adding the five fractions directly gives the same $\tfrac{422}{243}$ — always sanity-check a formula on a small case.

📝 Example — the chessboard wheat

A wise woman asks for $1$ grain on square 1, $2$ on square 2, $4$ on square 3, $\dots$, doubling through 64 squares. That is $1+2+4+\cdots+2^{63}$ with $a=1$, $r=2$, $n=64$:

$$S = \frac{1(1-2^{64})}{1-2} = 2^{64}-1 \approx 1.8\times 10^{19}\text{ grains.}$$

This is why the doubling factorization $1+2+4+\cdots+2^k = 2^{k+1}-1$ shows up everywhere.

24.3 Infinite Series & Convergence

A series need not stop. An infinite series is convergent if its partial sums (the sums of the first $n$ terms) approach a fixed value, and divergent otherwise. For example $1+\tfrac12+\tfrac14+\tfrac18+\cdots$ has partial sums $1, \tfrac32, \tfrac74, \tfrac{15}{8},\dots$ marching toward $2$.

For an infinite geometric series, start from the finite sum and watch $r^n$. Writing $S_n = \dfrac{a}{1-r}\big(1-r^{\,n}\big)$: when $|r|<1$ the powers $r^n$ shrink to $0$ (e.g. $0.5,\,0.25,\,0.125,\dots$), so the factor $\big(1-r^{\,n}\big)\to 1$ and the sum settles down:

Infinite geometric series ($|r|<1$) $$a + ar + ar^2 + ar^3 + \cdots = \frac{a}{1-r}$$

So $1+\tfrac12+\tfrac14+\cdots = \dfrac{1}{1-\tfrac12} = 2$, confirming the partial sums above.

An infinite geometric series converges only when $|r|<1$. If $|r|\geq 1$ the terms don't shrink to zero and the sum runs off to infinity (or oscillates) — the formula $\frac{a}{1-r}$ is meaningless there.
Terms shrinking to zero is necessary but NOT sufficient. The harmonic series $1+\tfrac12+\tfrac13+\tfrac14+\cdots$ has terms tending to $0$ yet diverges: grouping $\big(\tfrac13+\tfrac14\big)>\tfrac12$, $\big(\tfrac15+\cdots+\tfrac18\big)>\tfrac12$, $\dots$ you can pile up unlimited halves.
📝 Example — repeating decimal as a series

$0.\overline{3} = \tfrac{3}{10}+\tfrac{3}{100}+\tfrac{3}{1000}+\cdots$ is geometric with $a=\tfrac{3}{10}$, $r=\tfrac{1}{10}$:

$$\frac{a}{1-r} = \frac{3/10}{1-1/10} = \frac{3/10}{9/10} = \frac{1}{3}.$$

Every repeating decimal is secretly a convergent geometric series.

24.4 Sigma Notation

The capital Greek sigma $\sum$ ("S" for sum) is shorthand for adding up an indexed expression. The variable below is a dummy index (commonly $i$, $j$, $k$): it starts at the lower bound, increases by $1$, and stops at the upper bound, with the expression evaluated and added at each step.

Reading a sigma $$\sum_{k=1}^{5} k = 1+2+3+4+5 = 15 \qquad \sum_{k=3}^{7} 2^k = 8+16+32+64+128 = 248$$

Infinite sums let the index run to $\infty$, e.g. $\displaystyle\sum_{i=0}^{\infty} ar^i = \frac{a}{1-r}$ for $|r|<1$. Two manipulation rules follow straight from the laws of arithmetic:

Linearity of $\sum$ $$\sum (a_n + b_n) = \sum a_n + \sum b_n \quad(\text{associativity})$$ $$\sum c\,a_n = c\sum a_n \quad(\text{distributivity})$$

A parallel symbol, $\prod$ (capital pi), denotes a product the same way: $\displaystyle\prod_{k=1}^{4}(x-k) = (x-1)(x-2)(x-3)(x-4)$.

💡 Big Picture — if you can write the $i$-th term, you understand the sum Any time you meet an unfamiliar sum or product, try to capture it in $\sum$ or $\prod$ form. Pinning down a formula for the general term forces you to see the pattern generating the series — and that pattern is usually the key to summing it. The notation isn't just compression; it's a thinking tool.

24.5 Recursive Sequences

A sequence is simply a list — it may be given by a formula for its $n$-th term, written in braces with a dummy variable: $\{1\}$ is $1,1,1,\dots$;  $\{2n\}$ is $2,4,6,8,\dots$;  $\{(-1)^{n+1}/n\}$ is $1, -\tfrac12, \tfrac13, -\tfrac14,\dots$ (index starts at $1$, steps by $1$).

Alternatively a term may be defined from previous terms — a recursion. The classic is the Fibonacci sequence, where each term is the sum of the two before it, seeded with $F_0 = F_1 = 1$:

Fibonacci recursion $$F_n = F_{n-1} + F_{n-2}, \qquad F_0 = F_1 = 1$$ $$1,\ 1,\ 2,\ 3,\ 5,\ 8,\ 13,\ 21,\dots$$

Arithmetic and geometric sequences are themselves recursions: $a_n = a_{n-1} + d$ and $a_n = r\,a_{n-1}$ respectively, each with its own first term.

📝 Example — a Fibonacci identity by induction

Claim: $F_{n+2} = 1 + \displaystyle\sum_{i=0}^{n} F_i$. Base: $F_2 = 2 = 1 + F_0$. Step: assume it holds at $n=k-1$, i.e. $F_{k+1} = 1+\sum_{i=0}^{k-1}F_i$. Then

$$F_{k+2} = F_k + F_{k+1} = F_k + \Big(1+\sum_{i=0}^{k-1}F_i\Big) = 1 + \sum_{i=0}^{k}F_i,$$

so it holds at $n=k$. By induction it holds for all $n\geq 0$.

24.6 Sequences and Means

Why are these sequences named "arithmetic" and "geometric"? Because each interior term is the corresponding mean of its neighbors. For an arithmetic sequence, adding the terms just before and after $x_n$ gives $x_{n-1}+x_{n+1} = 2x_n$, so:

Arithmetic mean (average) $$x_n = \frac{x_{n-1}+x_{n+1}}{2}$$

For a geometric sequence the neighbors multiply: $x_{n-1}\,x_{n+1} = (a r^{n-2})(a r^{n}) = a^2 r^{2n-2} = (a r^{n-1})^2 = x_n^2$, so each term is the geometric mean $\sqrt{x_{n-1}\,x_{n+1}}$. The two means of numbers $x$ and $y$, together with the harmonic mean, are:

Three means of $x$ and $y$ $$\text{AM} = \frac{x+y}{2} \qquad \text{GM} = \sqrt{xy} \qquad \text{HM} = \frac{2}{\frac1x+\frac1y} = \frac{2xy}{x+y}$$

They are tightly linked. The harmonic mean is the reciprocal of the average of the reciprocals, and a neat identity ties all three: $\text{GM}^2 = \text{AM}\cdot\text{HM}$ (so GM is the geometric mean of AM and HM). For positive $x,y$ they always order as $\text{HM} \leq \text{GM} \leq \text{AM}$, with equality only when $x=y$.

"Insert $k$ means between $p$ and $q$" means find numbers making $p,\,?,\dots,?,\,q$ arithmetic (or geometric).

📝 Example — insert two geometric means between 2 and 16

We want $2, x, y, 16$ geometric, so $x=2r$, $y=2r^2$, $16=2r^3$. Then $r^3=8$, $r=2$, giving $x=4$, $y=8$: the sequence $2,4,8,16$. Indeed each term is $\sqrt{\text{neighbors}}$ — e.g. $4=\sqrt{2\cdot 8}$.

📝 Example — comparing the three means

For $x=2$, $y=8$: $\text{AM}=\tfrac{2+8}{2}=5$, $\text{GM}=\sqrt{16}=4$, $\text{HM}=\tfrac{2\cdot 2\cdot 8}{10}=3.2$. Check the identity: $\text{AM}\cdot\text{HM}=5\cdot 3.2=16=\text{GM}^2$. And $3.2 \leq 4 \leq 5$ as promised.

💡 Big Picture — the Greeks and the infinite The idea that infinitely many terms can have a finite sum took millennia to accept. Zeno's paradox argued motion is impossible: to cross a distance you first cross half, then half the rest, then half of that, forever. The resolution is the convergent geometric series $\tfrac12 + \tfrac14 + \tfrac18 + \cdots = 1$ — infinitely many steps, finite total distance and finite time. What stumped the Greeks is now a one-line consequence of $\frac{a}{1-r}$.
Series are the backbone of physics. Taylor expansions ($e^x = \sum x^n/n!$, $\sin x = x - x^3/6+\cdots$) approximate hard functions by polynomials — the small-angle pendulum $\sin\theta\approx\theta$ is the first Taylor term. Geometric series appear in damped oscillations (successive amplitudes shrink by a constant ratio, so total swing distance is $\frac{A}{1-r}$) and in charging an RC circuit through repeated pulses. Zeno-type sums describe a ball bouncing to fractional heights, settling in finite time. And perturbation series in quantum mechanics and general relativity expand a solution in powers of a small coupling, summing corrections term by term — convergence (the $|r|<1$ idea) is exactly what decides whether the expansion is trustworthy.

2024 AMC 12BProblem 5 sums & sign changes

In the following expression, Melanie changed some of the plus signs to minus signs: $1 + 3 + 5 + 7 + \cdots + 97 + 99$. When the new expression was evaluated, it was negative. What is the least number of plus signs that Melanie could have changed to minus signs?

$\textbf{(A)}\ 14 \quad \textbf{(B)}\ 15 \quad \textbf{(C)}\ 16 \quad \textbf{(D)}\ 17 \quad \textbf{(E)}\ 18$

Worked solution

The original sum is $1+3+5+\cdots+99 = 50^2 = 2500$.

Changing a term $k$ from $+k$ to $-k$ lowers the sum by $2k$. To make the result negative, the changed terms must satisfy $2\sum k > 2500$, i.e. $\sum k > 1250$.

To use the fewest sign changes, flip the largest terms first: $99, 97, 95, \ldots$. The sum of the largest $m$ odd numbers (down from $99$) is

$99 + 97 + \cdots + (99 - 2(m-1)) = m(100 - m).$

We need $m(100-m) > 1250$. For $m = 14$: $14 \cdot 86 = 1204 < 1250$. For $m = 15$: $15 \cdot 85 = 1275 > 1250$.

So $15$ changes (turning the sum into $2500 - 2\cdot 1275 = -50 < 0$) is the minimum.

Answer: (B) 15

2024 AMC 12BProblem 11 trigonometry

Let $x_n = \sin^2(n^\circ)$. What is the mean of $x_1, x_2, x_3, \ldots, x_{90}$?

$\textbf{(A)}\ \dfrac{11}{45} \quad \textbf{(B)}\ \dfrac{22}{45} \quad \textbf{(C)}\ \dfrac{89}{180} \quad \textbf{(D)}\ \dfrac{1}{2} \quad \textbf{(E)}\ \dfrac{91}{180}$

Worked solution

We need $\dfrac{1}{90}\sum_{n=1}^{90} \sin^2(n^\circ)$. Use the complementary-angle identity $\sin^2\theta + \sin^2(90^\circ - \theta) = \sin^2\theta + \cos^2\theta = 1$.

Pair $n$ with $90 - n$: the pairs $(1,89), (2,88), \ldots, (44,46)$ each sum to $1$, contributing $44$. The leftover terms are $n = 45$ and $n = 90$:

$\sin^2(45^\circ) = \tfrac{1}{2}, \qquad \sin^2(90^\circ) = 1.$

So $\sum_{n=1}^{90}\sin^2(n^\circ) = 44 + \tfrac{1}{2} + 1 = \tfrac{91}{2}$.

The mean is $\dfrac{91/2}{90} = \dfrac{91}{180}$.

2024 AMC 12BProblem 13 circles & optimization

There are real numbers $x, y, h$ and $k$ that satisfy the system of equations $x^2 + y^2 - 6x - 8y = h$ and $x^2 + y^2 - 10x + 4y = k$. What is the minimum possible value of $h + k$?

$\textbf{(A)}\ -54 \quad \textbf{(B)}\ -46 \quad \textbf{(C)}\ -34 \quad \textbf{(D)}\ -16 \quad \textbf{(E)}\ 16$

Worked solution

Complete the square in each equation:

$h = (x-3)^2 + (y-4)^2 - 25,$

$k = (x-5)^2 + (y+2)^2 - 29.$

Adding,

$h + k = \big[(x-3)^2 + (x-5)^2\big] + \big[(y-4)^2 + (y+2)^2\big] - 54.$

Minimize each bracket separately. The $x$-part $(x-3)^2 + (x-5)^2$ is minimized at $x = 4$, giving $1 + 1 = 2$. The $y$-part $(y-4)^2 + (y+2)^2$ is minimized at $y = 1$, giving $9 + 9 = 18$.

So the minimum of $h + k$ is $2 + 18 - 54 = -34$.

Answer: (C) -34
