4. Brief Review of Classical Statistics for Discrete Systems

4a–4b. Population, samples, and random variables

A population is the collection of all set members that have some trait, whether measured or not. The total number of members of a discrete population is the population number $n_P$ (can be infinite). A sample is a subset of the full population, of sample number $n_S\in\{1,\dots,n_P\}$ — a measurement sample is a set of measurements of some trait(s) of various population members. A variable is any quantity that can take on a set of different values; it's a random variable (RV) if its value can change from one measurement to the next.

4c. Means (averages)

The population mean of random variable $x$ is

$$\langle x\rangle \equiv \mu_x \equiv \frac{1}{n_P}\sum_{k=1}^{n_P}x_k$$

where $\{x_1,\dots,x_{n_P}\}$ is the set of all actual values in the population, indexed by which individual possesses that value. The sample mean is

$$\bar x \equiv m_x \equiv \frac{1}{n_S}\sum_{k=1}^{n_S}x_k$$

where $\{x_1,\dots,x_{n_S}\}$ is the sample. Under certain conditions $\bar x$ can be a good estimator of $\langle x\rangle$, which is useful when $n_P$ is large (typically requires a sample size of at least $\sim30$ to be a good estimator).

4d–4e. Histogram bins and probability

A bin is a range of values assigned a single label; this lets us have finite probability of a value falling in a given bin (a zero-width bin has zero probability). The bin population $(n_P)_b$ is the number of population members belonging to bin $b$, out of $n_B$ total bins. The representative bin value $\tilde x_b$ is the single value every member of bin $b$ is quantized to (e.g. all $3\le x<4$ might get quantized to $\tilde x=3$ or $3.5$, the bin's midpoint).

Bin populations must exhaust the whole population, $\sum_{b=1}^{n_B}(n_P)_b=n_P$, so the probability that a population member belongs to bin $b$ is $p_b\equiv\frac{(n_P)_b}{n_P}$, and these probabilities automatically sum to 1: $\sum_b p_b = \frac{1}{n_P}\sum_b(n_P)_b = \frac{1}{n_P}n_P=1$.

4f. Means in terms of probability

After quantizing the population to representative bin values, sub-groups of quantized values add up to the bin count times the representative bin value:

$$\langle x\rangle \equiv \mu_x \equiv \frac{1}{n_P}\sum_{k=1}^{n_P}x_k \approx \frac{1}{n_P}\Big[(n_P)_1\tilde x_1+\cdots+(n_P)_{n_B}\tilde x_{n_B}\Big] = \sum_{b=1}^{n_B}\frac{(n_P)_b}{n_P}\tilde x_b = \sum_{b=1}^{n_B}p_b\tilde x_b$$

(notice the upper limit of the sum changed from $n_P$ individuals to $n_B$ bins). If the bins are chosen fine enough that quantizing doesn't distort any values ($\tilde x_b=x_b$ exactly), this becomes an exact equality $\langle x\rangle=\sum_b p_b x_b$. The same rule applies to any function $f(x)$ of the RV: $\langle f(x)\rangle=\sum_b p_bf(\tilde x_b)$. This “value times probability, summed” pattern — $\langle x\rangle=\sum_bp_bx_b$ — is exactly the pattern quantum mechanics reuses for expectation values in Section 5g below.

5. Hello, Operator!

5a. Completeness and the Identity Operator

Given an $n$-level pure state in an orthonormal complete basis $\{|b_1\rangle,\dots,|b_n\rangle\}$ as $|\psi\rangle=\sum_{k=1}^n c_k|b_k\rangle$, we can extract the coefficients using orthonormality:

$$\langle b_j|\psi\rangle = \sum_{k=1}^n c_k\langle b_j|b_k\rangle = \sum_{k=1}^n c_k\delta_{j,k} = c_j \quad\Rightarrow\quad \boxed{c_k=\langle b_k|\psi\rangle}$$

Putting this back into $|\psi\rangle=\sum_k c_k|b_k\rangle$ reveals:

$$|\psi\rangle = \sum_{k=1}^n\langle b_k|\psi\rangle|b_k\rangle = \sum_{k=1}^n|b_k\rangle\langle b_k|\,|\psi\rangle = \left(\sum_{k=1}^n|b_k\rangle\langle b_k|\right)|\psi\rangle \equiv I|\psi\rangle = |\psi\rangle$$

which gives the completeness relation, valid for any orthonormal complete basis:

$$\boxed{\sum_{k=1}^n|b_k\rangle\langle b_k| = I}$$

where $I$ is the identity operator, meaning $I|\psi\rangle=|\psi\rangle$ for any state. The “bowties” $|b_k\rangle\langle b_k|$ are outer products and qualify as operators — while overlaps like $\langle b_j|\psi\rangle$ are inner products and are always scalars (plain numbers).

5b. Representing Operators as Matrices

Recall $\langle\phi|\psi\rangle=c_1^*d_1+c_2^*d_2$ for $|\phi\rangle=c_1|b_1\rangle+c_2|b_2\rangle$, $|\psi\rangle=d_1|b_1\rangle+d_2|b_2\rangle$, and the matrix form $|\psi\rangle\equiv\begin{pmatrix}d_1\\d_2\end{pmatrix}$. Using the “index-knitting” definition of matrix multiplication — a row vector $1\times2$ times a column vector $2\times1$ — the bra of $|\phi\rangle$ must be a row vector:

$$\langle b_1|\equiv(1\ \ 0),\quad \langle b_2|\equiv(0\ \ 1) \quad\Rightarrow\quad \langle\phi|\equiv c_1^*\langle b_1|+c_2^*\langle b_2| = (c_1^*\ \ c_2^*)$$

This defines the matrix-implementation of the Hermitian conjugate: $|\phi\rangle^\dagger\equiv\langle\phi|=(c_1^*\ \ c_2^*)^T=\big((c_1\ \ c_2)^T\big)^{*T}$, i.e. $\boxed{A^\dagger\equiv A^{*T}=A^{T*}}$, where $T$ is the transpose (row $\leftrightarrow$ column) and $*$ is the elementwise complex conjugate.

What about the “bowties” $|b_j\rangle\langle b_k|$ themselves? Column vectors encode ket basis states vertically; row vectors encode bra basis states horizontally — so their outer product is naturally 2-dimensional, defined as:

$$\text{outer product} \equiv |\psi\rangle\langle\phi| \equiv \begin{pmatrix}c_1\\c_2\end{pmatrix}\otimes(d_1^*\ \ d_2^*) \equiv \begin{pmatrix}c_1d_1^* & c_1d_2^*\\ c_2d_1^* & c_2d_2^*\end{pmatrix}$$

Using this on the computational basis gives the elementary basis of matrices:

$$|b_1\rangle\langle b_1|=\begin{pmatrix}1&0\\0&0\end{pmatrix},\ \ |b_1\rangle\langle b_2|=\begin{pmatrix}0&1\\0&0\end{pmatrix},\ \ |b_2\rangle\langle b_1|=\begin{pmatrix}0&0\\1&0\end{pmatrix},\ \ |b_2\rangle\langle b_2|=\begin{pmatrix}0&0\\0&1\end{pmatrix}$$

and any operator is a linear combination of these with scalars $A_{j,k}$:

$$A \equiv \sum_{j=1}^2\sum_{k=1}^2 A_{j,k}|b_j\rangle\langle b_k| \quad\Rightarrow\quad \boxed{A=\begin{pmatrix}A_{1,1}&A_{1,2}\\A_{2,1}&A_{2,2}\end{pmatrix}}$$

5c–5d. Motivating the Density (Probability) Operator

Recall $c_k=\langle b_k|\psi\rangle$, and probabilities $p_k=|c_k|^2=c_k^*c_k=(\langle b_k|\psi\rangle)^*\langle b_k|\psi\rangle$. Since $\langle\psi|\equiv|\psi\rangle^\dagger$, one shows $c_k^*=(\langle b_k|\psi\rangle)^*=\langle\psi|b_k\rangle$, so:

$$p_k = |c_k|^2 = \langle\psi|b_k\rangle\langle b_k|\psi\rangle = \langle b_k|\psi\rangle\langle\psi|b_k\rangle$$

Notice the “bowtie” quantities $|b_k\rangle\langle b_k|$ and $|\psi\rangle\langle\psi|$ both appear here (the first also appeared in the identity operator). Since $|\psi\rangle\langle\psi|$ depends only on the state, not the outcome $|b_k\rangle$, we define it as the probability density operator of pure state $|\psi\rangle$:

$$\boxed{\rho \equiv |\psi\rangle\langle\psi|}$$

Inserting the identity $I=\sum_j|b_j\rangle\langle b_j|$ on both sides and defining $\rho_{j,k}\equiv\langle b_j|\rho|b_k\rangle=\langle b_j|\psi\rangle\langle\psi|b_k\rangle=c_jc_k^*$ (just a complex number) gives the representation of $\rho$ in basis $\{|b_k\rangle\}$:

$$\rho = \sum_{j=1}^n\sum_{k=1}^n\rho_{j,k}|b_j\rangle\langle b_k|, \qquad p_k=\langle b_k|\psi\rangle\langle\psi|b_k\rangle=\langle b_k|\rho|b_k\rangle=\rho_{k,k}$$

so a state's probabilities are just the diagonal elements of $\rho$. Using the elementary-basis outer products from 5b, the density matrix (the matrix representation of the density operator) for $n=2$ is simply:

$$\boxed{\rho = \begin{pmatrix}\rho_{1,1} & \rho_{1,2}\\ \rho_{2,1} & \rho_{2,2}\end{pmatrix}}$$

— this is an operator that represents a state, rather than something that happens to a state.

5e. Basic Anatomy of a Density Matrix

Diagonals $\rho_{k,k}$ are matrix elements with matching indices, and are probabilities for those outcomes. Off-diagonals $\rho_{j,k\ne j}$ have different indices and tell us about superposition/coherence between outcomes $j$ and $k$. For pure states, $\rho_{j,k}\equiv\langle b_j|\rho|b_k\rangle=\langle b_j|\psi\rangle\langle\psi|b_k\rangle=c_jc_k^*$ — so off-diagonals are generally complex, while diagonals are real and nonnegative: $\rho_{j,j}=c_jc_j^*=|c_j|^2\ge0$.

$\rho$ is Hermitian, meaning it's invariant under Hermitian conjugation, $\rho^\dagger=\rho$ — direct computation on the $2\times2$ case confirms $\rho^\dagger=\begin{pmatrix}\rho_{1,1}&\rho_{1,2}\\\rho_{2,1}&\rho_{2,2}\end{pmatrix}=\rho$, so its elements obey the Hermiticity relation:

$$\boxed{\rho_{j,k}^* = \rho_{k,j}}$$

5f. Probabilities in Terms of Operators Only

Starting from $p_k=\langle b_k|\psi\rangle\langle\psi|b_k\rangle=\langle b_k|\rho|b_k\rangle$, insert an identity $I=\sum_j|b_j\rangle\langle b_j|$:

$$p_k = \langle b_k|I\rho|b_k\rangle = \sum_{j=1}^n\langle b_j|b_j\rangle\langle b_j|\rho|b_k\rangle = \sum_{j=1}^n\langle b_j|\big(\rho|b_k\rangle\langle b_k|\big)|b_j\rangle$$

Defining the projection operator $P_k\equiv|b_k\rangle\langle b_k|$ and the trace operation $\operatorname{tr}(A)\equiv\sum_j\langle b_j|A|b_j\rangle$ (sum of the diagonal elements $A_{1,1}+\cdots+A_{n,n}$), this simplifies to a remarkably clean form:

$$\boxed{p_k = \operatorname{tr}(\rho P_k)}$$

which lets us talk about probabilities purely in terms of operators: $\rho$ for the system state, $P_k$ for the outcome whose probability we want.

5g. Mean Values in Terms of Operators

Recall the classical mean $\langle x\rangle=\sum_bp_bx_b$ from Section 4f. Now, recalling $p_k=\operatorname{tr}(\rho P_k)$, what does the more general quantity $\operatorname{tr}(\rho A)$ mean for an arbitrary operator $A$? If $A$ is diagonal in the elementary basis, $A=\sum_jA_{j,j}|b_j\rangle\langle b_j|$, then:

$$\operatorname{tr}(\rho A) = \sum_{j=1}^nA_{j,j}\operatorname{tr}(\rho|b_j\rangle\langle b_j|) = \sum_{j=1}^nA_{j,j}\operatorname{tr}(\rho P_j) = \sum_{j=1}^np_jA_{j,j}$$

Comparing to the classical mean shows this is exactly a mean value! So for diagonal $A$, $\langle A\rangle=\operatorname{tr}(\rho A)=\sum_jp_jA_{j,j}$, where $A_{j,j}$ are the values associated with each outcome and $p_j=\operatorname{tr}(\rho P_j)$ their probabilities. It turns out this holds even for general, non-diagonal operators $A$:

$$\boxed{\langle A\rangle \equiv \langle A\rangle_\rho \equiv \operatorname{tr}(\rho A) = \langle\psi|A|\psi\rangle} \qquad \big(\text{mean/expectation value of observable } A \text{ for state } \rho=|\psi\rangle\langle\psi|\big)$$

where $A$ only qualifies as an observable operator if it's Hermitian, $A^\dagger=A$ (this guarantees mean values are always real, though not necessarily positive unless they're also probabilities). Mean values also depend on the state $\rho$ they're taken with respect to; $\langle A\rangle$ is also called the “expectation value of $A$.”

5h. Bell’s Inequality

Derivation of Bell’s Inequality

Recall the maximally entangled state $|\Psi^-\rangle=\frac{1}{\sqrt2}\big(|0\rangle\otimes|1\rangle-|1\rangle\otimes|0\rangle\big)$, and imagine two particles starting in this state flying apart, each headed toward a detector measuring its spin component in a direction adjustable at the detector. Bell considered the mean value of the product of spin components for qubits $A$ and $B$:

$$\langle\sigma_a\sigma_b\rangle \equiv \langle\Psi^-|\sigma_a\sigma_b|\Psi^-\rangle$$

where $\sigma_a\equiv\sigma_a^{(A)}\otimes I^{(B)}=(\boldsymbol\sigma^{(A)}\cdot\mathbf a)\otimes I^{(B)}$ is the spin component operator along direction $\mathbf a$ for particle $A$ (similarly $\sigma_b$ for $B$ along $\mathbf b$), built from the Pauli spin operators $\boldsymbol\sigma\equiv(\sigma_x,\sigma_y,\sigma_z)$. Quantum mechanics predicts:

$$\langle\sigma_a\sigma_b\rangle = -\mathbf a\cdot\mathbf b = -\cos(\theta_{a,b}); \qquad \theta_{a,b}\equiv\theta_a-\theta_b$$

which agrees with experiment. Bell then proposed two measurement functions $A(\mathbf a,\lambda)\in\{\pm1\}$ and $B(\mathbf b,\lambda)\in\{\pm1\}$ giving the individual measurement results for particles $A$ and $B$, determined by some hidden variable $\lambda$ with a normalized probability distribution $\rho(\lambda)\ge0$, $\int\rho(\lambda)\,d\lambda=1$. The expectation value of the spin-component product under this hidden-variable model is:

$$P(\mathbf a,\mathbf b) \equiv \int\rho(\lambda)A(\mathbf a,\lambda)B(\mathbf b,\lambda)\,d\lambda$$

He observed that when $\mathbf a=\mathbf b$ (parallel detectors), $P$ can only equal $-1$, as reality requires, if $B(\mathbf b,\lambda)=-A(\mathbf b,\lambda)$ for every $\lambda$. Substituting this in, and using a second direction $\mathbf c$:

$$P(\mathbf a,\mathbf b) = -\int\rho(\lambda)A(\mathbf a,\lambda)A(\mathbf b,\lambda)\,d\lambda, \qquad P(\mathbf a,\mathbf c) = -\int\rho(\lambda)A(\mathbf a,\lambda)A(\mathbf c,\lambda)\,d\lambda$$

Taking the difference, inserting $A^2(\mathbf b,\lambda)=1$ in the middle of the second term, factoring, and taking absolute values (using $|\rho(\lambda)|=\rho(\lambda)$, $|A(\mathbf a,\lambda)A(\mathbf b,\lambda)|=1$, and $|1-A(\mathbf b,\lambda)A(\mathbf c,\lambda)|=1-A(\mathbf b,\lambda)A(\mathbf c,\lambda)$ since the product is $\pm1$) eventually yields:

$$|P(\mathbf a,\mathbf b)-P(\mathbf a,\mathbf c)| \le \int\rho(\lambda)\,d\lambda - \int\rho(\lambda)A(\mathbf b,\lambda)A(\mathbf c,\lambda)\,d\lambda = 1 - P(\mathbf b,\mathbf c)$$

Using $-P(\mathbf b,\mathbf c)=\int\rho(\lambda)A(\mathbf b,\lambda)A(\mathbf c,\lambda)\,d\lambda$ (same substitution with $\mathbf b$ in place of $\mathbf a$) gives Bell's Inequality:

$$\boxed{|P(\mathbf a,\mathbf b)-P(\mathbf a,\mathbf c)| \le 1+P(\mathbf b,\mathbf c)}$$

Bell claimed this inequality must hold for any local hidden-variable theory of this system.

Violations of Bell’s Inequality

To see how quantum results can violate this inequality, consider one experiment with $\mathbf a$ perpendicular to $\mathbf b$, and another where detector $B$ is rotated to $\mathbf c$, $45^\circ$ between $\mathbf a$ and $\mathbf b$. The quantum result $\langle\sigma_a\sigma_b\rangle=-\mathbf a\cdot\mathbf b=-\cos(\theta_{a,b})$ then predicts:

$$P(\mathbf a,\mathbf b)=0, \qquad P(\mathbf a,\mathbf c)\approx-0.707, \qquad P(\mathbf b,\mathbf c)\approx-0.707$$

Plugging these into Bell's inequality $|P(\mathbf a,\mathbf b)-P(\mathbf a,\mathbf c)|\le1+P(\mathbf b,\mathbf c)$ yields the false statement:

$$0.707 \le 0.293$$

— a genuine Bell's inequality violation. Bell concluded such violations are proof that local hidden-variable theories are incompatible with quantum mechanics. Since quantum mechanics is experimentally correct about what it predicts (and therefore compatible with physical reality to some extent), and since local hidden-variable theories are incompatible with quantum mechanics (based on the ability of measurements to violate Bell's inequality), one can conclude that local hidden-variable theories are incompatible with physical reality. However, there may be more to the story (a nuance the lecture leaves open, rather than declaring fully settled).

This is the rigorous version of the “spooky action at a distance” thought experiment from Topic 1, Section 3a — Bell's inequality is what turns Einstein's philosophical objection into a number you can actually measure in a lab and compare against quantum predictions.

Practice Problems

These are extra warm-up problems for this topic. The actual assigned homework (HW 04+05) with full worked solutions lives on the Homework page.

Problem 1 — Density matrix from a ket
Write the density matrix $\rho=|\psi\rangle\langle\psi|$ for $|\psi\rangle=\frac{1}{\sqrt2}(|0\rangle+|1\rangle)$, and identify its diagonal (probability) and off-diagonal (coherence) elements.
Show solution

$|\psi\rangle=\frac{1}{\sqrt2}\begin{pmatrix}1\\1\end{pmatrix}$, so $\rho=\frac12\begin{pmatrix}1\\1\end{pmatrix}(1\ \ 1)=\frac12\begin{pmatrix}1&1\\1&1\end{pmatrix}$.

Diagonals: $\rho_{1,1}=\rho_{2,2}=\frac12$ — an equal 50/50 chance of each outcome, matching $|c_0|^2=|c_1|^2=\frac12$. Off-diagonals: $\rho_{1,2}=\rho_{2,1}=\frac12$ — nonzero, confirming this is a coherent superposition, not a classical 50/50 mixture (a classical coin flip would have the same diagonal but zero off-diagonals).

Problem 2 — Trace and probability
For the $\rho$ found in Problem 1 and $P_0=|0\rangle\langle0|=\begin{pmatrix}1&0\\0&0\end{pmatrix}$, compute $p_0=\operatorname{tr}(\rho P_0)$ and confirm it matches $\rho_{1,1}$.
Show solution

$\rho P_0 = \frac12\begin{pmatrix}1&1\\1&1\end{pmatrix}\begin{pmatrix}1&0\\0&0\end{pmatrix} = \frac12\begin{pmatrix}1&0\\1&0\end{pmatrix}$.

$\operatorname{tr}(\rho P_0) = \frac12(1+0) = \frac12$ — matches $\rho_{1,1}=\frac12$ exactly, as Section 5f guarantees ($p_k=\operatorname{tr}(\rho P_k)=\rho_{k,k}$).

Problem 3 — Hermiticity check
Is $M=\begin{pmatrix}2 & 3i\\ -3i & 5\end{pmatrix}$ a valid density-matrix-style Hermitian operator? Check $M^\dagger=M$.
Show solution

$M^{*}=\begin{pmatrix}2&-3i\\3i&5\end{pmatrix}$, then transpose: $M^{*T}=\begin{pmatrix}2&3i\\-3i&5\end{pmatrix}=M$. Yes — $M^\dagger=M$, so $M$ is Hermitian (note the off-diagonal pair $M_{1,2}=3i$, $M_{2,1}=-3i$ satisfies $M_{j,k}^*=M_{k,j}$ exactly as Section 5e requires). It could represent a valid observable, though it isn't itself a valid density matrix since its diagonal doesn't sum to 1.

Problem 4 — Bell's inequality arithmetic
Using the quantum prediction $P(\mathbf a,\mathbf b)=-\cos(\theta_{a,b})$, compute $P(\mathbf a,\mathbf b)$, $P(\mathbf a,\mathbf c)$, and $P(\mathbf b,\mathbf c)$ for $\theta_a=0^\circ,\theta_b=90^\circ,\theta_c=45^\circ$, and check whether Bell's inequality is satisfied or violated.
Show solution

$P(\mathbf a,\mathbf b)=-\cos(90^\circ)=0$; $P(\mathbf a,\mathbf c)=-\cos(45^\circ)\approx-0.707$; $P(\mathbf b,\mathbf c)=-\cos(45^\circ)\approx-0.707$ (this is exactly the example worked in the lecture).

$|P(\mathbf a,\mathbf b)-P(\mathbf a,\mathbf c)| = |0-(-0.707)| = 0.707$, while $1+P(\mathbf b,\mathbf c) = 1-0.707 = 0.293$. Since $0.707 \not\le 0.293$, Bell's inequality is violated — exactly the signature that rules out local hidden-variable theories.
