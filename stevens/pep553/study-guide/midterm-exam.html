📝 Midterm Format

The PEP553 midterm is a take-home exam worth 20% of the course grade. Exact logistics — release/due timestamps, open-book/open-note policy, collaboration rules, submission format — were not available at the time this guide was built. Confirm the exact rules and due date with your instructor/course site before you start.

What is reliably known is the instructor's usual grading approach on take-home exams (visible from the grading rubric notes used on the final): every claim must be backed by shown analysis — a stated result with no supporting integral, derivation, or operator algebra earns little or no credit, and a blank or unsupported answer earns no credit at all. Treat this review page the way you'd treat the exam itself: don't just quote a formula, show the two or three lines of work that get you there.

Wave Function Properties

Key Formulas

Full derivation and physical motivation: 01-wave-function-and-statistics.html.

$$P(x,t) = |\psi(x,t)|^2 = \psi^*(x,t)\,\psi(x,t) \quad \text{(probability density)}$$
$$\int_{-\infty}^{\infty} |\psi(x,t)|^2\,dx = 1 \quad \text{(normalization)}$$

$\psi$ itself is not observable; $|\psi|^2\,dx$ is the probability of finding the particle in $[x, x+dx]$. Normalization fixes the overall scale of $\psi$ up to an irrelevant phase.

Worked Example

Q: Normalize $\psi(x) = A\,e^{-|x|/a}$ over all space.
Show solution
$$\int_{-\infty}^{\infty} A^2 e^{-2|x|/a}\,dx = 2A^2\int_0^{\infty} e^{-2x/a}\,dx = 2A^2\left(\frac{a}{2}\right) = A^2 a = 1$$

So $A = 1/\sqrt{a}$. The exponent's absolute value is why the integral splits into two identical halves — always check for symmetry before integrating over the whole line.

Operators

Key Formulas

Full derivation: 01-wave-function-and-statistics.html.

  • Position: $\hat{x}\,\psi = x\,\psi$
  • Momentum: $\hat{p}\,\psi = -i\hbar\dfrac{\partial \psi}{\partial x}$
  • Kinetic energy: $\hat{T} = \dfrac{\hat{p}^2}{2m} = -\dfrac{\hbar^2}{2m}\dfrac{\partial^2}{\partial x^2}$
$$\hat{A}\,\phi = a\,\phi \quad \text{(eigenvalue equation: } a \text{ is the eigenvalue, } \phi \text{ the eigenfunction)}$$
$$[\hat{x},\hat{p}] = i\hbar \quad \text{(canonical commutator)}$$
$$\langle \hat{A} \rangle = \int_{-\infty}^{\infty} \psi^*\, \hat{A}\, \psi \; dx \quad \text{(expectation value)}$$

Worked Example

Q: Verify the canonical commutator $[\hat{x},\hat{p}] = i\hbar$ by acting on an arbitrary test function $f(x)$.
Show solution
$$[\hat{x},\hat{p}]f = \hat{x}\hat{p}f - \hat{p}\hat{x}f = x(-i\hbar f') - (-i\hbar)\frac{d}{dx}(xf)$$
$$= -i\hbar x f' + i\hbar\big(f + xf'\big) = i\hbar f$$

Since this holds for any $f$, the operators satisfy $[\hat{x},\hat{p}] = i\hbar$ as an operator identity — the product rule term $xf'$ cancels and only the "extra" $f$ from differentiating $xf$ survives.

Schrödinger Equation

Key Formulas

Full derivation: 01-wave-function-and-statistics.html.

$$i\hbar\frac{\partial \psi(x,t)}{\partial t} = \hat{H}\psi(x,t) \quad \text{(Time-Dependent SE)}$$
$$\hat{H}\phi(x) = E\phi(x) \quad \text{(Time-Independent SE)}$$
$$\boxed{\psi(x,t) = T(t)\phi(x) = \exp\!\left(-\frac{iEt}{\hbar}\right)\phi(x)} \quad \text{(general separated solution — the formula to actually learn)}$$

Erratum on the review sheet: the handout as issued has $\exp(+iEt/\hbar)$, but that's almost certainly a transcription typo, not a different physical convention — don't memorize it that way. This isn't a boundedness argument: $|e^{+iEt/\hbar}| = |e^{-iEt/\hbar}| = 1$ for real $E$, so neither sign "blows up." The minus sign is instead forced directly by the time-dependent Schrödinger equation itself — plugging $T(t)=e^{i\omega t}$ into $i\hbar\,\dot T = ET$ gives $i\hbar(i\omega) = E$, i.e. $\omega = -E/\hbar$, so $T(t)=\exp(-iEt/\hbar)$ is the only separated solution consistent with $i\hbar\,\partial_t\Psi = \hat H\Psi$ (not $-i\hbar\,\partial_t\Psi=\hat H\Psi$) — and it's the convention used consistently throughout Topics 1–4. Use the minus sign in your own worked math.

Worked Example

Q: Show that separating $\psi(x,t)=\phi(x)T(t)$ in the TDSE produces the TISE plus $T(t)=e^{-iEt/\hbar}$.
Show solution

Substitute into $i\hbar\,\partial_t\psi = \hat{H}\psi$ (with $\hat H$ acting only on $x$):

$$i\hbar\,\phi(x)\frac{dT}{dt} = T(t)\,\hat{H}\phi(x)$$

Divide both sides by $\phi(x)T(t)$:

$$i\hbar\,\frac{1}{T}\frac{dT}{dt} = \frac{1}{\phi}\hat{H}\phi(x)$$

Left side depends only on $t$, right side only on $x$ — both must equal the same constant, called $E$. The $x$-equation is exactly the TISE, $\hat{H}\phi=E\phi$. The $t$-equation, $i\hbar\,\dot{T}/T = E$, integrates to $T(t) = e^{-iEt/\hbar}$.

Particle in a Box

⚠️ Which "Particle in a Box" Convention?
The midterm review sheet's particle-in-a-box problem is the ASYMMETRIC well, walls at $x=0$ and $x=a$, with sine eigenfunctions $\phi_n(x)=\sqrt{2/a}\,\sin(n\pi x/a)$ — this is the same convention as Topic 2's primary treatment (02-infinite-potential-well.html), so you can lean directly on that page's worked derivations. The SYMMETRIC well ($-a/2$ to $a/2$, with even cosine / odd sine eigenfunctions split by parity) is a different convention, covered on Topic 2 only as a contrast case, and it resurfaces on final-exam.html alongside the parity discussion from Topic 7. Don't mix the two coordinate origins mid-calculation — a $\cos$ eigenfunction with boundary conditions at $0$ and $a$ is a symptom of exactly this mix-up.

Key Formulas (asymmetric well, 0 to a)

Full derivation: 02-infinite-potential-well.html.

$$\phi_n(x) = \sqrt{\frac{2}{a}}\,\sin\!\left(\frac{n\pi x}{a}\right), \qquad E_n = \frac{n^2\hbar^2\pi^2}{2ma^2}, \qquad n = 1, 2, 3, \dots$$

Worked Example

Q: For a box eigenstate $\phi_n$, find $\langle x \rangle$, $\langle p \rangle$, and $\langle H \rangle$.
Show solution

$\langle x \rangle$: $\sin^2(n\pi x/a)$ is symmetric about the midpoint $x=a/2$ for every $n$, so by symmetry (confirmed by direct integration using $\sin^2\theta=\tfrac12(1-\cos2\theta)$, whose cosine term integrates to zero over $n$ full or half periods):

$$\langle x \rangle = \int_0^a x\,|\phi_n|^2\,dx = \frac{a}{2}$$

$\langle p \rangle$: $\phi_n$ is a real, time-independent (stationary) state, so the probability density does not flow: $\langle p\rangle = m\,d\langle x\rangle/dt = 0$. (Equivalently, direct integration of $\phi_n(-i\hbar\,d/dx)\phi_n$ gives a purely imaginary integrand integrated against a real measure, which must vanish for a physical real result.)

$$\langle p \rangle = 0$$

$\langle H \rangle$: $\phi_n$ is an eigenstate of $\hat H$ with eigenvalue $E_n$, so the expectation value is trivially the eigenvalue itself — no spread, no integral needed:

$$\langle H \rangle = E_n = \frac{n^2\hbar^2\pi^2}{2ma^2}$$

Complete Sets & Eigenfunction Expansion

Key Formulas

Full derivation: 02-infinite-potential-well.html (orthonormal box basis) and 04-free-particle-wave-packets.html (expansion machinery generalized to continuous bases).

$$\langle \psi_n | \psi_m \rangle = \int \psi_n^* \psi_m \, dx = \delta_{nm} \quad \text{(orthonormality)}$$
$$\Psi(x,0) = \sum_n c_n \psi_n \qquad c_n = \int \psi_n^* \Psi(x,0)\, dx$$
$$\langle \hat{H} \rangle = \sum_n |c_n|^2 E_n \quad \text{(} |c_n|^2 \text{ is the probability of measuring } E_n \text{)}$$

Worked Example

Q: A particle in a box has $\Psi(x,0) = A\big[\phi_1(x) + \phi_2(x)\big]$. Find $A$, the possible energy-measurement outcomes with their probabilities, and $\langle H \rangle$.
Show solution

Orthonormality collapses the cross terms in normalization:

$$\int|\Psi|^2 dx = A^2\big(\langle\phi_1|\phi_1\rangle + \langle\phi_2|\phi_2\rangle\big) = A^2(1+1) = 2A^2 = 1 \;\Rightarrow\; A = \frac{1}{\sqrt2}$$

Reading off coefficients: $c_1 = c_2 = 1/\sqrt2$, all other $c_n = 0$. Measuring energy gives $E_1$ with probability $|c_1|^2 = 1/2$, or $E_2 = 4E_1$ with probability $|c_2|^2=1/2$ — nothing else. Then:

$$\langle H \rangle = \tfrac12 E_1 + \tfrac12 E_2 = \tfrac12 E_1 + \tfrac12(4E_1) = \frac{5}{2}E_1 = \frac{5\hbar^2\pi^2}{4ma^2}$$

Quantized Harmonic Oscillator

Key Formulas

Full derivation: 03-quantum-harmonic-oscillator.html.

$$\hat{H} = \frac{\hat{p}^2}{2m} + \frac{1}{2}k\hat{x}^2, \qquad [\hat{a},\hat{a}^\dagger] = 1, \qquad \hat{N} = \hat{a}^\dagger \hat{a}$$
$$E_n = \hbar\omega\left(n + \frac{1}{2}\right)$$
$$\hat{N}\phi_n = n\,\phi_n, \qquad \hat{a}\,\phi_n = \sqrt{n}\,\phi_{n-1}, \qquad \hat{a}^\dagger\phi_n = \sqrt{n+1}\,\phi_{n+1}, \qquad \langle \phi_n|\phi_m\rangle = \delta_{nm}$$

Useful bridge back to position space: $\hat{x} = \sqrt{\dfrac{\hbar}{2m\omega}}\big(\hat{a}+\hat{a}^\dagger\big)$.

Worked Example

Q: For the oscillator state $\phi_1$, find $\langle x \rangle$ and $\langle x^2 \rangle$ using ladder operators.
Show solution

$\langle x \rangle$: $\hat a\,\phi_1 = \sqrt1\,\phi_0$ and $\hat a^\dagger\phi_1=\sqrt2\,\phi_2$, both orthogonal to $\phi_1$:

$$\langle\phi_1|\hat x|\phi_1\rangle = \sqrt{\frac{\hbar}{2m\omega}}\Big(\sqrt1\langle\phi_1|\phi_0\rangle + \sqrt2\langle\phi_1|\phi_2\rangle\Big) = 0$$

$\langle x^2 \rangle$: expand $\hat x^2 = \dfrac{\hbar}{2m\omega}(\hat a^2 + \hat a\hat a^\dagger + \hat a^\dagger\hat a + \hat a^{\dagger 2})$. Acting on $\phi_1$: $\hat a^2\phi_1=0$ (since $\hat a\phi_0=0$) and $\hat a^{\dagger2}\phi_1 \propto \phi_3$ (orthogonal to $\phi_1$) both drop out. The middle two survive:

$$\hat a\hat a^\dagger\phi_1 = \hat a(\sqrt2\,\phi_2) = 2\,\phi_1, \qquad \hat a^\dagger\hat a\,\phi_1 = \hat a^\dagger\phi_0 = \phi_1$$
$$\langle\phi_1|\hat x^2|\phi_1\rangle = \frac{\hbar}{2m\omega}(2+1) = \frac{3\hbar}{2m\omega}$$

This matches the general result $\langle n|\hat x^2|n\rangle = \dfrac{\hbar}{m\omega}\big(n+\tfrac12\big)$ at $n=1$: $\dfrac{\hbar}{m\omega}\cdot\tfrac32 = \dfrac{3\hbar}{2m\omega}$. ✓

Superposition Principle

Key Formulas

Full derivation: 04-free-particle-wave-packets.html.

$$\Psi(x,t) = \sum_n c_n\,\psi_n(x)\,\exp\!\left(-\frac{iE_n}{\hbar}t\right), \qquad c_n = \int_{-\infty}^{\infty} \psi_n(x)\,\Psi(x,0)\,dx$$

(As transcribed from the review sheet — note the coefficient integral here omits the complex-conjugate star that appears on $\psi_n^*$ in the Eigenfunction Expansion topic above; for a general complex basis the conjugate belongs there. It's harmless whenever the basis functions are real, as with the box eigenfunctions, but keep the star when working with complex bases like plane waves.)

Worked Example

Q: Using the $c_1=c_2=1/\sqrt2$ box superposition from the Eigenfunction Expansion example, write $\Psi(x,t)$ and describe what does and doesn't change in time.
Show solution
$$\Psi(x,t) = \frac{1}{\sqrt2}\Big[\phi_1(x)\,e^{-iE_1t/\hbar} + \phi_2(x)\,e^{-iE_2t/\hbar}\Big]$$

Each $|c_n|^2$ is time-independent (only a pure phase multiplies each term), so the energy-measurement probabilities (1/2, 1/2) and $\langle H\rangle = \tfrac52 E_1$ are constant in time. But cross terms like $\langle x(t)\rangle$ depend on the relative phase $e^{-i(E_2-E_1)t/\hbar}$ and do oscillate, beating at frequency $(E_2-E_1)/\hbar$ — this is the hallmark signature that a state is a genuine superposition and not a stationary eigenstate.

Free Particle Schrödinger Equation

Key Formulas

Full derivation: 04-free-particle-wave-packets.html.

$$\hat{H}_{free}\,\psi(x) = E\,\psi(x) \;\Rightarrow\; -\frac{\hbar^2}{2m}\frac{d^2\psi(x)}{dx^2} = E\,\psi(x) \;\Rightarrow\; \frac{d^2\psi(x)}{dx^2} = -k^2\psi(x), \qquad k = \frac{\sqrt{2mE}}{\hbar}$$

Worked Example

Q: Find the de Broglie wavelength of a free electron with kinetic energy $E = 1.0\text{ eV}$.
Show solution
$$k = \frac{\sqrt{2mE}}{\hbar} = \frac{\sqrt{2(9.11\times10^{-31}\text{ kg})(1.602\times10^{-19}\text{ J})}}{1.055\times10^{-34}\text{ J·s}} \approx 5.12\times10^{9}\text{ m}^{-1}$$
$$\lambda = \frac{2\pi}{k} \approx 1.23\text{ nm}$$

This is the standard "1 eV electron → ~1.2 nm wavelength" benchmark — worth memorizing as a sanity-check scale for atomic-size problems.

Fourier Transform Decomposition

Key Formulas

Full derivation: 04-free-particle-wave-packets.html.

$$f(x) = \frac{1}{\sqrt{2\pi}}\int_{-\infty}^{\infty} F(k)\,e^{ikx}\,dk \quad \Leftrightarrow \quad F(k) = \frac{1}{\sqrt{2\pi}}\int_{-\infty}^{\infty} f(x)\,e^{-ikx}\,dx$$
$$\phi(k) = \frac{1}{\sqrt{2\pi}}\int_{-\infty}^{\infty} \Psi(x,0)\,e^{-ikx}\,dx$$
$$\Psi(x,t) = \frac{1}{\sqrt{2\pi}}\int_{-\infty}^{\infty} \phi(k)\,e^{i(kx-\omega t)}\,dk$$

For the free particle, $\omega(k) = \hbar k^2/2m$ (from $E=\hbar\omega=\hbar^2k^2/2m$) — each $k$-component propagates with its own phase, which is exactly why a free wave packet spreads (see Topic 4 for the group-velocity/spreading discussion).

Worked Example

Q: Qualitatively, what happens to $\phi(k)$ if $\Psi(x,0)$ is a Gaussian $\propto e^{-x^2/2\Delta^2}$ with a very small $\Delta$ (a tightly localized particle)?
Show solution

A Gaussian's Fourier transform is another Gaussian, with reciprocal width: $\phi(k) \propto e^{-\Delta^2 k^2/2}$. A narrow real-space Gaussian ($\Delta$ small) Fourier-transforms into a wide $k$-space Gaussian ($\Delta k \sim 1/\Delta$ large) — tight position localization forces a broad spread of momentum components. This is the Fourier-analysis root of the position–momentum uncertainty relation: it's baked into the transform pair itself, before any operator formalism is invoked.

Wave-packet Fourier decomposition is exactly the math behind ultrafast laser pulse shaping and mode-locking: a femtosecond pulse is a superposition of many frequency components locked in phase, and the pulse's time-domain shape and its frequency spectrum are a Fourier transform pair — same relation as $\Psi(x,0) \leftrightarrow \phi(k)$ above, just with $t\leftrightarrow\omega$ instead of $x\leftrightarrow k$. See 09-enrichment-nobel-and-applications.html for the Nobel-Prize-level version of this story.

Self-Check Practice Set

Six mixed problems spanning every topic above, same style/difficulty as typical exam questions. Work each one fully — remember the instructor's grading philosophy from the Overview box: show the analysis, not just the final number.

Problem 1 — Wave Function Properties
Normalize $\psi(x) = A\,e^{-x/a}$ for $x \ge 0$ (and $\psi=0$ for $x<0$).
Show solution
$$\int_0^\infty A^2 e^{-2x/a}\,dx = A^2\cdot\frac{a}{2} = 1 \;\Rightarrow\; A = \sqrt{\frac{2}{a}}$$
Problem 2 — Operators
Using the canonical commutator and the identity $[\hat{A}\hat{B},\hat{C}] = \hat{A}[\hat{B},\hat{C}] + [\hat{A},\hat{C}]\hat{B}$, evaluate $[\hat{x}^2,\hat{p}]$.
Show solution
$$[\hat{x}^2,\hat{p}] = \hat{x}[\hat{x},\hat{p}] + [\hat{x},\hat{p}]\hat{x} = \hat{x}(i\hbar) + (i\hbar)\hat{x} = 2i\hbar\,\hat{x}$$
Problem 3 — Particle in a Box
For the $n=2$ state of a particle in an asymmetric box of width $a$, find $\langle x \rangle$, $\langle p^2 \rangle$, and $\langle H \rangle$.
Show solution

$\langle x\rangle = a/2$ for every $n$ (symmetry of $\sin^2$ about the midpoint, shown in the § Particle in a Box worked example). Since the potential is zero inside the well, $\hat H = \hat p^2/2m$, so $\langle p^2\rangle = 2m\langle H\rangle = 2mE_n$. With $E_2 = 4E_1 = \dfrac{4\hbar^2\pi^2}{2ma^2} = \dfrac{2\hbar^2\pi^2}{ma^2}$:

$$\langle H\rangle = E_2 = \frac{2\hbar^2\pi^2}{ma^2}, \qquad \langle p^2\rangle = 2mE_2 = \frac{4\hbar^2\pi^2}{a^2}$$
Problem 4 — Eigenfunction Expansion
A box particle has $\Psi(x,0) = N\big[2\phi_1(x) - \phi_3(x)\big]$. Find $N$, the possible energy measurement probabilities, and $\langle H \rangle$ (in units of $E_1$).
Show solution
$$N^2(2^2+1^2) = N^2(5) = 1 \;\Rightarrow\; N = \frac{1}{\sqrt5}$$

$c_1 = 2/\sqrt5,\; c_3 = -1/\sqrt5$, so $P(E_1) = |c_1|^2 = 4/5$ and $P(E_3) = |c_3|^2 = 1/5$. With $E_3 = 9E_1$:

$$\langle H\rangle = \frac{4}{5}E_1 + \frac{1}{5}(9E_1) = \frac{13}{5}E_1$$
Problem 5 — Harmonic Oscillator (Ladder Operators)
Show that $\langle \phi_2 | \hat{x} | \phi_0 \rangle = 0$ for the harmonic oscillator, and state the general selection rule this illustrates.
Show solution

$\hat a\,\phi_0 = 0$ and $\hat a^\dagger \phi_0 = \phi_1$, so $\hat x\,\phi_0 = \sqrt{\hbar/2m\omega}\,\phi_1$ — a pure $n=1$ state. Then:

$$\langle\phi_2|\hat x|\phi_0\rangle = \sqrt{\frac{\hbar}{2m\omega}}\langle\phi_2|\phi_1\rangle = 0$$

Because $\hat x \propto \hat a + \hat a^\dagger$ only ever shifts $n$ by $\pm1$, $\hat x$ can only connect adjacent levels — $\langle n'|\hat x|n\rangle$ vanishes unless $n' = n\pm1$. This "$\Delta n = \pm1$" selection rule is the same structural idea behind dipole selection rules in atomic transitions.

Problem 6 — Free Particle / Fourier Transform
A free particle has $\psi(x) = A\,e^{ik_0x}$ for $-L/2 < x < L/2$ and $\psi=0$ elsewhere. Find $\phi(k)$ and describe how its width compares to a plane wave with no cutoff.
Show solution
$$\phi(k) = \frac{1}{\sqrt{2\pi}}\int_{-L/2}^{L/2} A\,e^{i(k_0-k)x}\,dx = \frac{A}{\sqrt{2\pi}}\cdot\frac{2\sin\!\big[(k_0-k)L/2\big]}{k_0-k}$$

This is a $\mathrm{sinc}$ function centered at $k=k_0$ with main-lobe width $\Delta k \sim 2\pi/L$. An infinite plane wave ($L\to\infty$) would give a delta function $\delta(k-k_0)$ — perfectly defined momentum, zero position localization. Truncating to a finite train of length $L$ trades some momentum sharpness ($\Delta k \sim 1/L$) for finite spatial extent — the same $\Delta x\,\Delta k$ trade-off as the Gaussian case in the § Fourier Transform worked example, just with a different functional form.
