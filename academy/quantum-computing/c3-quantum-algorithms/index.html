🛠️ Hands-On Project

QFT-Based Phase Estimation + Grover Search in Qiskit

Build up a complete algorithm pair: a quantum phase estimation circuit using the QFT to estimate the eigenphase of a unitary, and a Grover search circuit that finds a marked item in an unstructured list faster than any classical algorithm. Run both on the Qiskit simulator and verify the results against theory. You deliver a short report with circuit diagrams, results, and query-count comparisons. Week 1 includes installing Qiskit's visualization extras (step-by-step in Lecture 1) — building on the Qiskit install from C2.

Wk 1: install Qiskit extras (visualization) Wk 4: Grover oracle + diffusion operator working Wk 8: QFT + phase estimation circuit verified Wk 10: report + both algorithms submitted

💬 Discussions

Three checkpoints — weeks 3, 6, 9

  • Week 3: Deutsch–Jozsa and Bernstein–Vazirani both answer a structured question in one query where a classical computer needs many. What property of the oracle's structure is each algorithm exploiting?
  • Week 6: The QFT looks like the classical discrete Fourier transform but acts on amplitudes, not measured data. Why can't you just measure the input, run a classical FFT, and get the same speedup?
  • Week 9: "Quantum computers are exponentially faster than classical computers" is a common but imprecise claim. Using BQP vs. P/NP as a frame, what's the more honest statement of what we actually know?
