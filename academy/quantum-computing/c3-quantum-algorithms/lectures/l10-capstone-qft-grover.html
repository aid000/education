10.2Part A — Grover Search, Built Clean

Recall the shape from Week 4: start in the uniform superposition H⊗n|0⟩⊗n, apply the Grover iteration G = D·Uf exactly r ≈ (π/4)√(N/M) times (Week 5's corrected, M-aware formula), then measure. Today's version runs it for N=16 (n=4 qubits) with M=1 marked item, cleanly separated into its own function so it composes with Part B below without variable collisions.

N = 16, M = 1  ⟹  r ≈ (π/4)√16 = π ≈ 3.14  →  round to r = 3 iterationsSame formula as Week 5's worked example, just at a slightly larger N for a cleaner capstone demonstration.

10.3Part B — Phase Estimation, Built Clean

Recall the shape from Week 7: H⊗t on a t-qubit counting register, controlled-U(2ᵏ) applications encoding the target phase θ via phase kickback, then an inverse QFT to decode. Today's version targets θ = 3/8 (binary 0.011, needing t=3 ancilla qubits for exact recovery) — deliberately a slightly less trivial phase than Week 7's θ=1/4, to show the same machinery generalizing cleanly to a 3-bit target.

θ = 3/8 = 0.011₂, t = 3 ancilla qubits  ⟹  exact recovery expected, m = 011₂ = 33/8 is exactly 3-bit representable, so — exactly as in Week 7's worked example — the circuit should return m=3 with certainty, giving θ_est = 3/8 exactly.

🛠️ Hands-On: the full capstone script — Grover + QPE, side by side

This is the deliverable circuit code for the project. Run both parts, confirm both results match the worked example above, then write up the report (circuit diagrams — use qc.draw() — plus these printed results, plus the comparison table).

# capstone.py — Lecture 10 / Course Project
import numpy as np
from qiskit import QuantumCircuit
from qiskit.circuit.library import QFT
from qiskit.quantum_info import Statevector

# ---------- Part A: Grover search, N=16, M=1 ----------
def grover_search(n, marked):
    def oracle(qc):
        for i, b in enumerate(reversed(marked)):
            if b == '0': qc.x(i)
        qc.h(n - 1); qc.mcx(list(range(n - 1)), n - 1); qc.h(n - 1)
        for i, b in enumerate(reversed(marked)):
            if b == '0': qc.x(i)
    def diffusion(qc):
        qc.h(range(n)); qc.x(range(n))
        qc.h(n - 1); qc.mcx(list(range(n - 1)), n - 1); qc.h(n - 1)
        qc.x(range(n)); qc.h(range(n))
    qc = QuantumCircuit(n)
    qc.h(range(n))
    r = round((np.pi / 4) * np.sqrt(2**n))
    for _ in range(r):
        oracle(qc); diffusion(qc)
    return qc, r

n, marked = 4, "0110"           # N = 2^4 = 16
qc_grover, r = grover_search(n, marked)
probs = Statevector.from_instruction(qc_grover).probabilities_dict()
print(f"[Grover] N=16, marked={marked}, r={r} iterations -> P(marked) = {probs[marked]:.3f}")

# ---------- Part B: phase estimation, theta = 3/8, t=3 ----------
def phase_estimation(t, theta):
    qc = QuantumCircuit(t + 1)
    qc.x(t)                     # eigenstate |1> of the phase gate
    qc.h(range(t))
    for k in range(t):
        qc.cp(2 * np.pi * theta * 2**k, k, t)
    qc.append(QFT(t, inverse=True), range(t))
    return qc

t, theta = 3, 3/8
qc_qpe = phase_estimation(t, theta)
probs_qpe = Statevector.from_instruction(qc_qpe).probabilities_dict(qargs=range(t))
best = max(probs_qpe, key=probs_qpe.get)
m = int(best, 2)
print(f"[QPE] theta=3/8, t=3 -> measured m={best} ({m}), theta_est = {m}/{2**t} = {m / 2**t}")

Expected output: the Grover line reports P(marked) well above 0.9 after 3 iterations on N=16 — confirming the search succeeded with the predicted iteration count; the QPE line reports m=3 with theta_est = 0.375 = 3/8 exactly, confirming exact phase recovery — both results matching the worked example's comparison table precisely.

10.4Looking Back: the Full Ten-Week Arc

Week 1 opened with the smallest possible example: one oracle, one qubit, one trick (phase kickback) turning a 2-query classical problem into a 1-query quantum one. Weeks 2–3 scaled that exact trick to n bits (Deutsch-Jozsa), then repurposed it again to extract a hidden linear structure outright (Bernstein-Vazirani), with Simon's problem as a bridge toward genuinely hard period-finding. Weeks 4–5 left that whole oracle-promise framework behind for unstructured search, trading exponential-but-artificial speedups for a modest-but-provably-optimal and genuinely general one: Grover's √N.

Weeks 6–8 introduced an entirely different primitive — the QFT — and built it up from a circuit (Week 6) into a measurement protocol for eigenphases (Week 7, phase estimation) into the engine behind the single most consequential result in the course (Week 8, Shor's algorithm breaking RSA-style cryptography's core assumption). Week 9 stepped back to assess all of it honestly through the lens of BQP, correcting the overclaims popular coverage tends to make. And today closes the loop by actually building the two pieces — Grover and QFT/QPE — that the project asked for from day one.

AnalogyIf Course 2 taught you the alphabet of quantum circuits — individual gates, how they compose — this course taught you the first few real sentences: specific, named algorithms that say something nontrivial using that alphabet. Just as learning a few well-chosen sentences in a new language teaches you more about its grammar than memorizing vocabulary alone, these five algorithms (Deutsch-Jozsa, Bernstein-Vazirani, Grover, QFT/QPE, Shor) are the backbone vocabulary of quantum algorithm design — nearly every later quantum algorithm you'll encounter reuses pieces of this toolkit.

🔗 Where this is heading — Course 4

Every algorithm in this course was analyzed on a perfect, noiseless quantum computer — the Qiskit Statevector simulator used throughout never drops a qubit, never decoheres, never makes a gate error. Real hardware does all three, constantly, and that gap is exactly why Shor's algorithm (exponentially faster, in principle) hasn't broken RSA in practice yet: today's devices are nowhere near able to run it at a cryptographically meaningful size without errors overwhelming the computation. Course 4, Noise, Error Correction & NISQ, picks up precisely here — what noise actually does to a qubit, how quantum error correction fights back, and what's realistically achievable on today's "noisy intermediate-scale quantum" (NISQ) devices before fault tolerance arrives. If BQP's promise is real, Course 4 is about the engineering standing between here and there.
