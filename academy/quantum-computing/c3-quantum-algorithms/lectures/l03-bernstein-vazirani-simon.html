Week 3 · Lecture 3

Bernstein–Vazirani & Simon's Problem

The same H⊗n-oracle-H⊗n circuit, a third time — now it extracts an entire hidden string, not just a yes/no answer.

🎯 Learning Objectives

  • State the Bernstein–Vazirani problem: recover a hidden string s from f(x) = s·x mod 2.
  • Show the classical cost is n queries, and derive why the quantum cost is exactly 1.
  • Recognize this as the third algorithm reusing the same H⊗n-oracle-H⊗n circuit shape.
  • Describe Simon's problem (hidden XOR-periodicity) and sketch why quantum needs only O(n) queries.
  • Trace the Bernstein–Vazirani circuit by hand for n=3, s=101.

3.1The Bernstein–Vazirani Problem

Suppose f : {0,1}n → {0,1} is guaranteed to have the form f(x) = s·x mod 2 for some hidden n-bit string s, where s·x denotes the bitwise dot product s₀x₀ ⊕ s₁x₁ ⊕ … ⊕ sₙ₋₁xₙ₋₁. The task: find s, using as few queries to f as possible.

f(x) = s·x mod 2 = s₀x₀ ⊕ s₁x₁ ⊕ … ⊕ sₙ₋₁xₙ₋₁f is a fixed linear (mod-2) function of x, entirely determined by the n hidden bits of s.

Classically, the straightforward strategy is to query f on the n "unit vector" inputs e₀=100…0, e₁=010…0, …, eₙ₋₁=00…01 one at a time. Querying f(eᵢ) returns exactly sᵢ (every other term in the dot product vanishes since eᵢ is 0 everywhere except position i), so n queries recover all n bits of s, one bit per query — and no classical strategy beats this; you need n queries to pin down n independent bits.

Classical queries needed = nOne query per bit of s — there is no way to learn two bits of s from one classical query to a dot-product function.

3.2The Quantum Algorithm: the Same Circuit, a Third Time

Run exactly the circuit from Lectures 1 and 2: Hadamard every input qubit and the ancilla, query Uf once with the ancilla in |−⟩, Hadamard the input register again, measure. This is now the third algorithm in a row built from the identical H⊗n-oracle-H⊗n skeleton — worth pausing on, since it's a strong hint that this isn't three unrelated tricks but one circuit pattern solving three different oracle-structure problems.

Phase kickback with this particular f gives (−1)s·x|x⟩ for each term, and the key fact (the same Fourier-style identity used in Lecture 2, specialized to a linear f) is that H⊗n maps (−1)s·x|x⟩ exactly onto |s⟩ — not merely a state concentrated near s, but exactly |s⟩, with probability 1.

H⊗n [ (1/√2ⁿ) Σₓ (−1)^(s·x) |x⟩ ] = |s⟩The second layer of Hadamards is literally decoding s directly out of the phase pattern written by the single oracle query.

Measuring the input register after this second H⊗n therefore returns s itself, bit for bit, with certainty — in one query, regardless of n.

AnalogyThink of the classical approach as mailing one yes/no question per bit of s and waiting for n replies. The quantum approach is like encoding all n questions into a single interference pattern and reading the whole pattern back in one glance — the pattern itself is s, because the final Hadamard layer is built to decode exactly that linear structure.

3.3A Unifying Insight: Three Algorithms, One Circuit

Step back and compare the three algorithms seen so far. Deutsch (Lecture 1), Deutsch–Jozsa (Lecture 2), and Bernstein–Vazirani (today) all run the identical circuit — H⊗n, one oracle query with the ancilla in |−⟩, H⊗n again, measure — and differ only in what promise is placed on f and what the measurement outcome is interpreted to mean. Deutsch–Jozsa reads the outcome as a single bit (all-zeros or not). Bernstein–Vazirani reads the entire outcome string as the answer itself, s.

Common mistakeDon't conclude that "H⊗n-oracle-H⊗n" solves every oracle problem in one query. It solves problems whose oracle structure is compatible with this specific interference pattern — constant-vs-balanced promises and exactly-linear functions. Grover's algorithm (Lecture 4) tackles unstructured search, where no such promise exists, and correspondingly needs more than one query (O(√N), not O(1)) — the circuit shape has to change because the oracle no longer has this special linear/promise structure to exploit.

3.4Simon's Problem: Hidden XOR-Periodicity

Simon's problem moves to a different kind of hidden structure. You're promised f : {0,1}n → {0,1}n is exactly 2-to-1: there is a hidden nonzero string s such that f(x) = f(x ⊕ s) for every x, and f(x) ≠ f(y) for any other pair. Find s.

f(x) = f(y)  ⟺  y = x or y = x ⊕ sEvery output value is hit by exactly two inputs, x and x⊕s — f is "periodic" under XOR with the hidden mask s.

Classically this needs an exponential number of queries — in the worst case you must query close to 2n/2 inputs before a birthday-paradox-style collision f(x)=f(y) even turns up, let alone confirms s = x⊕y. Quantumly, Simon's algorithm needs only O(n) queries: each run of a modified H⊗n-oracle-H⊗n circuit (no clean ancilla trick this time, since f maps to n output bits, not one) yields a measured string y that is guaranteed to satisfy y·s = 0 mod 2. Collect about n such equations from n independent runs, then solve the resulting linear system over GF(2) — ordinary linear algebra done with XOR instead of addition — to pin down s. The derivation of exactly why each run yields a y satisfying y·s=0 is beyond today's scope; the idea to take away is: exponential classical cost, linear quantum cost, recovered via classical post-processing of several quantum measurement outcomes.

Classical: Ω(2ⁿ/²) queries (birthday-bound)   |   Quantum: O(n) queries + solving a GF(2) linear systemSimon's problem was historically the first exponential separation on a problem with no artificial "all-or-nothing" promise — and it directly inspired the period-finding idea behind Shor's algorithm (Week 8).
✦ Worked Example — Bernstein–Vazirani, n=3, s=101

Confirm the algorithm recovers s=101 using f(x) = s·x mod 2 = x₂ ⊕ x₀ (bit 1 of s is 0, so x₁ doesn't appear).

  1. Prepare: 3 input qubits in |000⟩, ancilla in |1⟩ → H⊗3 on input, H on ancilla: (1/√8)Σₓ|x⟩ ⊗ |−⟩, uniform over all 8 three-bit strings x.
  2. Apply the oracle (phase kickback): each |x⟩ picks up (−1)^f(x) = (−1)^(x₂⊕x₀). E.g. x=000→+1, x=001→−1, x=010→+1, x=101→−1, x=111→+1 (check: x₂⊕x₀ for 111 is 1⊕1=0, sign +1 ✓).
  3. State after the oracle: (1/√8) Σₓ (−1)^(x₂⊕x₀) |x⟩ ⊗ |−⟩ — exactly the form H⊗n is built to decode, with s=101 encoded in the sign pattern.
  4. Apply H⊗3 to the input register: by the identity in §3.2, this collapses the sum exactly onto |s⟩ = |101⟩ — the input register is now |101⟩ with amplitude 1, nothing else.
  5. Measure the input register: result is 101 with certainty — s is recovered completely in a single query to U_f, matching the hidden string exactly.

🛠️ Hands-On: Bernstein–Vazirani for a random hidden string

Build the circuit generically for any n-bit s, then confirm the measured input register always equals s exactly.

# bernstein_vazirani.py — Lecture 3
from qiskit import QuantumCircuit
from qiskit.quantum_info import Statevector

def bv_circuit(s):
    n = len(s)
    qc = QuantumCircuit(n + 1)
    qc.x(n)                 # ancilla -> |1>
    qc.h(range(n + 1))      # input -> uniform superposition, ancilla -> |->
    for i, bit in enumerate(reversed(s)):   # oracle: f(x) = s.x via CNOTs where s has 1-bits
        if bit == '1':
            qc.cx(i, n)
    qc.h(range(n))           # decode layer
    return qc

s = "101"
qc = bv_circuit(s)
sv = Statevector.from_instruction(qc)
probs = sv.probabilities_dict(qargs=range(len(s)))
print("hidden s =", s, "-> measured P(input register) =", probs)

Expected output: probability 1.0 concentrated on the exact bitstring '101' (Qiskit's qubit-ordering convention may print it reversed as '101' or '101' depending on endianness — check against the circuit's own s to confirm), with every other outcome at probability 0 — the hidden string recovered exactly, matching the worked example.

🔗 Where this is heading

Every algorithm so far has relied on a promise about f's structure (constant/balanced, exactly linear, exactly 2-to-1). Week 4 drops the promise entirely: Grover's algorithm searches an unstructured list where the only thing you know about f is that exactly one input makes it output 1. Without structure to exploit, one query can't possibly suffice — but Grover still beats classical search quadratically, using a genuinely different mechanism: amplitude amplification by repeated reflection, not a single clever interference pattern.

Q2. Classically, recovering all n bits of the hidden string s requires…
A. 1 query, always
B. 2ⁿ queries
C. n queries (one unit-vector input per bit)

C. Querying f at each of the n unit-vector inputs e₀,…,eₙ₋₁ reveals one bit of s per query — no classical shortcut learns two bits from one query to a dot-product oracle.

Q3. Deutsch, Deutsch–Jozsa, and Bernstein–Vazirani all share which property?
A. They all require measuring the ancilla qubit.
B. They run the identical H⊗n-oracle-H⊗n circuit shape, differing only in the oracle's promise and how the output is read.
C. They all need O(√N) queries.
D. None of them use phase kickback.
Show answer

B. All three reuse the same circuit skeleton; the underlying oracle structure and the way the final measurement is interpreted are what differ between them.

Q4. In Simon's problem, the hidden string s satisfies…

Show answer

A. Simon's f is exactly 2-to-1 under XOR with s: every output value is produced by precisely the pair {x, x⊕s}.
