Grover's Algorithm I: Amplitude Amplification

No promise, no shortcut structure — just an unstructured list and a quadratic speedup earned by rotating a vector toward the answer.

🎯 Learning Objectives

  • State the unstructured search problem and its classical O(N) query complexity.
  • Describe the Grover oracle (phase-flips the marked state) and the diffusion operator (reflects about the average amplitude).
  • Explain amplitude amplification geometrically as rotation in a 2D marked/unmarked plane.
  • Compute the number of Grover iterations needed to reach near-certainty for a given N.
  • Build a Grover search circuit in Qiskit for N=8 and verify the marked item is found.

4.1The Search Problem: No Structure to Exploit

Suppose f : {0,1}n → {0,1} is completely unstructured — the only guarantee is that exactly one input x₀ (out of N = 2n possibilities) satisfies f(x₀)=1, and f is 0 everywhere else. Unlike every oracle in Weeks 1–3, there is no promise of linearity or a constant/balanced split to exploit; x₀ could be any one of the N inputs, and nothing about f's "shape" narrows that down ahead of time.

Classical queries needed (worst case) = O(N)   (up to N − 1 to be certain)With no structure, the only classical strategy is to check inputs one at a time; in the worst case you check every one except the last before finding x₀.

This is the generic unstructured search problem: finding one marked item among N, "needle in a haystack," with zero shortcuts available. It is a much more common real-world shape than the Weeks 1–3 promise problems — SAT-solving, database lookup without an index, and brute-force key search all reduce to exactly this.

4.2The Grover Oracle and the Diffusion Operator

Grover's algorithm uses two building blocks, applied alternately. First, the oracle Uf, built to phase-flip the marked state and leave everything else alone:

U_f |x⟩ = −|x⟩ if x = x₀ (marked),   U_f |x⟩ = +|x⟩ otherwiseUnlike Weeks 1–3's XOR-style oracle, Grover's oracle directly attaches a minus sign to the one marked basis state — this is the "phase oracle" form, equivalent to the XOR form via the same |−⟩-ancilla trick from Lecture 1.

Second, the diffusion operator D (also called the Grover operator), which reflects every amplitude about their collective average:

D = 2|s⟩⟨s| − I,   where |s⟩ = H⊗n|0⟩⊗n is the uniform superpositionD flips each amplitude's distance from the mean average to the opposite side — amplitudes below average get pushed up, amplitudes above average get pushed down, same total "energy."

One Grover iteration G = D·Uf applies the oracle, then the diffusion operator. Starting from the uniform superposition |s⟩, each application of G increases the amplitude on the marked state x₀ and decreases it (slightly) on every other state — the amplitude amplification that gives the algorithm its name.

4.3The Geometric Picture: Rotation in a 2D Plane

The cleanest way to see what's happening is to project the whole N-dimensional state space down to just 2 dimensions: the axis spanned by the single marked state |x₀⟩, and the axis spanned by the uniform superposition of all N−1 unmarked states. Every state Grover's algorithm ever visits is a unit vector in this 2D plane, written as sinθ·|marked⟩ + cosθ·|unmarked⟩ for some angle θ. The starting state |s⟩ sits at a small angle θ₀ above the unmarked axis (θ₀ = arcsin(1/√N), tiny for large N), and each Grover iteration rotates this vector by a fixed angle 2θ₀ toward the marked axis — both the oracle and the diffusion operator are reflections, and two reflections compose into a rotation.

Since θ₀ ≈ 1/√N for large N, and the vector needs to rotate roughly π/2 radians total to reach the marked axis, the number of iterations needed is roughly (π/2)/(2θ₀) ≈ (π/4)√N — an O(√N) algorithm, a quadratic speedup over the classical O(N).

Optimal iteration count r ≈ (π/4)√NRounded to the nearest integer in practice — rotating by a non-integer number of steps isn't possible, so real implementations pick the closest r and accept a small residual error.
✦ Worked Example — one Grover iteration for N=4, x₀=|11⟩

Track how one iteration of G amplifies the amplitude on the marked state |11⟩ among N=4 states.

  1. Start: uniform superposition |s⟩ = ½(|00⟩+|01⟩+|10⟩+|11⟩) — every amplitude is ½, and θ₀ = arcsin(1/2) = 30°.
  2. Apply the oracle U_f (flip the sign on |11⟩ only): ½(|00⟩+|01⟩+|10⟩−|11⟩).
  3. Compute the average amplitude: (½+½+½−½)/4 = ¼.
  4. Apply the diffusion reflection about that average: each amplitude a becomes 2·(average) − a. For the three unmarked states: 2(¼)−½ = 0. For the marked state: 2(¼)−(−½) = 1.
  5. Result: 0·(|00⟩+|01⟩+|10⟩) + 1·|11⟩ = |11⟩. The marked state's amplitude jumped from ½ to 1 (probability ¼ → 1) after just one iteration — exactly the rotation toward the marked axis predicted geometrically, since one iteration at θ₀=30° moves the angle to (2·1+1)θ₀=90°, landing exactly on the marked axis (N=4 is small enough that one iteration reaches the marked state with certainty, which is why Grover search on N=4 needs only 1 iteration in practice).

🛠️ Hands-On: Grover search over N=8 items

Build the 3-qubit Grover circuit (N=2³=8), mark a single item, run ⌊(π/4)√8⌋ = 2 iterations, and confirm the marked item dominates the measurement distribution. Project checkpoint: this is the Grover half of the course project — keep this circuit, you'll extend it directly in Week 10.

# grover_search.py — Lecture 4
from qiskit import QuantumCircuit
from qiskit.quantum_info import Statevector
import numpy as np

n = 3   # N = 2^3 = 8 items
marked = "101"   # the one marked item, as a bitstring

def oracle(qc):
    # phase-flip |101>: sandwich a controlled-Z-like flip between X gates on the 0-bits
    for i, b in enumerate(reversed(marked)):
        if b == '0': qc.x(i)
    qc.h(n - 1); qc.mcx(list(range(n - 1)), n - 1); qc.h(n - 1)   # multi-controlled Z via H-MCX-H
    for i, b in enumerate(reversed(marked)):
        if b == '0': qc.x(i)

def diffusion(qc):
    qc.h(range(n)); qc.x(range(n))
    qc.h(n - 1); qc.mcx(list(range(n - 1)), n - 1); qc.h(n - 1)   # reflect about |0...0>, i.e. about the average
    qc.x(range(n)); qc.h(range(n))

qc = QuantumCircuit(n)
qc.h(range(n))                    # uniform superposition |s>
iterations = round((np.pi / 4) * np.sqrt(2**n))   # optimal r ~ 2 for N=8
for _ in range(iterations):
    oracle(qc)
    diffusion(qc)

sv = Statevector.from_instruction(qc)
probs = sv.probabilities_dict()
print(f"after {iterations} iterations -> P =", probs)

Expected output: the marked bitstring '101' dominates the distribution (probability well above 90% after 2 iterations for N=8), with the remaining probability spread thinly over the other 7 states — a clear amplification signature even though N=8 is too small for the asymptotic O(√N) to look dramatic yet.

🔗 Where this is heading

Today fixed the number of iterations at the apparently-right value, (π/4)√N — but what happens if you keep iterating past that point? And is O(√N) really the best any quantum algorithm could do, or just the best this particular construction achieves? Week 5 answers both questions: the rotation picture makes "overshooting" the answer visually obvious, and a separate (non-constructive) argument proves no quantum algorithm can beat √N for unstructured search — Grover's algorithm is not just good, it's provably optimal.

Q1. Classically, finding the one marked item among N unstructured items requires, in the worst case…
A. O(log N) queries
B. O(√N) queries
C. O(N) queries
D. exactly 1 query
Show answer

C. With no structure to exploit, you may have to check nearly every item before finding the marked one — linear, O(N), worst-case cost.

Q2. The Grover diffusion operator D = 2|s⟩⟨s| − I acts by…
A. measuring the state
B. reflecting every amplitude about their collective average
C. deleting the marked state entirely
D. applying a classical NOT gate to every qubit
Show answer

B. D reflects each amplitude about the mean amplitude — amplitudes below average rise, amplitudes above average fall, by the same amount in opposite directions.

Q3. Geometrically, each Grover iteration G = D·U_f acts on the 2D marked/unmarked state vector as…
A. a fixed-angle rotation toward the marked axis
B. a random walk with no fixed direction
C. a projection onto the unmarked axis
D. no change at all
Show answer

A. Both U_f and D are reflections, and composing two reflections yields a rotation by a fixed angle (2θ₀) — the geometric heart of amplitude amplification.

Q4. In the N=4 worked example, after one Grover iteration the marked state |11⟩'s amplitude went from…
A. ½ to 1
B. ½ to 0
C. ½ to ½ (unchanged)
D. 1 to ½
Show answer

A. The oracle flips its sign to −½, then the diffusion reflection about the new average (¼) pushes it to 1 — probability jumps from ¼ to 1, certainty, after just one iteration (matching θ₀=30° rotating to 90° at N=4, M=1).

Q5. The optimal number of Grover iterations for a search over N items scales as…
A. N
B. log₂ N
C. N²
D. roughly (π/4)√N
Show answer

D. Since the rotation angle per iteration is 2θ₀ ≈ 2/√N and the vector must rotate about π/2 total, the iteration count works out to roughly (π/4)√N — the source of Grover's quadratic speedup.
