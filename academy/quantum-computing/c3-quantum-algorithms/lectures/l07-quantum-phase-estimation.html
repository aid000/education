Quantum Phase Estimation (QPE)

Given a unitary and one of its eigenstates, read out the hidden eigenphase — the subroutine every algorithm from here on is secretly built around.

🎯 Learning Objectives

  • State the QPE problem: given U and an eigenstate |ψ⟩ with U|ψ⟩=e^(2πiθ)|ψ⟩, estimate θ.
  • Describe the QPE circuit: ancilla register + controlled-U powers + inverse QFT.
  • Explain how precision scales with the number of ancilla (counting) qubits t.
  • Trace a QPE circuit for θ=1/4 with t=2 ancilla qubits and confirm exact recovery.
  • State clearly that QPE is the key subroutine behind Shor's algorithm (Week 8).

7.1The Phase Estimation Problem

Let U be a unitary with an eigenstate |ψ⟩: applying U to |ψ⟩ returns |ψ⟩ unchanged except for an overall phase factor e2πiθ, for some unknown real number θ ∈ [0,1). Quantum phase estimation asks: given the ability to apply U (and controlled versions of U) as many times as needed, and given a copy of |ψ⟩, estimate θ as precisely as possible.

U|ψ⟩ = e^(2πiθ) |ψ⟩,   θ ∈ [0, 1) unknown. Estimate θ.Recall from Lecture 1 that a global phase has zero effect on measurement probabilities of |ψ⟩ alone — QPE's entire trick is making this invisible phase visible by entangling it with an ancilla register.

This generalizes something you've effectively already seen: Lecture 1's phase kickback trick wrote f(x) into a ± sign (a phase of 0 or ½) on the input register. QPE is the full generalization — instead of a single bit of phase information (0 or π), it extracts an arbitrarily precise real-valued phase θ.

7.2The QPE Circuit: Ancilla Register + Controlled-U Powers + Inverse QFT

The circuit uses two registers: a counting register of t ancilla qubits (initialized to |0⟩⊗t), and the eigenstate register holding |ψ⟩. The algorithm runs in three stages:

1) H⊗t on the counting register  →  2) controlled-U^(2ᵏ) from counting qubit k onto |ψ⟩  →  3) inverse QFT on the counting registerStep 2 is the heart of it: each counting qubit k controls U applied 2ᵏ times, which (via phase kickback, exactly like Lecture 1's mechanism) writes e^(2πiθ·2ᵏ) onto that counting qubit's phase.

After step 2, the counting register holds exactly the state the QFT formula from Lecture 6 §6.1 produces for a "frequency" proportional to θ — in other words, step 2 encodes θ into the counting register in precisely the format the QFT (run backwards) is built to decode. Step 3, the inverse QFT, does exactly that: it converts the phase-encoded counting register into a computational-basis state that — if θ is exactly representable in t bits — equals ⌊2tθ⌋ with certainty.

Measure counting register → integer m   ⟹   θ ≈ m / 2ᵗDividing the measured t-bit integer by 2ᵗ converts it back into the estimate of θ.

7.3Precision Scales with the Number of Ancilla Qubits

With t counting qubits, the circuit distinguishes 2t distinct outcomes, so it resolves θ to roughly 1/2t precision. If θ happens to be exactly representable with t bits (θ = m/2t for some integer m), the circuit returns m with probability 1 — exact recovery, zero error, as in the worked example below. If θ isn't exactly t-bit representable, the outcome distribution peaks sharply around the nearest m/2t, and adding more ancilla qubits tightens that peak — more ancillas, more bits of θ, finer resolution.

AnalogyThink of t ancilla qubits as a measuring tape marked off in 2ᵗ evenly spaced ticks between 0 and 1. If θ lands exactly on a tick mark, the needle (the measurement) points at it with certainty. If θ lands between two ticks, the needle hovers near the closest one, with a predictable spread — add more ticks (more ancilla qubits) and the needle's read-out gets correspondingly finer.
✦ Worked Example — QPE for θ = 1/4 with t = 2 ancilla qubits

θ = 1/4 = 0.01 in binary — exactly representable with 2 bits, so t=2 should recover it exactly.

  1. Prepare: counting register |00⟩, eigenstate register |ψ⟩ with U|ψ⟩ = e^(2πi/4)|ψ⟩ = i|ψ⟩.
  2. H⊗2 on the counting register: ½(|00⟩+|01⟩+|10⟩+|11⟩) ⊗ |ψ⟩.
  3. Controlled-U from counting qubit 0 (applies U once if that qubit is 1): kicks back phase e^(2πiθ·1) = e^(πi/2) = i onto terms where that qubit is 1.
  4. Controlled-U² from counting qubit 1 (applies U twice if that qubit is 1): kicks back phase e^(2πiθ·2) = e^(πi) = −1 onto terms where that qubit is 1.
  5. Combined phases per counting-register basis state (reading as qubit1,qubit0): |00⟩→1, |01⟩→i, |10⟩→−1, |11⟩→i·(−1)=−i. State: ½(|00⟩ + i|01⟩ − |10⟩ − i|11⟩) ⊗ |ψ⟩ — exactly the QFT-encoded form of the integer m=1 (binary 01) in a 2-bit register.
  6. Apply the inverse QFT to the counting register: by construction, this collapses the state exactly onto |01⟩ ⊗ |ψ⟩ — measuring the counting register gives m = 01₂ = 1 with certainty, and θ = m/2² = 1/4, recovered exactly.

🛠️ Hands-On: QPE for θ=1/4 in Qiskit

Use a phase gate as U (eigenstate |1⟩, eigenvalue e2πiθ) and build the full QPE circuit with t=2 counting qubits, confirming the measured integer matches the worked example.

# qpe_circuit.py — Lecture 7
import numpy as np
from qiskit import QuantumCircuit
from qiskit.circuit.library import QFT
from qiskit.quantum_info import Statevector

theta = 0.25   # target phase, exactly representable with t=2 bits
t = 2          # counting/ancilla qubits

qc = QuantumCircuit(t + 1)      # qubits 0..t-1 = counting register, qubit t = eigenstate |1>
qc.x(t)                         # prepare the eigenstate |1> of the phase gate
qc.h(range(t))                  # step 1: H on counting register

for k in range(t):
    # step 2: controlled-U^(2^k) from counting qubit k, U = phase gate e^(2 pi i theta)
    qc.cp(2 * np.pi * theta * 2**k, k, t)

qc.append(QFT(t, inverse=True), range(t))   # step 3: inverse QFT on counting register

sv = Statevector.from_instruction(qc)
probs = sv.probabilities_dict(qargs=range(t))
print("measured counting-register distribution:", probs)
# interpret the most likely outcome m as theta_est = m / 2^t

Expected output: probability 1.0 on a single counting-register outcome corresponding to m=1 (binary '01', modulo Qiskit's bit-ordering convention), giving θ_est = 1/4 = 0.25 — exact recovery, matching the worked example precisely.

🔗 Where this is heading

QPE is not the destination — it's the engine. Week 8's Shor's algorithm factors integers by finding the period r of a modular exponentiation function, and that period-finding step is literally phase estimation applied to a cleverly chosen unitary (whose eigenphase encodes 1/r). Everything built today — the counting register, the controlled-U powers, the inverse QFT read-out — carries over directly; Week 8's work is mostly in setting up the right unitary and the classical post-processing (continued fractions) needed to turn an estimated θ back into an integer period r.

Q1. Quantum phase estimation takes as input a unitary U and an eigenstate |ψ⟩, and estimates…
A. the dimension of U
B. the eigenphase θ in U|ψ⟩ = e^(2πiθ)|ψ⟩
C. a different eigenstate of U
D. the trace of U
Show answer

B. QPE's entire output is an estimate of the real number θ hiding in the eigenvalue e^(2πiθ) — a phase that has zero effect on |ψ⟩ alone until QPE's ancilla trick exposes it.

Q2. The three stages of the QPE circuit, in order, are…
A. inverse QFT, controlled-U powers, Hadamards
B. measurement, Hadamards, controlled-U powers
C. Hadamards on the counting register, controlled-U^(2ᵏ) applications, inverse QFT on the counting register
D. controlled-U powers only, nothing else
Show answer

C. H⊗t spreads the counting register into superposition, controlled-U powers kick back θ-dependent phases via phase kickback, and the inverse QFT decodes those phases into a readable integer.

Q3. With t ancilla (counting) qubits, QPE resolves θ to roughly what precision?
A. 1/t
B. t, exactly
C. no precision gain from more qubits
D. 1/2ᵗ
Show answer

D. t counting qubits distinguish 2ᵗ outcomes, so the circuit resolves θ to roughly 1/2ᵗ — more ancilla qubits means exponentially finer resolution.

Q4. In the θ=1/4, t=2 worked example, measuring the counting register gives integer m = …
A. 1, with certainty, giving θ_est = 1/4 exactly
B. 0, with certainty
C. a uniformly random 2-bit integer
D. 3, with certainty
Show answer

A. θ=1/4 is exactly 2-bit representable (binary 01), so the inverse QFT collapses the counting register exactly onto |01⟩=1, giving θ_est = 1/2² = 1/4 with zero error.
