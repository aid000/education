No-Cloning & the Measurement Postulate Revisited

You can't copy an unknown qubit, and you can't peek at one without disturbing it. Both facts turn out to be the same idea, viewed from two angles.

🎯 Learning Objectives

  • State the no-cloning theorem: no unitary can map |ψ⟩|0⟩ → |ψ⟩|ψ⟩ for arbitrary unknown |ψ⟩.
  • Follow the proof sketch via linearity showing why cloning is impossible.
  • Explain why no-cloning matters for quantum cryptography and error correction.
  • Rewrite projective measurement in the density-matrix language: ρ → ΠρΠ/Tr(Πρ).
  • Resolve the course's Week-9 discussion prompt: what would break if cloning were possible.

9.1The No-Cloning Theorem

Classical bits are trivial to copy — read the value, write it somewhere else. Can a quantum computer do the same for a qubit in an unknown state |ψ⟩? The no-cloning theorem says no:

No unitary U exists such that U(|ψ⟩⊗|0⟩) = |ψ⟩⊗|ψ⟩   for every unknown |ψ⟩"Unknown" is essential: if you already know |ψ⟩ classically, you can trivially prepare a second copy from scratch. The theorem forbids a universal copier that works without knowing the state in advance.

This is not a statement about current technology being too primitive — it is a hard mathematical fact about unitary operators themselves, true for any possible quantum hardware, present or future. It directly answers part of the Week-9 discussion prompt from the course page: there is no sense in which "better engineering" could someday build a universal qubit copier.

9.2Proof Sketch via Linearity

Suppose, for contradiction, that a cloning unitary U did exist, working correctly on two different known basis states:

U(|0⟩⊗|0⟩) = |0⟩⊗|0⟩    U(|1⟩⊗|0⟩) = |1⟩⊗|1⟩These two cases are unremarkable — cloning a definite, known basis state is easy classically too.

Now apply U to the superposition |ψ⟩ = (|0⟩+|1⟩)/√2 tensored with |0⟩. Because U is unitary, it must be linear — it distributes over the sum exactly like any linear operator:

U(|ψ⟩⊗|0⟩) = U[(|0⟩⊗|0⟩ + |1⟩⊗|0⟩)/√2] = (|0⟩⊗|0⟩ + |1⟩⊗|1⟩)/√2Linearity forces U to act on each term separately and add the results — U cannot "look at" the whole superposition first.

But correct cloning would require the output to be |ψ⟩⊗|ψ⟩ = [(|0⟩+|1⟩)/√2] ⊗ [(|0⟩+|1⟩)/√2] = (|00⟩+|01⟩+|10⟩+|11⟩)/2 — a product state with four equal terms. What linearity actually produced, (|00⟩+|11⟩)/√2, is instead a Bell state — maximally entangled, with only two terms. These are not the same state, so U fails to clone the superposition even though it clones the two basis states perfectly. No choice of U can fix this: linearity is forced by unitarity, and linearity always produces this mismatch for any superposition. Hence no universal cloning unitary can exist.

Common mistakeDon't confuse no-cloning with "you can't observe a qubit." No-cloning is about copying an unknown state without destroying or revealing it — a different (though related) restriction from the collapse that happens when you measure. You also cannot clone by measuring and re-preparing: measurement destroys the unknown amplitudes themselves (§9.3), so there is nothing left to copy from.

9.3Measurement Revisited: Projective Measurement on ρ

Lecture 1 described measurement informally as "collapse to a basis state with probability given by the Born rule." Now that you have the density-matrix language from Lecture 8, that same postulate can be written as a precise operator equation. Let Π be the projector onto a measurement outcome (e.g. Π₀ = |0⟩⟨0|). After measuring and obtaining that outcome, the state updates as:

ρ  →  ΠρΠ / Tr(Πρ)The numerator projects ρ onto the subspace of the observed outcome; the denominator Tr(Πρ) is exactly that outcome's probability, restoring normalization (trace 1) after the projection.

For a pure state ρ = |ψ⟩⟨ψ|, this formula reproduces exactly the familiar Lecture 1 picture: Πρ Π / Tr(Πρ) collapses to the pure state |b_k⟩⟨b_k| matching the observed outcome, with probability Tr(Π_kρ) = |c_k|² — the Born rule, unchanged. The advantage of the operator form is that it works identically for mixed states too, including the reduced density matrix of an entangled qubit from Lecture 8 — a case the ket-only picture from Lecture 1 had no language for at all.

9.4What Would Break If You Could Clone?

The course page's Week-9 discussion prompt asks what would break in physics or cryptography if cloning were possible. Now you have the tools to answer it directly:

If cloning existed → measure one copy in the {|0⟩,|1⟩} basis, measure another copy in the {|+⟩,|−⟩} basis → learn both α and β exactlyRepeating this over many clones of the same unknown |ψ⟩ would let you reconstruct the full state — something single-copy measurement can never do, since one measurement only yields one bit of basis-dependent information and destroys the rest.

Two concrete consequences follow immediately. Quantum key distribution (quantum cryptography, previewed for Course 4) relies on the fact that an eavesdropper intercepting a qubit cannot clone it, measure it undetected, and pass along a perfect copy — any interception attempt necessarily disturbs the state in a way the legitimate parties can detect. If cloning were possible, this entire security guarantee would vanish: an eavesdropper could silently clone every qubit, measure the clones at leisure, and forward the originals untouched. Quantum error correction (also Course 4) also depends on no-cloning: the usual classical fix for noise — keep three copies, vote on the majority — is unavailable for qubits, which is exactly why quantum error-correcting codes need a much more elaborate strategy (spreading one logical qubit's information across several physical qubits' correlations, rather than literal copies).

✦ Worked Example — applying the measurement update rule to a mixed state

Take ρ_A = I/2 (the maximally mixed reduced state from Lecture 8's Bell-pair example) and apply the measurement update for outcome Π₀ = |0⟩⟨0|.

  1. Compute Tr(Π₀ρ_A): Π₀ρ_A = |0⟩⟨0|·(½I) = ½|0⟩⟨0|, so Tr(Π₀ρ_A) = ½ — a 50% chance of measuring 0, as expected for a maximally mixed qubit.
  2. Compute the numerator: Π₀ρ_AΠ₀ = ½|0⟩⟨0|·|0⟩⟨0| = ½|0⟩⟨0| (using ⟨0|0⟩=1).
  3. Apply the update rule: ρ_A → (½|0⟩⟨0|) / (½) = |0⟩⟨0|.
  4. Interpretation: after measuring outcome 0, qubit A's state updates to the pure state |0⟩⟨0| — collapse happens for mixed states exactly as it does for pure ones, using the same operator formula. Before measurement, qubit A carried no information on its own (I/2); the act of measurement is what actually produces a definite outcome.

🛠️ Hands-On: simulate the cloning failure in QuTiP

Build the CNOT-based "classical copier" circuit from §9.2 and show it fails exactly on a superposition input, confirming the no-cloning proof numerically.

# no_cloning_check.py — Lecture 9
import numpy as np
from qutip import basis, tensor
from qutip.core.gates import cnot

ket0, ket1 = basis(2, 0), basis(2, 1)
U = cnot()                                     # the "copy" unitary: clones basis states correctly

# check U clones |0> and |1> correctly
out0 = U * tensor(ket0, ket0)
out1 = U * tensor(ket1, ket0)
print("clones |0> ->|00>:", (out0 - tensor(ket0, ket0)).norm() < 1e-9)   # True
print("clones |1> ->|11>:", (out1 - tensor(ket1, ket1)).norm() < 1e-9)   # True

# now try the superposition (|0>+|1>)/sqrt(2)
psi = (ket0 + ket1).unit()
actual   = U * tensor(psi, ket0)
intended = tensor(psi, psi)                    # what "successful cloning" would require

print("actual output:\n", actual)
print("intended (true) clone:\n", intended)
print("cloning succeeded:", (actual - intended).norm() < 1e-9)   # False -- matches the proof!

The actual output is the Bell state (|00⟩+|11⟩)/√2 predicted in §9.2 — entangled, not the product state |ψ⟩⊗|ψ⟩ true cloning would need. Try other superpositions, e.g. (ket0 + 1j*ket1).unit(), and confirm the mismatch persists.

Q1. The no-cloning theorem states that…
A. no unitary can map |ψ⟩|0⟩ → |ψ⟩|ψ⟩ for an arbitrary unknown |ψ⟩
B. qubits can never be measured twice
C. only entangled qubits can be copied
D. cloning is possible only with better hardware
Show answer

A. No-cloning is a mathematical fact about unitary operators — no universal copying unitary exists for an unknown state, regardless of hardware.

Q2. The proof of no-cloning relies crucially on the fact that unitary operators are…
A. Hermitian
B. non-invertible
C. linear
D. always diagonal
Show answer

C. Linearity forces U to distribute over a superposition term-by-term, producing an entangled Bell state instead of the desired product state |ψ⟩⊗|ψ⟩.

Q3. In density-matrix language, measuring outcome Π and obtaining it updates the state as…
A. ρ → ρ + Π
B. ρ → ΠρΠ / Tr(Πρ)
C. ρ → Π⁻¹ρΠ
D. ρ stays unchanged
Show answer

B. The projective measurement update rule projects ρ with Π and renormalizes by that outcome's probability Tr(Πρ), matching the Lecture 1 collapse picture when ρ is pure.

Q4. If cloning an unknown qubit were possible, which security application would be directly broken?
A. Classical RSA encryption
B. Classical hash functions
C. Classical majority-vote error correction
D. Quantum key distribution's eavesdropper-detection guarantee
Show answer

D. QKD's security relies on an eavesdropper being unable to clone a qubit and measure the clone undetected; cloning would let them intercept silently with no detectable disturbance.

Q5. Measuring outcome Π₀=|0⟩⟨0| on the maximally mixed state ρ=I/2 and obtaining 0 leaves the state in…
A. I/2, unchanged
B. (|0⟩+|1⟩)/√2
C. |0⟩⟨0|, a pure state
D. an undefined state, since I/2 has no ket representation
Show answer

C. Applying ρ → Π₀ρΠ₀/Tr(Π₀ρ) to ρ=I/2 gives exactly |0⟩⟨0| — the measurement produces a definite pure outcome even though the pre-measurement state was mixed.
