Week 3 · Lecture 3

Observables & Measurement

Lecture 1 gave you the Born rule for one special basis. This lecture shows it was really a special case of something much more general — and much more precise.

🎯 Learning Objectives

  • State why the eigenvalues of an observable are the only possible outcomes of measuring it.
  • Explain why the eigenvectors of an observable are the states the system collapses to.
  • Compute the expectation value ⟨A⟩ = ⟨ψ|A|ψ⟩ for a given state and operator.
  • Write the generalized Born rule (projective measurement) for an arbitrary Hermitian observable.
  • Compute ⟨Z⟩ for a qubit state by hand and verify it in QuTiP with expect().

3.1Eigenvalues Are the Only Possible Outcomes

Lecture 2 showed every observable is represented by a Hermitian operator A. Here is the payoff: when you measure the physical quantity that A represents, the number the instrument can display is never arbitrary — it must be one of A's eigenvalues, full stop.

A|ai⟩ = ai|ai⟩     →     measuring A can only ever return one of the numbers aiThe a_i are A's eigenvalues; the |a_i⟩ are its eigenvectors.

Because A is Hermitian, two convenient facts (proved in full generality, not just asserted) always hold: every eigenvalue ai is real — exactly what a measuring instrument needs to display — and eigenvectors belonging to different eigenvalues are automatically orthogonal. For the Pauli-Z observable, Z|0⟩ = +1|0⟩ and Z|1⟩ = −1|1⟩: the only possible outcomes of measuring Z are +1 and −1, and |0⟩, |1⟩ are the corresponding eigenvectors.

3.2Eigenvectors Are What You Collapse To

Lecture 1's collapse rule generalizes directly: if measuring A returns the specific value ai, the qubit's state immediately becomes the corresponding eigenvector |ai⟩. Measure A again right away and you get ai again with certainty — the state is now determinate for A. This is exactly what happened in Lecture 1 for the special case A = Z: getting outcome 0 collapsed the state to |0⟩, an eigenvector of Z with eigenvalue +1 (we just didn't call it that yet).

A general qubit state expands in A's eigenbasis as |ψ⟩ = c₁|a₁⟩ + c₂|a₂⟩, exactly the way it expands as α|0⟩ + β|1⟩ in the Z-eigenbasis. Which basis is "natural" depends entirely on which observable you're about to measure.

3.3The Expectation Value

If you measure A many times on identically-prepared copies of |ψ⟩, you get a spread of the eigenvalues ai, each with its own probability. The average of that spread is the expectation value, and it has a remarkably compact formula:

⟨A⟩ = ⟨ψ|A|ψ⟩The "sandwich" from Lecture 2, §2.2 — and the single most-used expression in the rest of this course.

This single expression secretly packages "sum of outcome times probability": expand |ψ⟩ in A's eigenbasis and ⟨A⟩ = Σi ai·|ci|² drops straight out. It requires A to be Hermitian — otherwise ⟨A⟩ could come out complex, which a real measured average never is.

Analogy⟨A⟩ is a weighted average exactly like a grade-point average: each possible "grade" (eigenvalue ai) is weighted by how likely you are to get it (|ci|²). ⟨ψ|A|ψ⟩ is just a compact way of writing that sum without ever picking a specific basis to expand in.

3.4Projective Measurement: the Generalized Born Rule

Here is Lecture 1's Born rule, restated for any Hermitian observable A with eigenvalues ai and orthonormal eigenvectors |ai⟩:

P(ai) = |⟨ai|ψ⟩|²The probability of measuring outcome a_i is the squared overlap between the state and that eigenvector.

Set A = Z and you recover exactly P(0) = |⟨0|ψ⟩|² = |α|² and P(1) = |⟨1|ψ⟩|² = |β|² from Lecture 1 — nothing new happened there, it was always this rule, in its simplest possible basis. The general version is called projective measurement: each outcome ai has an associated projector Pi = |ai⟩⟨ai|, and P(ai) = ⟨ψ|Pi|ψ⟩. Projective measurement is the formalism every later lecture's measurement step reduces to — multi-qubit measurement in Week 6, Bell-state measurement in Week 7, nothing fundamentally new ever gets added.

Common mistakeDon't confuse the expectation value ⟨A⟩ (a number you only get on average, after many measurements) with a single measurement's outcome (always exactly one eigenvalue ai, picked at random with probability P(ai)). ⟨A⟩ = −7/25 is a perfectly fine expectation value even though −7/25 is never itself a possible single-shot outcome of measuring Z (whose only outcomes are ±1) — you'll see exactly this in the worked example below.
✦ Worked Example — ⟨Z⟩ for a given qubit state

A qubit is prepared in |ψ⟩ = (3/5)|0⟩ + (4/5)|1⟩ (check: (3/5)² + (4/5)² = 9/25 + 16/25 = 1 ✓). Compute ⟨Z⟩.

  1. Method 1 — eigenvalue sum. Z's eigenvalues are +1 (for |0⟩) and −1 (for |1⟩), with probabilities P(0) = |3/5|² = 9/25 and P(1) = |4/5|² = 16/25. So ⟨Z⟩ = (+1)(9/25) + (−1)(16/25) = 9/25 − 16/25 = −7/25.
  2. Method 2 — the sandwich, directly. Z|ψ⟩ = (3/5)|0⟩ − (4/5)|1⟩ (Z flips the sign on |1⟩ only). Then ⟨ψ|Z|ψ⟩ = (3/5)(3/5) + (4/5)(−4/5) = 9/25 − 16/25 = −7/25. Same answer, as it must be.
  3. Interpretation: −7/25 = −0.28 is never a result any single measurement can show (only +1 or −1 are possible); it's the average you'd see over many repeated measurements, skewed toward −1 because P(1) = 16/25 is the bigger probability.

🛠️ Hands-On: expectation values with QuTiP's expect()

QuTiP has a built-in expect() function that computes ⟨ψ|A|ψ⟩ directly — no need to hand-expand in an eigenbasis.

# expectation.py — Lecture 3
from qutip import basis, sigmaz, expect

psi = 0.6 * basis(2, 0) + 0.8 * basis(2, 1)   # (3/5)|0> + (4/5)|1>, already normalized

print("<Z> =", expect(sigmaz(), psi))         # -0.28, matches the worked example (-7/25)

# Read off Z's eigenvalues and eigenvectors directly
eigvals, eigvecs = sigmaz().eigenstates()
print("Z eigenvalues:", eigvals)              # [-1.  1.] -- the only possible outcomes

Swap in sigmax() or sigmay() for the same state and recompute — ⟨X⟩ and ⟨Y⟩ come out different from ⟨Z⟩ because the state isn't an eigenstate of those operators. Try psi = (basis(2,0) + basis(2,1)).unit() and verify ⟨X⟩ = 1 exactly — that state is an eigenstate of X (it's |v₊⟩ from Lecture 2's worked example).

🔗 Where this is heading

Projective measurement is the last piece needed before the geometric picture of Week 4: every single-qubit state, together with the Z, X, and Y expectation values it produces, corresponds to one point on a sphere — the Bloch sphere. The eigenvalues ±1 of Z, X, and Y become the sphere's three coordinate axes, and ⟨Z⟩, ⟨X⟩, ⟨Y⟩ for a given state become that point's actual (x, y, z) coordinates. This is also the formalism behind Week 3's course discussion: measurement returns one eigenvalue at random and destroys the superposition — so in what sense was the qubit "really" in a superposition the instant before you looked?

Q1. Measuring observable A on a qubit can return…
A. any complex number
B. only one of A's eigenvalues
C. only +1 or −1, regardless of A
D. the expectation value ⟨A⟩ itself
Show answer

B. The measured value is always one of A's eigenvalues. (Option C only happens to be true for Pauli observables specifically, since their eigenvalues are ±1 — it isn't true in general.)

Q2. After a measurement of A returns outcome ai, the qubit's new state is…
A. unchanged from before the measurement
B. a random superposition
C. the eigenvector |ai⟩ corresponding to that outcome
D. the zero vector
Show answer

C. Collapse sends the state to the eigenvector matching the obtained eigenvalue — measuring A again immediately afterward returns ai with certainty.

Q3. The expectation value ⟨A⟩ = ⟨ψ|A|ψ⟩ is best described as…
A. the single most likely outcome of one measurement
B. always equal to one of A's eigenvalues
C. the state the system collapses to
D. the probability-weighted average outcome over many repeated measurements
Show answer

D. ⟨A⟩ is an average over many measurements, weighted by each eigenvalue's probability — and, as the worked example shows, it need not equal any single possible outcome.

Q4. For |ψ⟩ = (3/5)|0⟩ + (4/5)|1⟩, what is ⟨Z⟩?
A. −7/25
B. 7/25
C. 1
D. 0
Show answer

A. ⟨Z⟩ = P(0) − P(1) = 9/25 − 16/25 = −7/25, as derived two ways in the worked example.

Q5. The generalized Born rule P(ai) = |⟨ai|ψ⟩|² reduces to Lecture 1's P(0) = |α|², P(1) = |β|² when…
A. the state is unnormalized
B. A is chosen to be the Pauli-Z operator, whose eigenvectors are |0⟩ and |1⟩
C. the qubit is in a Bell state
D. A is not Hermitian
Show answer

B. Lecture 1's rule was always this general rule, just specialized to measuring Z in its own eigenbasis {|0⟩, |1⟩}.

✓ What you learned

  • An observable's eigenvalues are the only possible measurement outcomes; its eigenvectors are the post-measurement collapse states.
  • Computed expectation values ⟨A⟩ = ⟨ψ|A|ψ⟩ two equivalent ways.
  • Wrote the generalized Born rule — projective measurement — P(ai) = |⟨ai|ψ⟩|², and recovered Lecture 1's rule as the special case A = Z.
  • Computed ⟨Z⟩ by hand for a concrete state and verified it numerically with QuTiP's expect().
