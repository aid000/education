Week 1 · Lecture 1

States, Vectors & the Qubit

A classical bit is 0 or 1. A qubit is a vector — and that single change is where all the power comes from.

🎯 Learning Objectives

  • Write a qubit state in Dirac (ket) notation as a superposition of |0⟩ and |1⟩.
  • Interpret the complex amplitudes and apply the normalization condition.
  • Use the Born rule to turn amplitudes into measurement probabilities.
  • Explain why superposition is not "both values at once" in the classical sense, and what measurement does to a state.
  • Build a qubit state in QuTiP and read off its measurement probabilities.

1.1From Bit to Qubit

A classical bit is in exactly one of two states, 0 or 1. A quantum bit — a qubit — is described instead by a two-dimensional vector. We name the two basis states with Dirac's ket notation:

|0⟩ = [ 1 , 0 ]ᵀ     |1⟩ = [ 0 , 1 ]ᵀThe two "poles" — the quantum analogues of classical 0 and 1, written as column vectors.

A general qubit is a superposition — a weighted combination of both:

|ψ⟩ = α|0⟩ + β|1⟩ = [ α , β ]ᵀα and β are complex numbers called probability amplitudes.

The coefficients α and β are complex numbers, called amplitudes. The fact that they are complex (not just real, not just probabilities) is what gives quantum computing its interference effects — the engine behind every quantum algorithm later in this track.

1.2Normalization

Amplitudes are not probabilities, but their squared magnitudes must behave like one — they have to sum to 1. This is the normalization condition:

|α|² + |β|² = 1For a complex number z = a + bi, the squared magnitude is |z|² = a² + b² = z*z.

Geometrically, a qubit state is a unit vector: an arrow of length one in a two-dimensional complex space. Any physically valid qubit lives on that unit sphere; operations we apply later (gates) rotate the arrow but never change its length, because probability must always total 1.

AnalogyThink of the amplitudes as the legs of a right triangle and normalization as the Pythagorean theorem: |α|² + |β|² = 1 is just "the hypotenuse has length one." A quantum gate spins that unit arrow around; it never stretches it. (In Week 4 this picture becomes the Bloch sphere.)

1.3Measurement & the Born Rule

You cannot read α and β directly. The only way to extract information is to measure, and measurement is probabilistic. The Born rule says: measuring |ψ⟩ in the {|0⟩, |1⟩} basis returns…

P(0) = |α|²     P(1) = |β|²The probability of each outcome is the squared magnitude of its amplitude.

And then the state collapses: after you see outcome 0, the qubit is |0⟩; measure again and you get 0 with certainty. The superposition is gone. Measurement is irreversible and destroys the very thing — the amplitudes — you might have wanted to learn.

Common mistakeSuperposition is not "the qubit is secretly 0 and 1 at the same time" like a spinning coin you haven't looked at. The amplitudes can be negative or complex and can cancel (interfere) — something classical "hidden" probabilities can never do. Treating a qubit as a coin-you-haven't-flipped gives wrong predictions for every interference experiment.

1.4Global vs Relative Phase

Because only |α|² and |β|² are observable, multiplying the entire state by a phase factor eiφ changes nothing measurable — this is an unobservable global phase. But the relative phase between α and β is very real: it controls how amplitudes interfere when you apply gates. Hold onto this distinction; it is the source of half the subtle bugs in quantum algorithms.

eiφ|ψ⟩ ≡ |ψ⟩  (same physics)   but   |0⟩+|1⟩ ≠ |0⟩−|1⟩  (different physics)
✦ Worked Example — probabilities of a superposition

A qubit is prepared in the state |ψ⟩ = (|0⟩ + i|1⟩) / √2. Verify it's normalized, then find the probabilities of measuring 0 and 1.

  1. Read off the amplitudes: α = 1/√2 and β = i/√2.
  2. Squared magnitudes: |α|² = (1/√2)² = 1/2. For β, |i/√2|² = |i|²·(1/√2)² = 1·(1/2) = 1/2.
  3. Check normalization: |α|² + |β|² = 1/2 + 1/2 = 1 ✓ — a valid state.
  4. Born rule: P(0) = |α|² = 1/2, P(1) = |β|² = 1/2. It's a 50/50 measurement.
  5. Subtlety: this state and (|0⟩ + |1⟩)/√2 give the same 50/50 probabilities, yet they are physically different states — the factor of i is a relative phase that shows up the moment you apply a gate (Week 2+).

🛠️ Hands-On: build the state in QuTiP

QuTiP (the Quantum Toolbox in Python) is the free simulator we use all course. Week 1 setup: install it once (below), then reuse it every lecture and for the project.

⬇ Install Python + QuTiP (one-time, Week 1 setup)

With Python 3 installed (from python.org or your package manager), create an environment and install QuTiP + notebooks:

python3 -m venv qc-env
source qc-env/bin/activate         # macOS / Linux
qc-env\Scripts\activate            # Windows (PowerShell)
pip install qutip numpy matplotlib jupyter

Verify: run python -c "import qutip; print(qutip.__version__)" — a version string means you're set. No quantum hardware is ever required; everything runs on the simulator.

Now build |ψ⟩ = (|0⟩ + i|1⟩)/√2 and confirm the 50/50 probabilities from the worked example.

# qubit_state.py — Lecture 1
import numpy as np
from qutip import basis

ket0, ket1 = basis(2, 0), basis(2, 1)        # |0> and |1>
psi = (ket0 + 1j*ket1).unit()                # (|0> + i|1>)/sqrt(2), .unit() normalizes

alpha = psi[0, 0]                            # amplitude of |0>
beta  = psi[1, 0]                            # amplitude of |1>
print("P(0) =", abs(alpha)**2)               # 0.5
print("P(1) =", abs(beta)**2)                # 0.5
print("norm =", psi.norm())                  # 1.0

Change the state to (ket0 + ket1).unit() and to (2*ket0 + ket1).unit(). Predict P(0) and P(1) before running — the second is no longer 50/50.

🔗 Where this is heading

One qubit on a unit sphere doesn't beat a classical bit — the power appears when you combine qubits. Two qubits need 4 amplitudes, ten need 1,024, and n qubits need 2ⁿ: the state space grows exponentially (Week 6). Within that space live entangled states (Week 7) with correlations no classical system can reproduce, and the complex relative phases you met in §1.4 let amplitudes interfere — cancelling wrong answers and reinforcing right ones. That interference is exactly how Grover's search and the quantum Fourier transform get their speed-ups in Course 3.

❓ Lecture 1 Quiz

5 questions · click "Show answer" to check yourself.

Q1. In the state |ψ⟩ = α|0⟩ + β|1⟩, the numbers α and β are…
A. real probabilities that sum to 1
B. complex amplitudes whose squared magnitudes sum to 1
C. integers labeling the basis states
D. the measurement outcomes themselves
Show answer

B. Amplitudes are complex; it is |α|² and |β|² that are probabilities and sum to 1. Their complexity (and possible negativity) is what enables interference.

Q2. A qubit is in state |ψ⟩ = (√3/2)|0⟩ + (1/2)|1⟩. The probability of measuring 1 is…
A. 1/2
B. √3/2
C. 1/4
D. 3/4
Show answer

C. P(1) = |β|² = (1/2)² = 1/4. (Check: P(0) = (√3/2)² = 3/4, and 3/4 + 1/4 = 1 ✓.)

Q3. Immediately after you measure a qubit and obtain outcome 0, the state is…
A. unchanged — still a superposition
B. |1⟩
C. |0⟩ (it has collapsed)
D. destroyed and undefined
Show answer

C. Measurement collapses the state to the basis state matching the outcome. Measure again and you get 0 with certainty — the superposition is gone.

Q4. Which condition makes |ψ⟩ = α|0⟩ + β|1⟩ a valid qubit state?
A. α + β = 1
B. |α| + |β| = 1
C. |α|² + |β|² = 1
D. α² + β² = 1
Show answer

C. Normalization requires the squared magnitudes to sum to 1. (Option D fails for complex amplitudes — you need the squared magnitudes |α|², not α².)

Q5. Multiplying an entire qubit state by eiφ (a global phase)…
A. changes all measurement probabilities
B. has no observable effect
C. swaps |0⟩ and |1⟩
D. is not allowed
Show answer

B. A global phase is unobservable — |eiφα|² = |α|². Only the relative phase between amplitudes affects physics (through interference).

✓ What you learned

  • Wrote a qubit in Dirac notation as |ψ⟩ = α|0⟩ + β|1⟩ — a unit vector in a 2-D complex space.
  • Interpreted α, β as complex amplitudes and applied normalization |α|² + |β|² = 1.
  • Used the Born rule: P(0) = |α|², P(1) = |β|², followed by collapse on measurement.
  • Distinguished an unobservable global phase from a physically real relative phase.
  • Built and probed a qubit state in QuTiP.
