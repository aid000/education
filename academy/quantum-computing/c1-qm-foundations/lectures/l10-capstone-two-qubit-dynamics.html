10.2Step 1 — Define States and Apply Single-Qubit Operators

Start with the basics from Lecture 1 (states) and Lecture 5 (unitary operators): build the computational basis, then apply the Hadamard gate H to create a superposition.

H|0⟩ = (|0⟩+|1⟩)/√2    H|1⟩ = (|0⟩−|1⟩)/√2The Hadamard is a unitary operator — it preserves normalization while rotating a basis state into an equal superposition.

10.3Step 2 — Build an Entangled Pair with CNOT

Tensor a Hadamard-rotated qubit with a second qubit in |0⟩ (Lecture 6), then apply the two-qubit CNOT unitary — exactly the "classical copier" circuit from Lecture 9's no-cloning hands-on, now put to its actual intended use: entangling, not cloning.

CNOT · (H|0⟩ ⊗ |0⟩) = CNOT · [(|00⟩+|10⟩)/√2] = (|00⟩+|11⟩)/√2 = |Φ⁺⟩H creates the superposition on qubit A; CNOT then correlates qubit B's value with qubit A's, producing the Bell state from Lecture 7.

This two-gate recipe (Hadamard then CNOT) is the standard way to prepare any Bell state and reappears constantly once you reach circuits in Course 2.

10.4Step 3 — Evolve Under a Hamiltonian

Lecture 5 introduced the Schrödinger equation governing how a state changes continuously in time under a Hamiltonian H_sys (not to be confused with the Hadamard gate H above — unfortunate shared letter, standard notation). QuTiP's sesolve() (the Schrödinger-equation solver, for closed systems with no dissipation) numerically integrates this evolution for you:

i ħ d|ψ(t)⟩/dt = H_sys|ψ(t)⟩  ⟹  |ψ(t)⟩ = U(t)|ψ(0)⟩,  U(t) = e^(−iH_sys t/ħ)Unitary time evolution — the length of the state vector is preserved at every instant, exactly as required by probability conservation.

For a simple two-qubit coupling Hamiltonian (e.g. σ_x⊗σ_z), evolving the Bell state in time and tracking its measurement statistics is the heart of the full script below. The coupling is deliberately chosen to be asymmetric across the two qubits: a "same-Pauli" term like σ_z⊗σ_z or σ_x⊗σ_x leaves |Φ⁺⟩ completely unchanged (it's a simultaneous eigenstate of all three symmetric Pauli-pairs, so you'd only ever see a global phase), while σ_x⊗σ_z actually rotates it into the orthogonal Bell state |Ψ⁻⟩ and back, which is what produces a non-trivial correlation plot.

10.5Step 4 — Compute Measurement Statistics and Verify Correlations

With the entangled, time-evolved state in hand, apply everything from Lectures 1, 8, and 9: Born-rule probabilities for each qubit individually, the reduced density matrix of each qubit via partial trace, and the joint two-qubit outcome probabilities, to confirm the correlation pattern from Lecture 7 survives.

P(joint outcome) = Tr(ρ · P_outcome)    ρ_A = Tr_B(ρ)    ⟨σ_z^(A)σ_z^(B)⟩ = Tr(ρ · σ_z^(A)⊗σ_z^(B))The same three operator formulas from Lecture 8, now applied to the time-evolved state rather than the static Bell state.
✦ Worked Example — predicting the project's expected output by hand

Before running any code, predict what the script in §10.6 should report for the un-evolved Bell state |Φ⁺⟩, so you can sanity-check the simulation's output against hand calculation.

  1. Individual qubit probabilities: from Lecture 8, ρ_A = ρ_B = I/2, so P(0) = P(1) = 1/2 for each qubit alone.
  2. Joint probabilities: directly from |Φ⁺⟩'s amplitudes, P(00) = |1/√2|² = 1/2, P(11) = 1/2, and P(01) = P(10) = 0.
  3. Correlation check: P(00) + P(11) = 1 while P(01) + P(10) = 0 confirms the two qubits always agree — the same correlation pattern from Lecture 7's figure, now in explicit numbers.
  4. Expectation value: ⟨σ_z^(A)σ_z^(B)⟩ = (+1)(+1)P(00) + (−1)(−1)P(11) + (+1)(−1)P(01) + (−1)(+1)P(10) = ½+½+0+0 = +1 — perfect correlation, the maximum value possible.
  5. What to expect after time evolution: a nontrivial Hamiltonian will generally rotate these probabilities away from exactly 0.5/0.5 and the correlation away from exactly +1 — §10.6's script reports both the t=0 values (which should match this hand calculation exactly) and the evolved values.

🛠️ Hands-On: the full capstone script

This is longer than previous lectures' code on purpose — it is the actual project deliverable, assembled end to end. Run it section by section and compare the t=0 printout against the worked example above.

# capstone_two_qubit_project.py — Lecture 10 / Course Project
import numpy as np
from qutip import basis, tensor, qeye, sigmaz, sigmax, sesolve
from qutip.gates import hadamard_transform, cnot

# ---- Step 1: states + single-qubit operator (L1, L5) ----
ket0, ket1 = basis(2, 0), basis(2, 1)
H = hadamard_transform(1)                      # single-qubit Hadamard unitary
qA_super = H * ket0                            # (|0>+|1>)/sqrt(2)

# ---- Step 2: tensor + CNOT to build a Bell state (L6, L7, L9) ----
joint0 = tensor(qA_super, ket0)                # product state before entangling
CX = cnot()
bell = CX * joint0                             # |Phi+> = (|00> + |11>)/sqrt(2)
print("Bell state built:\n", bell)

# ---- Step 3: evolve under a two-qubit Hamiltonian (L5) ----
H_sys = 0.5 * tensor(sigmax(), sigmaz())       # coupling Hamiltonian; rotates |Phi+> into |Psi-> and back
times = np.linspace(0, 2 * np.pi, 50)
result = sesolve(H_sys, bell, times)           # closed-system unitary evolution (no dissipation)
psi_t = result.states[-1]                      # state at the final time

# ---- Step 4: measurement statistics, t=0 vs. evolved (L1, L8, L9) ----
def joint_probs(psi):
    rho = psi * psi.dag()
    P00 = tensor(ket0*ket0.dag(), ket0*ket0.dag())
    P01 = tensor(ket0*ket0.dag(), ket1*ket1.dag())
    P10 = tensor(ket1*ket1.dag(), ket0*ket0.dag())
    P11 = tensor(ket1*ket1.dag(), ket1*ket1.dag())
    return {k: (rho * P).tr().real for k, P in
            [("00",P00), ("01",P01), ("10",P10), ("11",P11)]}

def zz_correlation(psi):
    rho = psi * psi.dag()
    ZZ = tensor(sigmaz(), sigmaz())
    return (rho * ZZ).tr().real

print("t=0 joint probabilities:   ", joint_probs(bell))     # matches worked example exactly
print("t=0 <Z_A Z_B> correlation: ", zz_correlation(bell))   # +1.0
print("t=T joint probabilities:   ", joint_probs(psi_t))
print("t=T <Z_A Z_B> correlation: ", zz_correlation(psi_t))

# ---- reduced single-qubit states, confirming L8's I/2 result at t=0 ----
rho_A_t0 = (bell * bell.dag()).ptrace(0)
print("rho_A at t=0 (expect I/2):\n", rho_A_t0)

🎓 Course Recap — the Full 10-Week Arc

  1. Wks 1-2 — States & operators: a qubit is a unit vector |ψ⟩ = α|0⟩+β|1⟩; measurement follows the Born rule; bras, inner products, and matrices represent operators acting on states.
  2. Wk 3 — Observables & measurement: eigenvalues as outcomes, expectation values, and projective measurement as the formal operation behind collapse.
  3. Wks 4-5 — Geometry & dynamics: the Bloch sphere pictures a single qubit's full state; unitary evolution under the Schrödinger equation moves it around that sphere while preserving probability.
  4. Wks 6-7 — Multiple qubits: the tensor product builds 2ⁿ-dimensional joint spaces; entanglement is the failure to factor a joint state, with the four Bell states as the extreme case and Bell's inequality as the proof it's not classical "hidden" information.
  5. Wks 8-10 — Mixed states, limits, and synthesis: density matrices and the partial trace describe subsystems and uncertainty uniformly; the no-cloning theorem sets a hard limit on what quantum information allows; the capstone project strings every piece into one working two-qubit simulation.

This is the linear-algebra and postulate toolkit every later Academy course assumes you already have. Course 2 puts it into gates and circuits; Course 3 (algorithms) puts it to work solving problems; Course 4 (error correction & cryptography) pushes the no-cloning and entanglement ideas from this week into real protocols.
