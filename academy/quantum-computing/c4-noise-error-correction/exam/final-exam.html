Decoherence & Noise Channels · Weeks 1–3
1. An "open quantum system" is one that is…
Answer: D. Coupling to an environment is exactly what breaks the closed-system unitary picture used in C1–C3.
2. T1 and T2 differ because…
Answer: A. T1 is how fast population decays toward the ground state; T2 is how fast relative phase randomizes — and T2 ≤ 2·T1, never the reverse.
3. The Kraus-operator form ρ → Σᵢ KᵢρKᵢ† generalizes unitary evolution because it allows…
Answer: C. Setting all but one Kᵢ to zero recovers ordinary unitary evolution — Kraus form is strictly more general.
4. Which pair of Kraus operators defines the bit-flip channel with flip probability p?
Answer: D. With probability p, X is applied (a bit flip); with probability (1−p), nothing happens — and the completeness relation Σᵢ Kᵢ†Kᵢ=I holds for every p.
5. Applying the same depolarizing channel repeatedly to a state causes fidelity to the ideal state to decay…
Answer: B. Fₙ ≈ (1−p)ⁿ — each application multiplies the surviving fidelity by roughly (1−p) again, so small per-step losses compound into large losses over many operations.
Error Correction Basics: the Repetition Code · Week 4
6. The 3-qubit bit-flip repetition code encodes a logical qubit as…
Answer: A. Encoding entangles the three qubits — this is not cloning, which the no-cloning theorem forbids.
7. Syndrome measurement in the repetition code avoids collapsing the logical state by…
Answer: B. Parity checks reveal whether pairs of qubits agree or disagree without revealing the overall α,β superposition.
8. The repetition code offers zero protection against phase-flip (Z) errors because…
Answer: A. A Z error changes relative phase, not computational-basis population, so Z-basis parity checks see nothing wrong.
9. Compared to doing nothing, the repetition code reduces the logical bit-flip failure probability because…
Answer: C. Majority vote recovers from any single flip, so failure requires at least two simultaneous flips — roughly 3p²(1−p)+p³, smaller than p for p < 1/2.
Stabilizer Formalism · Weeks 5–6
10. An operator S "stabilizes" a codespace when…
Answer: D. Every valid codeword is a +1 eigenstate of every stabilizer in the group.
11. In stabilizer language, the 3-qubit repetition code's two generators are…
Answer: A. Z₁Z₂ and Z₂Z₃ are exactly the pairwise parity checks rewritten as stabilizer generators.
12. Generators of a stabilizer group are…
Answer: C. For an n-qubit code encoding k logical qubits, (n−k) independent generators suffice to generate the full group.
13. In the surface code, data qubits sit on…
Answer: B. Each vertex hosts a Z-type stabilizer over its surrounding edges; each face hosts an X-type stabilizer over its bordering edges.
14. The surface code protects against both bit-flip and phase-flip errors because…
Answer: A. Each error type anticommutes with the opposite stabilizer type, so having both stabilizer types everywhere on the lattice catches both error types.
Fault Tolerance & NISQ Reality · Weeks 7–8
15. The threshold theorem's central conclusion is that…
Answer: B. This is the precise statement behind why fault-tolerant quantum computing is believed possible in principle.
16. Above the threshold, scaling up a code's size…
Answer: C. Above threshold, every additional layer of correction introduces more errors than it fixes — the cure becomes worse than the disease.
17. Realistic threshold estimates for practical codes and architectures fall roughly in the range…
Answer: B. Depending on the code and hardware, p_th is typically estimated around one error in a thousand to one in a hundred per physical operation.
18. On today's good superconducting hardware, the dominant error source is typically…
Answer: D. Entangling two-qubit gates are harder to execute cleanly than single-qubit rotations, making them the dominant error contributor on most current hardware.
19. Readout error is distinct from gate error and decoherence because it…
Answer: D. Readout error happens after all quantum evolution is done — the state itself can be fine, and the detector still occasionally mis-reports the outcome.
20. Why isn't "best gates sit near the threshold" the same as "fault tolerance is practical today"?
Answer: A. The theorem's promise is real, but it demands a safety margin across every operation at scale that today's hardware hasn't yet reached.
Error Mitigation & Capstone · Weeks 9–10
21. Zero-noise extrapolation works by…
Answer: C. ZNE never achieves literally zero noise — it estimates the zero-noise answer by fitting a trend through deliberately noisier runs.
22. A confusion matrix, used in readout-error correction, records…
Answer: D. Calibration means preparing each known basis state and recording how often the detector misreports it as something else.
23. The key distinction between error mitigation and error correction is that mitigation…
Answer: D. Mitigation leaves the quantum circuit unchanged and works entirely on the classical output; correction spends real physical qubits and gates.
24. In the capstone's logical-vs-physical error rate sweep, "code wins" at a given noise strength means…
Answer: C. "Code wins" means the code's logical failure rate sits below the break-even diagonal P_logical=p — a direct, simulated instance of the threshold theorem's qualitative promise.
25. Course 5 (Variational & Hybrid Algorithms) connects to this course because it…
Answer: B. VQE/QAOA-style hybrid algorithms are the dominant near-term approach precisely because they're designed around the NISQ-era noise this course spent ten weeks characterizing.
