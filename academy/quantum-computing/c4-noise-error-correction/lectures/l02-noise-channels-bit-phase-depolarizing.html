Noise Channels: Bit-Flip, Phase-Flip & Depolarizing

Last week you watched noise act on a density matrix informally. This week you get the actual machinery — Kraus operators — and the three channels you'll see for the rest of the course.

🎯 Learning Objectives

  • Generalize unitary evolution ρ→UρU† to the Kraus-operator form ρ→Σᵢ KᵢρKᵢ† for non-unitary, noisy evolution.
  • State the completeness relation Σᵢ Kᵢ†Kᵢ = I and explain why it guarantees Tr(ρ)=1 is preserved.
  • Write down the Kraus operators for the bit-flip, phase-flip, and depolarizing channels.
  • Apply the bit-flip channel to a density matrix by hand and verify the result is still a valid, trace-1 density matrix.
  • Build all three channels in PennyLane and watch each one act differently on the same input state.

2.1From a Single Unitary to a Sum of Kraus Operators

Recall from C1 L5: closed-system evolution is a single unitary acting on both sides of the density matrix, ρ → UρU†. That picture has a hidden assumption — exactly one, fully-known U happens, with certainty. Open-system noise (Lecture 1's whole point) breaks that assumption: the environment might "apply" any of several different operators, each with some probability, and you don't get to know which one actually happened.

The fix is almost embarrassingly simple: replace the single U with a set of operators {Kᵢ}, called Kraus operators, and sum over all of them:

ρ → ℰ(ρ) = Σᵢ Kᵢ ρ Kᵢ†The Kraus-operator (operator-sum) representation of a quantum channel ℰ. Each Kᵢ is one "branch" of what might have happened to the qubit.

Set all but one Kᵢ to zero and this collapses back to ordinary unitary evolution — Kraus form is strictly more general, not a replacement. The one extra rule that makes it physical is the completeness relation:

Σᵢ Kᵢ† Kᵢ = IThis is exactly what guarantees Tr(ℰ(ρ)) = Tr(ρ) = 1 — total probability still sums to one after the channel acts, even though no single Kᵢ is unitary on its own.
AnalogyA single unitary is like a train that always takes the one track you laid down. A Kraus channel is a switchyard: the train might get routed down track K₀ with some probability, or track K₁ with another probability — you don't control (or see) which switch fired, but you know, in advance, exactly how likely each track is and where each one leads. The completeness relation is just the statement that the probabilities over all tracks add up to one.

2.2The Bit-Flip Channel

The simplest noise channel says: with probability p, the environment applies an unwanted Pauli-X (a bit flip); with probability (1−p), nothing happens. Two Kraus operators capture this exactly:

K₀ = √(1−p) · I    K₁ = √p · XK₀ is the "nothing happened" branch; K₁ is the "it flipped" branch.

Check completeness: K₀†K₀ + K₁†K₁ = (1−p)I†I + p·X†X = (1−p)I + pI = I, using X† = X and X² = I. The relation holds for any p ∈ [0,1], so this is a valid channel at every noise strength.

2.3The Phase-Flip Channel

Swap the X for a Z and you get the channel that attacks phase instead of population — the Kraus-operator version of the T2 dephasing from Lecture 1:

K₀ = √(1−p) · I    K₁ = √p · ZWith probability p, the relative phase between |0⟩ and |1⟩ flips sign (Z|0⟩=|0⟩, Z|1⟩=−|1⟩); with probability (1−p), nothing happens.

Phase-flip noise never touches the diagonal (population) entries of ρ at all — a qubit purely in |0⟩ or |1⟩ comes through completely unscathed. It only scrambles the off-diagonal coherence terms, which is exactly why it's invisible to a bit-flip-only countermeasure (foreshadowing: this is precisely the gap Lecture 4's repetition code will NOT close).

Common mistakeDon't assume "bit-flip code fixes bit flips, so it roughly handles noise." Phase-flip and bit-flip noise are structurally different — one is diagonal-preserving, one isn't — and a code built to catch one is, by construction, blind to the other. You'll see this gap explicitly in Lecture 4, and it's exactly why Lectures 5–6 generalize to stabilizer codes that catch both.

2.4The Depolarizing Channel

The third canonical channel is less surgical: with probability p, it throws away the qubit's state entirely and replaces it with the maximally mixed state I/2 (total ignorance — 50/50 on measurement, no coherence at all); with probability (1−p), it leaves the qubit alone.

ℰ(ρ) = (1−p)ρ + p · I/2This is the depolarizing channel written directly in terms of ρ, rather than as a sum over named Kraus operators — both forms are equivalent, and this is the form you'll use most often in code (Lecture 1's PennyLane snippet already used it).

Depolarizing noise is a convenient "worst case, average over all directions" model: it doesn't distinguish bit-flip from phase-flip error, it just uniformly scrambles everything with probability p. That's exactly why it shows up so often in Lecture 3's fidelity-decay analysis and in realistic device noise models later in the course.

✦ Worked Example — the bit-flip channel acting on |0⟩⟨0|

Apply the bit-flip channel with flip probability p to ρ = |0⟩⟨0| = [[1,0],[0,0]], and verify the result is still a valid density matrix.

  1. Set up the channel: K₀ = √(1−p)·I = [[√(1−p), 0],[0, √(1−p)]], K₁ = √p·X = [[0, √p],[√p, 0]].
  2. Compute K₀ρK₀†: K₀ρK₀† = (1−p)·[[1,0],[0,0]] = [[1−p, 0],[0, 0]].
  3. Compute K₁ρK₁†: K₁ρ = √p·X·[[1,0],[0,0]] = √p·[[0,0],[1,0]]. Then K₁ρK₁† = p·[[0,0],[0,1]] = [[0,0],[0,p]].
  4. Add them: ρ′ = K₀ρK₀† + K₁ρK₁† = [[1−p, 0],[0, p]].
  5. Verify Tr(ρ′) = 1: Tr(ρ′) = (1−p) + p = 1 for every p — exactly the completeness relation from §2.1 doing its job.
  6. Read the physics: ρ′ says "probability (1−p) the qubit is still |0⟩, probability p it flipped to |1⟩" — precisely what you'd expect from a channel that flips the bit with probability p. At p=0, ρ′=ρ (no noise); at p=1, the qubit flips with certainty, ρ′=[[0,0],[0,1]].

🛠️ Hands-On: all three channels, side by side, in PennyLane

PennyLane's default.mixed device (introduced in Lecture 1) ships BitFlip, PhaseFlip, and DepolarizingChannel as built-ins — no need to hand-code the Kraus matrices above, though it's worth confirming they match. One wrinkle: PennyLane's DepolarizingChannel(p) uses the Nielsen–Chuang convention (1−4p/3)ρ+(4p/3)(I/2), not the (1−p)ρ+p·I/2 form from §2.4 — the code below rescales p by 3/4 before calling it so the built-in matches this lecture's convention.

# three_channels.py — Lecture 2
import pennylane as qml
from pennylane import numpy as np

dev = qml.device("default.mixed", wires=1)

@qml.qnode(dev)
def channel_demo(p, kind):
    qml.Hadamard(wires=0)                 # start from |+> = (|0>+|1>)/sqrt(2), so coherence is visible
    if kind == "bitflip":
        qml.BitFlip(p, wires=0)
    elif kind == "phaseflip":
        qml.PhaseFlip(p, wires=0)
    elif kind == "depolarize":
        qml.DepolarizingChannel(3 * p / 4, wires=0)  # rescale: PennyLane's (1-4p_pl/3) = this lecture's (1-p)
    return qml.density_matrix(wires=0)

for kind in ["bitflip", "phaseflip", "depolarize"]:
    rho = channel_demo(0.3, kind)
    print(f"{kind:12s} p=0.3  rho =\n{np.round(rho, 3)}\n")

Watch the diagonal (populations) for bit-flip vs. the off-diagonal (coherence) for phase-flip: bit-flip noticeably moves population away from 50/50 only when applied repeatedly, phase-flip shrinks the off-diagonal terms directly, and depolarizing shrinks everything — diagonal and off-diagonal alike — uniformly toward the maximally mixed I/2.

❓ Lecture 2 Quiz

5 questions · click "Show answer" to check yourself.

Q1. The Kraus-operator form ρ → Σᵢ KᵢρKᵢ† generalizes unitary evolution ρ→UρU† because…
A. it only applies to mixed states, never pure ones
B. it allows a sum over several possible operators, each occurring with some probability, rather than one single certain unitary
C. it removes the need for a density matrix entirely
D. Kraus operators are always equal to the identity
Show answer

B. Setting all but one Kᵢ to zero recovers ordinary unitary evolution exactly — Kraus form is the strictly more general case where several "branches" can occur, each with its own weight.

Q2. The completeness relation Σᵢ Kᵢ†Kᵢ = I is required because…
A. it guarantees Tr(ℰ(ρ)) = 1, so the channel's output is still a valid probability-conserving density matrix
B. it forces every Kᵢ to be unitary individually
C. it is only needed for the depolarizing channel
D. it ensures the channel has exactly two Kraus operators
Show answer

A. Without completeness, Tr(ℰ(ρ)) could drift away from 1 — completeness is exactly the condition that keeps total probability conserved after the channel acts.

Q3. Which pair of Kraus operators defines the phase-flip channel?
A. K₀=√(1−p)·I, K₁=√p·X
B. K₀=I, K₁=X
C. K₀=√(1−p)·X, K₁=√p·I
D. K₀=√(1−p)·I, K₁=√p·Z
Show answer

D. Phase-flip uses Z in place of the bit-flip channel's X — it flips the relative phase between |0⟩ and |1⟩ instead of swapping their populations.

Q4. Why is phase-flip noise invisible to a qubit that starts purely in |0⟩ or |1⟩?
A. Phase-flip noise only acts on the off-diagonal (coherence) terms of ρ, which are already zero for a diagonal state
B. Phase-flip noise has zero probability by definition
C. Z and X have the same eigenvectors
D. |0⟩ and |1⟩ cannot be acted on by any Pauli operator
Show answer

A. Z|0⟩=|0⟩ and Z|1⟩=−|1⟩ up to an unobservable global phase — a basis state's diagonal density-matrix entries are untouched, so phase-flip noise only becomes visible once there's off-diagonal coherence to scramble.

Q5. The depolarizing channel ℰ(ρ) = (1−p)ρ + p·I/2 describes, with probability p…
A. replacing the qubit's state with the maximally mixed state I/2, discarding all information about ρ
B. applying a guaranteed bit flip
C. applying a guaranteed phase flip
D. measuring the qubit in the computational basis
Show answer

A. Depolarizing noise is the "total ignorance" channel: with probability p it swaps in I/2 (no memory of the original state at all), and with probability (1−p) it leaves ρ untouched.
