Week 8 · Lecture 8

NISQ-Era Reality: Gate Errors, T1/T2, Readout Error

The threshold theorem told you what's possible in principle. This week: the actual numbers on today's hardware — and why they fall short of "safely fault-tolerant," not because the theory is wrong, but because the engineering margin isn't there yet.

🎯 Learning Objectives

  • Cite typical real-hardware numbers: 2-qubit gate error rates (~10⁻³), T1/T2 (microseconds to ~100s of µs), and readout error.
  • Explain readout error as a distinct failure mode from gate error or decoherence — misclassifying a measurement outcome.
  • Explain why these numbers, taken together, keep full fault tolerance out of reach at today's scale.
  • Build a Qiskit-Aer noise model from realistic T1/T2 and gate-error parameters.
  • Show how circuit fidelity degrades as circuit depth increases under that noise model.

8.1The Numbers, Honestly

Every lecture so far has used abstract noise strengths — p, γ — as free parameters. This week, plug in what today's actual superconducting-qubit hardware reports:

QuantityTypical rangeWhat it costs
Single-qubit gate error~10⁻⁴ to 10⁻³relatively cheap; close to or below many threshold estimates
Two-qubit gate error~10⁻³ (good hardware)the dominant error source — entangling gates are harder than single-qubit rotations
T1 (relaxation)tens to ~100s of µsbounds how long a qubit can idle before decaying
T2 (dephasing)comparable to or shorter than T1bounds how long coherence/superposition survives
Readout error~1% to a few %misclassifying the final measurement — a distinct failure mode, see §8.2

Recall from Lecture 1: a two-qubit gate takes tens to hundreds of nanoseconds, while T1/T2 run tens to hundreds of microseconds — a thousand-fold gap that's exactly why there's a limited gate budget before decoherence wins, not an unlimited one.

8.2Readout Error: a Third, Distinct Failure Mode

Gate error and decoherence (T1/T2) both corrupt the quantum state itself before you ever measure it. Readout error is different: the qubit can be in a perfectly correct state, and the measurement apparatus still occasionally reports the wrong classical bit — a |0⟩ gets reported as "1" or vice versa, purely from imperfect discrimination in the detector electronics.

Common mistakeDon't lump readout error in with gate error or decoherence — it happens at a completely different stage (after all quantum evolution is already done) and is corrected differently. In fact, Week 9's readout-error mitigation technique fixes exactly this failure mode via classical post-processing, with zero change to the quantum circuit itself — a much cheaper fix than anything targeting gate error or decoherence.

8.3Why Full Fault Tolerance Isn't Practical Yet

Put Lecture 7's threshold theorem next to §8.1's table: today's best two-qubit gates (~10⁻³) sit near or sometimes nominally below conservative threshold estimates (10⁻³–10⁻²) — so the theorem's promise is, in principle, within reach. But a real fault-tolerant computation needs every operation across every qubit — idle periods, readout, crosstalk between neighboring qubits, calibration drift over the course of a run — to stay safely under threshold simultaneously, at the scale of thousands or millions of physical qubits implementing a useful logical circuit. No current device does that today.

That gap is precisely why this course doesn't end at "build the surface code and you're done." Week 9 introduces error mitigation: techniques that don't require extra encoding qubits at all, trading full fault tolerance for a pragmatic, near-term improvement using only classical post-processing.

🛠️ Hands-On: a realistic Qiskit-Aer noise model

This is where Qiskit-Aer's noise-model machinery (mentioned back in Lecture 1's install step, deliberately held off until now) finally returns — it's built specifically to encode exactly the kind of device numbers in §8.1's table.

# nisq_noise_model.py — Lecture 8
from qiskit import QuantumCircuit
from qiskit_aer import AerSimulator
from qiskit_aer.noise import NoiseModel, thermal_relaxation_error, depolarizing_error

# realistic-ish parameters (microseconds for T1/T2, nanoseconds for gate time)
T1, T2, gate_time_2q = 100_000, 80_000, 300   # ns: T1=100us, T2=80us, 2q-gate=300ns
two_q_error_rate = 1e-3

noise_model = NoiseModel()
relax_error = thermal_relaxation_error(T1, T2, gate_time_2q).tensor(
              thermal_relaxation_error(T1, T2, gate_time_2q))
depol_error = depolarizing_error(two_q_error_rate, 2)
noise_model.add_all_qubit_quantum_error(relax_error.compose(depol_error), ['cx'])

sim = AerSimulator(noise_model=noise_model)

# fidelity vs. circuit depth: a chain of CNOTs that should return to |00> if noiseless
for depth in [0, 2, 10, 30, 80]:
    qc = QuantumCircuit(2, 2)
    for _ in range(depth):
        qc.cx(0, 1); qc.cx(0, 1)   # CNOT is its own inverse -- noiseless result is always |00>
    qc.measure([0, 1], [0, 1])
    counts = sim.run(qc, shots=2000).result().get_counts()
    p00 = counts.get('00', 0) / 2000
    print(f"depth={depth:3d} (x2 CNOTs)   P(correct |00>) = {p00:.3f}")

With zero noise, every depth should return exactly '00' (CNOT∘CNOT = identity). Under the noise model, watch P(correct) fall steadily as depth grows — a direct, numerical replay of Lecture 3's fidelity-decay argument, now driven by real device-shaped numbers instead of an abstract p.

Q1. On today's good superconducting hardware, the dominant error source is typically…
A. single-qubit gates, at error rates around 50%
B. idle time with no gates at all
C. two-qubit gates, at error rates around 10⁻³
D. classical control electronics, which have zero error
Show answer

C. Entangling two-qubit gates are harder to execute cleanly than single-qubit rotations, making them the dominant error contributor on most current hardware.

Q2. Readout error is distinct from gate error and decoherence because it…
A. occurs during the measurement stage, misclassifying an already-correct quantum state into the wrong classical bit
B. corrupts the quantum state before any gate runs
C. is identical in mechanism to T1 relaxation
D. only happens in simulation, never on real hardware
Show answer

A. Readout error happens after all quantum evolution is done — the state itself can be fine, and the detector electronics still occasionally mis-report the outcome.

Q3. Why isn't "best gates sit near the threshold" the same as "fault tolerance is practical today"?
A. Because the threshold theorem has never been experimentally tested
B. Because fault tolerance requires every operation on every qubit — idle time, readout, crosstalk, drift included — to stay safely under threshold simultaneously, at large scale, which current devices don't achieve
C. Because thresholds only apply to classical bits
D. Because gate errors are actually zero on all current hardware
Show answer

B. The theorem's promise is real, but it demands a safety margin across every operation at scale that today's hardware hasn't reached yet — an engineering gap, not a theoretical one.

Q4. In the hands-on noise-model demo, a circuit made of CNOT-CNOT pairs (noiselessly equal to identity) shows what behavior as depth increases?
