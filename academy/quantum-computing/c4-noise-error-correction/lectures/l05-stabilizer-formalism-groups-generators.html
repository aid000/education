Stabilizer Formalism I: Stabilizer Groups & Generators

Last week's repetition code worked, but its description was ad hoc — parity checks, majority vote, a lookup table. This week: the language that describes any such code precisely, and generalizes.

🎯 Learning Objectives

  • Define a stabilizer: an operator S with S|ψ⟩=+1|ψ⟩ for every state |ψ⟩ in the codespace.
  • Describe the stabilizer group — the full set of operators that stabilize a codespace — and why it's closed under multiplication.
  • Explain generators: a small set of stabilizers whose products produce the entire stabilizer group.
  • Re-derive the repetition code's stabilizers (Z₁Z₂ and Z₂Z₃) from Lecture 4 in this new language.
  • Connect syndrome measurement (Lecture 4) to measuring stabilizer generators and reading off ±1 eigenvalues.

5.1A Stabilizer: an Operator That Leaves the Code Alone

A quantum error-correcting code is really just a special subspace of the full Hilbert space — the codespace — where all the valid encoded states live. The stabilizer formalism describes that subspace indirectly: instead of listing the states themselves, it lists the operators that leave every state in the codespace completely unchanged.

S|ψ⟩ = +1 · |ψ⟩    for every |ψ⟩ in the codespaceS "stabilizes" the codespace: every valid encoded state is a +1 eigenstate of S. States outside the codespace generally are not.

This might look backwards at first — describing a space by what doesn't change it — but it's exactly what makes error detection possible: if noise knocks a state out of the codespace, that state is no longer a +1 eigenstate of every stabilizer, and measuring a stabilizer will sometimes return −1, flagging that something went wrong, all without collapsing the logical information (because the stabilizers themselves commute with the logical operators — more on that below).

5.2The Stabilizer Group

If S₁ and S₂ both stabilize the codespace (S₁|ψ⟩=|ψ⟩ and S₂|ψ⟩=|ψ⟩), then so does their product: S₁S₂|ψ⟩ = S₁(S₂|ψ⟩) = S₁|ψ⟩ = |ψ⟩. The full collection of all operators that stabilize a given codespace is therefore closed under multiplication — it forms a mathematical group, the stabilizer group.

AnalogyThink of the stabilizer group like the set of all symmetries of a square (rotations by 90°, 180°, 270°, plus reflections) — composing any two symmetries gives you another symmetry of the same square. Here, instead of symmetries of a shape, you have operators that are "symmetries" of the codespace: apply any combination of them, and a valid codeword comes back unchanged.

5.3Generators: the Small Set That Builds the Whole Group

A stabilizer group for an n-qubit code can have a huge number of elements, but — just like a group of symmetries can be built from a couple of basic moves — the entire stabilizer group is always generated by a much smaller set of generators: operators whose products (and products of products) produce every element of the group.

⟨S₁, S₂, …, S_{n−k}⟩ = full stabilizer groupFor a code encoding k logical qubits into n physical qubits, exactly (n−k) independent generators suffice — each one is measured once per error-correction cycle.

This is the precise version of what Lecture 4's syndrome measurement was already doing: each generator Sᵢ, when measured, returns +1 (no error relative to that check) or −1 (an error was detected by that check) — and the full string of ±1 outcomes across all generators is the syndrome.

5.4Re-Deriving the Repetition Code's Stabilizers

Lecture 4's parity checks were already stabilizer generators in disguise. For the 3-qubit bit-flip code with codewords |000⟩ and |111⟩, the two generators are:

S₁ = Z₁Z₂    S₂ = Z₂Z₃Z on each qubit returns +1 for |0⟩ and −1 for |1⟩, so Z₁Z₂ returns +1 whenever qubits 1 and 2 agree (both |0⟩ or both |1⟩), and −1 when they disagree — exactly a parity check.

Check both codewords: for |000⟩, Z₁Z₂|000⟩ = (+1)(+1)|000⟩ = +1|000⟩ ✓, and Z₂Z₃|000⟩ = +1|000⟩ ✓. For |111⟩, Z₁Z₂|111⟩ = (−1)(−1)|111⟩ = +1|111⟩ ✓, and likewise Z₂Z₃|111⟩=+1|111⟩ ✓. Both codewords are +1 eigenstates of both generators — exactly the stabilizer condition from §5.1. Now flip qubit 2 (an X error): the state becomes |010⟩ or |101⟩, and Z₁Z₂ now returns −1 (qubits 1,2 disagree) while Z₂Z₃ also returns −1 (qubits 2,3 disagree) — syndrome (−1,−1), which is just Lecture 4's syndrome (1,1) written as eigenvalues instead of classical bits.

Common mistakeDon't confuse the stabilizer generators (Z₁Z₂, Z₂Z₃ — which detect errors) with the logical operators of the code (which act on the encoded information, e.g. X₁X₂X₃ flips the logical qubit). Stabilizers must commute with the logical operators — that's precisely what lets you measure a stabilizer to extract syndrome information without disturbing α, β at all.
✦ Worked Example — measuring Z₂Z₃ on an erroneous state

The logical state α|000⟩+β|111⟩ suffers a bit flip on qubit 3, becoming α|001⟩+β|110⟩. Find the outcome of measuring the stabilizer generator Z₂Z₃.

  1. Apply Z₂Z₃ to the |001⟩ term: qubit 2 is |0⟩ (Z→+1), qubit 3 is |1⟩ (Z→−1). Z₂Z₃|001⟩ = (+1)(−1)|001⟩ = −|001⟩.
  2. Apply Z₂Z₃ to the |110⟩ term: qubit 2 is |1⟩ (Z→−1), qubit 3 is |0⟩ (Z→+1). Z₂Z₃|110⟩ = (−1)(+1)|110⟩ = −|110⟩.
  3. Combine: Z₂Z₃(α|001⟩+β|110⟩) = −1·(α|001⟩+β|110⟩) — both terms pick up the same −1 eigenvalue, so the full superposition is a −1 eigenstate of Z₂Z₃, cleanly, with no collapse.
  4. Check the other generator: Z₁Z₂ on |001⟩: qubits 1,2 are both |0⟩ → (+1)(+1)=+1. On |110⟩: qubits 1,2 are both |1⟩ → (−1)(−1)=+1. So Z₁Z₂ gives +1.
  5. Read the syndrome: (Z₁Z₂, Z₂Z₃) = (+1, −1) — only the second generator flagged an error, uniquely pointing at qubit 3 (the one qubit involved in Z₂Z₃ but not Z₁Z₂) — correct it with a targeted X₃.

🛠️ Hands-On: verifying stabilizers with PennyLane

Confirm, numerically, that |000⟩ and |111⟩ are both +1 eigenstates of Z₁Z₂ and Z₂Z₃, and that a single bit-flip breaks exactly the generators touching that qubit.

# stabilizer_check.py — Lecture 5
import pennylane as qml
from pennylane import numpy as np

dev = qml.device("default.qubit", wires=3)

@qml.qnode(dev)
def stabilizer_expectation(bitstring, flip_wire=None):
    for i, b in enumerate(bitstring):
        if b == '1':
            qml.PauliX(wires=i)
    if flip_wire is not None:
        qml.PauliX(wires=flip_wire)        # inject a bit-flip error
    return [qml.expval(qml.PauliZ(0) @ qml.PauliZ(1)),   # S1 = Z1 Z2
            qml.expval(qml.PauliZ(1) @ qml.PauliZ(2))]   # S2 = Z2 Z3

print("|000>, no error:        ", stabilizer_expectation('000'))
print("|111>, no error:        ", stabilizer_expectation('111'))
print("|000>, flip wire 0:     ", stabilizer_expectation('000', flip_wire=0))
print("|000>, flip wire 1:     ", stabilizer_expectation('000', flip_wire=1))
print("|000>, flip wire 2:     ", stabilizer_expectation('000', flip_wire=2))

Expect [1.0, 1.0] for both clean codewords. Note the code's wires are 0-indexed (wire 0, 1, 2) while the prose above labels qubits 1, 2, 3 — wire 0 = qubit 1, wire 1 = qubit 2, wire 2 = qubit 3. Flipping wire 0 (qubit 1) touches only S1=Z₁Z₂, giving [-1.0, 1.0]. Flipping wire 1 (qubit 2, the middle qubit) touches both generators, since qubit 2 appears in S1=Z₁Z₂ and S2=Z₂Z₃ — giving [-1.0, -1.0]. Flipping wire 2 (qubit 3) touches only S2=Z₂Z₃ — not S1 — giving [1.0, -1.0], not [-1.0,-1.0]. These three rows are exactly Lecture 4's syndrome lookup table, now read off as stabilizer eigenvalues.

❓ Lecture 5 Quiz

5 questions · click "Show answer" to check yourself.

Q1. An operator S "stabilizes" a codespace when…
A. S is Hermitian
B. S collapses every state in the codespace to a single basis state
C. S has no eigenvalues
D. S|ψ⟩ = +1|ψ⟩ for every state |ψ⟩ in the codespace
Show answer

D. Stabilizing means leaving every codeword completely unchanged, i.e. every codeword is a +1 eigenstate of S.

Q2. The set of all operators that stabilize a given codespace forms a group because…
A. the product of any two stabilizers also stabilizes the codespace
B. stabilizers can never be multiplied together
C. every codespace has exactly one stabilizer
D. stabilizers are always unitary and Hermitian simultaneously, which is impossible otherwise
Show answer

A. If S₁|ψ⟩=|ψ⟩ and S₂|ψ⟩=|ψ⟩, then S₁S₂|ψ⟩=|ψ⟩ too — closure under multiplication is exactly the group property.

Q3. Generators of a stabilizer group are…
A. the logical operators of the code
B. randomly chosen Pauli strings with no structure
C. only ever a single operator, regardless of code size
D. a small set of stabilizers whose products build the entire stabilizer group
Show answer

D. For an n-qubit code encoding k logical qubits, (n−k) independent generators suffice to generate the full group via products.

Q4. In stabilizer language, the 3-qubit repetition code's two generators are…
A. X₁X₂ and X₂X₃
B. Z₁Z₂ and Z₂Z₃
C. Z₁ and Z₂ individually
D. Y₁Y₂ and Y₂Y₃
Show answer

B. Z₁Z₂ and Z₂Z₃ are exactly the pairwise parity checks from Lecture 4, rewritten as Pauli-Z stabilizer generators.

Q5. A bit-flip on qubit 2 of the repetition code changes the measured eigenvalues of Z₁Z₂ and Z₂Z₃ to…
A. (+1, +1) — no detectable change
B. (+1, −1)
C. (−1, −1) — both generators flip sign, since qubit 2 appears in both
D. (−1, +1)
Show answer

C. Qubit 2 is shared between both generators (Z₁Z₂ and Z₂Z₃), so flipping it breaks both parity checks simultaneously, uniquely identifying qubit 2 as the error.
