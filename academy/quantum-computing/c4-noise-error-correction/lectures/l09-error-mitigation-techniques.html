Week 9 · Lecture 9

Error Mitigation Techniques

Full error correction needs extra qubits and a safety margin today's hardware doesn't have. Error mitigation needs neither — just smarter classical post-processing on the noisy results you already have.

🎯 Learning Objectives

  • Describe zero-noise extrapolation: run a circuit at several artificially amplified noise levels, then extrapolate back to the zero-noise limit.
  • Describe readout-error correction: calibrate a confusion matrix for measurement errors, then invert it to correct observed counts.
  • Distinguish error mitigation from error correction — no extra qubits/encoding, just extra classical post-processing.
  • Explain why mitigation doesn't scale to arbitrarily long circuits the way true fault tolerance would.
  • Run a zero-noise-extrapolation demo in Qiskit and extrapolate a 1× / 3× noise-scaled result to the 0× limit.

9.1Zero-Noise Extrapolation: Make It Worse, on Purpose, to See the Trend

Zero-noise extrapolation (ZNE) sounds backwards at first: deliberately run the same circuit at several higher noise levels than your hardware's natural noise, then use the resulting trend to extrapolate back to what the answer would have been at zero noise — a level you can never actually run on real hardware, but can estimate.

measure at noise scale 1×, 2×, 3×, … → fit a curve → extrapolate to scale 0×Noise is amplified deliberately — e.g. by stretching gate pulses or inserting extra identity-equivalent gate pairs — not reduced; ZNE never needs noise lower than what the hardware naturally provides.

Why does this work? Because many physical observables degrade smoothly (often close to linearly, for small amplification factors) as noise strength increases — exactly the kind of compounding decay you tracked in Lecture 3's fidelity curves. If you know the value at 1× and 3× noise, you can fit a line (or a low-order polynomial) through those two points and read off its value at 0×, which is usually closer to the true, noiseless answer than the raw 1× measurement alone.

9.2Readout-Error Correction: Invert the Confusion Matrix

Lecture 8 introduced readout error as a distinct failure mode: a correct quantum state, misreported by the detector. Because this happens entirely in the classical measurement step, it has an entirely classical fix. First, calibrate: prepare each basis state (|0⟩, |1⟩, …) with no other noise in play, measure it many times, and record how often it gets misreported as something else — building a confusion matrix M, where M[i][j] is the probability of reading outcome j when the true state was i.

observed counts = Mᵀ · true counts   ⟹   true counts ≈ (Mᵀ)⁻¹ · observed countsThe transpose matters: M[i][j] has rows indexed by the true state and columns by the observed outcome, so summing over the true index i to get observed outcome j — observed_j = Σᵢ M[i][j]·trueᵢ — is exactly a multiplication by Mᵀ, not M. Once Mᵀ is calibrated and inverted (or fit via a more numerically stable least-squares method), it converts your raw, readout-corrupted counts back into an estimate of what the counts would have been with perfect readout.

This fix costs nothing in circuit complexity — the quantum circuit you run is identical. All the work happens after the fact, on the classical histogram of measurement outcomes.

9.3Mitigation vs. Correction: the Key Distinction

Both techniques above share the defining feature of error mitigation: no extra physical qubits, no encoding, no syndrome measurement — just the same circuit you already wanted to run, plus extra classical post-processing on the results. Compare that to error correction (Weeks 4–7), which spends real physical qubits and real additional gates to actively detect and reverse errors mid-circuit.

Common mistakeMitigation is not a free lunch, and it is not a substitute for correction at scale. Both ZNE and readout correction rely on the underlying noise being well-behaved and well-characterized (smooth trends for ZNE, a stable confusion matrix for readout correction) — assumptions that break down as circuits get deeper and noise compounds (Lecture 3). Mitigation buys you a meaningfully better answer on today's circuits; it does not scale to arbitrarily long circuits the way true fault tolerance (Lecture 7) would, in principle, if hardware ever gets safely below threshold.
AnalogyError correction is like replacing a cracked window pane entirely — expensive, but the fix is structural and holds up no matter how long the house stands. Error mitigation is like carefully photographing the view through the cracked pane from several angles and digitally reconstructing what you'd see through a clean one — cheap, immediately useful, and good enough for today's picture, but it doesn't actually fix the crack, and it gets harder to trust the longer and more complex the scene gets.

🛠️ Hands-On: zero-noise extrapolation in Qiskit

Scale up the noise model from Lecture 8 by 1× and 3×, measure the same observable at both scales, and linearly extrapolate to 0×.

# zne_demo.py — Lecture 9
from qiskit import QuantumCircuit
from qiskit_aer import AerSimulator
from qiskit_aer.noise import NoiseModel, depolarizing_error
import numpy as np

def make_noise_model(scale):
    nm = NoiseModel()
    nm.add_all_qubit_quantum_error(depolarizing_error(1e-2 * scale, 2), ['cx'])  # scale the noise, not the circuit
    return nm

def run_circuit(scale, shots=4000):
    qc = QuantumCircuit(2, 2)
    qc.h(0); qc.cx(0, 1)             # prepare a Bell pair -- ideal P(00)+P(11) = 1.0
    qc.measure([0, 1], [0, 1])
    sim = AerSimulator(noise_model=make_noise_model(scale))
    counts = sim.run(qc, shots=shots).result().get_counts()
    agree = counts.get('00', 0) + counts.get('11', 0)
    return agree / shots             # observable: probability the two qubits still agree

obs_1x = run_circuit(scale=1)
obs_3x = run_circuit(scale=3)

# linear extrapolation through (1, obs_1x) and (3, obs_3x), evaluated at scale=0
slope = (obs_3x - obs_1x) / (3 - 1)
obs_0x = obs_1x - slope * 1

print(f"observable at 1x noise: {obs_1x:.3f}")
print(f"observable at 3x noise: {obs_3x:.3f}")
print(f"extrapolated to 0x noise: {obs_0x:.3f}   (ideal value is 1.0)")

The extrapolated 0× estimate should land noticeably closer to the ideal value of 1.0 than the raw 1× measurement alone — that gap is exactly the value ZNE adds, for the cost of one extra (noisier) circuit run and a two-point line fit.

Q1. Zero-noise extrapolation works by…
A. reducing the hardware's natural noise to zero before measuring
B. running the circuit only once, at the hardware's natural noise level
C. adding extra physical qubits to cancel the noise
D. deliberately amplifying noise to several higher levels, then extrapolating the trend back to the zero-noise limit
Show answer

D. ZNE never achieves literally zero noise — it estimates what the zero-noise answer would be by fitting a trend through deliberately noisier runs.

Q2. A confusion matrix, used in readout-error correction, records…
A. the probability of reading outcome j when the true prepared state was i
B. the gate error rate of every two-qubit gate
C. the T1/T2 times of every qubit
D. the depth of the circuit being run
Show answer

A. Calibrating the confusion matrix means preparing each known basis state and recording how often the detector misreports it as something else.

Q3. The key distinction between error mitigation and error correction is that mitigation…
A. requires more physical qubits than correction
B. is identical to correction, just renamed
C. can only be applied to classical bits, never qubits
D. needs no extra qubits or encoding — just extra classical post-processing on the same circuit's results
Show answer

D. Mitigation leaves the quantum circuit itself unchanged and does all its work on the classical output; correction spends real physical qubits and gates to actively detect and reverse errors.

Q4. Why doesn't error mitigation scale to arbitrarily long circuits the way true fault tolerance would?
A. Because mitigation techniques rely on the underlying noise being smooth and well-characterized, assumptions that break down as noise compounds over longer, deeper circuits
B. Because mitigation is only a theoretical idea with no working implementation
C. Because mitigation requires exactly as many extra qubits as correction
D. Because mitigation only works on single-qubit circuits
Show answer

A. As circuits deepen, compounding noise (Lecture 3) eventually breaks the smooth trends ZNE relies on and the stability readout correction assumes — mitigation is a near-term patch, not a scalable foundation.
