Quantum Error Correction Basics: the Repetition Code

Three weeks of watching noise win. This week, the first real countermeasure: spend two extra qubits to catch a bit flip before it ruins the answer — without ever looking at the data directly.

🎯 Learning Objectives

  • Describe the 3-qubit bit-flip repetition code: |0⟩→|000⟩, |1⟩→|111⟩.
  • Explain how syndrome measurement detects which qubit flipped without collapsing the encoded logical state.
  • Apply a targeted correction (single-qubit X) based on the syndrome outcome.
  • Explain why this code beats doing nothing against bit-flip noise, and why it offers zero protection against phase-flip noise.
  • Build the repetition code in Qiskit, inject a bit-flip error, and verify the syndrome correctly identifies and corrects it.

4.1Encoding: One Logical Qubit, Three Physical Qubits

The core idea behind every error-correcting code is redundancy: don't store the information in one fragile place, spread it across several. The simplest version — the 3-qubit bit-flip repetition code — just copies the logical bit value into three physical qubits:

|0⟩L = |000⟩    |1⟩L = |111⟩Encoding a logical |ψ⟩=α|0⟩+β|1⟩ gives α|000⟩+β|111⟩ — still one logical qubit's worth of superposition, now spread across three physical qubits.

In circuit terms, encoding α|0⟩+β|1⟩ on qubit 0 (with qubits 1 and 2 starting in |0⟩) takes exactly two CNOTs: CNOT(0→1) then CNOT(0→2). This is not cloning — the no-cloning theorem (C1) still holds, because the state α|000⟩+β|111⟩ is entangled across all three qubits, not three independent copies of α|0⟩+β|1⟩. You can't read out qubit 1 alone and learn α and β; the information only exists in the joint, correlated state.

4.2Syndrome Measurement: Finding the Error Without Looking

Suppose bit-flip noise hits exactly one of the three physical qubits — say qubit 1 flips, turning |000⟩→|010⟩ (or |111⟩→|101⟩). You now need to find out which qubit flipped and fix it — but you cannot simply measure each qubit directly, because that would collapse the logical superposition α|000⟩+β|111⟩ and destroy exactly the information you're trying to protect.

The trick is to measure only parities between pairs of qubits, using two extra ancilla qubits, without ever measuring the data qubits themselves:

syndrome bit A = parity(q0, q1)    syndrome bit B = parity(q1, q2)Each parity check is measured via an ancilla: CNOT(q0→ancilla), CNOT(q1→ancilla), then measure the ancilla — this reveals q0⊕q1 without revealing q0 or q1 individually.

Both syndrome bits are 0 whenever all three data qubits agree (no error, or all three flipped — a case this code can't fix, see §4.4) — so a (0,0) syndrome means "no detectable single-qubit flip." A single flipped qubit breaks exactly one or both of the parities in a pattern that uniquely identifies which qubit disagrees with its neighbors, without the ancilla measurement ever learning α or β. This is the "majority vote" intuition: whichever single qubit disagrees with the other two is almost certainly the one that flipped.

4.3Correction: Flip It Back

Once the syndrome bits are read out classically, correction is simple: look up which single-qubit flip produces that syndrome pattern, and apply a targeted X gate to undo it. Syndrome (1,1) → q1 flipped → apply X to q1. Syndrome (1,0) → q0 flipped → apply X to q0. Syndrome (0,1) → q2 flipped → apply X to q2. Syndrome (0,0) → no detected error, do nothing.

Crucially, this entire detect-and-correct cycle never measured the logical information α, β — only parities, which are blind to the overall superposition. The logical state α|000⟩+β|111⟩ comes out the other side exactly as it went in, as long as at most one of the three qubits flipped.

4.4Why This Beats Nothing — But Isn't Enough

Against bit-flip noise specifically, this code is a clear win: if each physical qubit flips independently with probability p, the logical qubit only fails when two or more of the three flip simultaneously (since majority vote recovers from any single flip) — a probability of roughly 3p²(1−p) + p³, which is smaller than p itself whenever p < 1/2. Redundancy converts "likely to fail" into "unlikely to fail," at the cost of 3× the physical qubits.

Two standard terms worth attaching to this now: a code's distance d is the minimum number of physical errors needed to cause an undetectable logical error, and the number of errors it can correct is t = ⌊(d−1)/2⌋. This 3-qubit repetition code has d=3 (you need at least 3 simultaneous flips — one on every qubit — to fool majority vote with no syndrome warning) and t=⌊(3−1)/2⌋=1, matching exactly what §4.4 just showed: it corrects any single bit-flip, no more. Lecture 7's "bigger code → lower logical error rate" is really just "bigger d, bigger t" — a concrete number instead of a vague "bigger."

Common mistakeThis code protects against bit-flip (X) errors only. A phase-flip (Z) error on any one qubit is completely invisible to the parity checks above — Z|000⟩ and Z-on-one-qubit both leave the Z-basis parities q0⊕q1 and q1⊕q2 unchanged, because parity measurements in this basis only detect disagreements in the computational (Z) basis, not phase. Don't walk away thinking "repetition code = general error correction." It's one code for one specific error type. Lecture 5 reframes this same code in the language that generalizes to codes that catch both error types at once.

🛠️ Hands-On: the repetition code in Qiskit

Build the encode → inject error → syndrome → correct cycle explicitly. This lecture uses plain Qiskit circuit-building (not yet an Aer noise model — that realistic-noise machinery arrives in Week 8); the "error" here is injected by hand with a single X gate, so you can see exactly which syndrome it produces.

# repetition_code.py — Lecture 4
from qiskit import QuantumCircuit
from qiskit_aer import AerSimulator

qc = QuantumCircuit(5, 5)   # q0-q2: data, q3-q4: syndrome ancillas; 5 classical bits (2 syndrome + 3 data)
creg = qc.cregs[0]

# --- encode alpha|0>+beta|1> on q0 into q0,q1,q2 ---
qc.h(0)              # example logical state: (|0>+|1>)/sqrt(2) on q0
qc.cx(0, 1)
qc.cx(0, 2)

# --- inject a bit-flip error on q1, by hand ---
qc.x(1)

# --- syndrome extraction: parity(q0,q1) -> ancilla q3, parity(q1,q2) -> ancilla q4 ---
qc.cx(0, 3); qc.cx(1, 3)
qc.cx(1, 4); qc.cx(2, 4)
qc.measure(3, 0)   # c[0] = parity(q0,q1)
qc.measure(4, 1)   # c[1] = parity(q1,q2)

# --- correction, added to the circuit BEFORE any sim.run() call ---
# Qiskit 2.0 removed .c_if(); the control-flow builder replaces it:
with qc.if_test((creg, 1)):    # c[0]=1, c[1]=0 -> only parity(q0,q1) broke -> q0 flipped
    qc.x(0)
with qc.if_test((creg, 3)):    # c[0]=1, c[1]=1 -> both parities broke -> q1 flipped
    qc.x(1)
with qc.if_test((creg, 2)):    # c[0]=0, c[1]=1 -> only parity(q1,q2) broke -> q2 flipped
    qc.x(2)

qc.measure(0, 2); qc.measure(1, 3); qc.measure(2, 4)   # read out the corrected data qubits into c[2..4]

sim = AerSimulator()
result = sim.run(qc, shots=1).result()   # correction is already part of qc, so this run includes it
counts = result.get_counts()
print("full readout (c4 c3 c2 | c1 c0):", counts)

Run it: the syndrome bits c[0],c[1] (the rightmost two characters of the printed string) should read 1,1 every time, since q1 disagrees with both neighbors — that part is independent of which logical branch, |000⟩ or |111⟩, the Hadamard happens to collapse to. The three corrected data bits c[2],c[3],c[4] should always agree with each other (either all 0 or all 1), confirming the if_test correction above — now safely inside the circuit, before sim.run() — actually undid the injected flip. Try injecting the X error on q0 or q2 instead and confirm the syndrome becomes (1,0) or (0,1) and the correction still lands on the right qubit. Then try injecting a qc.z(1) phase-flip instead of qc.x(1) and confirm the syndrome comes back (0,0) — no if_test branch fires, exactly the blind spot from §4.4.

5 questions · click "Show answer" to check yourself.

Q1. The 3-qubit repetition code encodes a logical qubit as…
A. α|000⟩ + β|111⟩, an entangled state spread across three physical qubits
B. three independent, unentangled copies of α|0⟩+β|1⟩
C. |0⟩ on all three qubits, always
D. a classical bit stored three times with no quantum information
Show answer

A. Encoding entangles the three physical qubits; it is not cloning (which the no-cloning theorem forbids) — you cannot read off α,β from any single qubit alone.

Q2. Syndrome measurement avoids collapsing the logical state because it measures…
A. each data qubit directly, one at a time
B. only the pairwise parities between data qubits, via ancillas, never the data qubits themselves
C. the logical qubit in the X basis instead of Z
D. nothing — syndrome measurement always collapses the state
Show answer

B. Parity checks reveal only whether pairs of qubits agree or disagree, via an ancilla, which is blind to the overall α,β superposition — that's exactly what lets you detect and fix an error without destroying the encoded information.

Q3. If qubit 2 (of q0,q1,q2) is the one that bit-flips, the syndrome (parity(q0,q1), parity(q1,q2)) reads…
A. (0,0)
B. (1,1)
C. (0,1)
D. (1,0)
Show answer

C. q2 flipping breaks only the parity(q1,q2) check (since q2 now disagrees with q1), while parity(q0,q1) stays fine — giving syndrome (0,1), uniquely pointing at q2.

Q4. Why does the 3-qubit repetition code offer zero protection against a phase-flip (Z) error?
A. Because Z errors are always weaker than X errors in practice
B. Because the parity checks measure agreement/disagreement in the computational (Z) basis, which a phase-flip never changes
C. Because phase-flip errors only happen to ancilla qubits
D. Because the code only has two data qubits, not three
Show answer

B. A Z error changes relative phase, not which computational-basis outcome a qubit is "closer to" — so the Z-basis parity checks this code uses see nothing wrong at all.

Q5. Compared to doing nothing, the repetition code reduces the logical bit-flip failure probability because…
A. it eliminates noise entirely, reducing failure probability to exactly zero
B. the logical qubit only fails when two or more of the three physical qubits flip simultaneously, which is less likely than a single flip whenever p < 1/2
C. it only works when p = 0
D. it triples the physical error rate, which happens to help
Show answer

B. Majority vote recovers from any single flip, so failure requires at least two simultaneous flips — roughly 3p²(1−p)+p³, smaller than p for p < 1/2.
