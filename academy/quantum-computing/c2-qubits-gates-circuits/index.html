🛠️ Hands-On Project

Build & Measure Bell States + a Circuit Zoo in Qiskit

Build up a complete circuit library: single-qubit Pauli/Hadamard/phase gates, controlled-CNOT operations, all four Bell pairs, a teleportation circuit, and a small "zoo" of named circuits (GHZ state, swap test). Run each on the Qiskit simulator and verify the measurement statistics match theory. You deliver a short report with circuit diagrams and results. Week 1 includes a one-time Python + Qiskit install (step-by-step in Lecture 1) — the same toolkit you'll use all course.

Wk 1: install Python + Qiskit Wk 4: single- & multi-qubit gate circuits Wk 8: teleportation + superdense coding verified Wk 10: report + circuit zoo submitted

💬 Discussions

Three checkpoints — weeks 3, 6, 9

  • Week 3: A universal gate set (like H, T, CNOT) can approximate any unitary to arbitrary precision. Why does this matter for building real quantum hardware, where only a handful of native gates exist?
  • Week 6: The no-cloning theorem says no unitary gate can copy an unknown qubit. How does this constraint shape quantum error correction and quantum cryptography, where classical systems would just make a backup?
  • Week 9: Teleportation and superdense coding both pair entanglement with classical communication, but move information in opposite "directions." What's the deeper symmetry connecting them?
