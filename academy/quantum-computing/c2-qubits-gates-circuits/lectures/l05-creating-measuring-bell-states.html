Week 5 · Lecture 5

Creating & Measuring Bell States

Course 1 analyzed what entanglement means. This lecture hands you the two-gate recipe that actually builds it, on demand, for all four Bell states.

🎯 Learning Objectives

  • Draw and read the standard H+CNOT circuit that prepares a Bell state from |00⟩.
  • Produce all four Bell states by varying the input basis state fed into the same H+CNOT circuit.
  • Trace the H+CNOT circuit algebraically from |00⟩ to (|00⟩+|11⟩)/√2.
  • Connect the circuit's output to the measurement correlations Course 1 Lecture 7 analyzed.
  • Build and measure a Bell state in Qiskit and interpret a measurement-count histogram.

5.1The H+CNOT Recipe

Lecture 4's worked example already found it: start two qubits in |00⟩, apply H to the first, then CNOT with the first as control and the second as target. The result is |Φ⁺⟩ = (|00⟩+|11⟩)/√2, one of the four Bell states from Course 1 §7.2. This two-gate circuit is the standard, canonical way every Bell state in this course gets built:

|00⟩ ──[H]────●──── |Φ⁺⟩ = (|00⟩+|11⟩)/√2
|00⟩ ──────[⊕]──Qubit 0 (top wire) gets H, then acts as CNOT's control; qubit 1 (bottom wire) is CNOT's target. Figure 5.1 draws this circuit explicitly.

H alone creates the superposition on qubit 0; CNOT alone can't do anything to an unentangled |00⟩ (both rows it would swap already match), but once CNOT's control is in superposition, it correlates the target's value with the control's — producing exactly the entangled sum structure.

5.2All Four Bell States from One Circuit

The same two-gate circuit produces each of Course 1's four Bell states, just by changing the two-qubit input fed into it before the gates fire:

input |00⟩ → |Φ⁺⟩ = (|00⟩+|11⟩)/√2    input |01⟩ → |Ψ⁺⟩ = (|01⟩+|10⟩)/√2
input |10⟩ → |Φ⁻⟩ = (|00⟩−|11⟩)/√2    input |11⟩ → |Ψ⁻⟩ = (|01⟩−|10⟩)/√2Flipping the target qubit's input bit (via an X gate beforehand) swaps which pair of terms appears; flipping the control's input bit introduces the relative minus sign. One circuit, four possible inputs, all four Bell states.

This is a nice concrete illustration of Lecture 3's universality theme in miniature: a tiny, fixed gate sequence (H, CNOT, and optionally an X gate or two beforehand) reaches every state in an entire family, just by varying what's fed in.

5.4Measurement Correlations, Revisited

Once |Φ⁺⟩ exists, measuring it gives exactly the correlated outcomes Course 1 §7.3 analyzed in the abstract: each qubit alone is a fair coin, but the two outcomes always match (both 0 or both 1, never mixed). This lecture doesn't re-derive why that correlation is physically real — Course 1 §7.4's Bell-inequality argument already settled that. What's new here is purely practical: you now have the exact circuit that produces the state whose correlations Course 1 described.

AnalogyCourse 1 handed you the finished photograph of a Bell pair's correlations and explained why the photo couldn't have been faked by any classical trick. This lecture hands you the camera. Running the circuit of Figure 5.1 and measuring both wires is the "developing the photo" step — the same physics, but now something you can actually execute, in Qiskit, as many times as you like.
✦ Worked Example — tracing H+CNOT from |00⟩ to |Φ⁺⟩

Trace the circuit of Figure 5.1 algebraically, starting from the joint state |00⟩.

  1. Start: |ψ₀⟩ = |00⟩ (qubit 0 first, qubit 1 second).
  2. Apply H to qubit 0 only: H acting on the first factor of |00⟩ = |0⟩⊗|0⟩ gives (H|0⟩)⊗|0⟩ = [(|0⟩+|1⟩)/√2] ⊗ |0⟩ = (|00⟩+|10⟩)/√2.
  3. Apply CNOT (control=qubit 0, target=qubit 1): term by term, CNOT|00⟩=|00⟩ (control 0, no flip) and CNOT|10⟩=|11⟩ (control 1, target flips).
  4. Combine: CNOT · (|00⟩+|10⟩)/√2 = (|00⟩+|11⟩)/√2 = |Φ⁺⟩.
  5. Confirm entanglement: apply the factoring test from Course 1 §7's worked example — assume |Φ⁺⟩ = (a|0⟩+b|1⟩)⊗(c|0⟩+d|1⟩), match coefficients, and reach the same contradiction (ad=0 forces d=0, but then bd=1/√2 is impossible). |Φ⁺⟩ cannot be factored: the circuit genuinely entangled two previously independent qubits.

🛠️ Hands-On: build and measure a Bell state in Qiskit

Build the circuit of Figure 5.1, run it on the local simulator many times, and histogram the measurement counts.

# bell_state_circuit.py — Lecture 5
from qiskit import QuantumCircuit
from qiskit_aer import AerSimulator

qc = QuantumCircuit(2, 2)     # 2 qubits, 2 classical bits to store results
qc.h(0)                        # superposition on qubit 0
qc.cx(0, 1)                    # CNOT: control=0, target=1
qc.measure([0, 1], [0, 1])     # measure both qubits

sim = AerSimulator()
result = sim.run(qc, shots=1000).result()
counts = result.get_counts()
print(counts)        # e.g. {'00': 503, '11': 497} -- only 00 and 11 ever appear

# optional: from qiskit.visualization import plot_histogram; plot_histogram(counts)

Across 1000 shots you should see roughly a 50/50 split between '00' and '11', and never '01' or '10' — the circuit-level confirmation of the perfect correlation Course 1 §7.3 described, with real sampling noise around the ideal 50/50 split from finite shots.

5 questions · click "Show answer" to check yourself.

Q1. The standard circuit for preparing |Φ⁺⟩ = (|00⟩+|11⟩)/√2 from |00⟩ is…
A. CNOT alone, no single-qubit gate needed
B. X on qubit 0, then measure
C. Z on both qubits
D. H on qubit 0 (the control), then CNOT with qubit 0 as control and qubit 1 as target
Show answer

D. H first creates the superposition on the control qubit; CNOT then correlates the target with it — CNOT alone applied to |00⟩ does nothing, since both rows it would swap already agree.

Q2. Feeding the input |01⟩ into the same H(qubit 0)+CNOT circuit produces…
A. |Ψ⁺⟩ = (|01⟩+|10⟩)/√2
B. |Φ⁺⟩ = (|00⟩+|11⟩)/√2
C. |01⟩, unchanged
D. |11⟩, with certainty
Show answer

A. Changing the target's input bit from 0 to 1 shifts which pair of basis terms CNOT connects, producing |Ψ⁺⟩ instead of |Φ⁺⟩ — one of the other three Bell states reachable from the same fixed circuit.

Q3. In the H+CNOT circuit, tracing |00⟩ step by step, after H (but before CNOT) the joint state is…
A. (|00⟩+|11⟩)/√2, already entangled
B. (|00⟩+|10⟩)/√2, still a product state
C. |11⟩
D. |00⟩, unchanged by H
Show answer

B. H only touches qubit 0, giving [(|0⟩+|1⟩)/√2]⊗|0⟩ = (|00⟩+|10⟩)/√2 — still a perfectly good product state; entanglement only appears after CNOT correlates the two qubits.

Q4. Measuring both qubits of |Φ⁺⟩ many times, the possible measured bitstrings are…
A. all four bitstrings equally often
B. only '01' and '10', roughly 50/50
C. only '00' and '11', roughly 50/50
D. always '00', with certainty
Show answer

C. |Φ⁺⟩ has amplitude only on |00⟩ and |11⟩, so measurement outcomes are perfectly correlated between the two qubits — exactly Course 1 §7.3's correlation, now built by an explicit circuit.

Q5. Qiskit's Bell-state circuit reports measurement counts like {'00': 503, '11': 497} over 1000 shots. This confirms…
A. the circuit is broken, since it should always give exactly '00'
B. the two qubits are unentangled
C. CNOT failed to execute
D. the perfect correlation predicted for a Bell state, with realistic shot-to-shot sampling noise around a 50/50 split
Show answer

D. A roughly even 00/11 split, with neither 01 nor 10 ever appearing, is exactly the expected Bell-state measurement statistics — small deviations from a perfect 500/500 split are ordinary finite-sample noise, not an error.
