10.2Step 1: Single-Qubit Gates and Bell States

The project's foundation layer is the gate set from Lectures 1–3 (I, X, Y, Z, H, S, T) plus the H+CNOT Bell-state recipe from Lecture 5. A clean report builds all four Bell states from the same two-gate circuit (varying the input, as Lecture 5 §5.2 showed) and verifies each one's measurement histogram shows exactly the two expected correlated outcomes.

# capstone_part1_bell_states.py
from qiskit import QuantumCircuit
from qiskit_aer import AerSimulator

def bell_circuit(input_bits='00'):
    qc = QuantumCircuit(2, 2)
    if input_bits[0] == '1': qc.x(0)
    if input_bits[1] == '1': qc.x(1)
    qc.h(0); qc.cx(0, 1)
    qc.measure([0, 1], [0, 1])
    return qc

sim = AerSimulator()
for bits in ['00', '01', '10', '11']:
    counts = sim.run(bell_circuit(bits), shots=500).result().get_counts()
    print(f"input {bits} -> {counts}")   # four distinct Bell states, each a two-outcome histogram

10.3Step 2: Teleportation and Superdense Coding

Next, the project layers in Lecture 7's teleportation circuit and Lecture 8's superdense coding circuit — both built directly on top of the same Bell-pair-sharing step from Step 1, just with different follow-up gates. Running both side by side in the report makes the Lecture 8 §8.3 duality visually obvious: identical setup, mirrored direction of information flow.

shared ingredient: qc.h(0); qc.cx(0,1)   ⟶   teleportation adds a Bell measurement + classical correction
                                ⟶   superdense coding adds a Pauli encoding + Bell measurementBoth protocols are, structurally, "share a Bell pair, then do a small amount of extra work on one side" — they differ only in which side does the measuring and which side does the encoding.

10.4Step 3: The Circuit Zoo — GHZ and the Swap Test

The project's final layer is Lecture 9's zoo: a GHZ state for n≥3 qubits (chain-CNOT recipe) and the swap test for estimating state overlap. A good report runs the GHZ circuit for n=3, 4, and 5 qubits and confirms the two-outcome histogram pattern persists at every size, and runs the swap test on a pair of identical states and a pair of orthogonal states to confirm the two extreme-case probabilities from Lecture 9 §9.4.

# capstone_part3_zoo.py
from qiskit import QuantumCircuit
from qiskit_aer import AerSimulator

def ghz_circuit(n):
    qc = QuantumCircuit(n, n)
    qc.h(0)
    for i in range(1, n):
        qc.cx(0, i)
    qc.measure(range(n), range(n))
    return qc

sim = AerSimulator()
for n in (3, 4, 5):
    counts = sim.run(ghz_circuit(n), shots=500).result().get_counts()
    print(f"GHZ_{n} -> {counts}")   # only '0'*n and '1'*n should ever appear, at every size n
✦ Worked Example — the whole arc, traced in one sentence per lecture

As a capstone sanity check, re-derive why each circuit works, from memory, in one line each — the fastest way to confirm the ten weeks actually connect.

  1. L1–L2: every gate is a unitary matrix, and every single-qubit gate is some rotation of the Bloch vector (H, S, T included).
  2. L3–L4: {H, T, CNOT} is universal because single-qubit gates reach every one-qubit unitary and CNOT alone supplies the entangling, multi-qubit ingredient.
  3. L5: H then CNOT turns an unentangled product state into a Bell state, because CNOT correlates a definite target with a superposed control.
  4. L6: no CLONE gate exists because every gate is linear, and linearity forces a superposition input into an entangled (not duplicated) output.
  5. L7: teleportation moves (not copies) an unknown state by using a Bell pair plus two classical bits to pick one of four Pauli corrections — consistent with no-cloning since the original is destroyed.
  6. L8: superdense coding is teleportation's mirror image — the same four-gate table, used to encode two classical bits instead of decode a quantum state.
  7. L9: GHZ states extend Bell pairs via chain-CNOTs, and the swap test trades a full measurement for a statistical estimate of overlap, via a controlled-SWAP and an ancilla.

🔗 Where this is heading

Every circuit in this capstone is built from gates and entangling tricks — nothing here yet constitutes an algorithm that outperforms a classical computer at a real task. Course 3, Quantum Algorithms, is exactly where that changes: Deutsch-Jozsa shows a toy problem solvable in one quantum query versus exponentially many classical ones, and Grover's algorithm searches an unsorted list quadratically faster than any classical method can. Both lean directly on tools from this course — superposition, interference, and controlled operations, now aimed at a genuine computational advantage instead of just a demonstration circuit.
