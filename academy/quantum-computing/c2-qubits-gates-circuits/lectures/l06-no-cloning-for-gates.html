Week 6 · Lecture 6

The No-Cloning Theorem, Revisited for Gates

Course 1 proved no-cloning as a fact about state vectors. Here's the same fact asked the way a circuit builder actually asks it: why can't I just wire up a CLONE gate?

🎯 Learning Objectives

  • Restate the no-cloning theorem as a question about building a specific gate: does a CLONE gate exist?
  • Re-derive, at the circuit level, why linearity forces any candidate CLONE circuit to fail on superposition inputs.
  • Explain why CNOT looks like a classical copier but fails exactly where cloning would require it to succeed.
  • Connect no-cloning to the Week-6 discussion prompt on error correction and cryptography.
  • Preview why teleportation (Lecture 7) is the "loophole" that moves information without ever cloning it.

6.1Reframing No-Cloning as a Gate-Design Question

Course 1 Lecture 9 proved the no-cloning theorem as a fact about unitary operators: no U satisfies U(|ψ⟩⊗|0⟩) = |ψ⟩⊗|ψ⟩ for every unknown |ψ⟩. This course has spent five lectures building gates and circuits that do exist — Pauli gates, Hadamard, phase gates, CNOT. It's natural to ask the same question in gate-builder's language: can I design a CLONE gate — a circuit box labeled "CLONE" that takes an unknown qubit and an ancilla |0⟩ and outputs two copies?

CLONE gate, hoped-for behavior:   |ψ⟩ ──[CLONE]── |ψ⟩
                        |0⟩ ──[CLONE]── |ψ⟩This is exactly the same equation from Course 1 §9.1, just drawn as a circuit diagram with two wires in and two wires out instead of written as an abstract unitary equation.

The no-cloning theorem answers: no such two-qubit gate exists, for the same underlying reason Course 1 derived — and that reason becomes even more concrete once you picture it as a specific box you'd have to wire into a circuit.

6.2Why Any Candidate CLONE Circuit Fails

Suppose you tried to build CLONE out of gates you already know. The obvious first attempt is CNOT itself — after all, Lecture 4 showed CNOT acting on a definite control bit does look exactly like copying: CNOT|0⟩⊗|0⟩=|0⟩⊗|0⟩ and CNOT|1⟩⊗|0⟩=|1⟩⊗|1⟩, matching "both wires end up equal" for both basis states. The trap is assuming this pattern continues for a superposition input.

CNOT · [(|0⟩+|1⟩)/√2]⊗|0⟩ = (|00⟩+|11⟩)/√2     vs. desired: [(|0⟩+|1⟩)/√2]⊗[(|0⟩+|1⟩)/√2]The left side is exactly Lecture 5's Bell state — two terms, entangled. The right side (true cloning) is a four-term product state. These are provably different states, by the same factoring argument Lecture 5's worked example used.

This is Course 1 §9.2's linearity proof, now visible as a specific, concrete gate failure rather than an abstract one: CNOT is exactly the gate this course already built that would have been the natural CLONE candidate, and it demonstrably does not clone. No amount of swapping in a different two-qubit gate rescues the attempt — any unitary gate, being linear, is forced to distribute over a superposition term-by-term, and that distribution always produces an entangled sum, never the four-term product state true cloning would require. Every possible "CLONE gate" design hits this same wall.

Common mistakeDon't conclude from §6.2 that "CNOT is secretly broken" or that it fails at its actual job. CNOT does exactly what Lecture 4 defined it to do — flip the target iff the control is 1 — faithfully, on every input including superpositions. It simply never was a cloning gate; it only resembled one on the two basis-state cases where cloning happens to be classically easy anyway.

6.3The Discussion Prompt: What No-Cloning Protects

The course page's Week-6 discussion asks how the no-cloning constraint shapes error correction and cryptography, where classical systems would simply keep a backup copy. Course 1 §9.4 already answered this in the state-vector language: an eavesdropper can't silently clone a qubit in quantum key distribution, and error correction can't rely on majority-vote copies the way classical bit-flip correction does. The gate-level reframing of this lecture makes the "why" viscerally concrete: there is no CLONE gate sitting on the shelf next to H and CNOT waiting to be wired in. Any error-correction or eavesdropping scheme has to work around that absence, not through it — which is exactly why real quantum error-correcting codes spread one logical qubit's information across the correlations of several physical qubits (an entanglement-based trick, not a copying one) rather than keeping literal backups.

✦ Worked Example — testing a second candidate CLONE circuit

A student proposes a different candidate: apply H to the ancilla, then CNOT with the unknown qubit as target and the ancilla as control — the reverse wiring from §6.2. Does this clone (|0⟩+|1⟩)/√2?

  1. Set up the input: unknown qubit |ψ⟩=(|0⟩+|1⟩)/√2 on wire A, ancilla |0⟩ on wire B. Apply H to B first: joint state becomes [(|0⟩+|1⟩)/√2]A ⊗ [(|0⟩+|1⟩)/√2]B = (|00⟩+|01⟩+|10⟩+|11⟩)/2.
  2. Apply CNOT with B as control, A as target: flip A whenever B=1. Term by term: |00⟩→|00⟩, |01⟩→|11⟩ (A flips), |10⟩→|10⟩, |11⟩→|01⟩ (A flips).
  3. Sum the results: (|00⟩+|11⟩+|10⟩+|01⟩)/2 = (|00⟩+|01⟩+|10⟩+|11⟩)/2 — unchanged by the relabeling, since it's a symmetric sum of all four terms.
  4. Compare to the cloning target: true cloning of |ψ⟩=(|0⟩+|1⟩)/√2 would require exactly this same four-term equal-superposition product state [(|0⟩+|1⟩)/√2]⊗[(|0⟩+|1⟩)/√2] = (|00⟩+|01⟩+|10⟩+|11⟩)/2 — and it matches!
  5. The catch: this circuit only "clones" because H happened to put the ancilla into the same specific state |+⟩ already, regardless of what the unknown qubit was — it never looked at |ψ⟩ at all. Try it on a different unknown state, e.g. |ψ⟩=|0⟩: the circuit still outputs (|00⟩+|01⟩)/√2 = |0⟩⊗|+⟩, not |0⟩⊗|0⟩. It fails to clone |0⟩, confirming this candidate is not a universal cloner either — it just got lucky on the one input tested, exactly the kind of trap the no-cloning theorem warns against.

🛠️ Hands-On: confirm the CLONE-candidate failure in Qiskit

Build the CNOT "copier" from §6.2 and show its output on a superposition input does not factor into two identical copies.

# clone_attempt.py — Lecture 6
import numpy as np
from qiskit.quantum_info import Statevector, partial_trace
from qiskit import QuantumCircuit

qc = QuantumCircuit(2)
qc.h(0)        # unknown qubit 0 is prepared in (|0>+|1>)/sqrt(2)
qc.cx(0, 1)    # attempted "CLONE": CNOT with qubit 0 as control, ancilla 1 as target

out = Statevector.from_label('00').evolve(qc)
print(out)                              # (|00>+|11>)/sqrt(2) -- the Bell state, NOT a clone

# check: is qubit 1 alone really an independent copy of qubit 0's state?
rho1 = partial_trace(out, [0])          # reduced density matrix of qubit 1 alone
print(rho1)                             # I/2, maximally mixed -- not the pure state (|0>+|1>)/sqrt(2) you wanted

The reduced state of "qubit 1 alone" is maximally mixed, not a clean copy of qubit 0's superposition — exactly the Course 1 Lecture 8 signature of entanglement, and the circuit-level proof that the CNOT "copier" produced correlation, not duplication.

🔗 Where this is heading

No-cloning sounds like a pure restriction, but it has a constructive flip side: you can't clone an unknown state, but you absolutely can move it — destroying the original as you go, using entanglement plus a small amount of classical communication. That's precisely what quantum teleportation does, and it's no accident that Lecture 7 opens by reusing the exact Bell-pair recipe from Lecture 5. No-cloning is the rule teleportation respects; entanglement is the resource that lets it work anyway.

Q1. Restated at the gate level, the no-cloning theorem says…
A. no CLONE gate exists that maps |ψ⟩⊗|0⟩ → |ψ⟩⊗|ψ⟩ for every unknown |ψ⟩
B. no circuit gate can ever be unitary
C. CNOT is not a valid quantum gate
D. only known states can ever be used as circuit inputs
Show answer

A. This is the same Course 1 statement, just phrased as "does a specific two-qubit gate exist" rather than as an abstract unitary equation.

Q2. CNOT acting on a control qubit in the superposition (|0⟩+|1⟩)/√2 and a target |0⟩ produces…
A. two independent copies of (|0⟩+|1⟩)/√2
B. an error — CNOT cannot accept a superposed control
C. |00⟩, unchanged
D. the entangled Bell state (|00⟩+|11⟩)/√2, not a clone
Show answer

D. Linearity forces CNOT to distribute over the superposition term-by-term, giving an entangled two-term sum — not the four-term product state true cloning requires.

Q3. CNOT applied to the definite basis states |0⟩⊗|0⟩ and |1⟩⊗|0⟩ looks like cloning because…
A. CNOT is secretly a cloning gate for all inputs
B. copying a known, definite classical-like bit is easy by any method — the real test is an unknown superposition
C. |0⟩ and |1⟩ are themselves superpositions
D. the target qubit was never |0⟩ to begin with
Show answer

B. Both basis-state cases happen to match cloning's requirement trivially, since a known definite state can always be reproduced some other way; the theorem's real content only bites on unknown superposition inputs.

Q4. Checking the reduced state of the "target" qubit after a CNOT-based cloning attempt on a superposed control, you find it is…
A. a pure state identical to the control's original state
B. undefined
C. always exactly |0⟩
D. maximally mixed (I/2), not a clean copy
Show answer

D. The circuit produced entanglement, and the Course 1 Lecture 8 signature of entanglement is exactly that each qubit's reduced state is mixed — the opposite of a faithful, independent copy.

Q5. No-cloning is compatible with moving an unknown quantum state from one qubit to another because…
A. no-cloning actually forbids moving information too
B. teleportation secretly violates no-cloning but gets away with it
C. moving information always destroys the original, so no second copy ever exists simultaneously
D. moving only works for known, classical states
Show answer

C. Teleportation (Lecture 7) destroys the original as part of the protocol, so at no point do two valid copies of the unknown state coexist — fully consistent with, not a violation of, no-cloning.
