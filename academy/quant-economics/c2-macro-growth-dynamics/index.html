🛠️ Hands-On Project

Solve & Calibrate a Growth Model (Python)

Build a small toolkit that calibrates a growth model to real macro data, solves it numerically (Solow steady state, then the Ramsey/optimal-growth path), and simulates transition dynamics toward the steady state. You deliver a short report comparing your numerical solution against the by-hand steady-state and golden-rule results, with figures. Week 1 includes a one-time Python + QuantEcon + NumPy + SciPy install (step-by-step in Lecture 1).

Wk 1: install Python + QuantEcon + NumPy + SciPy Wk 4: Solow steady state + growth accounting Wk 8: numerical Ramsey solver + transition path Wk 10: calibrated report + figures submitted

💬 Discussions

Three checkpoints — weeks 3, 6, 9

  • Week 3: The Solow model predicts poor countries should grow faster and catch up. Where do we actually see convergence — and where does it fail to show up?
  • Week 6: In the Ramsey model, saving is a choice rather than a fixed rate. How does letting households optimize change what the model can and can't explain?
  • Week 9: Real-business-cycle models explain recessions as responses to productivity shocks. How convincing is that as a story for the booms and busts you observe?
