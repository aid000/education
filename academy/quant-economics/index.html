📊 Quantitative Economics

AP Micro & Macro, leveled up with real computation. Game theory and strategic micro, growth and business-cycle dynamics, econometrics, causal inference and policy evaluation, and computational economics — all in Python on free QuantEcon tools and public data. Complements the Quant Finance track.

🧭 Course Progression

Take them in order. C3 (econometrics) underpins C4; C5 ties the theory and data skills together.

C1 Game Theory → C2 Macro Dynamics → C3 Econometrics → C4 Causal Inference → C5 Computational Econ

🎯 Internship readiness

This sequence mirrors an undergraduate quantitative-economics core — micro/game theory, macro dynamics, econometrics, and modern causal inference — with the computational skills that set candidates apart. It gives Jane-Street-level micro/macro depth and pairs with the Quant Finance track for research, policy, and quant roles.

📖 Books (optional)

The courses are self-contained — lectures cover everything, no required textbook. For extra depth: Osborne, An Introduction to Game Theory (C1); the free QuantEcon lecture series (C2, C5); Stock & Watson, Introduction to Econometrics (C3); Angrist & Pischke, Mostly Harmless Econometrics (C4).

⚠️ Data note

All datasets are public (FRED, Yahoo Finance, and open policy datasets); no paid subscription is required. As in real applied work, sourcing and cleaning the data is part of each project.
