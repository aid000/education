Games, Strategies & Nash Equilibrium

When your best move depends on someone else's best move, you need more than calculus — you need equilibrium.

🎯 Learning Objectives

  • Describe a game in normal form: players, strategies, and payoffs.
  • Identify dominant and dominated strategies.
  • Define a best response and compute it from a payoff matrix.
  • Define a (pure-strategy) Nash equilibrium and find it in a 2×2 game.
  • Explain why the prisoner's dilemma's equilibrium is not the best joint outcome, and verify it with nashpy.

1.1What Is a Game?

In AP Micro you optimized a single decision-maker against fixed prices. Game theory is what you need when outcomes depend on several rational players at once — each one's best choice hinges on what the others do. A game in normal form has three ingredients:

⟨ Players,  Strategies,  Payoffs ⟩Who is choosing, what each can choose, and the reward each gets for every combination of choices.

For two players with a few choices each, we write the payoffs as a matrix: each cell lists (row player's payoff, column player's payoff) for that pair of strategies. Higher payoffs are better.

1.3Best Responses & Dominant Strategies

A best response is the strategy that maximizes your payoff given what the other player does. Work it out for the row player:

  • If the column player Cooperates: row gets 3 by cooperating vs 5 by defecting → Defect.
  • If the column player Defects: row gets 0 by cooperating vs 1 by defecting → Defect.

Defect is better no matter what the opponent does — it is a strictly dominant strategy. The game is symmetric, so the column player reasons identically. When every player has a dominant strategy, playing it is the obvious prediction.

AnalogyA Nash equilibrium is a "no-regret" state: given what everyone else chose, nobody wishes they'd done something different. Think of which side of the road to drive on — once everyone drives on the right, no individual gains by switching. That mutual no-regret is exactly the equilibrium condition.

1.4Nash Equilibrium

A Nash equilibrium is a strategy profile in which every player is simultaneously playing a best response to the others — so no one can gain by unilaterally deviating:

No player i can raise their payoff by changing strategy aloneEach strategy is a best response to the others' strategies — the defining mutual-consistency condition.

In the prisoner's dilemma, (Defect, Defect) is that profile: from there, switching to Cooperate drops your payoff from 1 to 0. So (D, D) with payoff (1, 1) is the unique Nash equilibrium.

Common mistakeA Nash equilibrium is not the same as the best joint outcome. Both players would prefer (Cooperate, Cooperate) = (3, 3), yet it is not an equilibrium — each is individually tempted to defect. Confusing "stable" with "efficient" (Pareto-optimal) is the single most common game-theory error, and it's the entire point of the dilemma.
✦ Worked Example — find the equilibrium

Two firms each choose a High or Low price. Profits (Firm 1, Firm 2): (High,High) = (4,4); (High,Low) = (1,5); (Low,High) = (5,1); (Low,Low) = (2,2). Find each firm's dominant strategy and the Nash equilibrium.

  1. Firm 1, if Firm 2 plays High: 4 (High) vs 5 (Low) → Low is better.
  2. Firm 1, if Firm 2 plays Low: 1 (High) vs 2 (Low) → Low is better. So Low strictly dominates for Firm 1.
  3. Firm 2: the game is symmetric, so Low strictly dominates for Firm 2 as well.
  4. Nash equilibrium: (Low, Low) with payoff (2, 2) — both firms' best responses coincide there.
  5. The catch: (High, High) = (4, 4) would double both firms' profits, but it isn't stable — each is tempted to undercut. This is a price war as a prisoner's dilemma, and it's why cartels are hard to sustain (Week 7).

🛠️ Hands-On: solve it in Python

We use the free QuantEcon stack plus nashpy (a small equilibrium solver) all course. Week 1 setup: install once (below), then reuse it every lecture and for the project.

⬇ Install Python + QuantEcon + nashpy (one-time, Week 1 setup)

With Python 3 installed, create an environment and install the stack:

python3 -m venv econ-env
source econ-env/bin/activate       # macOS / Linux
econ-env\Scripts\activate          # Windows (PowerShell)
pip install quantecon nashpy numpy matplotlib jupyter

Verify: run python -c "import nashpy, quantecon; print('ok')" — printing ok means you're set.

Now encode the prisoner's dilemma and let nashpy enumerate the equilibrium. The two matrices hold the row and column players' payoffs; rows/cols are ordered (Cooperate, Defect).

# prisoners_dilemma.py — Lecture 1
import numpy as np
import nashpy as nash

# rows/cols = (Cooperate, Defect)
A = np.array([[3, 0],      # row player's payoffs
              [5, 1]])
B = np.array([[3, 5],      # column player's payoffs
              [0, 1]])

game = nash.Game(A, B)
for eq in game.support_enumeration():
    print(eq)              # (array([0., 1.]), array([0., 1.])) -> both Defect

The output ([0,1], [0,1]) means each player puts 100% weight on their second strategy (Defect) — the Nash equilibrium. Now edit the payoffs to the price game in the worked example and confirm you get (Low, Low).

🔗 Where this is heading

Not every game has a strictly dominant strategy, and not every equilibrium is in "pure" strategies — sometimes the only stable play is to randomize (Week 3's mixed strategies, the math behind bluffing and unpredictable pricing). Nash's theorem guarantees an equilibrium always exists once we allow randomization. From there the same logic scales up to oligopoly pricing (Cournot & Bertrand, Week 7) and auctions (Week 9) — and it's the same strategic reasoning that underlies competition between trading firms in the Quant Finance track.

Q1. A strategy is a "best response" when it…
A. maximizes your payoff given the other players' strategies
B. maximizes the sum of all players' payoffs
C. is the same as your opponent's strategy
D. guarantees you win
Show answer

A. A best response maximizes your payoff, taking the others' choices as given. Maximizing the joint sum (B) is a different (efficiency) idea.

Q2. A strategy that yields a higher payoff than any alternative no matter what opponents do is called…
A. a mixed strategy
B. a Pareto strategy
C. a strictly dominant strategy
D. a maximin strategy
Show answer

C. A strictly dominant strategy beats every alternative against every opponent choice — so a rational player always plays it.

Q3. At a Nash equilibrium…
A. total payoff is always maximized
B. no player can gain by unilaterally changing strategy
C. all players use the same strategy
D. players must cooperate
Show answer

B. That mutual best-response / no-regret condition is the definition. It does not imply efficiency (A) — the prisoner's dilemma is the counterexample.

Q4. In the prisoner's dilemma, the (Cooperate, Cooperate) outcome is…
A. the unique Nash equilibrium
B. a dominant strategy for both
C. impossible to reach under any circumstances
D. better for both players than (Defect, Defect), but not a Nash equilibrium
Show answer

D. (C,C) Pareto-dominates (D,D) — both prefer it — yet it isn't stable, because each player is individually tempted to defect. That gap is the whole dilemma.

Q5. In a game where "Low price" strictly dominates "High price" for both firms, the Nash equilibrium is…
A. (High, High)
B. (Low, Low)
C. one firm High, one firm Low
D. there is no equilibrium
Show answer

B. If Low strictly dominates for each, both play Low, and (Low, Low) is the unique Nash equilibrium — even if (High, High) would be more profitable for both.
