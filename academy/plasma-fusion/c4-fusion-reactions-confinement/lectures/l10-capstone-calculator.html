10.1The Capstone Question

Every lecture in this course built one piece of a single pipeline: Q-values and reactions (L1), cross-sections and the Gamow factor (L2), the reactivity ⟨σv⟩ and fusion power density (L3), the Lawson criterion and triple product (L4), fusion gain Q and ignition (L5), confinement time and scaling laws (L6), beta and the Troyon limit (L7), magnetic vs inertial strategies (L8), and the Lawson diagram placing real devices (L9). The capstone's job is to fuse all of it into one calculator that, given a candidate plasma's density, temperature, and confinement time — or device parameters it can estimate confinement time from — tells you unambiguously where that design sits relative to ignition.

10.2The Complete Script

Every function below has already been independently verified in an earlier lecture (cited inline) — the capstone's only new work is wiring them together into one coherent tool with a clean interface.

🛠️ Hands-On: fusion_calculator.py — the full capstone tool

# fusion_calculator.py -- Capstone, Plasma & Fusion C4, Lecture 10
# Lawson-criterion + confinement-scaling-law calculator for D-T plasmas.
import numpy as np

# ---------------------------------------------------------------- constants
E_FUS_KEV   = 17.6e3    # D-T Q-value, keV  (Lecture 1)
E_ALPHA_KEV = 3.5e3     # alpha share retained in plasma, keV
KEV_TO_J    = 1.602176634e-16
IGNITION_TRIPLE = 3.0e21   # keV s/m^3 benchmark (Lecture 4)

# ---------------------------------------------------------------- reactivity (Lecture 3)
def sigmav_DT(T_keV):
    """Bosch-Hale (1992) D-T reactivity. Returns <sigma v> in m^3/s."""
    BG, mrc2 = 34.3827, 1124656.0
    C1,C2,C3,C4,C5,C6,C7 = 1.17302e-9,1.51361e-2,7.51886e-2,4.60643e-3,1.35e-2,-1.0675e-4,1.366e-5
    T = T_keV
    theta = T/(1 - (T*(C2+T*(C4+T*C6)))/(1+T*(C3+T*(C5+T*C7))))
    xi = (BG**2/(4*theta))**(1/3)
    return C1*theta*np.sqrt(xi/(mrc2*T**3))*np.exp(-3*xi)*1e-6

# ---------------------------------------------------------------- power balance (Lectures 3-5)
def fusion_power_density(n, T_keV):
    return 0.25*n**2*sigmav_DT(T_keV)*E_FUS_KEV*KEV_TO_J

def alpha_power_density(n, T_keV):
    return 0.25*n**2*sigmav_DT(T_keV)*E_ALPHA_KEV*KEV_TO_J

def loss_power_density(n, T_keV, tau_E):
    return 3.0*n*T_keV*KEV_TO_J/tau_E

def fusion_gain_Q(n, T_keV, tau_E):
    P_fus = fusion_power_density(n, T_keV)
    P_alpha = alpha_power_density(n, T_keV)
    P_loss = loss_power_density(n, T_keV, tau_E)
    P_aux = P_loss - P_alpha
    if P_aux <= 0:
        return np.inf   # ignited: no external heating needed
    return P_fus/P_aux

# ---------------------------------------------------------------- triple product (Lecture 4)
def triple_product(n, T_keV, tau_E):
    return n*T_keV*tau_E

def ignition_report(n, T_keV, tau_E):
    tp = triple_product(n, T_keV, tau_E)
    margin = tp/IGNITION_TRIPLE
    return tp, margin, (margin >= 1.0)

# ---------------------------------------------------------------- confinement scaling law (Lecture 6)
C_SCALE = 0.037
def tau_E_scaling(Ip_MA, n19, B_T, P_MW, R_m):
    return (C_SCALE*Ip_MA**0.93*n19**0.41*B_T**0.15
            *P_MW**-0.69*R_m**1.97)

# ================================================================= DEMO
if __name__ == "__main__":
    print("=== Design point: n=1e20 m^-3, T=13 keV, tau_E=3.0 s (assumed) ===")
    n, T, tau = 1.0e20, 13.0, 3.0
    tp, margin, ignited = ignition_report(n, T, tau)
    print(f"triple product = {tp:.3e} keV s/m^3  (threshold {IGNITION_TRIPLE:.1e})")
    print(f"margin = x{margin:.2f}   {'IGNITION' if ignited else 'sub-ignition'}")

    Q = fusion_gain_Q(n, T, tau)
    print(f"fusion gain Q  = {Q if np.isinf(Q) else f'{Q:.2f}'}")

    f_alpha = alpha_power_density(n,T)/loss_power_density(n,T,tau)
    print(f"alpha self-heating fraction f_alpha = {f_alpha*100:.1f}%")

    print()
    print("=== Estimate tau_E instead from device parameters (scaling law) ===")
    Ip, n19, B, P_heat, R = 15.0, n/1e19, 5.3, 50.0, 6.2
    tau_scaled = tau_E_scaling(Ip, n19, B, P_heat, R)
    print(f"Device: Ip={Ip} MA  n19={n19:.1f}  B={B} T  P={P_heat} MW  R={R} m")
    print(f"scaling-law tau_E = {tau_scaled:.2f} s")

    tp2, margin2, ignited2 = ignition_report(n, T, tau_scaled)
    print(f"triple product (scaled tau_E) = {tp2:.3e} keV s/m^3,  margin x{margin2:.2f}  "
          f"{'IGNITION' if ignited2 else 'sub-ignition'}")

10.3Reading the Output

Walk through what the script actually told you. At n=10²⁰ m⁻³, T=13 keV, τ_E=3 s, the triple product (3.90×10²¹ keV·s/m³) clears the ignition benchmark by a margin of ×1.30 — consistent with the fact that this is exactly the ITER-target point from Lecture 9. The fusion-gain function returns inf because at this design point the alpha power density alone already exceeds the loss power density (fα=139.6% > 100%) — meaning no external heating is needed at all, the signature of an over-ignited steady-state point in this reduced model. A real time-dependent plasma at fα>100% would in practice keep heating up (or need active cooling/control) rather than sit in a fixed steady state — this course's 0-D model flags the condition rather than evolving it in time.

The second block shows the calculator's other mode: instead of assuming τ_E, estimate it from device parameters via Lecture 6's scaling law. The two τ_E values (3.0 s assumed vs 3.71 s from scaling) are close but not identical — exactly what you'd expect, since the assumed value was itself chosen to be representative of an ITER-like discharge, and the scaling law independently predicts a similar number from first principles.

Common mistakeDon't treat an inf fusion gain as "impossible" or a bug. It is the mathematically correct limit of Q = P_fusion/P_aux when P_aux→0 — exactly Lecture 5's ignition limit (f_α→1). A real design would use this signal to back off (lower n or T) rather than interpret it as an error.

🔗 Where this is heading

This calculator is deliberately a reduced, 0-D model — exactly as flagged throughout the Plasma & Fusion specialization's modeling-scope note. Real reactor design uses 1-D and gyrokinetic transport codes, detailed MHD stability codes for the true beta limit, and radiation-hydrodynamics codes for ICF implosions. What you've built here is the right order-of-magnitude first pass that every one of those larger codes is ultimately checked against — the same role diffusion theory plays against Monte Carlo neutronics in the Nuclear specialization's C2 capstone.
