Week 4 · Lecture 4

Polynomial Interpolation

Given a handful of measured points, find the smooth curve that threads exactly through every one — and learn why reaching for a single high-degree polynomial can betray you.

🎯 Learning Objectives

  • State the interpolation problem and why a unique degree-n polynomial passes through n+1 distinct points.
  • Build the interpolant in three equivalent ways: the Vandermonde system, the Lagrange form, and Newton's divided differences.
  • Explain why the Newton form is the practical choice for adding points incrementally.
  • Recognize the Runge phenomenon — wild oscillation of high-degree interpolants on equispaced nodes — and how to defeat it.
  • Use NumPy and SciPy to interpolate a physical data table and compare a global polynomial against a piecewise cubic spline.

4.1The Interpolation Problem & the Vandermonde View

You have a table of measurements: temperature at six depths in a borehole, refractive index at five wavelengths, the cross-section of a reaction at a dozen energies. You want a value between the tabulated points, or a smooth function you can differentiate, integrate, or feed into a simulation. Interpolation is the task of constructing a function that passes exactly through every data point. (Contrast this with fitting/regression, where the curve need only pass near noisy points — a later topic.)

The classic choice is a polynomial. Suppose we have n+1 points (x0, y0), …, (xn, yn) with distinct x-values. We seek a polynomial of degree at most n:

p(x) = a0 + a1x + a2x² + … + anxnn+1 unknown coefficients a0…an — exactly matched to n+1 data constraints p(xi) = yi.

Writing the n+1 conditions p(xi) = yi as a linear system gives the famous Vandermonde matrix:

V a = y,  with  Vij = xijEach row is [1, xi, xi², …, xin]. Because the xi are distinct, det V ≠ 0, so the solution — the interpolating polynomial — exists and is unique.

That uniqueness is the cornerstone: through n+1 points with distinct abscissae there is exactly one polynomial of degree ≤ n. Two points fix a unique line, three a unique parabola, and so on. The three methods in this lecture all compute that same polynomial — they just differ in cost, numerical stability, and how easily you can extend them.

AnalogyThink of the coefficients as knobs on an equalizer with as many knobs as data points. Each data point is a constraint that locks one degree of freedom. With exactly as many knobs as constraints, there is one — and only one — setting that hits every target. The Vandermonde view says "turn the knobs by brute-force algebra"; Lagrange and Newton are smarter ways to reach the identical setting.
Common mistakeSolving V a = y directly is tempting but numerically dangerous: the Vandermonde matrix becomes badly ill-conditioned as n grows (its condition number explodes roughly geometrically), so the coefficients you recover can be swamped by round-off — exactly the conditioning issue from Lecture 1. Use it to understand existence and uniqueness, not as your everyday algorithm.

4.2The Lagrange Form: Interpolation by Construction

Lagrange's idea sidesteps the matrix entirely. For each node xi, build a cardinal basis polynomial Li(x) that equals 1 at xi and 0 at every other node:

Li(x) = ∏j≠i (x − xj) / (xi − xj)The numerator vanishes at every node except xi; the denominator normalizes so Li(xi) = 1. Thus Li(xk) = 1 if k = i, else 0.

Because each Li is a "switch" that is on only at its own node, stacking them weighted by the data values gives the interpolant immediately:

p(x) = ∑i=0n yi Li(x)Check: at x = xk, every term dies except ykLk(xk) = yk. So p(xk) = yk for all k — it interpolates by construction.

The Lagrange form is the cleanest theoretical object — it makes the existence proof a one-liner and underpins much of numerical integration (the weights in Newton-Cotes and Gaussian quadrature, Week 6, are integrals of these Li). Its drawback: if you add a new data point, every basis polynomial changes and you must rebuild from scratch. That is precisely what Newton's form fixes.

4.3Newton's Divided-Difference Form

Newton writes the same unique polynomial in a nested, incremental basis built from the nodes:

p(x) = c0 + c1(x−x0) + c2(x−x0)(x−x1) + … Each term adds one more node-factor. The coefficients ck are the divided differences of the data.

The coefficients are computed by a recursive table. The zeroth differences are the data values; each higher difference is a slope-of-slopes:

f[xi] = yi,   f[xi,…,xi+k] = ( f[xi+1,…,xi+k] − f[xi,…,xi+k−1] ) / (xi+k − xi)The Newton coefficient ck is the top entry of column k: ck = f[x0,…,xk].

Two big wins. First, incremental updates: to add a new point you only compute one new diagonal of the table and append a single term — the existing coefficients are untouched. That makes Newton's form the natural engine when data arrives over time or when you raise the degree adaptively. Second, cheap evaluation: the nested form is evaluated by Horner-like multiplication in O(n) operations once the coefficients are known.

There is also a beautiful link to calculus: the leading divided difference is a finite-sample stand-in for a derivative,

f[x0,…,xn] = f(n)(ξ) / n!  for some ξ in the data intervalThe same factor n! and a derivative show up in the interpolation error formula — see Section 4.4.
AnalogyNewton's form is like writing a number in expanding place values: you start with a coarse guess (c0, the value at the first node), then add a correction proportional to the local slope, then a curvature correction, and so on. Each divided difference is the next "decimal place" of detail. Adding a new data point just tacks on one more place value without rewriting the ones you already trust.

4.4The Runge Phenomenon & the Spline Cure

Naively, a higher-degree polynomial through more points should be more accurate. For equispaced nodes this can fail spectacularly. The interpolation error obeys

f(x) − p(x) = f(n+1)(ξ) / (n+1)! · ∏i(x − xi)The node product blows up near the ends of an equispaced grid, so even a smooth f can be interpolated terribly there.

The textbook demonstration is Runge's function f(x) = 1/(1 + 25x²) on [−1, 1]. As you raise the degree with equispaced nodes, the interpolant develops violent oscillations near ±1 whose amplitude grows without bound — the opposite of convergence. This is the Runge phenomenon, and it is a property of the node placement, not of f.

There are two standard cures. (1) Better nodes: cluster the nodes toward the endpoints using Chebyshev points, xk = cos(kπ/n); the node-product term is then tamed and high-degree interpolation converges beautifully. (2) Piecewise interpolation: abandon one global high-degree polynomial and instead glue together many low-degree pieces — this is a spline.

A cubic spline fits a separate cubic on each interval between data points, choosing the pieces so the curve and its first and second derivatives are continuous at every node. The result is smooth, non-oscillating, and uses only degree-3 polynomials no matter how many points you have — which is exactly why splines, not global polynomials, draw the smooth curves in plotting libraries, CAD surfaces, and animation paths.

Common mistakeBelieving "more data points ⇒ higher-degree polynomial ⇒ better accuracy." On equispaced nodes the reverse can be true past a modest degree (roughly 8–12) because of Runge. For more than a handful of points, reach for a spline or Chebyshev nodes — do not crank up the degree of a single global, equispaced interpolant.
✦ Worked Example — Newton interpolation of a 3-point table

A sensor logs a quantity at three times: (x, y) = (0, 1), (1, 3), (2, 7). Build the Newton interpolating polynomial and estimate the value at x = 1.5.

  1. Zeroth differences (the data): f[0] = 1, f[1] = 3, f[2] = 7.
  2. First divided differences: f[0,1] = (3 − 1)/(1 − 0) = 2;   f[1,2] = (7 − 3)/(2 − 1) = 4.
  3. Second divided difference: f[0,1,2] = (4 − 2)/(2 − 0) = 1.
  4. Assemble Newton form with c0=1, c1=2, c2=1:   p(x) = 1 + 2(x−0) + 1(x−0)(x−1) = 1 + 2x + x(x−1) = x² + x + 1.
  5. Check the nodes: p(0)=1 ✓, p(1)=1+1+1=3 ✓, p(2)=4+2+1=7 ✓. The interpolant is unique, so this is also what Lagrange or Vandermonde would give.
  6. Evaluate at x = 1.5: p(1.5) = (1.5)² + 1.5 + 1 = 2.25 + 1.5 + 1 = 4.75.

🛠️ Hands-On: global polynomial vs. cubic spline on a real table

The free Python + NumPy/SciPy/Matplotlib stack runs everything here. If you have not set it up yet, the Week 1 lecture has the one-time install (pip install numpy scipy matplotlib jupyter) — reuse that environment; nothing new is needed for this lecture.

We interpolate Runge's function on equispaced nodes to see the phenomenon, then contrast a global polynomial (numpy.polyfit on the nodes) with a SciPy cubic spline (CubicSpline). Watch the polynomial overshoot near the ends while the spline stays calm.

# interpolation.py — Lecture 4
import numpy as np
from numpy.polynomial import polynomial as P
from scipy.interpolate import CubicSpline, lagrange

f = lambda x: 1.0 / (1.0 + 25.0 * x**2)     # Runge's function on [-1, 1]

n = 10
nodes = np.linspace(-1, 1, n + 1)           # EQUISPACED -> triggers Runge
yvals = f(nodes)

xx = np.linspace(-1, 1, 400)                # dense grid for evaluation

# (1) global degree-n interpolating polynomial through the nodes
poly = lagrange(nodes, yvals)               # SciPy's Lagrange interpolant
err_poly = np.max(np.abs(poly(xx) - f(xx)))

# (2) piecewise cubic spline through the SAME nodes
spline = CubicSpline(nodes, yvals)
err_spline = np.max(np.abs(spline(xx) - f(xx)))

print(f"max |error| degree-{n} polynomial : {err_poly:.3f}")
print(f"max |error| cubic spline          : {err_spline:.3f}")
# polynomial error is large (overshoot near +/-1); spline error is tiny

# Bonus: Newton divided-difference coefficients, built incrementally
def divided_diff(x, y):
    n = len(y); coef = np.array(y, dtype=float)
    for k in range(1, n):
        coef[k:] = (coef[k:] - coef[k-1:-1]) / (x[k:] - x[:-k])
    return coef                              # coef[k] = f[x0,...,xk]

print("Newton coeffs:", divided_diff(np.array([0.,1.,2.]), np.array([1.,3.,7.])))
# -> [1. 2. 1.]  matches the worked example (x^2 + x + 1)

Now swap the equispaced grid for Chebyshev nodes nodes = np.cos(np.linspace(0, np.pi, n+1)) and rerun. Predict what happens to err_poly before you look — the same degree-10 polynomial should now track Runge's function almost perfectly.

Q1. How many distinct polynomials of degree at most n pass exactly through n+1 points with distinct x-values?
A. exactly one
B. infinitely many
C. exactly two
D. none in general
Show answer

A. The Vandermonde matrix is invertible when the xi are distinct, so the interpolant exists and is unique. (B) and (C) contradict uniqueness; (D) is wrong because existence is guaranteed.

Q2. Which property makes a Lagrange basis polynomial Li(x) special at the nodes?
A. it equals the data value yi everywhere
B. it equals 1 at xi and 0 at every other node
C. it is the derivative of the interpolant
D. it is constant between nodes
Show answer

B. Each cardinal polynomial is a "switch": Li(xi) = 1, Li(xk≠i) = 0, so Σ yiLi hits every data value. (A) confuses the basis with the data weight; (C) and (D) are unrelated.

Q3. The main practical advantage of Newton's divided-difference form over the Lagrange form is that…
A. it produces a different, more accurate polynomial
B. it avoids using the data values
C. adding a new data point requires only one extra term, not a full rebuild
D. it works even when two nodes share the same x-value
Show answer

C. Newton updates incrementally — one new divided-difference diagonal and one appended term. (A) is false: it is the same unique polynomial. (B) is nonsense, and (D) is false since distinct x-values are still required.

Q4. The Runge phenomenon refers to…
A. overflow when evaluating xn for large n
B. the spline failing to be continuous at nodes
C. Lagrange and Newton forms giving different answers
D. high-degree interpolants on equispaced nodes oscillating wildly near the endpoints
Show answer

D. The endpoint node-product term grows, so error explodes near the ends as degree rises. (A) is a floating-point issue, (B) describes a broken spline, and (C) is false — the interpolant is unique.

Q5. To interpolate many points smoothly without Runge oscillations, the recommended approach is to…
A. keep raising the degree of a single equispaced global polynomial
B. use a piecewise low-degree spline (or Chebyshev nodes)
C. solve the Vandermonde system in higher precision only
D. remove half the data points
Show answer

B. A cubic spline glues degree-3 pieces with C² continuity, or Chebyshev nodes tame the node product. (A) worsens Runge; (C) does not fix the oscillation (it is a node-placement problem, not just round-off); (D) discards information.

✓ What you learned

  • The interpolation problem: through n+1 points with distinct x-values there is exactly one polynomial of degree ≤ n (the Vandermonde view proves it but is ill-conditioned).
  • The Lagrange form builds the interpolant from cardinal "switch" polynomials and underlies quadrature weights.
  • Newton's divided differences give the same polynomial but update incrementally and evaluate cheaply.
  • The Runge phenomenon: high-degree equispaced interpolation oscillates near the ends — a node-placement defect, not a flaw in f.
  • The cures — Chebyshev nodes and piecewise cubic splines — and a project utility that compares a global polynomial against a SciPy spline.
