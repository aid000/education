Numerical Integration I — Trapezoidal & Simpson

When you only have data points or an integral with no closed form, you stitch simple shapes under the curve — and a clever choice of shape buys you orders of magnitude in accuracy for free.

🎯 Learning Objectives

  • Explain numerical integration (quadrature) as a weighted sum of sampled function values.
  • Derive the trapezoidal rule and Simpson's rule from fitting straight lines and parabolas.
  • Assemble composite rules over many panels and write their summation formulas.
  • State and use the error orders h² (trapezoid) and h⁴ (Simpson) to predict accuracy.
  • Apply both rules to a physics integral — work from a force curve or impulse from a force–time trace — in NumPy/SciPy.

6.1Quadrature: Adding Up Slivers of Area

A definite integral ∫ab f(x) dx is just the signed area under a curve. In the real world you rarely get a tidy antiderivative: the force on a piston is a wiggly measured curve, the radiated power of a star is a tabulated spectrum, a sensor logs voltage every millisecond. There is no symbol to integrate — only numbers. Numerical integration, classically called quadrature, estimates that area from a finite set of sampled values.

Every rule we build has the same skeleton: sample f at chosen points xi, multiply each value by a weight wi, and add them up.

∫ab f(x) dx ≈ Σi wi · f(xi)A quadrature rule is defined entirely by where it samples (the nodes xi) and how it weights them (the weights wi).

The simplest idea — adding up the areas of thin rectangles — is the Riemann sum you saw in calculus. It works, but it is crude: a rectangle ignores how the function tilts across each slice, so its error only falls in proportion to the slice width. The art of this lecture is replacing the flat top of each sliver with something that hugs the curve: first a slanted line (the trapezoid), then a parabola (Simpson). Better-fitting tops mean dramatically smaller error for the same number of samples.

AnalogyThink of measuring the area of a curved lake by laying floorboards across it. Rectangles are square-cut boards that leave triangular gaps at the shoreline. Trapezoids are boards cut to follow the slope of the bank — far less wasted edge. Simpson bends each board into a gentle arc that traces the shoreline almost perfectly. Same number of boards, but each smarter cut shrinks the leftover slivers enormously.

6.2The Trapezoidal Rule

Take one panel from x = a to x = b of width h = b − a. Connect the two endpoint values f(a) and f(b) with a straight line. The region under that line is a trapezoid, and its area is the average height times the width:

∫ab f(x) dx ≈ (h/2) · [ f(a) + f(b) ]Single-panel trapezoidal rule: width times the average of the two end heights.

One panel over a whole interval is usually too coarse. So we slice [a, b] into n equal panels of width h = (b − a)/n, apply the trapezoid to each, and add. Interior points are shared by two neighboring trapezoids, so each interior height is counted twice while the two endpoints are counted once. That gives the composite trapezoidal rule:

Tn = h · [ f(x0)/2 + f(x1) + f(x2) + ... + f(xn-1) + f(xn)/2 ]Endpoints get weight h/2, every interior node gets weight h. Here xi = a + i·h.

How good is it? A Taylor analysis shows the composite trapezoidal error is proportional to h² — it is a second-order method. The error also carries the curvature: it is exactly proportional to the second derivative f″, because a straight chord can never bend the way a curving function does.

Etrap = −(b − a)/12 · h² · f″(ξ)  ⟹   halving h cuts error by ≈ 4ξ is some point in [a, b]. Error ∝ h², so each doubling of the panel count quarters the error.
Common mistakeForgetting the ½ on the two endpoints. If you write h * sum(f) with all weights equal to 1, you over-count both ends and bias the result. The correct composite weights are [½, 1, 1, …, 1, ½] times h. (NumPy's np.trapz handles this for you — but you must know it when you hand-roll the loop.)

6.3Simpson's Rule: Fit a Parabola

If a straight chord is good, a parabola is far better — it can curve. Simpson's rule fits a quadratic through three consecutive points (two adjacent panels: x0, x1, x2, with the midpoint x1) and integrates the parabola exactly. The result for that pair of panels of width h each is:

∫x0x2 f(x) dx ≈ (h/3) · [ f(x0) + 4·f(x1) + f(x2) ]The famous 1–4–1 pattern: the middle (midpoint) sample carries four times the weight of the ends.

To cover the whole interval we tile these parabolic pairs, which forces n to be even (each parabola eats two panels). Adding the 1–4–1 stencils, the shared boundary nodes accumulate: odd-indexed nodes (panel midpoints) always get weight 4, while even-indexed interior nodes are shared between two parabolas and get weight 2. The two true endpoints keep weight 1. This is the composite Simpson's rule:

Sn = (h/3) · [ f0 + 4(f1+f3+...+fn-1) + 2(f2+f4+...+fn-2) + fn ]Pattern of weights: 1, 4, 2, 4, 2, ..., 4, 1, all times h/3. Requires n even.

The payoff is the error order. You might guess that fitting a degree-2 polynomial gives third-order accuracy, but a happy symmetry cancels the cubic term: Simpson is exact for cubics too, so its composite error is fourth-order, proportional to h⁴ and to the fourth derivative:

Esimp = −(b − a)/180 · h⁴ · f(4)(ξ)  ⟹   halving h cuts error by ≈ 16Error ∝ h⁴: each doubling of n shrinks error by a factor of sixteen, versus four for the trapezoid.

6.4When Is Simpson's Extra Accuracy Worth It?

Simpson costs essentially the same as the trapezoid — the same function samples, just different weights — yet converges at h⁴ instead of h². For a smooth function that is an enormous win: to reach 10⁻⁶ accuracy the trapezoid might need thousands of panels while Simpson needs dozens. The rule of thumb is simple:

  • Use Simpson by default for smooth integrands sampled on a uniform, even number of panels. Free accuracy.
  • Simpson's advantage evaporates when the integrand is not smooth — a kink, a corner, a discontinuity, or noisy data. Its h⁴ bound relies on a bounded fourth derivative; at a kink f(4) blows up and Simpson can drop back to (or below) trapezoidal accuracy.
  • The trapezoid is the safe choice for noisy experimental traces and for periodic functions integrated over a full period — where, surprisingly, the trapezoid is spectrally accurate (Course-3 territory).
Common mistakeCalling Simpson's rule with an odd number of panels (n odd, so an even number of points). Simpson tiles panels in pairs and needs n even — i.e. an odd number of sample points. Hand it an even count of points and the last parabola has no partner; libraries either error out or silently patch it with a lower-order rule. Always check parity.
✦ Worked Example — work done by a variable force

A spring-like force is measured as F(x) = 3x² newtons over a displacement from x = 0 to x = 2 m. The work is W = ∫02 3x² dx. The exact answer is x³ evaluated 0→2 = 8 J. Compare the trapezoidal and Simpson estimates using just n = 2 panels (h = 1, samples at x = 0, 1, 2).

  1. Sample the force: F(0) = 0, F(1) = 3·1 = 3, F(2) = 3·4 = 12 (newtons).
  2. Trapezoid (n = 2): T = h·[F0/2 + F1 + F2/2] = 1·[0 + 3 + 6] = 9 J. Error = 9 − 8 = +1 J (12.5% high — the chords sit above this upward-curving force).
  3. Simpson (n = 2): S = (h/3)·[F0 + 4F1 + F2] = (1/3)·[0 + 12 + 12] = 24/3 = 8 J. Error = 0.
  4. Why Simpson is exact here: F = 3x² is a quadratic, and Simpson integrates any parabola exactly. It even nails cubics for free. With only three samples it returns the true work; the trapezoid would need many panels to get close.
  5. Takeaway: for a smooth force curve, swapping the 1–1 endpoint weighting for the 1–4–1 stencil turned a 12.5% error into machine-exact — at zero extra measurement cost.

🛠️ Hands-On: impulse from a force–time trace

We reuse the free Python + NumPy/SciPy/Matplotlib stack from the Week 1 setup (the one-time install lives in Lecture 1) — nothing new to install here. We integrate a measured force–time pulse to get the impulse J = ∫ F dt, the change in momentum, and compare trapezoid vs Simpson against the analytic answer.

# integration_trap_simpson.py — Lecture 6
import numpy as np
from scipy.integrate import simpson   # trapezoid lives in numpy as np.trapz

# A half-sine force pulse: F(t) = F0 * sin(pi t / T) for t in [0, T]
# Analytic impulse J = integral_0^T F dt = 2*F0*T/pi
F0, T = 10.0, 0.5                      # 10 N peak, 0.5 s pulse
exact = 2 * F0 * T / np.pi
print("exact impulse:", exact, "N*s")

for n in [4, 8, 16, 32]:               # n panels -> n+1 sample points
    t = np.linspace(0.0, T, n + 1)     # uniform grid, n even
    F = F0 * np.sin(np.pi * t / T)
    J_trap = np.trapz(F, t)            # composite trapezoid
    J_simp = simpson(F, x=t)           # composite Simpson (needs n even)
    print(f"n={n:2d}  trap err={abs(J_trap-exact):.2e}   simp err={abs(J_simp-exact):.2e}")

# Watch trap error drop ~4x per row (h^2) and Simpson ~16x per row (h^4).

Run it and read the two error columns down the page: trapezoid roughly quarters each time you double n, Simpson roughly divides by sixteen. Then try a kinked force (e.g. np.abs(t - T/2)) and watch Simpson's h⁴ advantage collapse at the corner — exactly the smoothness caveat from §6.4.

🔗 Where this is heading

Trapezoid and Simpson are equally spaced Newton–Cotes rules — they sample on a fixed grid. Next week (Lecture 7) we let the method choose where to sample: Gaussian quadrature places nodes and weights optimally and integrates polynomials of degree 2n−1 exactly with only n points, crushing Simpson on smooth integrands. From there comes adaptive quadrature (SciPy's quad), which refines panels only where the function misbehaves, and Romberg integration, which Richardson-extrapolates a sequence of trapezoid estimates straight up the error order. These quadrature tools reappear everywhere downstream: evaluating partition-function and matrix-element integrals in the Quantum track, computing radiated power and cross-sections in Plasma, and pricing the expectation integrals at the heart of the Quant track.

💬 Discussion

You are handed a noisy experimental force–time trace — say, a sensor logging the foot-strike force of a runner at 1 kHz, with visible measurement jitter on every sample. A colleague says, "Simpson's rule is fourth-order and the trapezoid is only second-order, so always use Simpson — it's strictly better." Do you agree? Under what conditions would you prefer the trapezoidal rule (or neither) for computing the impulse, and what could go wrong if you blindly reach for Simpson on this kind of data? Frame your answer around the smoothness assumption behind the error bounds.

Show a model response

I disagree that Simpson is strictly better. The h⁴ error bound for Simpson hides an assumption: it is proportional to the integrand's fourth derivative. With smooth data that derivative is bounded and Simpson's accuracy is genuine. But measurement jitter is effectively high-frequency noise — differentiating it (even implicitly, through the rule's stencil) amplifies it. Simpson's 1–4–2–4 weights lean heavily on the relationship between neighboring samples; on noisy data those relationships are dominated by error, not signal, so the supposed fourth-order advantage is fictitious. The true error is set by the noise, not the rule's polynomial order.

For a noisy impulse I would prefer the trapezoidal rule: its flat weighting averages adjacent samples gently and is more forgiving of jitter, and over a periodic or well-localized pulse it loses little. Even better, I would first smooth or filter the trace (or fit a physical model) and then integrate — restoring the smoothness that both rules' error bounds assume. Blindly reaching for Simpson risks reporting extra significant figures that are pure noise, and at any genuine kink in the signal (a sharp foot-strike onset) Simpson can be no better than — or worse than — the trapezoid.

✓ Self-check rubric — a strong answer should:

  • Reject "strictly better" and tie Simpson's h⁴ bound to a bounded fourth derivative (the smoothness assumption).
  • Explain that noise/kinks violate that assumption, so the order advantage disappears.
  • Recommend a concrete remedy: prefer the trapezoid and/or filter/smooth before integrating.
  • Note the danger of reporting false precision from noisy data.

Q1. Numerical integration (quadrature) approximates a definite integral as…
A. the exact antiderivative evaluated at the endpoints
B. a weighted sum of sampled function values, Σ wᵢ·f(xᵢ)
C. the maximum value of f times the interval width
D. the slope of f between the endpoints
Show answer

B. Every quadrature rule is a set of nodes and weights summed as Σ wᵢ·f(xᵢ). (A) needs a closed-form antiderivative we usually don't have; (C) is a crude bound, not the integral; (D) describes differentiation, not integration.

Q2. In the composite trapezoidal rule, the weight applied to each interior sample point (relative to the endpoints) is…
A. half the endpoint weight
B. four times the endpoint weight
C. twice the endpoint weight (interior = h, endpoints = h/2)
D. the same as the endpoint weight
Show answer

C. Interior nodes are shared by two trapezoids, so they get weight h while the two endpoints get h/2 — interior weight is twice the endpoint weight. (B) is the Simpson midpoint factor, not trapezoid; (D) is the over-counting mistake.

Q3. Simpson's rule is built by fitting which curve through three consecutive points?
A. a straight line
B. a parabola (quadratic), integrated exactly
C. a cubic spline with free endpoints
D. a horizontal (constant) line
Show answer

B. Simpson fits a quadratic through three points and integrates it exactly, giving the 1–4–1 stencil. (A) is the trapezoid; (D) is the rectangle/midpoint idea; (C) is a different (spline) method, not basic Simpson.

Q4. A smooth integral is computed with composite Simpson's rule. If you double the number of panels (halve h), the error falls by roughly a factor of…
A. 16
B. 2
C. 4
D. unchanged
Show answer

A. Simpson is fourth-order (error ∝ h⁴), so halving h gives 2⁴ = 16. (C) is the trapezoid's second-order factor (2² = 4); (B) would be first-order; (D) is wrong for any convergent rule.

Q5. For which integrand is Simpson's fourth-order advantage over the trapezoid LEAST reliable?
A. a smooth polynomial like 3x²
B. a gentle exponential e^(−x)
C. a smooth sine over part of a period
D. a noisy or kinked signal with an unbounded fourth derivative
Show answer

D. Simpson's h⁴ bound assumes a bounded fourth derivative; noise or a kink makes f⁽⁴⁾ blow up, so the order advantage vanishes. (A), (B), (C) are all smooth, where Simpson cleanly outperforms the trapezoid (and is exact for the polynomial).

✓ What you learned

  • Quadrature approximates ∫f dx as a weighted sum Σ wᵢ·f(xᵢ) — defined entirely by its nodes and weights.
  • The composite trapezoidal rule fits chords; weights are [½, 1, …, 1, ½]·h and its error is second-order (h²).
  • Simpson's rule fits parabolas (1–4–1 stencil, n even); its error is fourth-order (h⁴) and it is exact through cubics.
  • Halving h cuts trapezoid error ≈4× but Simpson error ≈16× — Simpson is free accuracy for smooth integrands.
  • Simpson's edge collapses for noisy or kinked data; then prefer the trapezoid or smooth the data first — verified on a force–time impulse in NumPy/SciPy.
