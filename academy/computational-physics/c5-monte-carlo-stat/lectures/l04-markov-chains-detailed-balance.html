Week 4 · Lecture 4

Markov Chains & Detailed Balance

If you can't sample a distribution directly, build a random walk whose footprints, over time, pile up in exactly the right places — that is the trick that powers modern statistical physics.

🎯 Learning Objectives

  • Define a Markov chain by its transition probabilities and the memoryless property.
  • Explain what a stationary distribution is and write the equation it must satisfy.
  • State the detailed-balance condition and show it is a sufficient design rule for a target distribution.
  • Explain ergodicity (irreducibility + aperiodicity) and why convergence needs it.
  • Engineer a chain whose stationary distribution is the Boltzmann distribution and verify it numerically.

4.1A Random Walk With a Purpose

In Lecture 3 you watched a random walker wander aimlessly across space. A Markov chain takes that same idea and aims it. We have a set of states (for a physics system, a state is a full microscopic configuration — every spin, every particle position) and a rule that, from the current state, picks the next one at random. The defining feature is that the rule looks only at where you are now, never at how you got there:

P(Xt+1 = j | Xt = i, Xt-1, ...) = P(Xt+1 = j | Xt = i) = PijThe memoryless (Markov) property: the future depends on the present only. P_ij is the transition probability from state i to state j.

The numbers Pij form the transition matrix P. Each row is a probability distribution over "where to go next," so every row sums to 1. If today's probabilities of being in each state are a row vector πt, then tomorrow's are obtained by one matrix multiply:

πt+1 = πt P    and after n steps    πt+n = πt PnThe whole evolution of the distribution is just repeated multiplication by the transition matrix.

This is the engine of Markov-chain Monte Carlo (MCMC). Instead of trying to draw independent samples from a hopelessly complicated distribution — like the probability of every arrangement of 1023 spins — we let a cleverly built chain wander, and we collect the states it visits. The genius is that we get to design P so that the walker spends time in each state in exactly the proportion we want.

AnalogyThink of a tourist with no map wandering a city, choosing the next street only from the corner they stand on. If the streets are laid out cleverly, the fraction of time they end up spending in each neighborhood settles into a fixed pattern — independent of where they started. MCMC is the art of laying out the streets so that the tourist naturally lingers in the neighborhoods we care about, in precisely the right proportions.

4.2The Stationary Distribution

Run the chain long enough and the distribution of "where am I?" often stops changing. A distribution π that is unchanged by one step of the chain is called stationary (or invariant):

π = π P    i.e.    πj = Σi πi Pijpi is a left eigenvector of P with eigenvalue 1. Probability flowing into every state j exactly balances probability flowing out.

This is a global balance condition: for each state j, the total probability arriving from all other states equals the probability already there. The stationary distribution is the long-run fraction of time the walker spends in each state. Our goal in MCMC is to choose P so that this π is the distribution we actually want to sample — the target.

Common mistakeA stationary distribution is not a state the chain gets stuck in. The walker keeps moving every step — what becomes constant is the distribution over states, the long-run proportion of time spent in each. Confusing "π stops changing" with "the walker stops moving" is the single most common beginner error.

4.3Detailed Balance — the Design Principle

Solving π = πP directly means finding an eigenvector of a matrix with astronomically many entries — impossible for a real physics system. We need a way to build a chain whose stationary distribution is a given target π, without ever writing P out. Detailed balance is that tool. A chain satisfies detailed balance with respect to π if, for every pair of states,

πi Pij = πj PjiThe probability flux from i to j equals the flux from j back to i, for every pair. This is a "reversibility" condition.

This is far stronger than the global balance of 4.2: instead of all the flows into a state summing correctly, each individual pair of states is in balance. The payoff is a one-line theorem. Sum the detailed-balance equation over i:

Σi πi Pij = Σi πj Pji = πj Σi Pji = πjBecause row j of P sums to 1. So detailed balance => pi = pi P: pi is automatically stationary.

So detailed balance is sufficient for stationarity. (It is not necessary — some valid chains break it — but it is the easy, constructive route.) The beauty is that we only ever need to reason about one pair of states at a time. Crucially, the condition involves only the ratio πi/πj, so we never need the normalization constant of π — which is exactly the partition function Z we cannot compute. That single observation is what makes statistical-physics simulation possible at all.

AnalogyDetailed balance is like a busy revolving door between two rooms that, at equilibrium, lets exactly as many people through one way as the other. You don't have to audit the whole building's traffic; if every single doorway is individually balanced, the population of each room is automatically steady. Global balance audits the building; detailed balance audits each door — and checking doors is something a computer can actually do.

4.4Ergodicity, and Targeting Boltzmann

Detailed balance guarantees π is a stationary distribution, but two more conditions guarantee the chain actually converges to it from any start and that time-averages equal π-averages. Together these make the chain ergodic:

  • Irreducible: every state is reachable from every other state in a finite number of steps. No isolated islands the walker can never enter or leave.
  • Aperiodic: the chain doesn't return to states only on a fixed cycle (period 1). A single self-loop probability anywhere kills periodicity.

An ergodic chain has a unique stationary distribution, and the ergodic theorem promises that long-run time averages converge to expectations under π:

(1/N) Σt=1..N f(Xt) → Σi πi f(i)  as N → ∞This is why we can estimate equilibrium averages by simply averaging along one long chain.

Now the physics. In the canonical ensemble at temperature T, the probability of a microstate with energy E is the Boltzmann distribution:

πi = e-Ei/kBT / Z,    β = 1/(kBT)Z = sum over all states of e^(-E/kT) is the partition function — uncountable for real systems.

We can never compute Z, but detailed balance only needs the ratio πj/πi = e-β(Ej - Ei), where Z cancels. So we engineer transition probabilities that obey detailed balance for this ratio, then let an ergodic chain run. The walker spends time in each configuration exactly in proportion to its Boltzmann weight, and time-averaging gives us thermodynamic quantities. Building those exact transition rules — the acceptance rule — is the subject of next week's Metropolis-Hastings algorithm.

✦ Worked Example — find the stationary distribution of a 2-state chain

A two-state chain has transition matrix P with rows summing to 1: from state 1, stay with prob 0.7, jump to 2 with 0.3; from state 2, jump to 1 with 0.2, stay with 0.8. Find the stationary distribution π = (π1, π2) and check detailed balance.

  1. Write the balance equation π = πP. Component for state 1: π1 = 0.7π1 + 0.2π2.
  2. Rearrange: 0.3π1 = 0.2π2, so π1/π2 = 0.2/0.3 = 2/3.
  3. Normalize with π1 + π2 = 1. Set π1 = 2k, π2 = 3k; then 5k = 1, k = 0.2. So π = (0.4, 0.6).
  4. Verify stationarity: πP state-2 component = 0.4(0.3) + 0.6(0.8) = 0.12 + 0.48 = 0.60 = π2. ✓
  5. Check detailed balance: π1P12 = 0.4 × 0.3 = 0.12 and π2P21 = 0.6 × 0.2 = 0.12. Equal — so this chain is reversible, and (0.4, 0.6) is its unique stationary distribution (it is irreducible and aperiodic thanks to the self-loops).

🛠️ Hands-On: build a chain that lands on a target distribution

The free Python + NumPy / Matplotlib stack from the Week 1/2 setup (see the install panel in Lecture 1) is all you need — no new tools this week. We'll run a small chain, confirm it converges to the π we predicted, then build a 3-state chain whose stationary distribution is a tiny Boltzmann distribution.

# markov_chain.py — Lecture 4
import numpy as np

# --- Part 1: does the chain converge to pi = (0.4, 0.6)? ---
P = np.array([[0.7, 0.3],
              [0.2, 0.8]])

# Power iteration: a distribution times P, many times
pi = np.array([1.0, 0.0])          # start certain we're in state 1
for _ in range(50):
    pi = pi @ P
print("converged pi:", pi)         # -> [0.4 0.6]

# --- Part 2: a Boltzmann target over 3 energy levels ---
E    = np.array([0.0, 1.0, 2.0])   # energies (units of kT)
beta = 1.0
w    = np.exp(-beta * E)           # unnormalized Boltzmann weights
target = w / w.sum()              # the pi we WANT (Z divides out)

# Build a detailed-balance chain by simulation (Metropolis-style preview)
rng = np.random.default_rng(0)
state, counts, N = 0, np.zeros(3), 200_000
for _ in range(N):
    prop = rng.integers(0, 3)                     # propose a state
    ratio = w[prop] / w[state]                    # Z cancels here!
    if rng.random() < min(1.0, ratio):            # accept rule -> detailed balance
        state = prop
    counts[state] += 1

print("target  :", np.round(target, 3))
print("sampled :", np.round(counts / N, 3))       # matches target

Run it: the power iteration prints [0.4 0.6] regardless of the start vector, and the sampled frequencies track the Boltzmann target. Try changing beta — larger β (colder) piles probability onto the ground state. You just wrote a baby Metropolis sampler; next week we make it rigorous.

5 questions · click "Show answer" to check yourself.

Q1. The defining "memoryless" property of a Markov chain says the next state depends on…
A. the entire past trajectory of visited states
B. only the current state
C. the initial state alone
D. the stationary distribution
Show answer

B. The Markov property is P(Xt+1|Xt, Xt-1,...) = P(Xt+1|Xt) — only the present matters. A depends on history (that's a non-Markov process); C ignores the present; D is a long-run property, not a transition rule.

Q2. A distribution π is stationary for transition matrix P when…
A. π = π P
B. every entry of π is equal
C. π P = 0
D. the walker stops moving between states
Show answer

A. Stationary means one step leaves the distribution unchanged: π = πP (π is a left eigenvector with eigenvalue 1). C is wrong (it would force π=0); B is the uniform distribution, a special case only; D confuses a steady distribution with a frozen walker — the walker keeps moving.

Q3. The detailed-balance condition is…
A. Σi Pij = 1 for every j
B. πi Pij = πj Pji for every pair i, j
C. Pij = Pji for every pair
D. all states have equal energy
Show answer

B. Detailed balance equates the per-pair probability fluxes πiPij = πjPji. A is just the row-normalization of a stochastic matrix (and it's columns vs rows besides); C (symmetric P) is a special case that only gives the uniform stationary distribution; D is unrelated.

Q4. Why is detailed balance such a useful design tool for sampling the Boltzmann distribution?
A. it lets you compute the partition function Z exactly
B. it makes the chain converge in a single step
C. it only requires probability ratios, so the unknown Z cancels out
D. it removes the need for random numbers
Show answer

C. The condition uses only πj/πi = e-β(Ej-Ei), in which the intractable normalizer Z cancels. A is false — we never compute Z; B is false (convergence takes many steps); D is false — MCMC is fundamentally stochastic.

Q5. A chain satisfies detailed balance for π but has two disconnected groups of states the walker can never move between. Will time-averages converge to π from any start?
A. Yes — detailed balance alone is enough
B. Yes, but only if P is symmetric
C. Only if the chain is also periodic
D. No — the chain is not irreducible, so it isn't ergodic and won't converge to the unique π
Show answer

D. Disconnected groups mean the chain is reducible; it gets trapped in whichever group it started in, so it never explores all of π. Convergence needs ergodicity (irreducible + aperiodic), not just detailed balance. A ignores this; B is irrelevant; C is backwards — periodicity blocks convergence, it doesn't help.

✓ What you learned

  • A Markov chain is a memoryless random walk over states defined by a transition matrix P; distributions evolve as πt+1 = πtP.
  • A stationary distribution satisfies π = πP — the long-run fraction of time spent in each state, not a frozen walker.
  • Detailed balance (πiPij = πjPji) is a sufficient, constructive rule that makes any target π stationary — and needs only ratios, so Z cancels.
  • Ergodicity (irreducible + aperiodic) guarantees a unique π and that time-averages equal π-averages.
  • We engineer chains whose stationary distribution is the Boltzmann distribution, and confirmed it in NumPy — your Week-4 capstone milestone is a tested stationary_distribution + detailed-balance check.
