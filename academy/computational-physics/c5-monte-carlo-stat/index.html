🛠️ Hands-On Project

2D Ising across temperature (M, χ, C) or Lennard-Jones MD with g(r) (Python)

Pick one track. Ising: run single-spin-flip Metropolis on a 2D lattice across a sweep of temperatures and measure magnetization M, susceptibility χ, and heat capacity C, locating the critical temperature and showing the phase transition. Molecular dynamics: integrate a Lennard-Jones fluid with velocity-Verlet and compute the radial distribution function g(r) across phases. Either way you handle burn-in, autocorrelation, and proper error bars (blocking/bootstrap), then deliver a short report with clean code, figures, and a brief video demo. Week 1 includes a one-time Python + NumPy install (step-by-step in Lecture 1; Numba optional for speed).

Wk 1: install Python + NumPy/Matplotlib Wk 4: Markov-chain sampler + plan Wk 8: observables + autocorrelation/error analysis Wk 10: report + plots + demo submitted

💬 Discussions

Three checkpoints — weeks 3, 6, 9

  • Week 3: A random walker has no memory, yet diffusion is perfectly predictable on average. How does deterministic macroscopic behavior emerge from purely random microscopic steps?
  • Week 6: Metropolis only ever compares a spin to its neighbors, yet the whole lattice spontaneously orders below Tc. How does global order arise from purely local update rules?
  • Week 9: Monte Carlo samples configurations with no time, while molecular dynamics follows real trajectories in time. When does each approach win, and when do they agree on equilibrium averages?
