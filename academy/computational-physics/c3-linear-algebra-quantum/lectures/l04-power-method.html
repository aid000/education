The Power Method & Dominant Eigenvalues

Multiply a vector by a matrix again and again and it forgets everything except the loudest mode — that simple act is the seed of nearly every large-scale eigensolver.

🎯 Learning Objectives

  • Derive power iteration from the eigenvector expansion and explain why it converges to the dominant eigenvector.
  • Predict the convergence rate from the ratio |λ₂/λ₁| of the two largest eigenvalues.
  • Recover the dominant eigenvalue with the Rayleigh quotient and keep iterates stable by normalizing.
  • Use deflation to peel off the dominant mode and reach the next eigenpair.
  • Apply the inverse power method with a shift to target the smallest or any chosen eigenvalue.

4.1Why Repeated Multiplication Finds the Loudest Mode

Suppose a real symmetric (or, more generally, diagonalizable) matrix A has eigenpairs (λ1, v1), …, (λn, vn) ordered so that |λ1| > |λ2| ≥ … ≥ |λn|. The eigenvectors form a basis, so any starting vector can be written as a blend of them:

x₀ = c₁v₁ + c₂v₂ + ... + cₙvₙAny vector is a superposition of eigenvectors — provided c₁ ≠ 0, i.e. x₀ has some overlap with the dominant mode.

Now hit it with A repeatedly. Because Avi = λivi, each component just picks up its own eigenvalue raised to the power k:

Aⁿx₀ = c₁λ₁ⁿv₁ + c₂λ₂ⁿv₂ + ... + cₙλₙⁿvₙFactoring out the biggest growth factor λ₁ⁿ exposes who wins.

Pull out the largest factor λ1k:

Aⁿx₀ = λ₁ⁿ [ c₁v₁ + c₂(λ₂/λ₁)ⁿv₂ + ... ]Every ratio (λₖ/λ₁) is smaller than 1 in magnitude, so each term except the first decays to zero as k grows.

Every bracketed term except c1v1 contains a ratio (λi/λ1) with magnitude below 1, raised to the k-th power. Those terms die exponentially. After enough iterations the vector points (up to scale) along v1, the dominant eigenvector — the mode that grows fastest under A. In practice we renormalize every step so the numbers don't overflow, but the direction is what we keep.

AnalogyThink of A as one round of "interest" paid at different rates to different savings accounts (the eigen-directions). The account with the highest rate λ1 compounds fastest, so after many years it dwarfs all the others — even if it started small. Power iteration is just letting the highest-yield mode out-compound the rest, then reading off which direction the money piled up in.

4.2How Fast? The Eigenvalue Gap Sets the Rate

The slowest-decaying contaminant is the second eigenvector, scaled by (λ2/λ1)k. That single ratio governs everything: the error in the direction of v1 shrinks by a constant factor every iteration.

error after k steps ~ |λ₂ / λ₁|ⁿLinear (geometric) convergence with ratio r = |λ₂/λ₁|. The bigger the spectral gap, the faster.

This is linear convergence: each step buys you the same multiplicative factor r = |λ2/λ1|. If r = 0.5 you gain one bit per step; if r = 0.99 you crawl. To extract the eigenvalue itself once the direction has settled, use the Rayleigh quotient, which gives the best scalar λ fitting Ax ≈ λx:

λ ≈ (xᵀ A x) / (xᵀ x)For symmetric A the Rayleigh quotient converges as r² = |λ₂/λ₁|² — twice as many correct digits as the vector itself.

Why does this matter in the field? The web's original page-ranking algorithm is literally power iteration on a giant stochastic link matrix whose dominant eigenvector (eigenvalue 1) ranks pages. In quantum and vibration problems the dominant mode is often the one you care about — the fastest-growing instability, the stiffest normal mode, or the ground state once you flip to the inverse method in §4.4.

4.3Deflation: Peeling Off a Mode to Reach the Next

Power iteration gives you only the dominant pair. To reach λ2, you must remove v1 from the matrix so it can no longer dominate. For a symmetric matrix with a normalized dominant eigenvector v1 (so v1Tv1 = 1), Hotelling deflation subtracts the rank-one piece that λ1 contributes:

B = A - λ₁ v₁ v₁ᵀB has the same eigenvectors as A, but the eigenvalue at v₁ is shifted from λ₁ down to 0 — every other λ is untouched.

Running power iteration on B now converges to v2 with eigenvalue λ2, because λ2 is now the largest in magnitude. Repeat to peel off mode after mode. This is exactly how you build a handful of leading modes of a covariance matrix in principal-component analysis, or the first few vibrational modes of a structure, without ever forming a full eigendecomposition.

Common mistakeDeflation is only as accurate as the v1 you subtract. If you stop the first power iteration too early, the leftover v1 error contaminates every later mode, and the errors accumulate as you deflate further. Converge the dominant pair tightly before deflating, and for many modes prefer a block/orthogonal-iteration method (or the Lanczos algorithm in Week 6) over chaining many single deflations.

4.4The Inverse Power Method & Shifts: Targeting Any Eigenvalue

What if you want the smallest eigenvalue — the ground state of a Hamiltonian, the lowest buckling load, the slowest-decaying mode? Note that A and A−1 share eigenvectors, but the eigenvalues invert: if Av = λv then A−1v = (1/λ)v. The smallest λ of A is the largest 1/λ of A−1. So power iteration on A−1 converges to the smallest eigenvalue of A.

Better still, introduce a shift μ. The matrix (A − μI) has eigenvalues (λi − μ), so its inverse has eigenvalues 1/(λi − μ). Whichever λi is closest to your guess μ makes (λi − μ) tiny and 1/(λi − μ) huge — so it dominates:

(A - μ I)⁻¹ x -> eigenvector whose λ is nearest μConvergence rate is |λ₁ - μ| / |λ₂ - μ|, where λ₁, λ₂ are the eigenvalues nearest and 2nd-nearest to μ. Put μ close and it converges almost instantly.

You never compute the inverse explicitly. Instead, each iteration solves a linear system (A − μI) y = x (one LU factorization reused every step). If you also update μ to the current Rayleigh quotient each iteration, you get Rayleigh-quotient iteration, which converges cubically for symmetric matrices — the error roughly cubes each step once you are close. This shift-and-invert idea is the workhorse behind targeting interior eigenvalues of large sparse matrices in physics.

✦ Worked Example — three steps of power iteration by hand

Let A = [[2, 1], [1, 2]]. Its exact eigenvalues are λ1 = 3 (eigenvector [1, 1]) and λ2 = 1 (eigenvector [1, −1]). Start from x₀ = [1, 0] and iterate x ← Ax, normalizing by the largest-magnitude entry each step.

  1. Step 1: Ax₀ = [2·1 + 1·0, 1·1 + 2·0] = [2, 1]. Normalize by 2 → x₁ = [1, 0.5].
  2. Step 2: Ax₁ = [2 + 0.5, 1 + 1] = [2.5, 2]. Normalize by 2.5 → x₂ = [1, 0.8].
  3. Step 3: Ax₂ = [2 + 0.8, 1 + 1.6] = [2.8, 2.6]. Normalize by 2.8 → x₃ = [1, 0.929]. Heading toward [1, 1].
  4. Eigenvalue estimate: the normalizing factors 2, 2.5, 2.8, … climb toward 3 = λ1. The Rayleigh quotient at x₃ = [1, 0.929] gives (xᵀAx)/(xᵀx): with Ax₃ = [2.929, 2.858], this is (2.929 + 0.929·2.858)/(1 + 0.929²) ≈ 5.584/1.863 ≈ 2.997 — already within 0.1% of 3.
  5. Rate check: r = |λ2/λ1| = 1/3 ≈ 0.333, so the direction error should shrink by ~3× per step. Indeed the second component races 0 → 0.5 → 0.8 → 0.929 → (limit 1), each gap about a third of the last.

🛠️ Hands-On: power iteration, deflation, and shift-and-invert

This uses the same free Python + NumPy/SciPy/Matplotlib stack you set up in Week 1 (the one-time install lives in the early lectures — no new tools needed here). We will roll our own power iteration, then check it against numpy.linalg.eig, and use scipy.sparse.linalg for the shift-and-invert solve.

# power_method.py — Lecture 4
import numpy as np
from scipy.sparse.linalg import eigsh
from scipy.linalg import lu_factor, lu_solve

A = np.array([[2.0, 1.0], [1.0, 2.0]])

# --- 1. Power iteration for the DOMINANT eigenpair ---
def power_iteration(A, iters=50):
    x = np.random.rand(A.shape[0])
    for _ in range(iters):
        x = A @ x
        x /= np.linalg.norm(x)          # keep it unit length
    lam = x @ A @ x                      # Rayleigh quotient (x is unit)
    return lam, x

lam1, v1 = power_iteration(A)
print("dominant lambda ~", round(lam1, 6))     # ~3.0

# --- 2. Hotelling deflation -> next eigenpair ---
B = A - lam1 * np.outer(v1, v1)          # kills the dominant mode
lam2, v2 = power_iteration(B)
print("next lambda ~", round(lam2, 6))         # ~1.0

# --- 3. Inverse iteration with a shift mu near the SMALL eigenvalue ---
mu = 0.9
lu = lu_factor(A - mu * np.eye(2))       # factor once, reuse each step
x = np.random.rand(2)
for _ in range(50):
    x = lu_solve(lu, x)                  # solve (A - mu I) y = x
    x /= np.linalg.norm(x)
print("targeted lambda ~", round(x @ A @ x, 6))  # ~1.0 (nearest mu)

# sanity check against a library solver
print("numpy eigs:", np.sort(np.linalg.eigvalsh(A)))   # [1. 3.]

Try it on a larger random symmetric matrix and time how the convergence slows as you shrink the gap |λ2/λ1| toward 1. Then move the shift μ and watch inverse iteration lock onto whichever eigenvalue you aim it at.

🔗 Where this is heading

Power iteration is the atom of every modern large-scale eigensolver. Block versions (orthogonal/subspace iteration) chase several modes at once; building an orthonormal basis from the sequence x, Ax, A²x, … leads directly to the Krylov-subspace methods — Lanczos and Arnoldi — you will meet in Week 6, which power scipy.sparse.linalg.eigsh/eigs for million-dimensional sparse matrices. Shift-and-invert from §4.4 is exactly how you grab interior eigenvalues of a sparse Hamiltonian. Project checkpoint (Week 4): by the end of this week your capstone should compute the dominant eigenpair of a real coupling matrix (e.g. a vibrational stiffness or a tight-binding Hamiltonian) with your own power iteration and verify it against eigsh to within tolerance — the first runnable milestone of the eigensolver project. 5 questions · click "Show answer" to check yourself.

Q1. Power iteration converges to the eigenvector whose eigenvalue is…
A. largest in magnitude (the dominant eigenvalue)
B. smallest in magnitude
C. closest to zero
D. exactly 1
Show answer

A. Factoring out λ₁ⁿ shows every other component decays by (λi/λ1)ⁿ → 0, so the iterate aligns with the largest-magnitude eigenvalue. B/C describe the inverse method's target; D is only special for stochastic matrices, not power iteration in general.

Q2. The convergence rate of power iteration is governed by…
A. the largest eigenvalue alone
B. the ratio |λ₂/λ₁| of the two largest eigenvalues
C. the matrix dimension n
D. the trace of A
Show answer

B. The slowest-decaying contaminant is v₂, shrinking like (λ₂/λ₁)ⁿ, so r = |λ₂/λ₁| sets the rate. A and D are scalar facts that do not control the gap; dimension (C) does not directly set the rate.

Q3. If |λ₁| = 10 and |λ₂| = 9, power iteration will…
A. converge in a single step
B. diverge
C. converge slowly, since the ratio 0.9 is close to 1
D. fail to converge at all
Show answer

C. r = 9/10 = 0.9, so the error shrinks only ~10% per step — many iterations needed. It does converge (not B/D), just slowly; single-step convergence (A) would require r = 0.

Q4. Hotelling deflation B = A − λ₁ v₁ v₁ᵀ (with v₁ a unit dominant eigenvector) changes the spectrum by…
A. negating every eigenvalue
B. doubling λ₁
C. shifting all eigenvalues by −λ₁
D. moving the eigenvalue at v₁ to 0 while leaving the others unchanged
Show answer

D. The rank-one subtraction zeroes only the v₁ eigenvalue (3 → 0 in our example), so λ₂ becomes dominant on B. It does not negate (A), double (B), or uniformly shift (C) the spectrum.

Q5. To find the eigenvalue closest to a target value μ, you should…
A. run plain power iteration on A
B. run inverse iteration on (A − μI), i.e. repeatedly solve (A − μI)y = x
C. raise A to a high power directly
D. compute the determinant of A
Show answer

B. (A − μI)⁻¹ amplifies 1/(λi − μ), which is largest for the λi nearest μ; you solve a linear system each step rather than inverting. Plain power iteration (A) finds only the dominant mode; C/D give no eigenvector targeting.

✓ What you learned

  • Power iteration multiplies a vector by A repeatedly so the dominant eigenvector v₁ out-grows all others.
  • Convergence is linear with rate r = |λ₂/λ₁|; a big spectral gap means fast convergence, and the Rayleigh quotient recovers λ (quadratically for symmetric A).
  • Hotelling deflation B = A − λ₁v₁v₁ᵀ zeroes the dominant mode so the next pair becomes reachable.
  • The inverse power method with a shift (A − μI)⁻¹ targets the eigenvalue nearest μ — including the smallest — by solving a system each step, never inverting.
  • You implemented all three in NumPy/SciPy and checked them against a library eigensolver — your Week-4 capstone milestone.
