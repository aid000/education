PDE Classification & Finite Differences · Weeks 1–2
1. For a linear second-order PDE with discriminant D = B² − 4AC, a PDE with D = 0 is classified as…
Answer: A. The heat equation (A=α, B=0, C=0) gives D=0 — parabolic. D<0 is elliptic, D>0 is hyperbolic, and the sign of D says nothing about linearity.
2. Which statement about boundary-value vs. initial-value problems is correct?
Answer: B. With no time derivative, an elliptic PDE's interior is fixed entirely by data on the boundary, solved globally in one shot. Parabolic and hyperbolic problems march forward from initial data instead.
3. The five-point Laplacian stencil in 2D assigns which weights (before dividing by h²) to the center and its four neighbors?
Answer: C. Summing the 1D second-derivative stencils along x and y gives center −4 and +1 on each of the four neighbors, all over h². Option B is the 1D second-derivative stencil, not the 2D Laplacian.
Explicit Diffusion & the CFL/Stability Limit · Weeks 3–4
4. The FTCS update for the 1D heat equation is called "explicit" because…
Answer: D. "Explicit" means the future value is given by a direct formula in known quantities — no linear solve. It is an approximation (not exact) and only conditionally stable (r ≤ 1/2), unlike implicit schemes.
5. With diffusion number r = αΔt/Δx², the stability condition for explicit FTCS is…
Answer: A. Von Neumann analysis gives amplification factor G = 1 − 4r·sin²(kΔx/2); requiring G ≥ −1 for the worst-case mode yields r ≤ 1/2, i.e. Δt ≤ Δx²/(2α).
6. Von Neumann analysis of FTCS gives amplification factor G = 1 − 4r·sin²(kΔx/2). The mode that first violates stability as r increases is…
Answer: B. The jagged, point-to-point sawtooth mode (kΔx = π) hits sin² = 1 first and drives G below −1 before any smoother mode does — exactly why blow-ups look like alternating +/− spikes.
7. You halve Δx on an explicit heat solver to improve spatial resolution. The largest stable Δt…
Answer: C. Since Δt ≤ Δx²/(2α), halving Δx multiplies the bound by (1/2)² = 1/4 — the brutal dx² penalty that motivates implicit methods.
8. Running explicit FTCS with r = 0.8 (exceeding the stability limit) produces a solution that…
Answer: D. At r > 1/2 the center weight (1−2r) in the weighted-average form goes negative, so a hot point overshoots colder than its neighbors — an oscillation that grows every step.
9. The general CFL (Courant) condition for an explicit scheme is fundamentally a statement that…
Answer: A. CFL is about information, not accuracy or round-off: an explicit stencil only sees nearby cells, so the true physical signal may not outrun that reach.
Implicit Methods & Boundary Conditions · Weeks 5–6
10. The defining difference between an implicit and an explicit scheme for the heat equation is that an implicit scheme…
Answer: B. Implicit schemes evaluate uxx at level n+1, so the unknowns are coupled and must be solved together — more expensive per step, not less, and boundaries still matter.
11. Backward Euler (BTCS) for the 1D heat equation has amplification factor G = 1/(1 + 4r·sin²(kΔx/2)). This means it is…
Answer: C. The denominator is always ≥ 1, so |G| ≤ 1 for any r — unconditional stability. This is about stability, not accuracy: backward Euler is still only first-order in time.
12. The Crank-Nicolson scheme is best described as…
Answer: D. Centering the spatial term at the midpoint n+1/2 cancels the leading O(Δt) error, giving O(Δt²+Δx²) accuracy while keeping |G| ≤ 1 for all r.
13. A single implicit step for the 1D heat equation requires solving a tridiagonal linear system. Despite needing a solve, this costs only O(N) work because…
Answer: A. The matrix is tridiagonal (not dense), and the Thomas algorithm — a specialized Gaussian elimination — solves it in O(N) with one forward and one backward sweep.
14. For a Neumann (zero-flux) boundary condition, using the ghost-point construction u(−1) = u(1) instead of the one-sided difference (u₁ − u₀)/h matters because…
Answer: B. The one-sided difference is only O(h); a scheme's global order equals its worst local order, so a first-order boundary caps an otherwise second-order interior. The ghost point restores O(h²) at the edge.
15. A steady 1D Poisson problem with Neumann conditions on both ends of the domain has what issue?
Answer: C. Only derivatives are constrained, so adding any constant to a solution gives another valid solution — the matrix is singular until one value (or the mean) is anchored.
The Wave Equation · Week 7
16. For a string under tension T with mass per unit length ρ, the wave speed in ∂²u/∂t² = c²∂²u/∂x² is…
Answer: D. Newton's law on a string segment gives ρ·utt = T·uxx, so c² = T/ρ and c = sqrt(T/ρ). Option C is the string's impedance Z, not its wave speed.
17. The leapfrog (CTCS) scheme for the wave equation links three time levels (n−1, n, n+1). What extra step is required to begin the simulation?
Answer: A. With only u⁰ known, the first step uses the initial velocity v(x) in a centered approximation to supply the missing past level — after that, leapfrog runs on its own.
18. A right-moving pulse on a string reflects off a fixed (Dirichlet, u=0) end. The reflected pulse is…
Answer: B. A clamped end must push back, flipping the sign of the returning pulse (R = −1). A free (Neumann) end instead reflects it upright (R = +1).
Poisson/Laplace & Relaxation · Week 8
19. In the discrete Laplace equation on a square grid, an interior value φ(i,j) satisfying ∇²φ = 0 equals…
Answer: C. The five-point stencil for ∇²φ = 0 rearranges to φ(i,j) = ¼(sum of 4 neighbors) — the average, not the sum (off by ¼).
20. Compared to Jacobi iteration, Gauss-Seidel converges roughly twice as fast because it…
Answer: D. Gauss-Seidel reuses just-computed values as it sweeps, letting news propagate across the grid within one pass; Jacobi (which needs two grid copies) uses only old values.
21. For a large N×N grid, Successive Over-Relaxation (SOR) with the optimal relaxation factor ω reduces the number of sweeps needed to converge from O(N²) (Jacobi/Gauss-Seidel) down to about…
Answer: A. Optimal SOR needs only O(N) sweeps versus O(N²) for Jacobi/Gauss-Seidel — turning ten thousand sweeps into a few hundred, the big classical speedup.
Maxwell's Equations, FDTD & Capstone Synthesis · Weeks 9–10
22. On the Yee grid, E and H are stored at points offset by half a cell in both space and time. The purpose of this staggering is…
Answer: B. Every derivative needed is a clean centered difference of values that already exist on the grid — no interpolation, no extra memory, and FDTD remains explicit and only conditionally stable.
23. In 1D FDTD, the Courant number is S = cΔt/Δx. Choosing Δt so that S = 1.3 causes…
Answer: C. S > 1 violates the CFL condition — the grid cannot support a signal outrunning the light cone, so the scheme responds with exponential blow-up within a few dozen steps.
24. In going from a 1D to a 2D (or 3D) FDTD grid, the stable Courant number tightens from S ≤ 1 to S ≤ 1/√2 (2D) or 1/√3 (3D) because…
Answer: D. A diagonal wave covers √2 (or √3) times the axis spacing between the grid samples it uses, so no single Δt matches the light cone in every direction at once — the diagonal is the worst case the bound must protect.
25. In the capstone's diagnostic philosophy, a secular (sustained) rise in a conserved or monotonic quantity — total heat in an insulated box, or EM field energy in a lossless PEC box — most likely indicates…
Answer: D. Pretty color maps lie; conserved quantities don't. A rising diagnostic in a closed, lossless system is an instant red flag for a CFL violation or a leaking/mis-implemented boundary.
