🛠️ Hands-On Project

A simplified transient / safety analysis in Python

Build a simplified transient / safety analysis in Python: model a reactor transient — a loss-of-flow, a small-break LOCA, a decay-heat removal scenario, or a reactivity excursion — using point-kinetics and lumped thermal-hydraulics, and check the result against the relevant acceptance criterion (e.g., peak clad temperature, shutdown margin). Because the industry-standard code RELAP5-3D is license-gated, we use an open Python model built on NumPy + SciPy instead. You deliver a short report comparing your simulation's output against hand-worked estimates. Week 1 includes a one-time Python + NumPy + SciPy install (step-by-step in Lecture 1).

Wk 1: install Python + NumPy + SciPy Wk 4: transient scenario + acceptance criterion chosen Wk 8: Python transient run + plots Wk 10: report + figures submitted

💬 Discussions

Three checkpoints — weeks 3, 6, 9

  • Week 3: Defense-in-depth deliberately stacks redundant, independent barriers. When does adding "one more safety system" actually reduce risk — and when does it just add cost and complexity?
  • Week 6: Decay heat means a reactor keeps generating power even after shutdown. Why does that single fact drive so much of a plant's safety design, and what happens if cooling is lost?
  • Week 9: ALARA says keep dose "as low as reasonably achievable" — not zero. Why isn't the goal simply zero dose, and how should that tradeoff shape waste and decommissioning choices?
