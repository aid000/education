Why AI works now & how models learn · Weeks 1–2
1. The course frames three "unlocks" that made modern AI possible after decades of being impractical. Which trio is correct?
Answer: A. Compute (GPUs for massively parallel matrix math), data at web/ImageNet scale, and the transformer architecture together turned a long-impossible problem into a practical one.
2. The 2012 result widely credited with kicking off the deep-learning era was…
Answer: B. AlexNet (2012) showed a deep neural net trained on GPUs could crush prior image-recognition methods, proving the approach scaled — the spark for the modern era.
3. The 2017 paper "Attention Is All You Need" mattered chiefly because the transformer it introduced…
Answer: C. Unlike older sequential RNNs, transformers process a sequence in parallel and use self-attention to capture long-range relationships — the key to scalable training and the scaling era that followed.
4. At its core, a large language model is trained to do which task?
Answer: D. The base objective is next-token prediction: P(next token | previous tokens). Surprisingly broad abilities emerge from doing this at scale.
5. Which best describes the difference between a token and an embedding?
Answer: A. Text is split into tokens (word-pieces), and each token is turned into an embedding — a numeric vector — so similar meanings land near each other in vector space.
6. Put the typical training stages of a modern chat model in order.
Answer: B. First broad pretraining on next-token prediction, then fine-tuning on task/instruction data, then RLHF to align responses with human preferences (helpful, honest, harmless).
7. What is the main point of RLHF (reinforcement learning from human feedback)?
Answer: C. RLHF uses human preference ratings to tune behavior and style; it aligns responses with what people find useful rather than teaching large amounts of new knowledge.
What frontier models can do · Week 3
8. "Multimodal" model means it can…
Answer: D. Multimodal = multiple modalities. A model might read an image and describe it, or take audio and produce text, in addition to plain text.
9. A "reasoning" model differs from a standard chat model mainly because it…
Answer: A. Reasoning models trade extra compute at inference for step-by-step internal reasoning, improving math, logic, and planning — they still hallucinate and are usually slower/costlier per answer.
10. "Function calling" / tool use lets a model…
Answer: B. The model outputs a structured call (e.g., a JSON function name + arguments); the system runs the real tool and feeds the result back — connecting the model to actions and live data.
Prompting — clarity, structure & reasoning · Weeks 4–5
11. Which prompt is most likely to get a useful, on-target answer?
Answer: C. Specificity wins: audience, length, tone, constraints, and a clear goal give the model what it needs. Vague prompts force it to guess.
12. "Role prompting" means…
Answer: A. Giving the model a role focuses its tone, vocabulary, and priorities toward an expert lens, which usually sharpens the response.
13. You include two solved examples in your prompt before asking the model to classify a new support ticket. This technique is called…
Answer: D. Showing a handful of input→output examples is few-shot prompting; it demonstrates the pattern and format you want. (Zero examples is zero-shot.)
14. Adding "Let's work through this step by step" to a hard reasoning prompt is an example of…
Answer: A. Encouraging the model to lay out intermediate steps (chain-of-thought) tends to improve accuracy on multi-step math and logic.
15. "Giving the model an out" (telling it that "I don't know" or "not enough information" is an acceptable answer) primarily helps to…
Answer: B. Without an out, models tend to invent a plausible-sounding answer. Explicitly allowing "I don't know" reduces fabrication on questions it can't actually answer.
16. You need the model's reply to be machine-readable so your script can parse it. The best prompting move is to…
Answer: C. Asking for a precise structured format (JSON, a table, fixed fields) makes outputs predictable and parseable — essential when feeding results into other software.
17. After the model drafts an answer, you prompt: "Now critique your draft, list any weaknesses, and produce an improved version." This technique is…
Answer: D. Self-critique (reflection) asks the model to review and revise its own output, often catching errors a single pass misses.
18. "Tree-of-thoughts" prompting differs from plain chain-of-thought because it…
Answer: A. Tree-of-thoughts branches into multiple possible lines of reasoning and evaluates among them — useful for problems with several plausible approaches.
From chatbots to agents & agentic workflows · Weeks 6–7
19. What most distinguishes an agent from a plain chatbot?
Answer: B. A chatbot responds turn-by-turn; an agent perceives, plans, acts via tools, observes results, and repeats in a loop with memory until the goal is met.
20. The ReAct pattern stands for…
Answer: C. ReAct interleaves thinking ("reason") with doing ("act"): the model reasons about what to do, takes a tool action, observes the result, and loops.
21. Which sequence best captures one cycle of the agent loop?
Answer: D. The agent loop is perceive → plan → act, observing each result and feeding it back into the next iteration until the task is done or a stop condition is hit.
22. In a multi-step agentic workflow, why is "human in the loop" emphasized?
Answer: A. Autonomy is powerful but error-prone; a human checkpoint before high-impact actions (sending, deleting, paying) balances speed against control and catches mistakes.
23. "Retrieval" (as in RAG) is used in agentic workflows mainly to…
Answer: B. Retrieval pulls in relevant chunks (from your docs, a database, or the web) and adds them to the prompt — grounding responses in facts the base model may not know or that change often.
24. Why does an agentic workflow need an evaluation step?
Answer: C. Evaluation (test cases, checks, scoring) turns "it seems better" into evidence, so you can iterate on prompts and pipelines without regressing.
Tools, limits & capstone · Weeks 8–10
25. You must summarize a 200-page internal report in one pass and keep all of it "in view." Which capability matters most when picking a tool?
Answer: D. Holding a long document in one prompt needs a large context window — a strength associated with assistants built for long-context work. Match the tool's capability to the task (search for live info, long context for big documents) rather than to a brand reflex.
