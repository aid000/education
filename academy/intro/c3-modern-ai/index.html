🛠️ Hands-On Project

Build Your Personal "AI Operating System"

Build a curated library of 20+ high-performance prompts organized by use case (research, planning, learning, debugging, writing). Create and test one multi-step agent workflow (research a topic → extract key sources → generate an outline → draft sections → self-critique). Quantify the time/effort savings and deliver the full system + a usage guide. All on free AI tiers + a Jupyter prompt log.

Wk 1: set up free AI accounts + a Jupyter prompt log Wk 4: 20+ prompt library by use case Wk 8: build + A/B-test one agent workflow Wk 10: full "AI OS" + usage guide + measured time savings

💬 Discussions

Three checkpoints — weeks 3, 6, 9

  • Week 3: What is one task you tried with an AI that failed, and one that surprised you? What does the difference tell you about where today's models are strong vs weak?
  • Week 6: What actually turns a "chatbot" into an "agent"? Sketch a 3-step task you would want an agent to do for you and mark where a human should stay in the loop.
  • Week 9: Share a real hallucination you caught (or nearly missed). What verification habit would have caught it earlier?
