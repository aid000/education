🛠️ Hands-On Project

Run a Real Goal as a 4-Week Scrum + Theory-of-Constraints Analysis

Choose a real personal or school goal (e.g. launch a study group, complete a research project). Run it as a 4-week Scrum on free Trello/Notion (or a Python pandas Kanban/Gantt), and apply the Theory of Constraints to find and relieve the bottleneck. Deliver a project charter, sprint retrospectives, and a reflection on which "great manager" principles you used on yourself or teammates — short recorded demo or written report.

Wk 1: set up Trello/Notion + pick a real goal Wk 4: project charter + sprint 1 retro Wk 8: ToC bottleneck analysis + further sprints Wk 10: final report + great-manager reflection

💬 Discussions

Three checkpoints — weeks 3, 6, 9

  • Week 3: Describe a real project (school, club, or job). Was it run more "predictive" or "agile"? Which single Scrum event would have helped most, and why?
  • Week 6: Find the bottleneck in a system you know (a study routine, a kitchen, a checkout line). Apply the five focusing steps — what would you exploit before spending any money?
  • Week 9: First, Break All the Rules argues people do not change that much, so build on strengths. Do you agree? Give an example where focusing on a strength beat fixing a weakness.

📝 Final Exam

Comprehensive · ~25 questions · no midterm Live

A self-graded, ~25-question multiple-choice final exam spanning all ten weeks — predictive vs Agile, the PMP process groups, Scrum, estimation, the Theory of Constraints, and the great-manager principles. Submit in-browser to score yourself and reveal explanations. Worth 30% of the grade.
