Week 2 · Lecture 2

Logic Gates & Combinational Circuits

Boolean logic in hardware — and the stateless building blocks that compute with it.

🎯 Learning Objectives

  • Explain why NAND and NOR are the natural CMOS gates, and why AND/OR cost extra.
  • Read and write truth tables for AND, OR, NOT, XOR, NAND, and NOR.
  • State what it means for NAND (or NOR) to be a universal gate.
  • Describe multiplexers, decoders, and encoders as gate-built combinational blocks.
  • Recognize combinational logic as stateless — output depends only on present inputs.

2.1Gates from Transistors

A logic gate turns one or more binary inputs into a binary output, following a fixed rule. In CMOS, every gate is built from complementary pairs: an n-MOS pull-down network that connects the output to ground (logic 0) and a p-MOS pull-up network that connects it to the supply (logic 1). The two networks are duals — exactly one conducts for any input, so the output is always cleanly driven.

That structure makes NAND and NOR the natural gates. A 2-input NAND, for example, is just two n-MOS in series pulling down (output goes low only when both inputs are high) plus two p-MOS in parallel pulling up:

2-input NAND = (2 n-MOS in series) + (2 p-MOS in parallel)Output is low only when A AND B are both high — otherwise a p-MOS pulls it high.

What you don't get for free is AND or OR. A single CMOS stage is always inverting, so a true AND is built as a NAND followed by an inverter — an extra two transistors. Designers therefore prefer NAND/NOR wherever possible.

AnalogyA logic gate is a decision rule wired into hardware: instead of a person checking "are both switches on?", the transistors themselves enforce it, instantly and forever. The series n-MOS in a NAND are like two switches in a row — current only gets through (pulls the output down) when both are closed.

2.2Boolean Algebra & Truth Tables

Each gate implements a Boolean function — a rule mapping input bits to an output bit. A truth table lists the output for every input combination. The core operators:

AND: 1 only if all inputs are 1 · OR: 1 if any input is 1NOT: flips the bit · XOR: 1 only if the inputs differ · NAND/NOR: AND/OR followed by NOT

The headline result of Boolean algebra for hardware is universality: any logic function can be built from NAND gates alone — or from NOR gates alone. Build NOT, AND, and OR out of NANDs and you can compose anything. That's why a single cheap gate type can implement a whole processor.

2.3Combinational Building Blocks

Wire gates together and you get reusable combinational blocks — bigger functions with names:

A multiplexer (mux) selects one of several data inputs and routes it to the output, chosen by select lines. A 2:1 mux has two data inputs and one select bit; an n-bit select picks among 2n inputs.

A decoder does the reverse fan-out: it takes an n-bit code and activates exactly one of 2n output lines (used for address decoding — picking a memory word). An encoder is its inverse, collapsing one active input line down to a compact binary code. All three are pure gate networks — no clock, no memory.

AnalogyA multiplexer is a railroad switch: several incoming tracks (the data inputs) converge, and the select line throws the switch to decide which single track's train reaches the output line. Flip the select and a different input flows through — but nothing is ever stored at the junction.

2.4Combinational = No Memory

Everything in this lecture is combinational: the output is a pure function of the present inputs. There is no stored state, no clock, and no dependence on what happened before. Change an input and the output follows (after a tiny propagation delay) — then forgets all about it.

output = f(current inputs)  ·  no history, no memory

The headline combinational circuit you'll meet is the adder in Week 4: feed it two numbers and it produces their sum directly from the input bits, with nothing remembered between operations. The moment a circuit needs to remember — a counter, a register, a state machine — you've crossed into sequential logic, the subject of the next lecture.

Common mistakeKeep three things straight. (1) NAND and NOR are the cheap, natural CMOS gates — AND and OR need an extra inverter on top. (2) "Universal" means all logic can be built from NAND alone (or NOR alone), not just some of it. (3) Combinational logic is stateless — its output follows the inputs immediately, with no memory of the past.
✦ Worked Example

Show that NAND is universal by building NOT from it, and confirm the NAND truth table.

  1. NAND truth table: the output is 0 only when both inputs are 1 — otherwise 1: 00→1, 01→1, 10→1, 11→0.
  2. Tie the inputs together: feed the same signal A into both NAND inputs. Now only the rows where both inputs match matter: A = 0 uses row 00 → output 1; A = 1 uses row 11 → output 0.
  3. That's a NOT: A NAND A = NOT A. Input 0 gives 1, input 1 gives 0 — exactly the inverter.
  4. And AND comes for free: since NAND = NOT(A AND B), feeding a NAND's output through this inverter gives AND = (A NAND B) NAND (A NAND B). With NOT, AND, and OR all reachable, NAND alone builds any function.

🛠️ Hands-On: describe gates & a 2:1 mux in Verilog

Verilog lets you describe logic structurally with assign statements. Put this in gates.v, then simulate with Icarus (iverilog) and view the waveform in GTKWave.

// Logic gates & a 2:1 mux — Lecture 2
module gates(input a, input b, input sel,
             output y_and, output y_or, output y_xor,
             output y_nand, output y);
  assign y_and  = a & b;        // AND
  assign y_or   = a | b;        // OR
  assign y_xor  = a ^ b;        // XOR
  assign y_nand = ~(a & b);     // NAND (universal)
  assign y      = sel ? b : a;  // 2:1 mux: sel=0→a, sel=1→b
endmodule

Compile and run: iverilog -o gates.vvp gates.v tb.v then vvp gates.vvp. Write a small testbench (tb.v) that sweeps a, b, sel and dumps a VCD ($dumpfile/$dumpvars), then open it with gtkwave dump.vcd. Confirm y follows a when sel=0 and b when sel=1.

❓ Lecture 2 Quiz

5 questions · click "Show answer" to check yourself.

Q1. Which gates are "universal" — any logic function can be built from them alone?
A. NAND (and NOR)
B. AND and OR
C. XOR only
D. NOT only
Show answer

A. NAND alone (or NOR alone) can build NOT, AND, OR, and therefore any Boolean function. That's what "universal" means.

Q2. A multiplexer…
A. stores a bit
B. selects one of several inputs to pass to the output, based on select lines
C. adds two numbers
D. inverts a signal
Show answer

B. A mux routes one chosen data input to the output; the select lines pick which one. It's pure combinational steering — no storage.

Q3. In CMOS, the most natural and efficient basic gates are…
A. XOR and XNOR
B. AND and OR
C. NAND and NOR
D. buffers
Show answer

C. A single CMOS stage is inverting, so NAND and NOR fall out directly. AND and OR need an extra inverter on top, costing more transistors.

Q4. A combinational circuit's output depends on…
A. the previous output
B. the inputs and stored state
C. the clock edge
D. only the current inputs (it has no memory)
Show answer

D. Combinational logic is stateless — the output is a function of the present inputs alone. Dependence on stored state or a clock is sequential logic.

Q5. You can build a NOT gate from a NAND by…
A. tying its two inputs together
B. grounding one input
C. adding a capacitor
D. using two NANDs in series
Show answer

A. A NAND A = NOT A: with both inputs the same, input 0 gives 1 and input 1 gives 0 — exactly an inverter.

✓ What you learned

  • NAND and NOR are the natural CMOS gates (e.g. NAND = series n-MOS pull-down + parallel p-MOS pull-up); AND/OR cost an extra inverter.
  • Truth tables for AND, OR, NOT, XOR, NAND, NOR, and that NAND (or NOR) is universal — any logic from it alone.
  • Combinational blocks: multiplexers (select one input), decoders, and encoders, all built from gates.
  • Combinational logic is stateless — output = f(current inputs), with no memory (the Week 4 adder is the headline example).
