CMOS Transistor Review

From a single MOSFET switch to the CMOS inverter — the digital building block.

🎯 Learning Objectives

  • Recall how an n-MOS and a p-MOS each behave as a near-ideal on/off switch.
  • Build the CMOS inverter from a p-MOS pull-up and an n-MOS pull-down sharing one input.
  • Explain why CMOS burns almost zero static power in either steady state.
  • Distinguish dynamic (switching) power from static leakage, and name the role of delay and noise margins.
  • Model an inverter in Verilog and view the waveform with the course toolchain.

1.1The MOSFET as a Switch

From C1 you already know the transistor as an amplifier and a switch. In digital design we lean entirely on the switch picture: a MOSFET is either fully ON (a closed switch, near-zero resistance) or fully OFF (an open switch, essentially no current). The gate voltage decides which.

An n-MOS conducts when its gate is driven high — specifically when the gate-to-source voltage exceeds the threshold:

n-MOS ON ⟺ VGS > Vth  (gate high)Below threshold the channel is cut off and the device is an open switch.

A p-MOS is the complement: it conducts when its gate is driven low. Pair them up and any input level turns exactly one type on and the other off — the idea the whole rest of this lecture is built on.

AnalogyA CMOS inverter is a see-saw of two switches: exactly one switch connects the output to power, the other connects it to ground, and they are never both closed at the same time. Because there is never a closed path straight from power to ground, no current is wasted flowing through.

1.2The CMOS Inverter

The CMOS inverter stacks the two complementary switches between the supply rails. A p-MOS pull-up connects the supply VDD to the output node; an n-MOS pull-down connects the output node to ground. Both gates are tied together — that shared node is the input.

input LOW → p-MOS ON → output pulled HIGH  ·  input HIGH → n-MOS ON → output pulled LOW

So a 0 in becomes a 1 out, and a 1 in becomes a 0 out. It inverts — the simplest logic gate, and the seed from which every other gate grows.

Notice the symmetry: the input controls both devices at once, and the output sits at the node between them. Whichever transistor is on "wins" and ties the output to its rail.

1.3Why CMOS Wins

Here is the magic that made CMOS the dominant logic family. In either steady state — input firmly low or firmly high — exactly one of the two transistors is off:

input LOW → n-MOS OFF  ·  input HIGH → p-MOS OFF

Because one device is always cut off, there is no conducting path from VDD to ground while the output is settled. No path means no current; no current means almost zero static (standby) power.

Pstatic ≈ 0  (only tiny leakage flows)Older logic families (e.g. NMOS, TTL) burned power continuously through a pull-up; CMOS does not.

That near-free standby is exactly why CMOS dominates: billions of gates can sit idle on a chip without draining the battery.

1.4Dynamic Power, Delay & Noise Margins

CMOS is not entirely free, though. The power it does burn is dynamic power — the energy spent charging and discharging the load capacitance every time an output switches:

Pdynamic ≈ CL · VDD² · fMore switching activity (higher frequency f) ⟹ more dynamic power.

Two more practical metrics shape every design:

Propagation delay

It takes a finite time for the on-transistor to charge or drain the output through the load capacitance. That propagation delay sets how fast the gate — and ultimately the whole chip — can run.

Noise margins

Real signals are noisy. Noise margins are the voltage cushions that keep a "0" reliably read as 0 and a "1" reliably read as 1, even when a signal is nudged by noise. Healthy margins keep your logic levels distinct and the chip robust.

Common mistakeKeep the two devices straight: the n-MOS pulls DOWN (toward 0) and the p-MOS pulls UP (toward 1) — they are complementary. In steady state one is always off, so the static current is ≈ 0. Don't picture both transistors conducting at once; that only happens briefly during a switch, not in a settled state.
✦ Worked Example — inverter logic + power

Trace both input states of a CMOS inverter and account for the power in each.

  1. Vin = 0 (low): the p-MOS turns ON, the n-MOS turns OFF → the output is connected to VDD → Vout = VDD (logic 1).
  2. Vin = 1 (high): the n-MOS turns ON, the p-MOS turns OFF → the output is connected to ground → Vout = 0 (logic 0).
  3. Static power: in both cases one device is off, so the VDD-to-ground path is broken → no steady current → static power ≈ 0.
  4. Where the energy goes: power is spent only during the switch, charging/discharging the load capacitance — i.e. dynamic power, not static.

🛠️ Hands-On: model an inverter in Verilog

The course toolchain is Icarus Verilog for simulation and GTKWave for viewing waveforms. (Installing both is the Week-1 project setup.) Model the inverter, drive it with a tiny testbench, and watch y flip.

// inv.v — a CMOS inverter, behaviorally
module inv(input a, output y);
    assign y = ~a;        // y is the logical inverse of a
endmodule

// tb.v — tiny testbench
module tb;
    reg a; wire y;
    inv dut(.a(a), .y(y));
    initial begin
        $dumpfile("inv.vcd"); $dumpvars(0, tb);
        a = 0; #10 a = 1; #10 a = 0; #10 $finish;
    end
endmodule

Compile and run, then open the waveform:

iverilog -o inv.out inv.v tb.v
vvp inv.out
gtkwave inv.vcd

Expected: y is the mirror image of a — high when a is low, low when a is high. That inversion is the CMOS inverter in software form.

❓ Lecture 1 Quiz

5 questions · click "Show answer" to check yourself.

Q1. In a CMOS inverter, when the input is HIGH, the output is…
A. HIGH
B. LOW
C. floating
D. V_DD/2
Show answer

B. LOW. A high input turns the n-MOS on, which pulls the output down to ground.

Q2. CMOS draws almost no static power because…
A. it uses tiny transistors
B. it has no capacitance
C. in steady state one of the two transistors is always off, so there's no V_DD-to-ground path
D. the clock is off
Show answer

C. In either settled state exactly one device is off, breaking the path from V_DD to ground — so no steady current flows.

Q3. An n-MOS transistor turns on when…
A. V_GS exceeds the threshold V_th (gate high)
B. the gate is low
C. the drain is grounded
D. never
Show answer

A. An n-MOS conducts once V_GS > V_th — i.e. when its gate is driven high. (The p-MOS is the complement: it turns on when its gate is low.)

Q4. In the inverter, the p-MOS acts as the…
A. pull-down
B. load resistor
C. clock
D. pull-up (connects the output to V_DD when the input is low)
Show answer

D. The p-MOS is the pull-up: when the input is low it turns on and ties the output to V_DD. The n-MOS is the complementary pull-down.

Q5. The main power a CMOS gate consumes is…
A. static leakage only
B. dynamic (switching) power charging/discharging capacitance
C. none
D. thermal only
Show answer

B. Static power is ≈ 0; the real consumption is dynamic — energy spent charging and discharging the load capacitance each time the output switches.

✓ What you learned

  • A MOSFET is a switch: an n-MOS conducts when V_GS > V_th (gate high), and a p-MOS is complementary (conducts when its gate is low).
  • The CMOS inverter = p-MOS pull-up to V_DD + n-MOS pull-down to ground, gates tied as the input — low in → high out, high in → low out.
  • CMOS wins because in either steady state one transistor is off, so there's no V_DD-to-ground path → static power ≈ 0.
  • The power CMOS burns is dynamic (switching) power; propagation delay sets speed and noise margins keep 0s and 1s distinct.
