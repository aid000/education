Sequential Logic

Adding memory and a clock — the leap from computing to remembering.

🎯 Learning Objectives

  • Explain how sequential logic differs from combinational logic — output depends on inputs and stored state.
  • Describe the SR latch, the level-sensitive D latch, and the edge-triggered D flip-flop.
  • Build an N-bit register from N flip-flops sharing a clock.
  • Understand edge-triggered clocking and the basics of setup/hold timing.
  • Trace a D flip-flop's output as its input changes between clock edges.

3.1Adding Memory

So far every circuit has been combinational: the output is a pure function of the inputs right now. Change the inputs and the output changes immediately; the moment the inputs go away, the circuit forgets. That's enough to compute, but it isn't enough to remember.

Sequential logic breaks that limitation. Its output depends on the current inputs and on stored internal state — a memory of what happened before. And rather than reacting instantly, a sequential circuit advances its state on the tick of a clock, a periodic signal that says "now is the moment to update." This combination of stored state plus a clock is what lets circuits count, sequence steps, and hold values over time.

3.2Latches & Flip-Flops

The smallest unit of memory is built by feeding a gate's output back to its input. The classic SR latch (Set/Reset) does exactly this: two cross-coupled NOR (or NAND) gates that hold one bit — Set drives the output to 1, Reset to 0, and with neither asserted the latch holds its last value. That feedback loop is memory.

A D latch tames the SR latch by adding a data input D and an enable: while enable is high the latch is transparent (Q follows D), and when enable goes low it freezes the last value. Because it copies D the whole time enable is high, the D latch is level-sensitive.

The edge-triggered D flip-flop is the workhorse of digital design. It captures D only at the instant the clock transitions — usually the rising edge — and holds that value steady until the next edge. This single, well-defined capture moment makes it the basic 1-bit memory cell of every CPU.

3.3Registers

One flip-flop stores one bit — useful, but a CPU works on whole words. Wire N flip-flops side by side, all driven by the same clock, and you get an N-bit register: on each clock edge, all N bits load together, storing one N-bit value. An 8-bit register holds a byte; a 32- or 64-bit register holds a machine word.

Registers are the CPU's fast working storage — the handful of named slots (like a general-purpose register file) that the processor reads operands from and writes results back to, far faster than reaching out to memory. Almost every instruction shuffles data through registers.

3.4Clocking Basics

Edge-triggered storage gives a digital system a heartbeat: state changes only at clock edges, so the entire machine advances in lockstep, one well-defined step per tick. Between edges, combinational logic settles and the flip-flop outputs hold steady.

For a flip-flop to reliably capture the right value, its data input must be stable around the clock edge. The data has to be steady for a short window before the edge (the setup time) and remain steady for a short window after it (the hold time). Violate setup or hold and the flip-flop can go metastable — hovering between 0 and 1 — which is why the clock can only run as fast as the slowest logic path allows the data to settle.

AnalogyA flip-flop is like a light switch that remembers its position until the next clock "tick" tells it to update. Combinational logic forgets the instant its inputs change — it has no memory of a moment ago. Sequential logic holds its value between ticks, so it can carry information forward through time.
Common mistakeA latch is level-sensitive — transparent (Q tracks D) the whole time its enable is high — whereas a flip-flop is edge-triggered, capturing only on the clock edge. A register isn't a new device; it's just a group of flip-flops sharing one clock. And remember: sequential logic needs a clock to sequence its state, while combinational logic does not.
✦ Worked Example

Trace a single D flip-flop. Just before four successive rising clock edges, the input D presents the values 1, 0, 1, 1. What does Q do?

  1. Before edge 1, D = 1: at the rising edge the flip-flop captures D, so Q → 1 and holds.
  2. Before edge 2, D = 0: at the edge Q → 0, even if D wiggled earlier in the cycle — only the value at the edge matters.
  3. Before edge 3, D = 1: at the edge Q → 1.
  4. Before edge 4, D = 1: at the edge Q stays 1.
  5. Result: Q follows the sequence 1, 0, 1, 1 — but Q changes only at the edges, holding its value steady in between.

🛠️ Hands-On: a D flip-flop in Verilog

Describe an edge-triggered D flip-flop in Verilog, simulate it with the open-source Icarus toolchain, and watch Q track CLK in GTKWave.

// dff.v — edge-triggered D flip-flop (Lecture 3)
module dff(input clk, input d, output reg q);
    always @(posedge clk)   // capture on the rising edge
        q <= d;
endmodule

// (or a small counter to see state advance each tick)
// always @(posedge clk) count <= count + 1;

Compile and run with iverilog -o dff.vvp dff_tb.v dff.v, then vvp dff.vvp to dump a .vcd, and open it in gtkwave dump.vcd. Add CLK, D, and Q to the wave window: you'll see Q step to D's value on each rising clock edge and hold in between.

C. A flip-flop is edge-triggered: it samples D only at the clock transition (e.g. the rising edge) and holds that value until the next edge.

B. N latches with no clock

A. N flip-flops driven by a common clock load all N bits together on each edge, storing one N-bit word.

A. edge-triggered
B. level-sensitive (transparent while enabled)
C. always opaque
D. clockless and edge-triggered

B. A latch is level-sensitive — transparent (Q follows D) the whole time its enable is high — while a flip-flop captures only at the clock edge.

B. two power supplies

C. Sequential logic advances its stored state on a clock; without a clock there's no defined moment to update. Combinational logic needs no clock.

Model response

Combinational logic has no memory, so it can't remember past inputs, count, or sequence actions over time — its output is purely a function of this instant's inputs. Sequential logic adds stored state and a clock, which unlocks memory (registers), counting, and finite-state machines that step through a sequence of behaviors.

A CPU is fundamentally sequential: it needs registers to hold operands and results, a program counter to remember which instruction is next, and state to march through fetch → decode → execute one step per clock. None of that — holding values, knowing "where you are," doing things in order — is possible without memory and a clock.
