CMOS & logic gates · Weeks 1–2
1. In a CMOS inverter, when the input is HIGH the output is…
Answer: B. A HIGH input turns the n-MOS on and the p-MOS off, connecting the output to ground — so the output goes LOW. The inverter negates its input.
2. CMOS draws almost no static power because…
Answer: C. In a static CMOS gate the pull-up and pull-down networks are complementary, so in either steady state one network is off — there is no DC path from VDD to ground, so static current is near zero.
3. Which gates are universal (any logic function can be built from them alone)?
Answer: A. NAND and NOR are each functionally complete — any Boolean function can be realized using only NAND gates (or only NOR gates).
4. A multiplexer…
Answer: D. A mux uses select lines to route one chosen data input through to its single output — a fundamental steering element in a datapath.
5. In CMOS the most natural, efficient basic gates are…
Answer: B. CMOS naturally produces inverting gates; NAND and NOR are the simplest and most efficient. AND/OR cost more because they are a NAND/NOR followed by an inverter.
Sequential logic & the ALU · Weeks 3–4
6. Sequential logic's output depends on…
Answer: A. Unlike combinational logic, a sequential circuit has memory — its output is a function of both the present inputs and the stored internal state.
7. A D flip-flop captures its input…
Answer: C. A D flip-flop is edge-triggered: it samples D and updates Q only at the active clock edge, holding the value steady between edges.
8. An N-bit register is built from…
Answer: B. A register is just N flip-flops sharing a common clock, so all bits load on the same edge — storing one N-bit word.
9. In two's complement, A − B is computed as…
Answer: D. Negating B in two's complement means inverting its bits and adding 1, so A − B = A + (NOT B) + 1 — letting one adder do both add and subtract.
10. An ALU is what kind of circuit?
Answer: A. The ALU is purely combinational: given operands and an operation-select code it produces a result with no stored state of its own.
Datapath & control · Weeks 5–6
11. The datapath consists of…
Answer: C. The datapath is where data moves and is operated on — the ALU, register file, buses/muxes, and program counter. The control unit steers it but is separate.
12. The register file…
Answer: B. The register file is a small, fast bank of registers right next to the ALU; instructions read their operands from it and write results back each cycle.
13. The program counter (PC)…
Answer: D. The PC is a register holding the memory address of the instruction being fetched; it advances each cycle (or is loaded by a branch).
14. The control unit…
Answer: A. The control unit interprets the opcode and produces the control signals (mux selects, ALU op, write-enables) that direct the datapath each cycle.
15. Hardwired control is…
Answer: C. Hardwired control implements the logic directly in fixed gates — fast, but changing the design means redesigning the circuitry. Microcoded control trades speed for flexibility.
ISA, cycle & pipelining · Weeks 7–8
16. The ISA defines…
Answer: B. The Instruction Set Architecture is the hardware/software contract: the set of instructions, the registers, and the instruction formats software can rely on, independent of how it's built.
17. In the FETCH step…
Answer: D. Fetch reads the instruction from memory at the address held in the PC; later steps (decode, execute, memory, write-back) act on it.
18. Pipelining improves…
Answer: A. Pipelining overlaps stages so a new instruction can finish each cycle — raising throughput. A single instruction still takes the same (or slightly more) total time.
19. The classic 5 pipeline stages are…
Answer: C. The classic RISC pipeline is Instruction Fetch, Instruction Decode, Execute, Memory access, and Write-Back.
20. A data hazard occurs when…
Answer: B. A data hazard is a dependency: a later instruction needs an operand that an earlier, still-in-flight instruction hasn't written back yet. Forwarding or stalls resolve it.
Memory & clocking · Weeks 9–10
21. Compared with DRAM, SRAM (used for cache) is…
Answer: D. SRAM's 6-transistor cell is fast and needs no refresh, but it's bigger and pricier per bit — so it's used for small, fast caches, while dense cheap DRAM is main memory.
22. DRAM requires…
Answer: A. Each DRAM cell stores a bit as charge on a tiny capacitor (one transistor, one capacitor). The charge leaks away, so the array must be periodically refreshed.
23. With a hit time of 1 ns, a miss rate of 5%, and a miss penalty of 100 ns, the AMAT is…
Answer: C. AMAT = hit time + miss rate × miss penalty = 1 + 0.05 × 100 = 1 + 5 = 6 ns.
24. The clock period must be at least…
Answer: B. Signals must propagate through the longest (critical) combinational path and meet the flip-flop's setup time before the next edge, so the period is bounded by that delay.
25. The "power wall" refers to…
Answer: D. Power (and heat) density rises sharply with clock frequency, so chips could no longer just clock faster — the industry turned to multiple cores instead.
