ECO Flows

Making a late, surgical change to a nearly-finished chip without redoing everything.

🎯 Learning Objectives

  • Define an Engineering Change Order (ECO) and explain why it isn't a full re-run of the flow.
  • Distinguish a functional ECO (a logic fix) from a timing/DRV ECO (closing timing).
  • Explain how a metal-only ECO rewires pre-placed spare cells to re-spin only the top masks.
  • Apply ECO discipline: keep changes minimal and incremental on the affected region.
  • Reason about why a metal-only ECO is dramatically cheaper and faster than a full re-spin.

9.1What an ECO Is

An Engineering Change Order (ECO) is a late, targeted change to a near-final design — made to fix a bug or to close a timing or power violation — without re-running the entire flow from scratch. By the time you're considering an ECO, synthesis, placement, routing, and most of signoff are already done; tearing all of that down to fix one problem would be slow, risky, and expensive.

Instead, an ECO surgically modifies just what needs to change. The goal is to reach a fixed, signed-off design with the least possible disturbance to everything that already works.

9.2Functional vs Timing ECOs

ECOs come in two flavors depending on what you're fixing:

A functional ECO fixes the logic — a late design bug found in verification or silicon. It changes what the circuit computes (adding a gate, retargeting a connection, gating a path).

A timing / DRV ECO doesn't change the logic at all; it closes timing or fixes design-rule violations. Typical moves: insert buffers, resize cells (upsize for setup, add delay for hold), or fix hold violations by padding short paths.

AnalogyAn ECO is renovating one room of a finished house without rebuilding it. A functional ECO changes what the room is for (turn a closet into a bathroom — new plumbing logic); a timing ECO just adjusts the fittings so everything lines up (swap a fixture, add a spacer) without changing the room's purpose.

9.3Metal-Only ECOs

The cheapest kind of ECO changes only the metal and via layers. The trick: the layout was built with spare cells — unused gates deliberately scattered throughout the die during placement. A metal-only ECO rewires those pre-placed spare cells with new metal to implement the fix.

Because the transistor / base layers (implant, poly, contact) are untouched, you re-spin only a few top masks. The expensive base mask set is reused as-is. That means cheaper masks and a much faster turnaround than remaking the whole set.

9.4ECO Discipline

The governing rule for any ECO is: keep the change minimal and incremental. Run incremental place / route / STA only on the affected region, so you don't perturb timing that was already closed elsewhere on the die.

A sloppy, global re-run can introduce brand-new violations far from your fix — turning a one-line correction into days of re-closure. Surgical ECOs preserve the enormous engineering investment already locked into the rest of the chip.

Common mistakeA metal-only ECO reuses spare/filler cells and changes only the upper (metal/via) masks — so it is far cheaper than a full re-spin, which remakes all masks. Don't re-run the whole flow for a small fix: ECOs must be minimal and incremental so you don't disturb timing that was already closed. And don't conflate the two kinds — a functional ECO fixes logic, while a timing ECO buffers/resizes to close slack.
✦ Worked Example

Why is a metal-only ECO so cheap compared with a full re-spin?

  1. A full mask set is large: dozens of masks — base/implant/poly/contact layers plus many metal and via layers. Making a whole new set is a major cost.
  2. A full re-spin pays for all of it: remake every mask and re-run synthesis → placement → routing → signoff, with the risk of new violations across the die.
  3. A metal-only ECO remakes only the top layers: just the few metal/via masks change; the base/transistor masks are reused unchanged.
  4. The fix reuses existing silicon: spare cells are already placed, so you only rewire them — a quick incremental route on the affected region, not a full flow.
  5. Net result: you pay for a handful of masks and a short incremental run instead of an entire new mask set and full re-run — a small fraction of the cost and time.

🛠️ Hands-On: walk a spare-cell metal-only ECO

Conceptually walk the steps a tool would take to apply a metal-only fix, using a finished layout that contains scattered spare cells.

* Metal-only ECO — conceptual flow (Lecture 9)
1. Identify the fix          ; e.g. add an inverter on net N to fix logic/slack
2. Find nearby spare cells   ; locate unused spares close to the affected net
3. Map fix onto spares       ; assign the needed gate(s) to available spare cells
4. Rewire with new metal     ; route metal/via only — base layers untouched
5. Incremental STA on region ; re-check timing locally, confirm nothing else moved
6. Re-spin top masks only    ; remake the few metal/via masks; reuse the base set

Notice that only steps 4–6 touch masks, and only the top metal/via layers — everything below is reused. Verify your fix by running incremental STA on just the affected region and confirming no new violations appear elsewhere.

Model response

A full re-spin re-runs synthesis, placement, and routing and remakes the entire mask set — which is expensive (a mask set costs a lot) and slow, and it perturbs timing that was already closed, potentially creating new violations. A metal-only ECO instead changes only the metal/via masks: it rewires spare cells that were deliberately scattered through the layout to implement the fix, leaving the base/transistor layers and most of the routing untouched. So only a few top masks are remade and only the affected region is re-routed and re-checked — a small fraction of the cost and time, with minimal disturbance.

The trade-offs: you're limited to what the available spare cells and free routing can implement, the spare cells may not be where you need them, carrying spares costs a little area, and any large functional change still forces a full re-spin.
