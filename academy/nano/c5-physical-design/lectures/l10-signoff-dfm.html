Signoff & DFM

The final inspection before tape-out — proving the layout is correct, manufacturable, and high-yield.

  • Describe the reliability checks: antenna diodes, electromigration/IR signoff, and latch-up rules.

10.1Physical Signoff

Once the layout is complete, physical signoff is the last gate before tape-out — three checks run on the final database, with no further hand-edits expected:

DRC  ·  LVS  ·  PEXgeometry rules  ·  layout matches netlist  ·  extract real parasitics

DRC (design rule check) verifies the geometry obeys the foundry's rules — minimum widths, spacings, enclosures. LVS (layout-versus-schematic) confirms the drawn polygons connect into exactly the netlist you intended — no shorts, opens, or stray devices. PEX (parasitic extraction) pulls the real resistance and capacitance out of the finished interconnect so that final timing is signed off on actual silicon parasitics, not estimates.

PEX is the bridge from "the layout looks right" to "the layout will run at speed": the extracted RC feeds the last static-timing run that closes the design.

10.2DFM — Design for Manufacturability

Passing DRC means the layout is legal. DFM (design for manufacturability) goes beyond pass/fail rules to proactively raise yield — the fraction of fabricated dies that actually work. A layout can be 100% DRC-clean and still yield poorly; DFM closes that gap.

Common DFM moves

Tools (or the engineer) apply optimizations wherever there is room:

via doubling  ·  wire spreading  ·  metal fill  ·  OPC awareness

Via doubling adds a redundant via in parallel so a single via defect doesn't open the net. Wire spreading nudges nets apart where space allows, reducing bridging defects and coupling. Metal fill drops in dummy metal to keep density uniform for planar CMP. OPC awareness (optical proximity correction) means drawing shapes the lithography can actually print at scale. None of these are required by DRC — they are insurance for yield.

10.3Reliability Checks

Beyond "works on day one," signoff also proves the chip keeps working. Three reliability checks matter:

Antenna effect

During fabrication, long metal traces connected to a thin gate can collect charge and damage the gate oxide. The fix is an antenna diode that bleeds the charge to substrate, or breaking the net up a metal layer.

Electromigration & IR drop

Electromigration (EM) signoff checks that no wire carries enough current density to slowly erode itself over years. IR drop signoff confirms the power grid delivers voltage without sagging too far under load. EM/IR are signed off together on the final layout.

Latch-up

Latch-up rules enforce well/substrate tap spacing and guard rings so the parasitic CMOS thyristor never triggers into a destructive short.

✦ Worked Example

Via doubling for yield. Suppose a single via has a probability p = 0.1% of being defective (open). What happens to the open-connection probability when DFM replaces it with a redundant double via?

  1. Single via: the connection opens if that one via fails — probability p = 0.001 (0.1%).
  2. Double (redundant) via: the connection opens only if both vias fail. Assuming independent defects, that's p² = (0.001)² = 0.000001 (0.0001%).
  3. Gain: the open probability drops by a factor of ~1/p = 1000× — roughly the square of a single via's failure rate, at negligible extra area.
  4. Why DFM does it everywhere: that's an enormous yield/reliability win for almost no cost, so tools double vias wherever there's room.
