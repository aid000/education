Flow & layout · Weeks 1–2
1. The VLSI design flow proceeds as…
Answer: B. The standard flow runs RTL → synthesis → place & route → signoff → GDSII, descending from abstract intent to physical geometry.
2. "Tape-out" means…
Answer: C. Tape-out is the moment the verified GDSII layout is released to the foundry to be manufactured.
3. A layout is…
Answer: A. A layout is the set of physical polygons drawn on each fab layer (diffusion, poly, metals, etc.) — what actually gets manufactured.
4. Design rules (DRC) specify…
Answer: D. Design rules are the fab's geometric constraints — minimum widths, spacings, enclosures — that keep a layout manufacturable.
HDL & combinational logic · Weeks 3–4
5. Verilog fundamentally describes…
Answer: B. Verilog is a hardware description language: it specifies concurrent hardware, not sequential software instructions.
6. always @(posedge clk) q <= d; infers…
Answer: A. A clocked posedge block with a registered output synthesizes an edge-triggered flip-flop.
7. In a combinational always @(*) block, not assigning an output in every branch…
Answer: C. If an output isn't driven on every path, it must "remember" its old value, so the tool infers an unintended latch.
8. assign sum = a + b; synthesizes…
Answer: B. A continuous assignment of a + b maps to combinational adder logic.
9. In clocked sequential blocks you should use…
Answer: D. Nonblocking <= in clocked blocks models registers correctly and avoids simulation race conditions.
10. Synthesis maps RTL onto…
Answer: A. Synthesis translates RTL into a gate-level netlist built from cells in the standard-cell library.
Synthesis & timing · Weeks 5–7
11. Large on-chip memory is best built from…
Answer: C. Compiled SRAM macros are far denser and lower-power than equivalent flip-flop arrays for large memories.
12. The same RTL can produce different netlists depending on…
Answer: B. Synthesis is constraint-driven — different timing, area, or power targets steer the tool toward different gate choices.
13. The standard-cell library (.lib) provides…
Answer: D. The .lib characterizes every cell — delay, area, and power — so the tools can optimize and analyze the netlist.
14. Static timing analysis…
Answer: A. STA analytically checks every timing path against constraints with no stimulus needed — exhaustive and vectorless.
15. A setup violation means the path is…
Answer: C. A setup violation means data arrives too late — after the capturing clock edge's setup deadline — so the path is too slow.
16. Slack is defined as…
Answer: B. Slack = required − arrival; positive slack means the signal arrives in time, negative means a violation.
Physical design & routing · Weeks 8–9
17. Floorplanning sets…
Answer: D. Floorplanning fixes the die outline, I/O and macro locations, and the power distribution grid before detailed placement.
18. Clock tree synthesis (CTS)…
Answer: A. CTS builds a balanced buffer tree that delivers the clock to every flip-flop with minimal skew.
19. Placement positions standard cells to…
Answer: C. Placement legally positions cells to shorten wires, ease congestion, and help close timing.
20. Routing proceeds as…
Answer: B. Global routing plans coarse paths/regions first; detailed routing then assigns exact tracks and vias.
21. Routing congestion happens when…
Answer: D. Congestion arises where the demand for routing tracks in a region exceeds the supply available.
Signoff · Week 10
22. DRC (design-rule check) verifies…
Answer: A. DRC confirms the drawn geometry satisfies the foundry's width, spacing, and enclosure rules.
23. LVS (layout-versus-schematic) verifies…
Answer: C. LVS extracts the layout's connectivity and confirms it matches the intended schematic/netlist.
24. Signoff timing analysis is performed…
Answer: B. Signoff STA checks timing across PVT corners so the design works over the full range of process, voltage, and temperature.
25. "Tape-out" is…
Answer: D. Tape-out is the final step: the fully verified GDSII is handed off to the foundry for fabrication.
